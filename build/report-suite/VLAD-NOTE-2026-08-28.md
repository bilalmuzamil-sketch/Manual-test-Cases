## The one detail we need you to check — C30277

The words on C30277 did not change, but **the way its Expected Results is stored changed.**

It used to be stored as plain text with ordinary line breaks. Saving it put the text inside a
paragraph tag, and inside that tag those line breaks stopped working, so for a couple of minutes the
case page showed all five expectations run together in one block. We spotted it straight away,
stopped, and put it right by re-storing the same words with proper line-break tags.

* **On screen it now looks exactly as it did before** — same five numbered lines, same wording. We
  compared the page before and after, line by line.
* **If your automation reads the raw field through the TestRail API,** what it gets back is different
  in shape: it is now `<p>line one<br>line two…</p>` instead of `line one` newline `line two`. A
  check that splits that text on newlines would now see one long line.

**If your checks work from the steps, or from what the page displays, nothing changes for you.**
