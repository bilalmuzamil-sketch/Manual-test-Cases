## Notes on each observed case

### C30162 — CSV formats: Margin % plain; dates mm-dd-yyyy; currency plain; no color
**DEVIATION.** SBC spec v15 S14-R9/R10/R11 require a plain Margin % with no percent sign, dates as mm-dd-yyyy, and currency as plain numbers with no dollar sign or thousands separators. The live Summary CSV emits "100.0%", "Jul 31 2026" and "$1,979.40" - all three violated. NOT covered by SV-8823, which names only Inventory Value.

### C30191 — Sorting is applied on the server and re-fetches the first page
**PASS.** Server-side sort driven live on range=last_quarter (113 rows): sortBy=subtotal ascending returned the five lowest, descending returned 15720519/7703636/7455238/7266590/7174661, and page 2 continued at 6146807 - the whole set is re-ordered and re-paginated server-side. sortBy=zzz_not_a_column returned HTTP 200 with default order, safely ignored.

### C30287 — CSV cells: plain numbers, signed Inv. Hrs, empty Margin %, (Inactive)
**DEVIATION.** SBR spec v17 S14-R17 requires plain numbers with no currency symbol or thousands separators and Margin % as a bare number. The live Expanded CSV emits "$1,979.40", "100.0%" and "Jul 31 2026". NOT covered by SV-8823.

### C30442 — The Location filter is the rightmost multi-select; All Locations = select-all
**PARTIAL.** The TU Location filter IS built - a Location multi-select with a Clear Location action (data-test-id clear_report_location_filter), label "Location All locations", and with both locations selected a Location column appears second, after Technician. The "All locations acts as select-all / not offered to a single-location user" items were not driven.

### C30500 — Asset filter shows Unit # and VIN and matches text against either one
**PARTIAL.** The shared-unit-number data SV-8908 names is confirmed present: customer Euwood Paving holds two open work orders both with unit number 854 and different VINs (1HTKTSWK4RH442544 and 5SHFE4730MB001604), and 854 is the ONLY unit number among the 115 WIP rows carrying more than one VIN. The Asset filter dropdown itself was not driven, so the omission half of the ticket is not re-verified this pass.

### C30506 — Column Selection toggles columns; Total is not offered at all
**PASS.** aria-label "Column Selection" on data-test-id button_column_selection; opens 15 toggles; Total is NOT offered in the control at all.

### C30510 — Work In Progress: a three-dot menu holds Download (PDF) and Download (CSV)
**DEVIATION.** The three-dot menu DOES hold exactly "Download (PDF)" and "Download (CSV)" (data-test-ids action_wip_export_pdf / action_wip_export_csv) - that half passes. But clicking Download (PDF) from the menu produced HTTP 500, no file and no toast. SV-8907.

### C30562 — The report values inventory as of the END of the selected range
**DEVIATION.** SV-8820 reproduces: a custom range ending 2026-07-15 produced a CSV whose own metadata line reads "As of: 2026-07-16" - one day after the end of the range. A range ending 2026-07-31 read "As of: 2026-08-01".
