## 2 · The three findings that matter, in order of seriousness

### 2.1 · "Spec-backed, build differs" was **wrong** on the download menu — the spec says what the build says

The 2026-08-10 pass recorded, for **C30172 · C30173 · C30194**:

> *"SBC **S14-R1/R2**, **S15-R1/R2**, **S16-R1**: the item reads "Download (CSV)", "Download (PDF)",
> and Print is the third item"* → **"case correct — build deviates"**

**The specification says the opposite, on all three counts.** Verbatim, from the live capture:

- **S14-R2** — *"The two menu items read **exactly** "Download Summary (CSV)" and "Download Expanded
  View (CSV).""*
- **S15-R2** — *"The two menu items read **exactly** "Download Summary (PDF)" and "Download Expanded
  View (PDF).""*
- **Story 16** — *"**(removed — Print retired)**"*, retired in the 2026-07-29 change-log entry:
  *"removed Print; split exports into Summary and Expanded (CSV + PDF, four menu items)"*.

**So the build matches the specification and our three cases matched neither.** They are stale
survivors of the pre-2026-07-29 spec. Class **A** — they sit in **Steps** — and they were changed.

**And our own suite already knew.** Four sibling cases in the same sections carried the four-item
wording and cited **spec version 16** for it: [C30159](https://shopview.testrail.io/index.php?/cases/view/30159)
(*"The menu items read, in order: "Download Summary (PDF)", "Download Expanded View (PDF)", "Download
Summary (CSV)", "Download Expanded View (CSV)" — and there is NO "Print" item"*),
[C30164](https://shopview.testrail.io/index.php?/cases/view/30164),
[C38856](https://shopview.testrail.io/index.php?/cases/view/38856) and TU's
[C30434](https://shopview.testrail.io/index.php?/cases/view/30434). **The contradiction was inside
our own suite before anyone opened the build.**

**A consequence worth stating: one of the seven "build deviations" the previous pass reported does
not exist.** It listed *"no "Print" item at all, which SBC S16-R1 requires"*. Story 16 requires
nothing — it was retired. **C30159 asserts there is no Print item, and the build agrees. That case
passes.**

### 2.2 · The QA lead's own example resolved — the WIP tabs

Five cases write the tabs in lower case; the build shows Title Case; **WIP S1-R2 writes them lower
case.** The previous pass froze all five. The answer depends entirely on where the string sits:

| Case | Where | What it is doing | Class | Action |
|---|---|---|:---:|---|
| [C30488](https://shopview.testrail.io/index.php?/cases/view/30488) | **Preconditions** | *"The report shows jobs in the "…" tab"* | **A** | changed |
| [C30489](https://shopview.testrail.io/index.php?/cases/view/30489) | **Preconditions** | same | **A** | changed |

| [C30464](https://shopview.testrail.io/index.php?/cases/view/30464) | **Expected** | same shape | **C** | changed |

**Why the three Expected changes are not Rule-57 breaches, stated plainly because it is the one
judgement in this pass a reader should be able to challenge.** In every one the assertion is
**placement or arithmetic** — *does this work order appear in that tab*, *does that tab's total match
the figure*. The tab name is a **locator**. Capitalising it changes **nothing** about what the case
asserts and **nothing** about whether it can fail. Leaving Steps and Expected disagreeing inside
C30490 would have been worse: a Rule-28 coherence defect in a case we had just touched.

**The one case where the label IS the assertion was NOT changed.**
[C30452](https://shopview.testrail.io/index.php?/cases/view/30452) says *"Four tabs are shown,
**labeled in this order**: "Approved - Partially Completed", …"* — that is class **B**, and it is the
genuine contradiction the previous pass flagged: **the case currently asserts the BUILD's Title Case
while S1-R2 pins lower case.** Moving it means changing an expectation and flipping a verdict.
**That is the QA lead's call, and it is escalated, not taken.**

**Nothing was changed on C30434** — a marker and a known-issue note are a **verdict**, and this pass
is authorised for the label layer. Reported for the QA lead.
