## The line used for splitting (Rule 136 §1 to §4)

Split when every part (a) checks its own requirement or its own report, with its own results and quotes, (b) starts from preconditions a tester can set up without running another case, (c) has no result that depends on another part's steps, (d) stays a full Rule 117 case with at least two steps. Kept whole when: a later step checks an earlier one's effect or uses a value captured earlier (order on screen then PDF, CSV and reload; a count or list compared later; a code noted and reused; export Totals compared with the screen's); the parts are the same rule applied to several columns or items of one report (same quotes); or a part would be a single step. Shared records: every split part reads the same seeded records as part 1 and changes none, so the example names stay those of the original key (Rule 136 §3). Titles: part 1 keeps its title unless it named both parts (23 titles changed, listed below).
