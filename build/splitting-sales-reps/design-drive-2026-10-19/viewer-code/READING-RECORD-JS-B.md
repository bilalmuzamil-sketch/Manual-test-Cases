## 3. canvas.json fields the code reads

All are parsed in `Kv`/`LF`/`Dne`/`Nne`/`Mne` (63538-63914). The live-sync store copies the same artboard set (85135-85146).

- **Top level:** `artboards`, `annotations`, `pages`, `launch` (63734-63758). Any other key is ignored and dropped on save (63781-63790).
- **Artboard** (63697-63716):
  - `file` must name an existing `*.dc.html`. An unknown or duplicate file is dropped.
  - `x` and `y` default to 0 and are clamped to ±1,000,000.
  - `w` defaults to 800 and `h` to 600; both are clamped to 120-8,000.
  - `title` has control characters stripped, is trimmed, and is cut to 120 characters.
  - `expand` keeps only the value "fill". `print` keeps only "flow". `is_interactive` keeps only true.
  - `page` must match `[A-Za-z0-9_-]{1,40}`.
  - Any other artboard key is dropped.
- **Unlisted boards:** any `*.dc.html` not listed is added 80 px to the right of the right-most artboard, at 800 x 600 with no title (63717-63747).
- **Annotation (sticky note)** (63638-63662):
  - `id` must match `[A-Za-z0-9_-]{1,40}`, otherwise the note is dropped.
  - `x` and `y` are clamped to ±1e6.
  - `w` defaults to 240 and is clamped to 120-2,000.
  - `text` loses control characters other than tab and newline, and is cut to 5,000 characters.
  - `size` is clamped to 8-400 or uses a named size: s=14, m=24, l=40, xl=72, xxl=120. The default is 14.
  - `kind` is "title1", or "text" when the size is 40 or more; anything else is "note".
  - `bold`, `italic`.
  - `color` is one of gray, red, orange, green, teal, blue, purple or pink; anything else is "default".
  - `page`.
  - At most 200 notes; duplicate ids are dropped.
- **Pages** (63663-63678): at most 40. Each has an `id` (same pattern) and a `name`, cut to 120 characters, default "Page N".
- **Launch** (63679-63696): `{view:"canvas", page}` or `{view:"focused", file}`.
- **Unknown page:** an item whose `page` is not a known page id moves to the first page (63759-63766).

Our canvas.json, checked by a read-only script:

- Artboard keys are only file, x, y, w, h, title and page. Note keys are only id, x, y, w, text and page.
- All 68 files are listed: none missing, none extra.
- Longest title is 42 characters; longest note is 1,004 characters.
- Artboard w is 390-2,625 and h is 600-1,000; note w is 390-1,400.

**Nothing in our canvas.json is cut, dropped, clamped or restyled.**

## 4. Findings
