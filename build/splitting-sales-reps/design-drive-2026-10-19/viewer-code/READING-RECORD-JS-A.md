Related fields that JS-A code reads from each **board page** (`*.dc.html`), not from canvas.json, at L44920-44979 and L45029-45096:

- `<x-dc>`: the template, including its `<helmet>`
- `script[data-dc-script]`: the page's script text
- `data-props`: JSON. Keys not starting with `$` become props; `$preview` is a preview object which, when present, stops the full-page CSS from being added.
- `propsMeta[k].default`: default prop values
- `propOverrides`: values that override the props
- the page path name `*.dc.html`, which is the root name
