# SV-11265 — Splitting Sales Representatives - Story 1 - Give a work order its sales representative

## Summary

Replace the work order's Sales Representative with one field on the card, built like Lead Technician and Service Advisor, so the service writer can set who sold the work order and the right person is credited when it is invoiced.

## Context

The user needs the 'Work Orders — Create & Edit' permission. The field can be changed only while the work order is not invoiced or paid, and not when the work order is opened from its history.

Context note: before this change Lead Technician reserved a 20px strip for messages under itself, so the gap to Service Advisor measured 36px while the others measured 16px. S1-R6 makes every gap 16px.

## Requirements

* S1-R1: The work order card shows a Sales Representative field directly under Service Advisor.
* S1-R2: The field is the same field as Lead Technician and Service Advisor: the label "Sales Representative" sits inside it on the first line and the name on the second, in the same text style, size, weight and left edge.
* S1-R3: At rest the field shows no box, no dropdown arrow and no buttons beside it.
* S1-R4: Hovering anywhere on the Sales Representative rows shows, on every Sales Representative field at once, the same box Lead Technician and Service Advisor show on hover, around the label and the name together, at the same 44px height and the same left edge. The dropdown arrow (S1-R11) and the buttons beside the fields (S2-R1, S2-R8) show at the same time. All of them stay shown while a Sales Representative dropdown or the + menu is open, or while a field has keyboard focus.
* S1-R5: The box ends 16px before the 32px column that holds the + and remove x buttons.
* S1-R6: The vertical gap between Lead Technician, Service Advisor and every Sales Representative field on the card is 16px. This holds with one field, with the Labor and Parts fields (S2-R5), and on the read-only card (S2-R17).
* S1-R7: With nobody assigned, the field reads "Unassigned".
* S1-R8: Clicking the field opens a dropdown. Its first option is "Unassigned", followed by every active sales representative, sorted by first name, then last name, A to Z.
* S1-R9: The option for the person in the field is checked. With nobody assigned, "Unassigned" is checked.
* S1-R10: The field has no x inside it. Picking "Unassigned" from the dropdown clears it.
* S1-R11: The dropdown arrow sits at the right end of the field, vertically centered on the label and the name together, the same as on Lead Technician and Service Advisor.
* S1-R12: The dropdown has no search box.
* S1-R13: Picking a person assigns them to the whole work order, labor and parts.
* S1-R14: Each change is saved as it is made. There is no Save button.
* S1-R15: The dropdown closes when the user picks an option, clicks outside it or presses Escape.
* S1-N1: A user without 'Work Orders — Create & Edit', or a work order that is invoiced, paid or opened from its history, shows the field as plain text with the same label and wording, with no + or remove x. If a change is sent by any other route, the system refuses it.
* S1-N2: A staff member whose Sales Representative switch is off is not listed and cannot be picked. If one is sent by any other route, the system refuses it with "The selected staff member is not a sales representative."
* S1-N3: If a change cannot be saved, the field returns to the last saved value and an error message shows.
* S1-E1: A change made while the previous change is still saving is ignored, and the + and remove x cannot be clicked until the save finishes. When it finishes, the field shows what was saved.
* S1-E2: A person whose Sales Representative switch was turned off, or whose staff account was deactivated, stays in the field until someone changes it. The field reads their name followed by "(Inactive)", for example "Elliot Brennan (Inactive)". They are not offered in the dropdown, so no option is checked while they hold the field.

## Acceptance Criteria

- [ ] Given a work order card, when it opens, then a Sales Representative field shows directly under Service Advisor, built like Lead Technician and Service Advisor: the label "Sales Representative" inside it on the first line and the name on the second, in the same text style, size, weight and left edge.
- [ ] Given the card at rest, when nothing is hovered or focused, then the field shows no box, no dropdown arrow and no buttons beside it.
- [ ] Given the card, when the user hovers anywhere on the Sales Representative rows, then every Sales Representative field at once shows the same 44px hover box Lead Technician and Service Advisor show, around the label and the name, together with the dropdown arrow and the buttons beside the fields; all of them stay shown while a Sales Representative dropdown or the + menu is open, or while a field has keyboard focus.
- [ ] Given the hover box shows, then it ends 16px before the 32px column that holds the + and remove x buttons, and the dropdown arrow sits at the right end of the field, vertically centered on the label and the name together.
- [ ] Given a card with one field, with the Labor and Parts fields, or read-only, then the vertical gap between Lead Technician, Service Advisor and every Sales Representative field is 16px.
- [ ] Given nobody is assigned, then the field reads "Unassigned", and when the user opens the dropdown "Unassigned" is checked.
- [ ] Given the user clicks the field, then a dropdown opens with "Unassigned" first, followed by every active sales representative sorted by first name, then last name, A to Z, with no search box, and the person in the field is checked.
- [ ] Given a person is in the field, when the user picks "Unassigned", then the field clears. The field has no x inside it.
- [ ] Given the dropdown is open, when the user picks a person, then that person is assigned to the whole work order, labor and parts, and the change is saved at once with no Save button.
- [ ] Given the dropdown is open, when the user picks an option, clicks outside it or presses Escape, then it closes.
- [ ] Given a user without 'Work Orders — Create & Edit', or a work order that is invoiced, paid or opened from its history, then the field shows as plain text with the same label and wording, with no + or remove x, and a change sent by any other route is refused.
- [ ] Given a staff member whose Sales Representative switch is off, then they are not listed and cannot be picked, and if one is sent by any other route the system refuses it with "The selected staff member is not a sales representative."
- [ ] Given a change that cannot be saved, when the save fails, then the field returns to the last saved value and an error message shows.
- [ ] Given a change is still saving, when the user makes another change, then it is ignored and the + and remove x cannot be clicked until the save finishes; when it finishes, the field shows what was saved.
- [ ] Given the person in the field has had their Sales Representative switch turned off or their staff account deactivated, then they stay in the field until someone changes it, the field reads their name followed by "(Inactive)", for example "Elliot Brennan (Inactive)", they are not offered in the dropdown, and no option is checked.
