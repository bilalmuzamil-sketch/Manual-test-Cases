## Summary

Write a log entry for every change to a work order's representatives, reading both sides when it is split, so the shop manager can see who changed them and from what.

## Context

Part Sales Update v1 must be released first, with its log entry for representative changes (SV-10266, S5-R4).

The user needs the 'Work Orders — Create & Edit' permission. The log opens from Audit Log in the work order's menu, which shows only to those users.

Context note: Part Sales Update v1 adds the log entry for a single representative, on part sales and work orders. This story makes the work order entry read both sides. It ships after that release.

## Requirements

* S7-R1: Each change to a work order's representatives, including adding or removing the Parts field, writes one log entry, "Sales representative changed".
* S7-R2: The entry shows "Sales Representative: {before} → {after}". A work order that is not split reads the one name, or "Unassigned".
* S7-R3: A split work order reads both sides, Parts first: "Devon Whitfield (Parts) · Elliot Brennan (Labor)". An empty side reads "Unassigned", for example "Devon Whitfield (Parts) · Unassigned (Labor)".
* S7-R4: A change that leaves the representatives as they were writes no entry.
* S7-R5: Representatives copied from the customer when a work order is created (S4-R24, S4-R25) write no "Sales representative changed" entry.

## Acceptance Criteria

- [ ] Given a work order, when its representatives change, including adding or removing the Parts field, then one log entry "Sales representative changed" is written.
- [ ] Given a work order that is not split, then the entry reads "Sales Representative: {before} → {after}" with the one name, or "Unassigned".
- [ ] Given a split work order, then the entry reads both sides, Parts first, for example "Devon Whitfield (Parts) · Elliot Brennan (Labor)", and an empty side reads "Unassigned", for example "Devon Whitfield (Parts) · Unassigned (Labor)".
- [ ] Given a change that leaves the representatives as they were, then no entry is written.
- [ ] Given a work order is created with representatives copied from the customer, then no "Sales representative changed" entry is written.
