## Summary

Print both representatives on the printed work order, Parts first, so the paper copy matches the card.

## Context

The user needs the 'Work Orders — View' permission. The work order is printed from its menu with Print Work Order; Print is not offered on a work order opened from its history.

## Requirements

* S6-R1: The printed Sales Representative row reads the one name when one person holds both sides, for example "Devon Whitfield", or "Devon Whitfield (Inactive)" when they are inactive.
* S6-R2: When two people hold the two sides, the row reads both, Parts first: "Devon Whitfield (Parts) · Elliot Brennan (Labor)". An inactive person reads "(Parts, inactive)" or "(Labor, inactive)".
* S6-R3: When one side is empty, the row reads "Devon Whitfield (Parts) · Unassigned (Labor)" or "Unassigned (Parts) · Elliot Brennan (Labor)", the same wording as the work order log (S7-R3).
* S6-R4: With nobody on either side, the row is left off the printout, as today.
* S6-N1: A side whose staff member no longer exists prints as Unassigned. A row never reads a bare "(Inactive)".

## Acceptance Criteria

- [ ] Given one person holds both sides, when the work order is printed, then the Sales Representative row reads their one name, for example "Devon Whitfield", or "Devon Whitfield (Inactive)" when they are inactive.
- [ ] Given two people hold the two sides, when printed, then the row reads both, Parts first: "Devon Whitfield (Parts) · Elliot Brennan (Labor)", and an inactive person reads "(Parts, inactive)" or "(Labor, inactive)".
- [ ] Given one side is empty, when printed, then the row reads "Devon Whitfield (Parts) · Unassigned (Labor)" or "Unassigned (Parts) · Elliot Brennan (Labor)".
- [ ] Given nobody on either side, when printed, then the row is left off the printout.
- [ ] Given a side whose staff member no longer exists, when printed, then it prints as Unassigned, and the row never reads a bare "(Inactive)".
