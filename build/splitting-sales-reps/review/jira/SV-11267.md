## Summary

Give the service writer on a phone or tablet the same Sales Representative fields, + and remove x as on a desktop, so the representatives can be set away from a desk.

## Context

Same as Story 1: the user needs the 'Work Orders — Create & Edit' permission, and the fields can be changed only while the work order is not invoiced or paid, and not when the work order is opened from its history.

The user is on a phone or tablet: a touch screen with no mouse pointer. Builds on Stories 1, 2 and 4.

## Requirements

* S3-R1: Tapping a Sales Representative field opens the same dropdown Lead Technician and Service Advisor open on a phone, with the same options as on a desktop (S1-R8, S1-R9).
* S3-R2: The + and remove x buttons are always shown, at the same 32px size (S2-R1, S2-R8), and work as on a desktop (Story 2).
* S3-R3: A field is cleared as on a desktop, by picking "Unassigned" (S1-R10). There is no x inside a field.
* S3-R4: Nothing in the fields or the buttons depends on hover.
* S3-R5: On a phone, the Edit Customer and New Customer representative fields, their + and remove x work as on a desktop (Story 4), with the same native dropdown (S3-R1).
* S3-R6: On a phone the work order card opens collapsed, without Lead Technician, Service Advisor or the Sales Representative fields. They show after Show Details, as Lead Technician and Service Advisor do today.

## Acceptance Criteria

- [ ] Given a phone, when the user taps a Sales Representative field, then the same dropdown Lead Technician and Service Advisor open on a phone opens, with the same options as on a desktop.
- [ ] Given a phone, then the + and remove x are always shown at the same 32px size and work as on a desktop.
- [ ] Given a phone, when the user picks "Unassigned", then the field clears; there is no x inside a field.
- [ ] Given a phone, then nothing in the fields or the buttons depends on hover.
- [ ] Given a phone, when the user opens the Edit Customer or New Customer window, then its representative fields, + and remove x work as on a desktop, with the same native dropdown.
- [ ] Given a phone, when the work order card opens, then it is collapsed without Lead Technician, Service Advisor or the Sales Representative fields, and they show after Show Details.
