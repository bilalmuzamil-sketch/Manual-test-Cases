# SV-8947 — Technician Utilization technician filter and its select-all control are labelled differently from the specification

1. What happens now
The technician filter on Technician Utilization is labelled "Technician", and the control that selects everybody is labelled "All technicians". The written description asks for "Filter by Technician" and "Select all".
2. What should happen instead
Technician Utilization specification, version 6, requirement S5-R1: "The toolbar has a filter labeled 'Filter by Technician' where the user can select more than one technician."
The same specification, requirement S5-R6: "The filter has a control labeled 'Select all' to select all technicians at once."
Requirement S5-R7 asks for "Clear all", and that one does match.
3. How to see it
Open Reports > Technician Utilization.
Read the label above the technician filter in the toolbar - it reads "Technician".
Open that filter and read the first two entries - they read "All technicians" and "Clear all".
Exact test data this was seen with: organisation Staging Foothills Group Inc; signed-in user Admin ShopView; active location Staging Heavy Duty - 9919; the other accessible location Staging Lethbridge - 4310; date range This Year (1 January 2026 to 6 August 2026), which returns 29 technicians.
4. What was actually shown
The toolbar label is "Technician". The first entry in the list is "All technicians" where the description asks for "Select all". The second entry, "Clear all", matches.
5. What was ruled out
It is not a translation or a display width problem - the full words are shown and there is room for more.
It is not the control being wrong. Both controls do exactly what they should; only the wording differs.
Note for triage: the download menu on this same report has a related wording difference, already reported as SV-8881.
6. How often
Every time.
7. Where it was seen
Reports > Technician Utilization, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
 
Where this expected behaviour comes from: the Technician Utilization report specification, version 6, which writes the labels out in full — requirement S5-R1: "The toolbar has a filter labeled “Filter by Technician” where the user can select more than one technician."; requirement S5-R6: "The filter has a control labeled “Select all” to select all technicians at once."; requirement S5-R7: "The filter has a control labeled “Clear all” to clear all technicians at once."
