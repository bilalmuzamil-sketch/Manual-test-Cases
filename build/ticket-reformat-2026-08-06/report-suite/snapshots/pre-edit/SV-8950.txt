# SV-8950 — Technician Utilization downloads leave out the Summary row

1. What happens now
None of the four Technician Utilization downloads contains the Summary row. The files end on the last technician. The written description asks for the Summary row in every one of them.
2. What should happen instead
Technician Utilization specification, version 6, requirement S7-R5: "The Summary PDF shows the technician rows and the Summary row."
The same specification, requirement S7-R6: "The Expanded PDF shows the technician rows, each technician's per-day breakdown, and the Summary row."
The same specification, requirement S7-R7: "The CSV file shows the technician rows and the Summary row."
3. How to see it
Open Reports > Technician Utilization and set the date range to This Quarter, so there is only one technician and the files are short.
Note the Summary row at the bottom of the table on screen.
Open the three-dot menu and take all four downloads in turn. Look at the last line of each file.
Exact test data this was seen with: organisation Staging Foothills Group Inc; signed-in user Admin ShopView; active location Staging Heavy Duty - 9919; the other accessible location Staging Lethbridge - 4310; date range This Year (1 January 2026 to 6 August 2026), which returns 29 technicians. This Quarter returns the single technician Admin ShopView with 1.31 hours.
4. What was actually shown
Every file ends on the last technician row. The Summary row - which on screen reads "Summary  15916.03  12843.23  3072.80  80.7%  $462,687.13" for This Year - is not in any of them.
This was checked on both the short This Quarter view and the full This Year view, in the spreadsheets and in the PDFs.
5. What was ruled out
It is not the row being on a page nobody looked at. The PDF's last page ends on the last technician above the footer, and the spreadsheet's last line is the last technician.
It is not the Summary row being missing on screen - it is present and correct there, and its figures were checked against the underlying data.
It is not a filter side-effect. Nothing was unticked when these files were taken.
6. How often
Every time, in all four downloads.
7. Where it was seen
Reports > Technician Utilization, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
 
Where this expected behaviour comes from: the Technician Utilization report specification, version 6, which names the Summary row in all three files — requirement S7-R5: "The Summary PDF shows the technician rows and the Summary row."; requirement S7-R6: "The Expanded PDF shows the technician rows, each technician's per-day breakdown, and the Summary row."; requirement S7-R7: "The CSV file shows the technician rows and the Summary row."
