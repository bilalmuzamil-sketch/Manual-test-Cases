# SV-8927 — Inventory Value opens with Margin and Total Sell already switched on; both should start hidden

### 1. What happens now
The first time somebody opens the Inventory Value report in a browser, every column is already switched on - including Margin and Total Sell.
### 2. What should happen instead
Those two columns are meant to start switched off, so the report opens on the narrower default view and the user turns them on if they want them.
- Inventory Value requirement S3-R12: "On first visit, the visible columns are: Part #, Description, Category, Vendor, Qty on Hand, Unit Cost, Unit Sell, Margin %, and Total Cost." Margin and Total Sell are not in that list.
- Inventory Value requirement S3-R13: "The Margin and Total Sell columns are hidden by default and can be turned on from the column-selection control."
- Inventory Value requirement S8-R3: "Margin and Total Sell are off by default, the rest on by default."
### 3. How to see it
1. Open a browser window that has never opened this report before (a private window works).
2. Sign in and open Reports > Inventory Value.
3. Read the column headers across the top of the table.
Exact test data this was seen with: no seeding needed. Locations Staging Heavy Duty - 9919 and Staging Lethbridge - 4310, date range This Month.
### 4. What was actually seen
The headers on a genuine first visit read:
{noquote}
Part # | Description | Category | Vendor | Location | Qty | Unit Cost | Unit Sell | Margin | Margin % | Total Sell | Total Cost
{noquote}
The saved view the page writes for itself on that first load also lists all of them, Margin and Total Sell included.
### 5. What was ruled out
- It is not a leftover setting. This was a brand-new browser session with nothing stored for this report - the saved view did not exist until the page created it, and it was created with both columns on.
- The control itself works. Turning Margin off hides it and turning it back on restores it in the right place, so this is only about the starting state.
- It is not the separate Location question. The Location column is a different, still-open point. Margin and Total Sell are described plainly in three places with no disagreement.
### 6. How often
Every time, on every fresh browser.
### 7. Where it was seen
Reports > Inventory Value, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
 
Where this expected behaviour comes from: the Inventory Value report specification, version 4, requirement S3-R12, which lists what is on screen at the start: "On first visit, the visible columns are: Part #, Description, Category, Vendor, Qty on Hand, Unit Cost, Unit Sell, Margin %, and Total Cost." Margin and Total Sell are not in that list.
The same specification, requirement S3-R13, says so directly: "The Margin and Total Sell columns are hidden by default and can be turned on from the column-selection control (Story 8)." And requirement S8-R3 repeats it: "Every other column is available in the control; Margin and Total Sell are off by default, the rest on by default (S3-R12)."
