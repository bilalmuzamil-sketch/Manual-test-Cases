# SV-8948 — Technician Utilization downloads ignore the technician filter and include everybody

1. What happens now
Every Technician Utilization download contains all technicians, whatever is ticked in the technician filter. Unticking someone on screen does not remove them from the file, and choosing a download with nobody ticked still produces a full file with a success message.
2. What should happen instead
Technician Utilization specification, version 6, requirement S7-R8: "Every download includes only the technicians that are currently selected in the technician filter, and covers the location(s) currently selected in the location filter."
The same specification, Story 7 note S7-N1, says a download chosen with no technician selected should do nothing at all - no file and no message.
3. How to see it
Open Reports > Technician Utilization and set the date range to This Year.
Open the technician filter and untick one technician - Andrew Wade was used. The toolbar then reads 28 technicians and his row disappears from the table.
Open the three-dot menu and choose Summary (CSV). Open the file and search for Andrew Wade.
Then untick everybody with "Clear all" - the table shows the empty message - and choose Summary (CSV) again.
Exact test data this was seen with: organisation Staging Foothills Group Inc; signed-in user Admin ShopView; active location Staging Heavy Duty - 9919; the other accessible location Staging Lethbridge - 4310; date range This Year (1 January 2026 to 6 August 2026), which returns 29 technicians.
4. What was actually shown
With Andrew Wade unticked, the downloaded spreadsheet still held 29 technician rows including his - 1080.44 hours. The request the page sent for the file carried the dates and the locations but nothing at all about the technician filter.
With every technician unticked, the download still arrived - the same full 29-row file - and a success message appeared reading "Success / Data exported successfully."
5. What was ruled out
It is not the filter failing on screen. The row really does disappear and the Summary really does recalculate; it is only the download that ignores it.
It is not the location or the date range being ignored too. Both are carried into the download correctly, and the file's own heading lines show the right range and locations.
It is not a stale file from an earlier download. Each file was fetched fresh and its contents read.
6. How often
Every time, on both the spreadsheet and the PDF.
7. Where it was seen
Reports > Technician Utilization, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
 
Where this expected behaviour comes from: the Technician Utilization report specification, version 6, requirement S7-R8, which says: "Every download includes only the technicians that are currently selected in the technician filter, and covers the location(s) currently selected in the location filter."
The same specification, requirement S7-N1, covers the empty case: "If no technician is selected, choosing a download option does nothing: no file downloads and no message appears."
