# SV-8979 — Sales By Representative expand and collapse chevrons are half the required touch size

1. What happens now
The expand and collapse chevrons in the table measure 22 by 22 pixels. The written description asks for at least 44 by 44 for the controls inside the table, which is the ordinary minimum for a finger.
2. What should happen instead
Each chevron should offer a touch target of at least 44 by 44 pixels, even if the arrow drawn inside it stays small.

4. How bad is it
Low, but it is felt on every use: a small target in a dense table is easy to miss and the next tap lands on the row instead.
5. What we ruled out
We measured the other named controls in the same breath and they ARE correct - the three-dot download button is 44 by 44 and the Show Unassigned switch is 44 tall. So it is the chevrons specifically. We also confirmed the chevrons work on touch and by keyboard, so this is the size only.
6. Where this expected behaviour comes from
Where this expected behaviour comes from: the Sales By Representative report specification, version 17, requirement S17-R6, which says: "All interactive controls in the dense table (chevrons, toggles, the button, the dialog's X) present a touch target of at least 44x44 px.". That is source type 2: the specification (PRD) in Confluence. The version number given is the Confluence page version, not the version written inside the page.
