# SV-8973 — Sales By Representative empty-state message uses different wording from the one written down

1. What happens now
When the filters match no invoices at all, the report shows the message "No sales data found for the selected filters."
The written description gives the wording word for word, and it is different.
2. What should happen instead
The message should read "No sales activity matches the current filters."

4. How bad is it
Low. Nothing is broken - it is the wording only.
5. What we ruled out
The rest of the empty state is correct and was checked: no data rows are drawn, and the toolbar stays visible and usable so the user can widen the range. Reproduced two ways - by choosing a date range with no invoices in it, and by leaving a saved date range that is no longer valid.
6. Where this expected behaviour comes from
Where this expected behaviour comes from: the Sales By Representative report specification, version 17, requirement S16-R1, which says: "the table shows no data rows and the empty-state message "No sales activity matches the current filters."". That is source type 2: the specification (PRD) in Confluence. The version number given is the Confluence page version, not the version written inside the page.
