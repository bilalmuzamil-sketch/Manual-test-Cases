What changes, and what does not
Name sorts, and says so. The header carries an arrow for the direction applied, ascending on open.
The QuickBooks column sorts too. A category that has never been mapped shows Parts there and sorts under P with everything else; no row is moved to the bottom (S1-R17).
Default stays pinned, exactly as it is today. “Uncategorized” is the first row under every sort and in both directions, and the rest of the list sorts beneath it. That is the one row whose position this feature must not change.
Worth knowing for whoever builds it: the pin comes from the server today. A sort written as a plain comparison over all the rows will move this row and nobody will notice in review. Spec rule S1-R19.
