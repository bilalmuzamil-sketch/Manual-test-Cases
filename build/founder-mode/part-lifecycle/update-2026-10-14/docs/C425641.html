Setup: Searching track or no does not find untracked parts by their tracking

Test case: C425641, Founder Mode / Part Lifecycle. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Admin at {Location-A} (for example Staging Heavy Duty - 9919); the Admin role has 'Part Library & Inventory → View', 'Part Library & Inventory → Create & Edit' and 'Part Library & Inventory → Delete' and can see costs and prices.

• Parts → Inventory is open on the Active tab at {Location-A}.

• Bin {Bin-A} is the default bin of {Location-A} (for example General Storage), the bin New Inventory Part fills in.

• Inventory part {Part-A} (for example ZZAUTOTEST-PL-SRCHB-U1, described ZZAUTOTEST PL SEARCH B WASHER) is untracked at {Location-A}, and none of its fields contains "track" or "no".

• Inventory part {Part-B} (for example ZZAUTOTEST-PL-SRCHB-K1) is tracked at {Location-A}, and its description contains TRACKBAR (for example ZZAUTOTEST PL SEARCH B TRACKBAR).

• Inventory part {Part-C} (for example ZZAUTOTEST-PL-SRCHB-O1) is tracked at {Location-A}, and its description contains NOZZLE (for example ZZAUTOTEST PL SEARCH B NOZZLE).

• Every ZZAUTOTEST name contains the letter t, so the single letter t cannot be checked with this case's own data; track and no stand in for part of the words.

Part 1. Setup for manual QA tester

1. Sign in as an Admin, pick {Location-A} (for example Staging Heavy Duty - 9919) in the location switcher in the top bar, and open Parts → Inventory on the Active tab.

2. Click New Inventory Part and note the bin the Inventory section fills in (for example General Storage); this is {Bin-A}, the location's default bin. Click Cancel.

3. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL SEARCH B WASHER) and a Part Number (for example ZZAUTOTEST-PL-SRCHB-U1), pick any Category (for example Uncategorized) and type Cost 2.00. This part is {Part-A}.

4. Click the Track quantities and cost of goods switch so it is off (grey); Min and Max disappear.

5. In the Inventory section keep the bin row the dialog fills in ({Bin-A}) and set its Quantity to 3.

6. Click Save. The dialog closes.

7. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL SEARCH B TRACKBAR) and a Part Number (for example ZZAUTOTEST-PL-SRCHB-K1), pick any Category (for example Uncategorized) and type Cost 2.00. This part is {Part-B}.

8. Leave Track quantities and cost of goods on and leave Min and Max empty.

9. In the Inventory section keep the bin row the dialog fills in ({Bin-A}) and set its Quantity to 4.

10. Click Save. The dialog closes.

11. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL SEARCH B NOZZLE) and a Part Number (for example ZZAUTOTEST-PL-SRCHB-O1), pick any Category (for example Uncategorized) and type Cost 2.00. This part is {Part-C}.

12. Leave Track quantities and cost of goods on and leave Min and Max empty.

13. In the Inventory section keep the bin row the dialog fills in ({Bin-A}) and set its Quantity to 5.

14. Click Save. The dialog closes.

15. Check the setup worked: searching ZZAUTOTEST-PL-SRCHB- lists the three rows and only {Part-A} reads "Not Tracked".
