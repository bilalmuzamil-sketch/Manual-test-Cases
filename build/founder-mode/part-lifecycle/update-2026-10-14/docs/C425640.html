Setup: Importing Min, Max and a bin quantity for an untracked part saves them

Test case: C425640, Founder Mode / Part Lifecycle. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Admin at {Location-A} (for example Staging Heavy Duty - 9919); the Admin role has 'Part Library & Inventory → View', 'Part Library & Inventory → Create & Edit' and 'Part Library & Inventory → Delete' and can see costs and prices.

• Bin {Bin-A} is the default bin of {Location-A} (for example General Storage), the bin New Inventory Part fills in.

• Inventory part {Part-A} (for example ZZAUTOTEST-PL-IMPORT-U1, described {Description-A}, for example ZZAUTOTEST PL IMPORT UNTRACKED) is active and untracked at {Location-A}, with Min 2 and Max 6 saved while it was tracked and 4 in {Bin-A}.

• Import file {File-A} (for example ZZAUTOTEST-PL-IMPORT-U1.csv) holds one row for {Part-A} giving {Bin-A} the quantity 9, Min 3 and Max 8.

Part 1. Setup for manual QA tester

1. Sign in as an Admin, pick {Location-A} (for example Staging Heavy Duty - 9919) in the location switcher in the top bar, and open Parts → Inventory on the Active tab.

2. Click New Inventory Part and note the bin the Inventory section fills in (for example General Storage); this is {Bin-A}, the location's default bin. Click Cancel.

3. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL IMPORT UNTRACKED) and a Part Number (for example ZZAUTOTEST-PL-IMPORT-U1), pick any Category (for example Uncategorized) and type Cost 10.00. This part is {Part-A}.

4. Leave Track quantities and cost of goods on and type Min 2 and Max 6.

5. In the Inventory section keep the bin row the dialog fills in ({Bin-A}) and set its Quantity to 4.

6. Click Save. The dialog closes.

7. Write down the description you typed; it is {Description-A}.

8. Search {Part-A}, click its row, click the Track quantities and cost of goods switch so it is off, and click Save.

9. Make the import file {File-A} (for example ZZAUTOTEST-PL-IMPORT-U1.csv) with the header name,part_number,uom,quantity,min_qty,max_qty,grid_location,purchase_price,core_price,vendor,manufacturer,category,tags and one row: name {Description-A}, part_number of {Part-A}, quantity 9, min_qty 3, max_qty 8, grid_location {Bin-A}, and the category you picked; leave the other cells empty.

10. Check the setup worked: the {Part-A} row shows "Not Tracked", bin "{Bin-A} | 4", Min 2 and Max 6, and {File-A} holds that one row.

• Read Part History on screen (/parts/history/<Part-A id>); the arrow in the entry is the character →.

Access

  • Ask the QA lead for the environment's cookies (sv_sso_session, cf_clearance and PHPSESSID). Keep them in /tmp only, with file mode 600. Never write a cookie into a document, a commit or a log.
