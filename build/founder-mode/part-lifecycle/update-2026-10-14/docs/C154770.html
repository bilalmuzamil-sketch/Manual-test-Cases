Setup: Turning tracking on gives a part with no bin the default bin at zero

Test case: C154770, Founder Mode / Part Lifecycle. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Admin at {Location-A} (for example Staging Heavy Duty - 9919); the Admin role has 'Part Library & Inventory → View', 'Part Library & Inventory → Create & Edit' and 'Part Library & Inventory → Delete' and can see costs and prices.

• Parts → Inventory is open on the Active tab at {Location-A}.

• Bin {Bin-A} is the default bin of {Location-A} (for example General Storage), the bin New Inventory Part fills in.

• Inventory part {Part-A} (for example ZZAUTOTEST-PL-TRKON-NOBIN-01) is active and untracked at {Location-A} and has no bin location: its Edit Inventory Part dialog shows no bin row.

Part 1. Setup for manual QA tester

1. Sign in as an Admin, pick {Location-A} (for example Staging Heavy Duty - 9919) in the location switcher in the top bar, and open Parts → Inventory on the Active tab.

2. Click New Inventory Part and note the bin the Inventory section fills in (for example General Storage); this is {Bin-A}, the location's default bin. Click Cancel.

3. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL TRACK ON NO BIN) and a Part Number (for example ZZAUTOTEST-PL-TRKON-NOBIN-01), pick any Category (for example Uncategorized) and type Cost 10.00. This part is {Part-A}.

4. Click the Track quantities and cost of goods switch so it is off (grey); Min and Max disappear.

5. In the Inventory section remove the bin row the dialog filled in, so that no bin row is left (a bin is optional while tracking is off), and click Save.

6. If the dialog does not let you remove that last bin row, click Cancel and do this instead: open Settings → Bin Locations and add a bin location at {Location-A} for this case only (for example ZZAUTOTEST-PL-NOBIN-TEMP); it is {Bin-B}. Create {Part-A} as above with tracking off, change the filled-in row's Bin Location to {Bin-B}, keep its Quantity at 0 and click Save. Then go back to Settings → Bin Locations and delete {Bin-B}; {Part-A} holds 0 there.

7. Do not use Settings → Data Import for this part: an imported part with an empty Grid Location is put in a bin named "Unassigned", so it has a bin.

8. Check the setup worked: open {Part-A}; the switch is off and the Inventory section shows no bin row. If a bin row is still there (for example "Unassigned" or {Bin-B}), the starting state cannot be made by hand: mark the case Blocked with the comment "no way to leave an untracked part with no bin" and tell the QA lead. Close the dialog with Cancel.

Access

  • Ask the QA lead for the environment's cookies (sv_sso_session, cf_clearance and PHPSESSID). Keep them in /tmp only, with file mode 600. Never write a cookie into a document, a commit or a log.
