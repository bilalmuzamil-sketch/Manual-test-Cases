Setup: After its default bin is deleted, turning tracking on marks the remaining bin

Test case: C573675, Founder Mode / Part Lifecycle. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Admin at {Location-A} (for example Staging Heavy Duty - 9919); the Admin role has 'Part Library & Inventory → View', 'Part Library & Inventory → Create & Edit' and 'Part Library & Inventory → Delete' and can see costs and prices.

• Parts → Inventory is open on the Active tab at {Location-A}.

• Bin locations {Bin-B} (for example ZZAUTOTEST-PL-E2-OLDDEF) and {Bin-C} (for example ZZAUTOTEST-PL-E2-KEEP) were added at {Location-A} for this case only.

• Inventory part {Part-A} (for example ZZAUTOTEST-PL-E2-BINDEL-01) is active and untracked at {Location-A}, with 5 in {Bin-C}.

• {Bin-B} was the default bin of {Part-A}, holding 0, and has since been deleted in Settings → Bin Locations.

Part 1. Setup for manual QA tester

1. Sign in as an Admin, pick {Location-A} (for example Staging Heavy Duty - 9919) in the location switcher in the top bar, and open Parts → Inventory on the Active tab.

2. Open Settings → Bin Locations and add two bin locations at {Location-A}: one (for example ZZAUTOTEST-PL-E2-OLDDEF), which is {Bin-B}, and one (for example ZZAUTOTEST-PL-E2-KEEP), which is {Bin-C}. Go back to Parts → Inventory.

3. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL DEFAULT BIN DELETED) and a Part Number (for example ZZAUTOTEST-PL-E2-BINDEL-01), pick any Category (for example Uncategorized) and type Cost 10.00. This part is {Part-A}.

4. Leave Track quantities and cost of goods on and leave Min and Max empty.

5. In the Inventory section change the filled-in row's Bin Location to {Bin-B}, keep its Quantity at 0 and keep it marked Default.

6. Click Add Bin Location, pick {Bin-C} and set its Quantity to 5. Click Save. The dialog closes.

7. Search {Part-A}, click its row, click the Track quantities and cost of goods switch so it is off, and click Save.

8. Open Settings → Bin Locations, find {Bin-B} and delete it ({Part-A} holds 0 there).

9. Check the setup worked: open {Part-A}; the switch is off and the Inventory section lists only {Bin-C} with 5 and no Default pill. If deleting {Bin-B} is refused, mark the case Blocked with the comment "the part's default bin could not be deleted" and tell the QA lead. If a Default pill still shows, run the case anyway: Step 2 then fails. Close the dialog with Cancel.

Part 2. Setup for Claude session

• Settings → Bin Locations is /administration/bins (playbook, Settings sidebar, Parts group). UNVERIFIED: record the add and delete controls and the requests they send; record {Bin-B id} and {Bin-C id}.

• Create the parts through New Inventory Part with Playwright, exactly as Part 1 says. UNVERIFIED: the tech plan says the dialog now sends POST /api/inventory/parts/create with partNumber, description and isTracked (no catalogPartId); capture the body the dialog really sends once and reuse it for the other parts, recording the real field names.

• Record {Part-A id} = the part_id in the create response, or the id of the row returned by GET /api/inventory/parts?search=<its part number>.

• Order matters: create {Part-A} tracked with {Bin-B} as its Default at 0 and {Bin-C} at 5, turn tracking off, then delete {Bin-B}. The part must be untracked when the steps turn tracking on (PRD v29 S5-E2, first way).

• Trap: delete only this case's ZZAUTOTEST bin {Bin-B}; never delete the location's default bin or a bin other parts use. Cleanup: delete {Part-A} (Delete Part), then {Bin-C}.

• Turn tracking on in the dialog only; screenshot the Inventory section before and after the switch.

• Observe each result on the screen: read the row's cells by their visible text (Total Qty, Bin Location / Quantity, Min, Max). UNVERIFIED: the tech plan says GET /api/inventory/parts rows carry is_active and is_tracked; use them only as a cross-check, never as the result.
