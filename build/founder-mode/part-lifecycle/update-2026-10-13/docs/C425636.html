Setup: Cycle count shows Not Tracked for an untracked part and never counts it

Test case: C425636, Founder Mode / Part Lifecycle. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Admin at {Location-A} (for example Staging Heavy Duty - 9919); the Admin role has 'Part Library & Inventory → View', 'Part Library & Inventory → Create & Edit' and 'Part Library & Inventory → Delete' and can see costs and prices.

• Parts → Inventory is open on the Active tab at {Location-A}.

• Bin {Bin-A} is the default bin of {Location-A} (for example General Storage), the bin New Inventory Part fills in.

• Inventory part {Part-A} (for example ZZAUTOTEST-PL-CC-T1) is active and tracked at {Location-A}, with 5 in {Bin-A}.

• Inventory part {Part-B} (for example ZZAUTOTEST-PL-CC-U1) is active and untracked at {Location-A}, with 3 in {Bin-A}.

• Both part numbers start with {Prefix-A} (for example ZZAUTOTEST-PL-CC-), which is typed in the Inventory search.

• No Cycle count is in progress on the Inventory list.

Part 1. Setup for manual QA tester

1. Sign in as an Admin, pick {Location-A} (for example Staging Heavy Duty - 9919) in the location switcher in the top bar, and open Parts → Inventory on the Active tab.

2. Click New Inventory Part and note the bin the Inventory section fills in (for example General Storage); this is {Bin-A}, the location's default bin. Click Cancel.

3. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL CYCLE COUNT TRACKED) and a Part Number (for example ZZAUTOTEST-PL-CC-T1), pick any Category (for example Uncategorized) and type Cost 10.00. This part is {Part-A}.

4. Leave Track quantities and cost of goods on and leave Min and Max empty.

5. In the Inventory section keep the bin row the dialog fills in ({Bin-A}) and set its Quantity to 5.

6. Click Save. The dialog closes.

7. Click New Inventory Part, type a Description (for example ZZAUTOTEST PL CYCLE COUNT UNTRACKED) and a Part Number (for example ZZAUTOTEST-PL-CC-U1), pick any Category (for example Uncategorized) and type Cost 10.00. This part is {Part-B}.

8. Click the Track quantities and cost of goods switch so it is off (grey); Min and Max disappear.

9. In the Inventory section keep the bin row the dialog fills in ({Bin-A}) and set its Quantity to 3.

10. Click Save. The dialog closes.

11. The shared start of the two part numbers (for example ZZAUTOTEST-PL-CC-) is {Prefix-A}; type it in the Inventory search.

12. Check the setup worked: the list shows {Part-A} "5 Available" and {Part-B} "Not Tracked" with "{Bin-A} | 3", and the toolbar shows the ⋮ menu (no Cycle count is running).

Part 2. Setup for Claude session

• Create the parts through New Inventory Part with Playwright, exactly as Part 1 says. UNVERIFIED: the tech plan says the dialog now sends POST /api/inventory/parts/create with partNumber, description and isTracked (no catalogPartId); capture the body the dialog really sends once and reuse it for the other parts, recording the real field names.

• Record {Part-A id} and {Part-B id}.

• Drive Cycle count in the browser (⋮ → Cycle count, the count box of the tracked row, Save). UNVERIFIED: the tech plan says the count cell of an untracked row has no input (text_count_not_tracked_<id>) and is never sent in the count request; record the real request.

• Read "Count changes available" in the toolbar before and after Step 4; an untracked row must never use up that budget.

• Trap: the list headers are the short production labels "Total Qty" and "Avg Cost" (design board 4.0); read the header's text node, not a guessed label.
