## **New questions, 27 October 2026**
[Chris Ward](mailto:chris.w@shopview.com) Dear Sir, thank you for your answers of 14 October. We have now updated all the Part Lifecycle test cases to your page as you edited it on 23 October (version 33), and checked the whole design again. These points are still open. Each one decides what a tester marks as pass or fail, and some tests wait for your answer. Could you please write your answer under each question? A short answer is perfect. The new questions have blue headings.
## **13. Opening a core's own Part History page**
**What the page says:** a core's name and history show on "the core's own Part History page" (S5-E3). A core has no row on the Inventory list, in Export or on the Part Library list, so we have not found a screen that opens that page.
**Question:** (a) How does a user open a core's own Part History page? (b) Does the search box in the top bar list a core ("Core for …"), with the grey Inactive tag and "Not Tracked" like any other part?  
**Answer: 13. (a) A core's Part History page has no link on screen in this release. Its entries are recorded (S5-E3), and you can check them by opening the core's Part History address directly. (b) No. Global search never lists a core, active or inactive, tracked or not, the same as today (S9-R18a).**
## **14. A part with no bin location at all**
**What the page says:** turning tracking on for a part with no bin location gives it the location's default bin (S5-R7). But the part window never lets the last bin be removed (Story 4 note), and the import puts a part with no bin into an "Unassigned" bin (S7-N10).
**Question:** how does a part end up with no bin location at all, so we can test S5-R7?
**Answer: 14. No screen leaves a part with no bin location. The part window keeps the last bin, the import uses "Unassigned", receiving uses the default bin, and Bin Locations won't delete a bin that still holds a part. To test S5-R7, create an untracked part with no bins through a direct system request (ask Nemanja for it), then open the part and turn tracking on. It gets the location's default bin at 0, marked default.**
## **15. The Delete button in an open "Edit Library Part" window**
**What the page says:** Delete in the "Edit Library Part" window is disabled while a part uses the entry (S11-R3c).
**Question:** if the last part using the entry is deleted in another tab while that window is open, does its Delete button become enabled without a reload?
**Answer: 15. No. Delete stays disabled until the page is reloaded (S11-E5). Note that an open part request or a part return using the entry also keeps Delete disabled, not only an inventory part (S11-R3c).**
## **16. Parts added by the parts import**
**What the page says:** the import adds new parts and updates stocked ones (S7-N7 to S7-N10), but it doesn't say whether a new part is tracked.
**Question:** (a) Is a part the import adds tracked or untracked? (b) Is the import template's "name" column the part's description?
**Answer: 16. (a) Tracked. The import has no tracking column, and it never changes an existing part's tracking. (b) Yes, the "name" column is the part's description (S7-N11).**
## **17. Where Bin Locations is**
**What the page says:** Bin Locations is under "Administration" (S5-E2, and your answer 5). On screen it is under Settings.
**Question:** which name should the tests use?
**Answer: 17. Settings. The path is Settings → Parts → Bin Locations (S5-E2). Roles & Permissions is also under Settings (S12-R6).**
## **18. "5 Available" or "3 Available"**
**What the page says:** SV-10380 keeps the shop-floor availability calculation unchanged.
**Question:** for a part with bins of +5 and −2, should the Inventory list's badge read "5 Available" (positive bins only, as today) or "3 Available" (net)?
**Answer: 18. "5 Available." The Inventory list counts only bins above zero, the same as production today, and this feature doesn't change it.**
## **19. The close X on status confirmations**
**What the design shows:** every status confirmation (Deactivate part?, Activate part?, Deactivate parts?, Activate parts?) has a close X at the top right.
**What the page says:** the confirmation has a title, a message, an optional note, Cancel and a confirm button (section 4), with no X.
**Question:** (a) Should the X be there? (b) If yes, does clicking it do the same as Cancel?
**Answer: 19. (a) Yes, the X stays. It's part of the standard dialog. (b) Yes, it does exactly what Cancel does: nothing changes, and from the part window you return with your picked status kept. Esc and clicking outside don't close it (S10-R11a).**
## **20. The note on design board 7.2**
**What the design shows:** the note on board 7.2 says a Part Library entry "can be edited and deleted" on its page. The board's picture shows no Delete.
**What the page says:** the page has no Delete button; Delete is in the "Edit Library Part" window (S11-R3), as your answer 12 confirmed.
**Question:** can you confirm the note on board 7.2 is out of date? Our tests follow the page.
**Answer: 20. Yes, the board 7.2 note is out of date. Follow the page: the detail page has no Delete. Delete is in the "Edit Library Part" window (S11-R3).**
## **21. Long Part History entries**
**What the design shows:** board 2.6 wraps a long event (for example a part number change ending "| Changed at: \<location\>") onto a second line. The engineering plan cuts it off with "..." instead. The page doesn't say.
**Question:** should a long entry (a) wrap onto more lines, or (b) be cut off with "..."? If (b), how does the user read the full entry?
**Answer: 21. (a) It wraps onto more lines, as on board 2.6. The full entry always shows and is never cut short (S10-R21).**
## **22. Who can open Parts → Returns today**
**What the page says:** opening Parts → Returns and starting a vendor return "keep the access today's 'Vendor Order Management' settings give" (S9-N3a), without naming that access.
**Question:** (a) Can a role with no Vendor Order Management permission open Parts → Returns? (b) Can a role with Vendor Order Management → View, but not Create & Edit, start a vendor return? (c) Can any role reach a return's or a vendor credit's part search without Part Library & Inventory → View, so the access error of S9-N3 can be seen?
**Answer: 22. (a) No. Without Vendor Order Management, Parts → Returns is hidden and refused. (b) Not on screen: without Create & Edit, the Create Return button doesn't show. Today the Create Return page still opens if its address is typed directly. That's a gap in production now, which this feature doesn't change. (c) Not through normal screens. Vendor Order Management → Create & Edit, which is what shows Create Return, also gives part search access, so every role that can start a return can search parts. To see the S9-N3 error, use a role with Vendor Order Management → View only and none of the other settings that give part search access (Part Library & Inventory → View, Part Sales → Create & Edit, work order pick parts, Settings Parts, See financial data). Then type the Create Return address directly and search for a part.**
## **23. Renaming a part to a look-alike at the same location**
**What the page says:** Story 7 refuses a look-alike part number at this location with "AB-100 already exists at this location." (S7-N3, S7-N5b). The new S13-N1a refuses a rename that matches a part at any location that stocks the part with "AB-100 already exists at {location}."
**Question:** when a part is renamed to a look-alike of another part at the same location (for example ab 100 when AB-100 is stocked here), which message shows?
**Answer: 23. "AB-100 already exists at this location." (S7-N3), or the inactive version (S7-N4) if the AB-100 here is inactive. The "{location}" wording shows only for a clash at another location that stocks the part, or for a rename made on the Part Library page (S13-N1a).**
## **24. When the other Part Library messages show**
**What the page says:** six messages that name the shared list are renamed (S12-R11). We can reach "This Part Library entry is in use and cannot be deleted." and "Part Library entry not found." on screen.
**Question:** which screen action, if any, shows the others: (a) "Part Library entry not found" (no full stop); (b) "Part Library entry not found for ID: {id}." and "... for part number: {part number}."; (c) "Part Library entry missing category."; (d) "A part from the Part Library must have Vendor as its source."?
**Answer: 24. Only these show through normal screen use: "This Part Library entry is in use and cannot be deleted.", "Part Library entry not found." (save an entry deleted in another tab, S11-E4), and "Part Library entry not found for ID: {id}." (open the address of a deleted entry). (a) and (c) show only with damaged or legacy data. (b) "for part number" and (d) are never raised today. All are renamed anyway, so no old wording remains. Check those in code review, not on screen (S12-R11a).**
## **25. Where a special order's cost shows**
**What the page says:** a special-order result from two vendors uses the most recent delivery's vendor and cost (S12-R14b).
**Question:** after picking the result in New Part Request, is the Cost field where its cost shows?
**Answer: 25. Yes. Picking it fills Cost with the most recent delivery's cost and sets Vendor to that delivery's vendor (S12-R14b). Sell Price is calculated from that cost. Users who can't see financial data don't see Cost.**
## **26. A renamed part on an open work order line**
**What the page says:** renaming keeps the line (S13-R18) and lists the open work that takes the new number: purchase order lines, part requests, canned jobs and returns (S13-R19). Work order part lines are not in that list, and the engineering plan leaves them unchanged.
**Question:** after a rename, does a work order line that already holds the part show the old number or the new one?
**Answer: 26. It depends on the line. A part already received onto a work order or part sale line keeps the number it was added with. A part request not yet received or returned takes the new number (S13-R19e).**
## **27. A page opened before a role change**
**What the page says:** without "Part Library & Inventory → Delete", status changes, deleting and tracking changes are refused (S8-N1 to S8-N3).
**Question:** if an Admin removes that permission from a user's role while the user has the part page open, does the open page keep showing its old controls (Delete Part, Part Status, the tracking switch) until it is reloaded, with the save then refused?
**Answer: 27. Changing a user's role logs that user out on their next action, with "Session expired, please log in again." Until then the old controls stay on screen. After logging back in, they follow the new role. Also note: unticking only Delete may not remove the right on the server, because some other settings carry it today (Story 8 context note). For S8-N1 to S8-N3, use a role without Part Library & Inventory Create & Edit, Vendor Order Management Create & Edit, Part Sales Delete, Settings Parts or See financial data.**
