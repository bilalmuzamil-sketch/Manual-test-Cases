6. Deleting a customer that pays for others

Customers, Edit Customer, Delete. A customer with work orders, assets or contacts cannot be deleted at all, as today, so this flow uses Murrieta Diesel Repair, which has none. For the shots Murrieta was saved as Valders Diesel & Fleet Repair's default Bill To; "Remove as default Bill To" then cleared it, which is also the original state. Murrieta was never deleted.
