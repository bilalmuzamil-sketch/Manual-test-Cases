Setup: Edit Line will not save an emptied Title and shows the required message

Test case: C549075, Founder Mode / What/Why. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Admin (all permissions) at {Location-A} (for example Staging Heavy Duty - 9919) on the What/Why QA build.

• Customer {Customer-A} (for example ZZAUTOTEST-WW-A02 Fleet) has a contact person and an asset, {Asset-A} (for example ZZAUTOTEST-WW-A02 Truck).

• Work order {Work-order-1} (for example S2-15440) is open for {Customer-A} and {Asset-A} at {Location-A}, not invoiced.

• {Work-order-1} has a line {Line-1} with Title (for example Replace tie rod) and Description (for example excessive play).

Part 1. Setup for manual QA tester

1. Sign in to the What/Why QA build as an Admin and pick the location you will use in the top bar (for example Staging Heavy Duty - 9919). This is {Location-A}.

2. Open Customers and create a customer named (for example) ZZAUTOTEST-WW-A02 Fleet, with one contact person (for example Pat Tester). This is {Customer-A}.

3. On {Customer-A}, add an asset (for example a truck named ZZAUTOTEST-WW-A02 Truck, 2018 Freightliner Cascadia). This is {Asset-A}.

4. Open Work Orders and click New Work Order. Choose {Customer-A} and {Asset-A} and click Create.

5. Write down the work order number the app shows (for example S2-15440). This is {Work-order-1}.

6. If the work order has no contact, set it to {Customer-A}'s contact person and answer YES when asked to keep that contact for the asset. If it asks for mileage, enter any number (for example 123456).

7. Open {Work-order-1}, go to the Lines tab and click New Line.

8. In Title type Replace tie rod (for example) and do not pick a canned line from the list. In Description type excessive play (for example).

9. Choose any Labor Rate, set Estimated Time (for example 1), and click Save & Close. This line is {Line-1}.

10. If the typed title was not kept, pick any canned line instead, click Save & Close, then click the line's title to open Edit Line, set Title and Description to the values above and click Save & Close. Delete any part request the canned line added.

11. Check the setup worked: {Line-1} is listed on {Work-order-1}'s Lines tab and opening it shows the Title and Description you typed. Close Edit Line without saving.
