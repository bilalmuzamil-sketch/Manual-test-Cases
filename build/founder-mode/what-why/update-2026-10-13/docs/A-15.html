Setup: An Invoices import file with Line Title and Line Description swapped is rejected

Test case: (new case), Founder Mode / What/Why. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Admin (all permissions, including Settings → Data Import) at {Location-A} (for example Staging Heavy Duty - 9919) on the What/Why QA build.

• Import file {File-A} (for example ZZAUTOTEST-WW-A15.csv) is made from the Invoices import template with one Labor row for customer {Customer-A} (for example ZZAUTOTEST-WW-A15 Fleet), invoice number {Invoice-number-A} (for example ZZWW-A15-1), *Line Title value (for example Replace tie rod) and Line Description value (for example excessive play); but its 16th and 17th columns are swapped, header and value: Line Description first, then *Line Title.

Part 1. Setup for manual QA tester

1. Sign in to the What/Why QA build as an Admin and pick a location in the top bar (for example Staging Heavy Duty - 9919). This is {Location-A}.

2. Open Settings and, under Data Import, click Invoices. Download the template (sample file).

3. Open it in a spreadsheet and fill one row: every column whose name starts with * must be filled. Use item type Labor, customer name {Customer-A} (for example ZZAUTOTEST-WW-A15 Fleet), *Line Title (for example Replace tie rod) and Line Description (for example excessive play). Invoice number (for example) ZZWW-A15-1. This is {Invoice-number-A}.

4. Swap the *Line Title and Line Description columns (header and value move together). Save as plain CSV named (for example) ZZAUTOTEST-WW-A15.csv. This is {File-A}.

5. Check the setup worked: in a text editor the header row reads ...,*Item,Line Description,*Line Title,Tech Story,... and the rest matches the template.

Access

  • Ask the QA lead for the environment's cookies (sv_sso_session, cf_clearance and PHPSESSID). Keep them in /tmp only, with file mode 600. Never write a cookie into a document, a commit or a log.
