Same as a work order note
The @ tagging, tag groups, quick notes, attachments, edit and delete all behave exactly as they do on a work order. The notification lands in the same inbox.
Two differences, both deliberate
The pill reads Part Sale: and links to the Part Sale screen rather than the work order. There is no Customer Visible checkbox: part sale notes are internal to the shop.
Who sees it. A part sale is a work order row, so a note on one is reachable with Work Orders: View or Part Sales: View, the same pair that opens the Part Sale screen itself. A parts person with neither does not see the tab.
