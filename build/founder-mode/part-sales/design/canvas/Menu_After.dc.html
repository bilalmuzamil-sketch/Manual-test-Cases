4. Reordered, with Audit Log

Audit Log → Add Parts Sale Fee / Discount → Set status → Delete Part Sale. Only the ends moved: Delete went from first to last, Audit Log took the top, and Delete lost its red so it reads like the work order's.

Set status and Add Parts Sale Fee / Discount are arguably in the wrong place, and they were left exactly where they were anyway: that is where people already click, and their position was not hurting anyone. Delete sitting first was — a destructive action under the cursor, with the audit trail nowhere. Swapping the two ends is what makes this menu read like the work order's, so the two stop disagreeing about where the dangerous item lives.
