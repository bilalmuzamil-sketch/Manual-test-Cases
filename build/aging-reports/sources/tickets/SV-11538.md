# SV-11538 — A/R and A/P Report Sorting - Story 8 - Report descriptions and layout
Story · TESTING QA · assignee None · parent SV-11315 · QA branch https://sv11315.qa.shopview.com

## Description
h2. Summary

Explain each report behind the native info icon beside its title, pin and bold the headline column, fit every column at 1440 pixels, and use the native totals, empty, loading and error states.

h2. Context

As a user, I want each report to say what it includes and to keep its key total in view so that I understand why totals differ between reports.

Prerequisites: User must have 'Reports → Page Access' setting enabled.

Form factor: Desktop only by rule: detailed reports.

h2. Requirements

* S8-R1: Each report has the native report info icon (the one Work In Progress and Technician Utilization use) directly right of its title. Hovering, keyboard focus or a tap shows the report's description in a tooltip; moving away or Escape closes it. The descriptions: • A/R Summary: "Each customer’s unpaid balance as of the selected date, after unused credit memos and deposits, with a breakdown of overdue amounts." • A/R Detail: "Each customer’s unpaid invoices, unused credit memos and deposits as of the selected date, grouped by how overdue they are." • A/R Collection: "Overdue invoices, unused credit memos and deposits for each customer to help you follow up on payments. Excludes invoices that aren’t due yet." • A/P Summary: "Your unpaid balance with each vendor as of the selected date, after unused vendor credits, with a breakdown of overdue amounts." • A/P Detail: "Unpaid bills and unused vendor credits as of the selected date, grouped by how overdue they are." • A/P Unpaid Invoices: "Unpaid bills and unused vendor credits grouped by vendor, showing each bill’s due date and days overdue."
* S8-R2: The title, its info icon and the Export menu stay on one line at 1440 pixels wide; the filter row sits below them, positioned as on the native reports.
* S8-R3: The headline column (Open Balance; Total on the Summaries) is pinned to the right edge and bold on the header, every row, every expanded row and the Totals row, as on Sales By Customer. At 1440 pixels wide every column of all six reports is visible without scrolling sideways: the customer or vendor name and Transaction type wrap long values onto a second line, Location wraps only on A/P Detail (nine columns), column headings never wrap, and money, date and number columns never wrap. Narrower than 1440 pixels, the table scrolls sideways under the pinned column.
* S8-R4: The Totals row uses the native totals row style of the newer reports.
* S8-R5: While a report loads it shows the native table progress bar. When the filters leave no rows, it shows the native empty state: "No record matches these filters" and "Try changing filters to widen your results.", with a "Clear all filters" button when a customer or vendor, Past due or Location is chosen; that button keeps the as-of date and returns the customer or vendor, Past due and Location to their defaults (every location ticked).
* S8-R6: If a report fails to load, it shows "Something went wrong loading this report. Please try again." in place of the rows, with the standard error message.
* S8-N1: The descriptions appear on screen only, not in the PDF or CSV.

h2. Acceptance Criteria

* Given each report, when the user hovers, focuses or taps the info icon right of the title, then its S8-R1 description shows in a tooltip, word for word; moving away or Escape closes it; the descriptions are not in the PDF or CSV (S8-R1, S8-N1).
* Given a 1440-pixel-wide window, then the title, info icon and ⋯ stay on one line with the filter row below, and every column of all six reports is visible without scrolling sideways, text columns wrapping to a second line, money, date and number columns not wrapping (S8-R2, S8-R3).
* Given any report, then the headline column (Open Balance; Total on the Summaries) is pinned right and bold on the header, every row, every expanded row and the native Totals row; narrower than 1440 pixels the table scrolls sideways under it (S8-R3, S8-R4).
* Given filters that leave no rows, then "No record matches these filters" / "Try changing filters to widen your results." shows, with "Clear all filters" when a customer or vendor, Past due or Location is chosen, which keeps the as-of date (S8-R5).
* Given a load failure, then "Something went wrong loading this report. Please try again." shows in place of the rows, with the standard error message (S8-R6).

h3. Totals, loading, empty, error [S8-R4, S8-R5, S8-R6]

* Dark mode: links, the pinned column, group rows, the pinned group row and the Totals row are readable.
* 375 px: the page does not break; the table scrolls sideways.

h2. Known mismatches (not bugs)

* PRD S8-R3 still says Location wraps only on A/P Detail; it also wraps on A/P Unpaid (Product agreed, wording fix pending).
* At 1400 px A/P Detail and A/P Unpaid are 2–4 px too wide: a tiny sideways scrollbar, Amount a few pixels under the pinned Open Balance. The PRD guarantees the fit at 1440 only.
* At 375 px a closed group's Amount covers the end of a long name (kept; no money value is cut).
* A/R Detail's columns shift about 34 px sideways when you click Expand all.
* The four grouped reports use slightly tighter cell padding at 1440 px (8 px instead of 12 px) to fit nine columns.
* Titles are unchanged and differ from the PRD names: "A/R Aging Collection" (PRD "A/R Collection"), page title "A/P Unpaid Invoices Report" (menu "A/P Unpaid Invoices").
* Dark mode link contrast is slightly under 4.5:1 (app-wide link blue).

h2. What is NOT impacted

* Other reports' layout. The shared info icon gained the Escape-after-hover close; check it once on Work In Progress.
