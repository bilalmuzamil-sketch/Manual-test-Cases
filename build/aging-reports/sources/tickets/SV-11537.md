# SV-11537 — A/R and A/P Report Sorting - Story 7 - Document links open where they can
Story · TESTING QA · assignee None · parent SV-11315 · QA branch https://sv11315.qa.shopview.com

## Description
h2. Summary

Make a document number a link only when the user can open it in its own location, with the existing switch-location prompt for an invoice at another enrolled location; fixes SV-5706.

h2. Context

As a user, I want a document number to open only when I can actually view it, in its own location, so that I never land on an error.

Prerequisites: An invoice or part sale opens for a user with 'Invoicing & Payments → View' and 'Work Orders → View' (work orders) or 'Part Sales → View' (part sales). A bill opens for a user with 'Vendor Order Management → View' or 'Vendor Order Management → Create & Edit'. A customer name on A/R Summary links to A/R Collection for a user with 'Customers → View', as today. A vendor name on A/P Summary links to A/P Unpaid Invoices for everyone who can open the reports, as today.

Form factor: Desktop only by rule: detailed reports.

h2. Requirements

* S7-R1: A document number is a link only when the user has the permission to open it and can open it in its own location; otherwise it shows as plain text.
* S7-R2: An invoice or part sale at the user's current location opens its finance page, as today.
* S7-R3: An invoice or part sale at another location the user is enrolled in shows the existing location-switch prompt on the report, before leaving it: title "Switch location?", message "This work order is in {location}. Switch your active location to view it?" (for a part sale: "This part sale is in {location}. Switch your active location to view it?"), buttons "Cancel" on the left and "Switch location" on the right, and a close × at the top right.
* S7-R4: "Switch location" changes the active location to that location and opens the document.
* S7-R5: "Cancel" or the × closes the prompt; the user stays on the report exactly where they were: same page address, filters, sort, expanded groups and scroll position.
* S7-R6: A bill at the user's current location opens its delivery, as today. A bill at another location shows as plain text, because the bill page cannot switch location.
* S7-R7: Links use the native report link style (the same blue as Work In Progress, semi-bold, no underline, underlined only on keyboard focus), readable in light and dark theme.
* S7-R8: Opening a link in a new tab opens the document page, which asks to switch location itself.
* S7-R9: On A/P Detail and A/P Unpaid Invoices, a vendor credit's number links to the vendor return it came from, under the same rules and permissions as a bill (S7-R6). A vendor credit that did not come from a vendor return shows as plain text.
* S7-R10: A/R credit memos and deposits show as plain text: they have no page of their own.
* S7-N1: A document at a location the user is not enrolled in shows as plain text.
* S7-N2: A document the user lacks the permission for shows as plain text.
* S7-E1: The location switcher in the top right of ShopView is not changed.

h2. Acceptance Criteria

* Given an invoice or part sale at the user's current location and the permissions in the prerequisites, when its number is clicked, then its finance page opens (S7-R1, S7-R2).
* Given an invoice at another location the user is enrolled in, when clicked, then the prompt "Switch location?" / "This work order is in {location}. Switch your active location to view it?" shows on the report (part sale: "This part sale is in {location}. ..."), with "Cancel" on the left, "Switch location" on the right and a close × at the top right; "Switch location" switches and opens it, and "Cancel" or the × leaves the address, filters, sort, expanded groups and scroll unchanged (S7-R3 to S7-R5).
* Given a bill at the current location, then it opens its delivery; at another location, plain text; a vendor credit links to the vendor return it came from under the same rules, or is plain text when it came from no return; A/R credit memos and deposits are plain text (S7-R6, S7-R9, S7-R10).
* Given a document at a location the user is not enrolled in, or without the permission, then it is plain text (S7-N1, S7-N2).
* Given a link, then it is the native report link style (Work In Progress blue, semi-bold, no underline, underlined on keyboard focus), readable in light and dark; opening it in a new tab opens the document page, which asks to switch location itself (S7-R7, S7-R8).
* Given a row, when the user clicks anywhere but the link, then nothing opens.

h2. QA Checklist (do these)

h3. Summary name links [S7-R1, S5-R11]

* A/R Summary, user with Customers → View: the customer name is a link (blue, semi-bold, no underline) → A/R Collection for that customer with the same As of, Past due and locations.
* Custom role with Reports → Page Access but without Customers → View: the name is plain text.
* A/P Summary: the vendor name links for everyone → A/P Unpaid for that vendor.
* Clicking anywhere else on a row does nothing.

h3. A/R documents (Detail and Collection) [S7-R2–S7-R5, S7-R10]

* Invoice or part sale at your current location → the number is a link → a plain click opens its finance page.
* Ctrl/Cmd-click, Shift-click or middle-click → a new tab; the report stays as it was; the document page asks to switch location itself when needed.
* Invoice at another location you are enrolled in → a prompt on the report: "Switch location?" / "This work order is in {location}. Switch your active location to view it?" (part sale: "This part sale is in {location}. …"). "Cancel" on the left, "Switch location" on the right (small l), × top right.
* "Switch location" → the active location changes and the document opens.
* "Cancel" or × → nothing changes: same address, filters, sort, open groups and scroll position.
* Credit memos and deposits → plain text.

h3. A/P documents (Detail and Unpaid) [S7-R6–S7-R9]

* Bill at the current location → opens its delivery. At another location → plain text (A/P never shows the prompt).
* Vendor credit that came from a vendor return → links to that return, same rules. Any other vendor credit → plain text.

h3. Plain text when the user can't open it [S7-N1, S7-N2, S7-E1]

* Location you are not enrolled in → plain text.
* Missing permission → plain text: invoices and part sales need Invoicing & Payments → View plus Work Orders → View / Part Sales → View; bills and returns need Vendor Order Management (view or edit).
* The top-right location switcher is unchanged.

h3. Link look

* Links use the Work In Progress report blue, semi-bold, no underline, in light and dark mode. A long number ends in "…" and shows in full on hover; the link still works.

h2. Known mismatches (not bugs)

* The work order and part sale pages' *own* prompt (after a Ctrl-click into a new tab) reads "Switch Location" with a capital L. That is the app-wide button style, not changed here. The prompt on the aging reports reads "Switch location".
* Dark mode: link contrast is slightly under 4.5:1 on dark rows (the app-wide link blue).
* Seen while testing, not caused by this change: switching location (top right) while on another location's work order finance page shows a 400 "Invoice not found".

h2. What is NOT impacted

* [ ] Work order, part sale, delivery and vendor return pages themselves.
* [ ] The work order / part sale location prompt elsewhere: Cancel still returns to Work Orders with its message; dashboard tiles with {{?locationId}} still open the right list (SV-11597).
