C715582 A drill-down link saved before the release still opens on its customer
PRE: Preconditions
- Sign in as an Admin user (the "Admin" role).
- Make sure that before the release was installed, you clicked customer A's name on A/R Summary and saved the address of the A/R Collection page it opened, and did the same for vendor A on A/P Summary.
- Make sure customer A had overdue invoices and vendor A unpaid bills on the day the addresses were saved.
- Use a desktop browser window 1440 px wide.
- After the release is installed, click Dashboard in the top menu.
STEPS: - Paste the A/R Collection address saved before the release into the browser's address bar and press Enter (it opens on the Reports page).
- Paste the A/P Unpaid Invoices address saved before the release into the browser's address bar and press Enter (it opens on the Reports page).
EXP: Expected Result
Step 1:
- A/R Collection opens, with no error.
- The chip reads "Customer: " and customer A's name.
- Only customer A's group is listed.Step 2:
- A/P Unpaid Invoices opens, with no error.
- The chip reads "Vendor: " and vendor A's name.
- Only vendor A's group is listed.
Why: today's drill-down writes the customer or vendor into the address in an older form; the tech plan says the new reports still read it, so bookmarks made before the release keep working.
