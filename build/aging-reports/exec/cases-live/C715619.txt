C715619 Inventory Value keeps or forgets its filter between visits as before
PRE: Preconditions
- Sign in as an Admin user (the "Admin" role).
- Have open documents in these reports at two locations, location A and location B, with location A's name first in A to Z order.
- Make sure you are enrolled at both locations, so both are in Inventory Value's Location filter.
- Make sure that before the release was installed, you did the steps below on Inventory Value and noted whether the unticked location was still unticked when you came back.
- Use a desktop browser window 1440 px wide.
- After the release is installed, open Inventory Value (Reports, then "Inventory Value" under PARTS in the left menu).
STEPS: - In its Location filter, untick location B.
- Open A/R Summary (Reports, then "A/R Aging Summary" under ACCOUNTS RECEIVABLE in the left menu).
- Open Inventory Value (Reports, then "Inventory Value" under PARTS in the left menu) again from the Reports menu.
EXP: Expected Result
Step 1:
- Inventory Value narrows to location A.Step 2:
- A/R Summary opens.Step 3:
- Inventory Value opens again.
- Its Location filter is kept, or forgotten, exactly as you noted before the release.
Why: the six reports must not remember filters (they reuse the shared filter parts with that switched off); the other reports, which share those parts, must keep doing whatever they did before.
