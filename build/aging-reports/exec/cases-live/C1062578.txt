C1062578 A/R Collection: a Location sort returns to Date order when one location is left
PRE: Preconditions
- Sign in as an Admin user (the "Admin" role).
- Have open documents in these reports at two locations, location A and location B, with location A's name first in A to Z order.
- Have a customer, customer A, with three overdue invoices: invoice A at location B dated 40 days ago, invoice B at location A dated 20 days ago and invoice C at location A dated 30 days ago.
- Use a desktop browser window 1440 px wide.
- Open A/R Collection (Reports, then "A/R Aging Collection" under ACCOUNTS RECEIVABLE in the left menu).
- Leave the report with only customer A ticked in the Customer filter.Setup
- Locations to use: Use "Staging Heavy Duty - 9919" as location A (it comes first in A to Z order) and "Staging Lethbridge - 4310" as location B. To work at location B, click the location name and your initials at the top right of the top bar, then Change Location, then "Staging Lethbridge - 4310"; switch back to "Staging Heavy Duty - 9919" the same way when you are done.
- Make customer A: Click Customers in the top bar, then New Customer. Type a new Name for customer A, type a Phone, then click Save. On the customer's page click the edit icon beside the name; in Edit Customer pick Credit Terms "Net 30", pick Taxes "Exempt (0%)" and type 0 in Default Shop Supplies (so totals stay exact), then click Save. Click Add Contact, type a First name and Last name, then click Save. On the Assets tab click New Asset, pick the Contact, fill Make and the other boxes the window marks as required, then click Save.
- Make invoice A: While switched to location B (see the Locations to use item): First set customer A's Credit Terms to "Due on Receipt" (edit icon beside the name, Edit Customer, Save), so this invoice falls due on its own date; set them back to "Net 30" right after. On customer A's page click New Work Order, pick the Asset, then click Save (click Ok if a Customer Notes window opens). In the New Line window type a Title, pick Labor Rate "Fixed Line Total" (type "Fixed" in the box to find it), type 100.00 in Fixed Line Total, tick Line Approved, then click Save & Close. On the line click Complete; in Tech stories type a story and click Complete All Lines (if Missing Details asks for Mileage, type it and click Complete All Lines again). Open the Finance tab and click Mark Reviewed (if a window asks for the VIN, type one and click Confirm Review). Type the date 40 days before today in Invoice Date, then click Create Invoice. When the New Customer Payment window opens, reload the page (F5) so the invoice stays unpaid. Do not close that window with its ×: that takes the new invoice away again.
- Make invoice B: First set customer A's Credit Terms to "Due on Receipt" (edit icon beside the name, Edit Customer, Save), so this invoice falls due on its own date; set them back to "Net 30" right after. Same way as invoice A, on customer A's page: Fixed Line Total 200.00; type the date 20 days before today in Invoice Date; then in the New Customer Payment window reload the page (F5) so the invoice stays unpaid. Do not close that window with its ×: that takes the new invoice away again.
- Make invoice C: First set customer A's Credit Terms to "Due on Receipt" (edit icon beside the name, Edit Customer, Save), so this invoice falls due on its own date; set them back to "Net 30" right after. Same way as invoice A, on customer A's page: Fixed Line Total 300.00; type the date 30 days before today in Invoice Date; then in the New Customer Payment window reload the page (F5) so the invoice stays unpaid. Do not close that window with its ×: that takes the new invoice away again.
STEPS: - Expand customer A's group.
- Click the "Location" header.
- In the Location menu, untick location B.
- Expand customer A's group.
EXP: Expected Result
Step 1:
- Invoice A, invoice C and invoice B are listed, oldest date first.Step 2:
- "Location" is marked as the sorted column (a small arrow beside its heading).
- Invoice B and invoice C (location A) are above invoice A (location B).Step 3:
- The Location column is no longer shown.
- Every group is collapsed.
- "Date" is marked as the sorted column again: the report is back in its opening order.Step 4:
- Invoice C (30 days ago) is above invoice B (20 days ago): oldest date first.
- Invoice A is no longer listed.
Exact quotes from the source (for reproducibility)
From: PRD "A/R and A/P Report Sorting, Export and Location Filter", Confluence 947650561, version 11 (5 Nov 2026, Chris Ward), read 10 Nov 2026 · Epic SV-11315, story SV-11531 (Story 1, Reports open in QuickBooks name order), story SV-11532 (Story 2, Sort by clicking any column header), story SV-11534 (Story 4, Collapse all, Expand all and pinned group rows), story SV-11536 (Story 6, Location column)
- S2-R7a: “If the report is sorted by Location and the Location column then hides (Story 6), whether the Location filter is narrowed to one location or a new as-of date leaves only one location in the list, the sort returns to the opening order (Story 1), so a sorted header is always visible.”
- S1-R6: “A/R Collection groups by customer and A/P Unpaid Invoices by vendor, groups in name order (S1-R2 to S1-R4); inside each group, rows open oldest date first; rows on the same date, whatever the time of day they were created, go in document-number order (S2-R4).”
- S1-R7: “The column the report opened on is marked as sorted: the name column on the Summaries and Detail reports, the Date column on Collection and Unpaid Invoices.”
- S6-R2: “The column is shown when two or more locations are ticked (All locations counts when the report's list has two or more) and hidden when one or none is ticked.”
- S4-N1: “Changing the as-of date, the customer or vendor filter, the Past due filter or the Location filter collapses every group, as changing the date or filter does today.”Last checked against build v26.45.2-6a8b89c (QA site sv11315) on 11/10/2026.
