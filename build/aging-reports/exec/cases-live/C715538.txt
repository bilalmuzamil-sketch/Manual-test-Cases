C715538 Design: A/R Collection after Expand all matches the design picture
PRE: Preconditions
- Sign in as an Admin user (the "Admin" role).
- Have open documents in this report at two locations, so the Location column shows.
- Make sure your role has the "View and Manage AP/AR Data" switch on, so the credit term shows.
- Make sure customer A, first in name order, has an overdue invoice, an unused credit memo, a phone number and a credit term.
- Use a desktop browser window 1440 px wide, in light theme at 100% zoom.
- Open A/R Collection (Reports, then "A/R Aging Collection" under ACCOUNTS RECEIVABLE in the left menu).
- Leave the report with every group collapsed.
- Open the design picture "Expand all from the header" (ar-ap-p3-expand-all-from-the-header.png) (attached to this case) beside the browser at 100% zoom; compare the layout, labels and styles, not the names and amounts, which are only examples.Setup
- Make customer A: Click Customers in the top bar, then New Customer. Type the Name 000 ZZAUTOTEST First Customer (a name that sorts first), type a Phone, then click Save. On the customer's page click the edit icon beside the name; in Edit Customer pick Credit Terms "Net 30", pick Taxes "Exempt (0%)" and type 0 in Default Shop Supplies (so totals stay exact), then click Save. Click Add Contact, type a First name and Last name, then click Save. On the Assets tab click New Asset, pick the Contact, fill Make and the other boxes the window marks as required, then click Save.
- Make invoice 1: On customer A's page click New Work Order, pick the Asset, then click Save (click Ok if a Customer Notes window opens). In the New Line window type a Title, pick Labor Rate "Fixed Line Total" (type "Fixed" in the box to find it), type 100.00 in Fixed Line Total, tick Line Approved, then click Save & Close. On the line click Complete; in Tech stories type a story and click Complete All Lines (if Missing Details asks for Mileage, type it and click Complete All Lines again). Open the Finance tab and click Mark Reviewed (if a window asks for the VIN, type one and click Confirm Review). Type the date 45 days before today in Invoice Date, then click Create Invoice. When the New Customer Payment window opens, reload the page (F5) so the invoice stays unpaid. Do not close that window with its ×: that takes the new invoice away again.
- Make credit memo 1: On customer A's page open the Invoices tab and click Issue Credit. Type today's date in Credit Date, type 50.00 in Amount, click Issue Store Credit (not Issue Refund), type a Reason, then click Issue Credit.
STEPS: - Click the chevron button in the table's top-left header cell.
