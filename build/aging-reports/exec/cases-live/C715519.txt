C715519 Design: the Switch location? dialog for a work order at another location
PRE: Preconditions
- Sign in as an Admin user (the "Admin" role).
- Have open documents in these reports at two locations, your current location and location B.
- Make sure you are enrolled at both locations.
- Have a customer with an open work order invoice A made at location B.
- Use a desktop browser window 1440 px wide, in light theme at 100% zoom.
- Open A/R Detail (Reports, then "A/R Aging Detail" under ACCOUNTS RECEIVABLE in the left menu).
- Leave the report with that customer ticked and its rows showing.
- Open a link to a work order made at location B (copied from the address bar) in a second tab, so the existing location-switch prompt shows there for comparison.
STEPS: - Click invoice A's number.
- Compare the dialog with the location-switch prompt open in the second tab.
- On the report's tab, click "Cancel".
- Switch ShopView to dark theme.
- Click invoice A's number again.
EXP: Expected Result
Step 1:
- A dialog opens over the report.
- Read letter for letter, in order: title "Switch location?", message "This work order is in " then location B's name and "Switch your active location to view it?", then the button "Cancel" on the left and the button "Switch location" (small l) on the right, and a close "×" at the top right.Step 2:
- It is the existing location-switch prompt: the same look, buttons and position as the prompt in the second tab.Step 3:
- The dialog closes.Step 4:
- The page switches to dark theme.Step 5:
- The dialog opens again and is readable in dark theme.
What you should see today: in step 1, the right-hand button of the "Switch location?" dialog reads "Switch Location" with a capital L instead of "Switch location". This is a known problem and it is already reported — see https://shopview.atlassian.net/browse/SV-12139 (filed by Chris Ward on 3 Nov 2026).
