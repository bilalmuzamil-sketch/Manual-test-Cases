C715468 A/R Summary: a PDF of exactly 2,000 customers downloads, 2,001 is refused
PRE: Preconditions
- Sign in as an Admin user (the "Admin" role).
- Pick two as-of dates: date A, on which A/R Summary lists exactly 2,000 customers, and date B, on which it lists exactly 2,001.
- Use a desktop browser window 1440 px wide.
- Open A/R Summary (Reports, then "A/R Aging Summary" under ACCOUNTS RECEIVABLE in the left menu).
STEPS: - Set the as-of date to date A.
- Choose "Download (PDF)" from the ⋯ menu.
- Set the as-of date to date B.
- Choose "Download (PDF)" from the ⋯ menu.
EXP: Expected Result
Step 1:
- 2,000 customer rows (the Totals row is not counted).Step 2:
- The PDF downloads with the "Success" message.Step 3:
- 2,001 customer rows.Step 4:
- "This report is too large for PDF. Export it as CSV, or narrow the filters, then try again.": exactly one message and no PDF downloaded (no new file in the browser's downloads).
The row count is the customers listed, not the Totals row. No test site has 2,000 customers with open invoices (the QA organization has 46), so this exact boundary is checked by the developers (SV-11595); the PDF boundary itself is checked by hand on A/P Detail.
Exact quotes from the source (for reproducibility)
From: PRD "A/R and A/P Report Sorting, Export and Location Filter", Confluence 947650561, version 11 (5 Nov 2026, Chris Ward), read 10 Nov 2026 · Epic SV-11315, story SV-11533 (Story 3, Export to PDF and CSV)
- S3-N1: “Over 2,000 rows, the PDF is refused before anything is generated: no download, and the message "This report is too large for PDF. Export it as CSV, or narrow the filters, then try again." Exactly 2,000 rows is allowed.”
- S3-R9: “The row count for the export limits is the number of customer or vendor rows (Summaries) or document rows (the other four), not counting headers, subtotals or the Totals row.”
- S3-N3: “A refused export shows exactly one message (S3-N1 or S3-N2), never a second generic error.”Last checked against build v26.45.2-6a8b89c (QA site sv11315) on 11/10/2026.
