Tested on the QA branch [https://sv9138.qa.shopview.com] (build {{v26.40.12-944b391}}) on 8 October 2026. All 10 checks passed.

New duplicate "Uncategorized" categories can no longer be created. On production today, importing a parts file whose Category column has "Uncategorized" with extra spaces or in capitals adds a new "Uncategorized" category every time. On this branch, the same file puts every part into the one existing "Uncategorized" category, and both places named in the ticket (the Category dropdown and Settings > Categories) show it once.

h3. How to see it yourself

# Log in at [https://sv9138.qa.shopview.com], then open [https://sv9138.qa.shopview.com/administration/categories]. This is *Categories* (left-hand menu, under *PARTS*). The first row reads {{Uncategorized}} with a blue {{Default}} badge, and there is no second "Uncategorized" anywhere in the list.
# In the top menu, click {{Parts}}. In the left-hand menu, click {{Inventory}}. Click the blue {{New Inventory Part}} button at the top right, then click the {{Category}} box. The list starts with one {{Uncategorized}}, then {{70%override}}.
# Close the window. In the search box next to the word *Inventory* at the top left, type {{ZZ9138-}}. You see the parts ZZ9138-A to ZZ9138-I from my test file. In the {{Category}} column, A to F read {{Uncategorized}}, G and H read {{ZZAUTOTEST-9138-Cat}}, and I reads {{HD-Fasteners}}.
# To run the import yourself, download the attached [^SV-9138-test-import.csv] (you can use it as it is). Open [https://sv9138.qa.shopview.com/administration/inventory-import] (left-hand menu, under *IMPORTS*, {{Inventory}}), click {{Select CSV File}} and pick the file, click {{Submit File}} at the top right, then click the green {{Import Inventory}} button. Go back to *Categories*: there is still only one {{Uncategorized}}, and nothing new has appeared.
# Still on *Categories*, click the blue {{New Category}} button at the top right and type {{Uncategorized}} with a space in front of it. An orange {{Category Name Is Already In Use.}} warning appears under the name and {{Save & Close}} stays greyed out.
