======================== PAGE turn-2 — ROUND 2 · ALIGNED AND LABELLED / Mark OK on one edge, with a clear marked state ========================
ROUND 2 · ALIGNED AND LABELLED
Mark OK on one edge, with a clear marked state

Every option keeps a text label and puts the section, field and axle actions on one vertical line. Axle 2 is shown after it was marked, so each option also shows what “marked OK” looks like. The dashed line marks the shared edge.

2a
One right edge, one button shape
Axles run full width inside the field card, so the section, field and axle actions all end 16px from the same edge. Every action is the same 150px green-outline button with a label. Once used it turns solid green and reads Marked OK, with Undo beside it.

2c
A checkbox that shows the state
Each level gets the same labelled checkbox on the same right edge: Section OK, Field OK, Axle OK, with the count still open. Ticking it sets what is left to OK. It shows as ticked whenever everything under it is OK, however that happened, so it is status as well as action.

Mark OK: four directions

Same screen in every board: section Brakes, one checkbox field, one per-axle field with Axle 1 partly filled. Each option only ever sets unanswered positions to OK and keeps the Undo that follows it today. 1a and 1b keep the action where it is and change its form; 1c and 1d move it out of the headers.
