Digital Inspections V2

Every screen in one document, in the order the work happens: a manager builds the template, a technician fills it on a laptop or a phone, and the findings become work order lines. Two rules run through all of it. Nothing is required, so nothing is auto-filled; the neutral state is Not inspected and it stays that way until someone says otherwise. And a verdict belongs to the smallest thing it describes: one tire position. Every roll-up above that is derived, never stored.

Fill screen: desktop

A dual axle records four tire pressures, so it needs four verdicts. Each value carries its own: a dropdown attached to the input it judges, so left outer can be Not OK while left inner is OK. That grid is the whole record: no status column, no per-row legend, no axle roll-up badge, no counters. Colour lives on the value that earned it and on the control you press. A tire in the top view takes the worst verdict entered for it so far and stays grey until one arrives; nothing is ever auto-filled. Switching Single / Dual asks nothing; typed values come back if you switch back. Marking OK in bulk exists at three levels: the inspection row, the section row, and every field’s own card header, whatever its type. Mark all OK, Mark section OK and Mark field OK are the same quiet action on the same right edge, so the level is read from the row it sits on rather than from the label. Each fills only what is still Not inspected, never overwrites a verdict already picked, and never writes a value.

SERVICE BULLETIN Page 1 of 3
Slack Adjuster Travel, Measurement Procedure Applies to air-brake foundation assemblies on tractors and trailers.

Free stroke and applied stroke must both be measured with the system at full reservoir pressure. Chock the wheels and release the parking brake before beginning.

Before you start

Air pressure at or above 90 psi. Engine off. Wheels chocked. Parking brake released and the transmission in neutral.

Measuring free stroke
1Mark the push rod where it leaves the chamber with the brakes fully released.
2Using a lever, move the slack adjuster until the shoes contact the drum.
3Measure between the mark and the chamber face. Free stroke should read between 3/8 in. and 5/8 in.
Measuring applied stroke
4Have an assistant make a full brake application and hold it.
5Measure the total travel of the push rod. Compare against the chamber size table on page 2.

Record both figures on the inspection. Travel beyond the readjustment limit is an out-of-service condition under FMCSA Appendix G.

SERVICE BULLETIN Page 2 of 3
Readjustment limits by chamber size
CHAMBEROUTSIDE DIA.LIMIT
Type 124 21/32 in.1 3/8 in.
Type 165 1/4 in.1 3/4 in.
Type 205 1/2 in.1 3/4 in.
Type 245 25/32 in.1 3/4 in.
Type 306 3/8 in.2 in.

Measure the outside diameter of the chamber to identify the type when the stamping is not legible. If the reading is within 1/8 in. of the limit, mark the position Monitor and note the figure so the next PM can compare.

Common causes of excessive travel

Worn brake lining, a stretched or misaligned push rod, a seized automatic slack adjuster, or a chamber diaphragm that has begun to leak. Replace the adjuster rather than attempting to free a seized unit.

SERVICE BULLETIN Page 3 of 3
Recording the result

Enter both figures on the inspection against the axle and position measured. A position beyond the readjustment limit is Not OK, requires a note describing the cause, and requires a photograph of the assembly.

Out-of-service criteria

Under FMCSA Appendix G a vehicle is placed out of service when 20 percent or more of the brakes on the unit are defective. A single brake beyond the adjustment limit counts as defective for that calculation.

Torque values
Clamp band—25–30 ft-lbs
Chamber mounting nuts—85–115 ft-lbs
Slack adjuster clevis—35–40 ft-lbs

Re-check free stroke after any adjuster or chamber replacement, and again after a short road test.

Bulletin SB-2024-11 · supersedes SB-2019-04 · for reference only, always follow the manufacturer’s current service literature.

Pressing it asks nothing: the technician lands on the work order with the lines already proposed and pre-selected, reviewing rather than instructing. The same action and the same panel appear wherever a finished inspection is met, on the inspection itself, on the work order’s Notes tab, in the unit’s Inspections list, and started from the work order with no inspection at all.

SV-8181 · DIGITAL INSPECTIONS V2 · CONDITIONAL FOLLOW-UP

A follow-up attached to one response

The reference file on a checkbox field is unconditional: the technician sees it whatever they answer. A follow-up is the same content, text plus one optional file, tied to a single response and shown only when that response is given. The technician reads it on the card as an instruction; the builder calls it a follow-up, because that is what the author is adding. Acknowledgement is offered on Monitor and Not OK only, on by default, and the author can turn it off. Follow-ups on OK and N/A are read-only and never need acknowledging. Where it is on, the inspection cannot be submitted until the technician has confirmed they read it. It carries no colour of its own. The blue already used for the reference file marks it as something to read, and the acknowledgement pill takes the colour of the response that triggered it, so red and amber keep meaning what they mean. Per axle fields do not carry follow-ups: a verdict there belongs to a position, and a follow-up would have no single position to sit on.
