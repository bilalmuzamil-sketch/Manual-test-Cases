* A Tech View role with *Customers → View* only (the Technician) sees no checkbox on customer and asset notes. It should show greyed out.

h3. What it should be

Chris stated in [comment 77996|https://shopview.atlassian.net/browse/SV-10323?focusedCommentId=77996]:

{quote}"Everywhere else (customer, asset and part sale notes), follow S10-R5b: edit permission for that record means the checkbox works, view-only means it shows greyed out. The Full View rule no longer applies to those."{quote}

Spec S10-R5b (Notifications Update V1, version 28) states:

{quote}"A user who can only view the record sees the checkbox disabled, so they can still tell which files the customer sees. Exception: on work order and work order line notes, a role whose Work Orders view is set to Tech View does not see the checkbox at all, as today."{quote}
