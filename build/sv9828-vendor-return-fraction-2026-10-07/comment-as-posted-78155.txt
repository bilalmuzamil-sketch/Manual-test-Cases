h3. How to see it yourself

On screen, with the Create Return path (the part's stock is shown on screen):
# Open [sv9828.qa.shopview.com|https://sv9828.qa.shopview.com] and click the *Admin* quick-login button.
# In the top menu, click {{Parts}}. The {{Inventory}} page opens.
# Above the list, click {{Search}} and type *MD668D*. Its row shows a stock badge, for example *15.75 Available*. Note the number.
# In the left menu, click {{Returns}}, then click {{Create Return}} at the top right.
# In {{Vendor}}, choose *Roselle Park Trailer Repair Ltd*.
# In {{Part Number}}, type *MD668D* and pick the row that says *Inventory Qty*.
# In the {{Qty To Return}} column, type *2.5* in the {{Quantity}} box, then click {{Save Return}}.
# Go back to {{Parts}} > {{Inventory}} and search *MD668D* again. The badge has dropped by exactly 2.5 (for example 15.75 > 13.25).

The core return, the path this ticket fixes: work order *S9828-17586* already has a core waiting.
# In {{Parts}} > {{Returns}}, tick the box at the left of the row *S9828-17586 ... Core for FUEL/W.. 2.50*, then click {{Receive Credit}}.
# On the {{Process Return}} screen, type any {{Credit Memo Number}}, leave {{Accepted Quantity}} at *2.50*, and click {{Post Credit}}.
# The core's stock drops by exactly 2.5. Core parts are not listed under Parts > Inventory, so this number can only be checked behind the screen.
