# SV-12457 Tiered Pricing - Story 5 - Price Part Simulator

## Description

## Summary

On a matrix page, a parts manager types any part cost and sees what Default and every tier would sell it for and the profit, so they can check a matrix before a customer sees the price. Nothing is saved.

## Context

* Role: user with 'Settings — Parts' and 'See Financial Data', on a matrix page (Story 3). Desktop only (settings).
* Prices follow the pricing order in Story 10, including Same as previous tier.

## Requirements

* S5-R1: Under the grid on the matrix page, on both tabs, a separate table titled "Price Part Simulator" with the info tooltip "Type a part cost to see each tier's price and profit. Nothing is saved." has one Part Cost field in dollars, starting at $100.00. Its columns line up with the grid's. Tier pages and category pages have no simulator.
* S5-R2: For the typed cost, the table shows under Default and each active tier the sell price and the profit ("$12.50 profit") for a part in a category on this matrix, on that tab's side. Profit is sell price minus cost, per unit, before Fees & Discounts, rounded to the cent.
* S5-R3: Prices follow Story 10 exactly, Same as previous tier included. A cost on a range boundary is priced by the range that contains it; a cost with more than two decimals is rounded to the cent first.
* S5-R4: The table updates as the cost is typed and, while the grid is in edit, reflects the unsaved values.
* S5-R5: A negative profit shows with a minus sign; a sell price below the cost shows the below-cost warning icon with the tooltip "Below cost."
* S5-R6: Nothing typed in the simulator is saved or changes a price.
* S5-N1: An empty cost, zero, or a value that isn't a number shows an error on the field and "—" under every column.

## Acceptance Criteria

- [ ] Given a matrix page, when it opens, then the "Price Part Simulator" table shows under the grid with Part Cost $100.00 and a sell price and profit under Default and each active tier, its columns lined up with the grid's.
- [ ] Given the Part Sale Matrix tab, then the simulator prices from the Part Sale side.
- [ ] Given a tier page or a category page, then there is no simulator.
- [ ] Given Default is 35% markup and Tier 2 is 10% off, when the cost is $100.00, then Default shows $135.00 and $35.00 profit, and Tier 2 shows $121.50 and $21.50 profit.
- [ ] Given a tier on Same as previous tier, then it shows the same price as the tier before it.
- [ ] Given a cost exactly on a range boundary, then the range that contains it prices it; given $10.005, then it is priced as $10.01.
- [ ] Given the grid is in edit, when a value is changed and not saved, then the simulator shows the unsaved result; after Cancel it shows the saved result.
- [ ] Given a tier that sells below cost, then its price shows the below-cost warning icon with "Below cost." and a negative profit with a minus sign.
- [ ] Given an empty cost, 0 or "abc", then the field shows an error and every column shows "—".
- [ ] Given any cost is typed and the user leaves the page, then nothing is saved and no price changes.
