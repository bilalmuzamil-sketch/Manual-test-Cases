# SV-4387 Fixed sell price vs. Matrix

## Description

**Fixed sell price is always top priority if it’s configured, no matter what is going on with Price Matrix.**

‌

**Update Matrix**

Steps:

* Set matrix for the category
* Set a fixed sell price for any part in that category
* Change the matrix rule (markup) for that category

Actual:

* Sell Price is recalculated using the updated matrix and the Fixed Sell price is removed

Expected:

* Fixed price should not be removed for added or new parts, it should always be higher priority than matrix price
* sell price for any _new part_ that doesn’t have fixed price added to WO _should be updated_ with the price from matrix 
* sell price for all _already added parts_ that don’t have fixed price _shouldn’t be updated_ on WO (any status of WO: completed, in progress, approved…)

---

**Delete Matrix Rule**

Steps:

* Set matrix rules for the category
* Set a fixed sell price for any part in that category
* Delete the matrix rule that included the part’s cost range
* Leave other rules
* Save & Close

Actual:

* The Sell Price is recalculated using the remaining matrix rules, even if the part does not match any of them, and the Fixed Sell Price is removed

Expected:

* the fixed sell price remains for that part, deletion of the matrix doesn’t have any impact on the price

---

**Delete Matrix Category**

Steps:

* Set matrix for the category
* Set a fixed sell price for any part in that category
* Delete matrix category

Actual:

* Sell Price is removed completely

Expected:

* Fixed sell price remains for that part, deletion of the category doesn’t impact price if there's fixed sell price for that part

---

**Delete All Matrix Rules**

Steps:

* Set matrix for the category
* Set a fixed sell price for any part in that category
* Delete all matrix rules
* Save & Close

Actual:

* Sell Price is removed completely

Expected:

* Fixed sell price remains for that part, deletion of the matrix doesn’t impact price if there's fixed sell price for that part
