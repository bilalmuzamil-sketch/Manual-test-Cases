# SV-12679 Verify: Categories list, category page, New Category, name rules and category delete (Phase 16)

## Description

**Covers:** TP-S7-R1, R2, R4, R6, R9, R11–R13, R15, N1; TP-S8-R1, R3, R4, R8, R10, N3, E1, E2; TP-S16-R8, R11; TP-S19-R3, R6, R14, R19; decisions D29, D31

**Checklist**

1. List on `/administration/categories` (TP-S7-R1, TP-S7-R4): Category, Pricing Matrix (the General Matrix with its Default badge), Default, then one column per active tier with its number and name. Uncategorized first, then A to Z, with more loading as you scroll. Search matches category and matrix names; sorting by Category or Pricing Matrix keeps Uncategorized first; no match reads 'No categories match the search "…".' with Clear Search; search and sort are kept on return.
2. Cells and hover (TP-S7-R2, TP-S4-R31, D29, D31): each Default and tier cell sums up its Work Order side rule: one rule as "35% markup", "30% margin", "Cost + $5", "10% off" or "$5 off"; one type with different values as "% markup", "% margin", "Cost + $", "% off" or "$ off"; different types as "Mixed rules"; or "Uses previous tier". The hover lists each cost range on its own line ("$0.00 to $25.00: 35% markup"; the last reads "<start> and up: …"), with the popover spinner while it loads. A "Uses previous tier" cell reads "Uses previous tier, 2 · Wholesale." or, through a chain, "Uses previous tier, 3 · Fleet. Priced by 2 · Wholesale's rule."
3. Restricted role (TP-S16-R8, TP-S16-R11, TP-S7-N1): with 'Settings — Parts' but not 'See Financial Data', the list shows only the Category column, and New Category and a category's page show no Pricing Matrix field and no grid; a new category uses the General Matrix. Without 'Settings — Parts' there is no Categories page.
4. Category page (TP-S7-R6, TP-S7-R9, TP-S7-R12, TP-S7-R15): a click anywhere on a row opens it with the breadcrumb Settings › Categories › <category>. The name renames in place. Picking another Pricing Matrix moves the category at once, shows that grid and confirms "<category> now uses <matrix>" with "Parts already on work orders keep their prices." QuickBooks Products and Services (only when QuickBooks is connected) and Tax Exempt save on change. The read-only grid has no simulator, and the line above it reads "The <matrix> matrix also prices <n> other categories: <A> · <B>." or, for the General Matrix, "The General Matrix also prices every other category without a matrix of its own (<n>)."
5. Edit (TP-S7-R13, TP-S8-R4): when only this category uses the matrix, Edit opens the matrix in edit, and the breadcrumb leads back here. Otherwise Edit is grayed with "Can't edit here. The <matrix> matrix prices <n> categories, so edit it from the matrix." and a "Go to the <matrix> matrix" link. Uncategorized's page is read-only (no rename, Delete or matrix picker), with Edit grayed and a link to the General Matrix.
6. New Category (TP-S8-R10, TP-S19-R3, TP-S19-R14, TP-S7-R11): a name, a Pricing Matrix (the General Matrix unless another is picked), QuickBooks Products and Services, Tax Exempt and the picked matrix's read-only grid, with Save and Cancel. Cancel creates nothing, and leaving with changes asks "Discard these changes?" New Matrix on a category's page opens a new matrix with that category picked.
7. Names (TP-S8-N3): in New Category, or as a rename on the category page, a duplicate in other capitals shows "A category called <name> already exists" inline under the name, and a name under 3 characters is refused as today; "Credits not tied to a part" is an ordinary name.
8. Delete (TP-S8-R8, TP-S8-E1, TP-S8-E2): on a category that parts use, Delete in the page's ⋯ menu asks "Delete <category>?" with "Its parts and lines, invoiced ones included, move to Uncategorized, and its QuickBooks mapping is removed. Invoices already sent aren't sent again; one synced again later books these parts to Uncategorized's QuickBooks item. This can't be undone." and Cancel / Delete (red), with no counts. Afterwards its parts and lines show Uncategorized with unchanged prices, and its matrix is still in the Matrices list.
9. Audit Log (TP-S19-R19): "Audit Log: <category>" from the category page and "Audit Log: Categories" from the list, showing the category events, deleted categories included.
