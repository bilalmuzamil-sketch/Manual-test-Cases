# SV-12753 Verify: the report page: filters, page address, Totals, column chooser, empty and error states (Phases 3 and 11)

## Description

**Covers:** RPT-S1-R2, R3, R6–R14, N1, E1, E2, E4–E9, EH1; RPT-S2-R1–R5, N1, E1, EH1; RPT-S3-R1–R10, R12, N1, E1; RPT-S5-R1–R6, N1, E1–E4, EH1; RPT-UF1, RPT-UF2, RPT-UF6; decisions R-D13, R-D16, R-D25, R-D28

**Checklist**

1. Filters (RPT-S3-R1, RPT-S3-R3, RPT-S3-R5, RPT-S3-R9): as `admin` on `/reports/sales-by-tier`, the chips are Date range (first, required, this month by default, one year at most), Priced By, Category, Customer, Sales Type and Location (last). Priced By lists every tier, archived ones marked "(archived)", then Fixed price, Fixed line total, Manual and Before tiers; Category lists Uncategorized first, then A to Z; Sales Type has "Part Sales" and "Work Orders". All are selected by default.
2. Customer and Location (RPT-S3-R4, RPT-S3-R2, R-D13): the Customer chip searches for one or more customers as on Sales by Customer, through the report's own customer search, which also finds a customer whose only activity in the range is a credit with part lines; empty means all. Location is multi-select, opens on the signed-in location, is hidden for a user with one location, and carries over when the user switches location; a Location column shows only when more than one location is in scope.
3. Columns (RPT-S1-R6): the first column, then Parts Cost, Parts Invoiced (bold), Parts Credits, Parts Net, Parts Margin, Parts Margin % and % of Total, whose info tooltip reads "Share of Parts Invoiced for everything that matches your filters."
4. Totals (RPT-S1-R7): a bold "Totals" row stays at the bottom while scrolling and sums the whole filtered result, not only the rows loaded.
5. Column chooser (RPT-S1-R14, R-D25): it can hide Parts Cost, Parts Credits, Parts Net, Parts Margin, Parts Margin % and % of Total, while the first column and Parts Invoiced always show. Hide Parts Margin, sort by Parts Invoiced and reload: the column stays hidden and the sort is back to the first-load order. The choice is remembered per report and per browser.
6. Page address (RPT-S3-R6, R-D28): the filters are in the page address, so back, reload, a link or a bookmark reopens the same view, "Sales Type: None" included; a new visit starts from the defaults. Requests send `salesType` as one value (both → `all`, Part Sales → `parts`, Work Orders → `service`, neither → `none`) and the other parameter names from the plan's Section 5.
7. Empty states (RPT-S1-N1, RPT-S3-N1, RPT-UF1, RPT-UF2): with default filters and nothing invoiced or credited in the range, the page shows "There are no results for selected date range" and no Totals row. Filters that match nothing, Sales Type None included, show "No record matches these filters", "Try changing filters to widen your results." and a "Clear All Filters" button, with no Totals row. No empty state shows before the first load finishes.
8. Load error (RPT-S1-EH1, RPT-S5-EH1, RPT-UF6): a failed load shows Sales by Customer's report error state and keeps the filters, and never says there are no results.
9. Sales by Category (RPT-S5-R1, RPT-S5-N1): the same page with "Category" as the first column, and the same filters, columns, Totals, chooser and states.
10. Browser console shows no red errors during this walk.
