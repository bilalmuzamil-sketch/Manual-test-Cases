# SV-11696 Tiered Pricing - Story 6 - Every matrix in one list

## Description

## Summary

Settings › Pricing gets Tiers, Matrices and Fixed Rules tabs, and the Matrices tab lists every reusable matrix with its status, categories and tiers, with search and filters. A parts manager finds any matrix and gives the same pricing to several categories.

## Context

* Role: user with 'Settings — Parts' and 'See Financial Data'. Desktop only (settings).
* What must be true first: the matrix library (Story 1) and the matrix page (Story 3).
* Dependency: this list replaces the pricing matrices sorting work in SV-11258; the tech plan decides whether that work ships first or folds into this list.

## Requirements

* S6-R11: Settings › Pricing has Tiers, Matrices and Fixed Rules tabs, replacing today's Pricing matrices and Fixed rules tabs. Fixed Rules lists only fixed rules, as today.
* S6-R1: Matrices lists every matrix with Matrix, Status, Categories, Tiers, Work Order Matrix (Default's rules in short) and Part Sale Matrix (On or Off). Status is Active or Inactive, with "No categories use this matrix" on hover for Inactive.
* S6-R10: Tiers reads "All" when every active tier has its own rules in the matrix, otherwise the numbers of the tiers that do ("1, 2, 4"), names on hover. Default always counts; archived tiers never show; only the Work Order Matrix side counts.
* S6-R8: The General Matrix is first with the Default badge; its Categories cell reads "All categories without a matrix (n)", Uncategorized included.
* S6-R7: Other matrices show up to three category names, then "+N" with the full list on hover; a matrix with no categories shows "—" and stays listed.
* S6-R9: Each row has Edit (opens the matrix in edit) and a More Actions menu with Duplicate and Delete, as on the Digital Vehicle Inspection templates list. New Matrix opens a new matrix page that can be cancelled before it is saved.
* S6-R2: Search matches matrix and category names; a Status filter (Active, Inactive).
* S6-R3: No search match: 'No matrices match the search "…".' with Clear Search; no filter match: "No matrices match these filters" with Clear All Filters.
* S6-R6: 50 matrices a page, the General Matrix first, then A to Z. Matrix and Categories sort; Categories sorts by the number of categories, most first on the first click. Search, sort and page are kept on return.
* S3-N3 applies here: the General Matrix's Delete is disabled.
* Error: a failed load shows "Ooooops! An error occurred" with Try again, keeping search, sort and page.

## Acceptance Criteria

- [ ] Given Settings › Pricing, then it shows Tiers, Matrices and Fixed Rules tabs, and Fixed Rules lists only fixed rules.
- [ ] Given the Matrices tab, then it shows Matrix, Status, Categories, Tiers, Work Order Matrix and Part Sale Matrix, with the General Matrix first with the Default badge, then A to Z.
- [ ] Given an Inactive matrix, then Status reads Inactive and hover shows "No categories use this matrix"; its Categories cell shows "—" and it stays listed.
- [ ] Given a matrix with 5 categories, then 3 names show, then "+2" with the full list on hover.
- [ ] Given the General Matrix, then its Categories cell reads "All categories without a matrix (n)" with n counting those categories now, Uncategorized included.
- [ ] Given tiers 1–4 where tiers 2 and 4 have their own rules on the work order side, then Tiers reads "1, 2, 4" with names on hover; given every active tier has its own rules, then "All"; an archived tier with rules never shows; Part Sale side rules don't change the cell.
- [ ] Given Default is 35% markup in every range, then Work Order Matrix reads "35% markup"; given the Part Sale switch on, then Part Sale Matrix reads On.
- [ ] Given a row, then Edit opens the matrix page in edit, and More Actions offers Duplicate and Delete; for the General Matrix, Delete is disabled.
- [ ] Given New Matrix, then a new matrix page opens and cancelling creates nothing.
- [ ] Given a search for "brak", then matrices whose name or a category name contains it show; given no match, then 'No matrices match the search "…".' with Clear Search.
- [ ] Given the Status filter on Inactive with none, then "No matrices match these filters" with Clear All Filters.
- [ ] Given more than 50 matrices, then the list pages at 50; given a sort by Categories and page 2, when the user opens a matrix and comes back, then search, sort and page are kept.
- [ ] Given the list fails to load, then "Ooooops! An error occurred" with Try again shows and search, sort and page are kept.
