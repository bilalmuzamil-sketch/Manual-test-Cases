# SV-12680 Verify: customer tier fields in New and Edit Customer and the customer card's Pricing section (Phase 17)

## Description

**Covers:** TP-S9-R1–R5, R7–R12, R14–R24, R27, R30, R31, N1, N3, N6, E2, E3, E5–E7; TP-S16-R4; TP-S19-R18; decision D21

**Checklist**

1. With only Default active, New Customer and Edit Customer show no tier fields (TP-S9-R31). Create a second tier: Edit Customer shows Work Order Tier and Part Sales Tier directly under Default Shop Supplies, before Notes, with no other field moved, and New Customer shows both set to Default; an imported customer starts on Default for both (TP-S9-R2, TP-S9-R3).
2. Pickers (TP-S9-R1, TP-S9-R30, TP-S19-R18): active tiers are listed by number as "4 · Fleet", and archived tiers aren't offered; typing "4" lists tier 4 first, then the tiers whose names contain "4"; changing one field never changes the other.
3. Saving (TP-S9-R7, TP-S9-R27, D21): the dialog says "Existing work orders and Part Sales keep their prices and tier." After the change, the customer's open work orders and Part Sales keep their tier and show no Manual icons, and a new work order prices by the new tier; a work order tier change doesn't affect Part Sales.
4. Counter Sale (TP-S9-R8): on the Counter Sale customer ShopView created when the account was set up, the tier fields show the tooltip "Every walk-in sale uses this tier."; a client-created customer named Counter Sale shows no tooltip.
5. Permissions (TP-S16-R4, TP-S9-R15): 'Customers — Create & Edit' views and changes tiers in Edit Customer and New Customer without 'Settings — Parts'; without it the fields aren't there. 'Customers — View' with 'View and Manage AP/AR Data' shows the tiers read-only in the customer card's Pricing section.
6. Customer card Pricing section (TP-S9-R12, D21): on the customer page, under IBS, "Pricing" shows Labor Rate (the rate at your current location, with "Varies by location" when it differs at another location), Shop Supplies ("No shop supplies", the customer's own charge, or "Location default"), Tax (the picked tax's name exactly as named in Settings, or "Default Tax Settings", the same label Edit Customer shows), then Work Order Tier and Part Sales Tier with their numbers, only when there is more than one active tier.
7. Visibility (TP-S9-R11, TP-S9-R14, TP-S9-R15, TP-S9-R16): the section shows only to users with 'View and Manage AP/AR Data'; it shows for a customer with no address, while the other rows stay as today; the card's edit icon opens Edit Customer. The section shows a skeleton while loading and an inline error with Try again if it fails. The Customers list is unchanged, and Edit Customer works at phone width.
