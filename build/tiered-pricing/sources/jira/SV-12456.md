# SV-12456 Tiered Pricing - Story 4 - The tier grid: every tier of a matrix, edited in place

## Description

## Summary

A parts manager sees and changes every tier's rule for every cost range of a matrix on one grid, so they can compare tiers and fix margins in one place instead of opening each tier separately.

## Context

* Role: user with 'Settings — Parts' and 'See Financial Data'. Desktop only (settings).
* The grid is edited on a matrix page (Work Order Matrix and Part Sale Matrix tabs) and shown read-only on a category's page (Story 7). Rule types, ranges and validation are in Story 3.
* A matrix used by more than one category is edited from the matrix, never from a category (Story 7).

## Requirements

* S4-R1: Columns are Cost Range, Default, then each active tier by number; each tier header shows its number and name, with no tooltip. Rows are the matrix side's cost ranges.
* S4-R27: Default and tier columns share the grid's width evenly, 128px to 176px each, in view, edit and the Price Part Simulator. Below 128px the grid scrolls sideways with Cost Range pinned; the grid is never wider than 1760px. Columns can't be resized; a long tier name is cut short and shows in full on hover. At 1512 wide, at least Default and 3 tiers show without scrolling.
* S4-R3: Each cell shows its rule in short ("10% off", "$5 off", "Cost + $5", "35% markup", "30% margin"); a Same as previous tier column reads "Uses previous tier", and its hover names the tier it follows by number and name, plus the tier whose rule actually prices it when that tier also uses its previous tier: "Uses previous tier, 3 · Fleet. Priced by 2 · Wholesale's rule." There is no "How it's priced" row.
* S4-R4: Edit turns every cell editable. The edit bar shows "No changes yet" or "<n> changes" with Cancel and Save. A new matrix has Cancel and Create Matrix in the page head instead. Only what the user edited counts, against the last saved version; gray auto-fill and cells that follow another column don't count.
* S4-R5: Each column's rule picker sits under its name: Previous tier; Off default price: % Off, $ Off; From cost: + $, Markup %, Margin %. Picking a type applies it to every range of the column and clears its values.
* S4-R28: A From cost cell's $ or % symbol is a small picker that changes that range's type only. A column with different types shows "Mixed rules" in its header picker (never offered as a choice) and in view.
* S4-R31: One-label summaries: one rule everywhere shows its value ("35% markup"); one type with different values shows the type alone ("% markup"); different types show "Mixed rules".
* S4-R29: Tab moves down the column, then to the top of the next column; Shift+Tab goes back. Alt+Down on a From cost value opens that range's rule picker.
* S4-R7: % Off and $ Off take each range's value off Default's sell price in that range; a new rule type starts empty.
* S4-R26: Typing a value fills every range below it that is empty or auto-filled, in gray, with that range's type and value; auto-fill follows the last range entered. Gray values can be typed over and are saved.
* S4-R10: Choosing Same as previous tier fills the column with what the previous tier pays here, editable; unchanged, the tier keeps following the previous tier; changed, it saves as its own rules.
* S4-R12: Save validates (S3-R6), saves every column at once after any question below, and shows "<matrix> saved" with what changed and "Parts already on work orders keep their prices." It names up to three changes, then "and <n> more".
* S4-R20: Cells whose rule changed stay highlighted until the user leaves the page.
* S4-R15: "Default" in every label is the Default tier's current name ("Off Retail price" if renamed); the Default badge keeps reading "Default".
* S4-R30: Saving a change to Default's rules, a range end included, lists every tier that prices from Default in this matrix, one per line, under "Change Default's Prices?" (Cancel / Save); it joins S4-R16 or S4-R18 when they apply.
* S4-R16: Saving a matrix used by more than one category asks "Change Prices in <n> Categories?", lists every category on its own line, with Cancel / Change All. It never counts parts or customers.
* S4-R22: Change All saves the edited grid for every category using the matrix.
* S4-R18: Saving the General Matrix confirms "Save the General Matrix?" with "This changes prices for <n> categories without a matrix of their own." (Cancel / Save); it never asks Change All.
* S4-R19: Edit on an archived tier's Pricing tab opens the archived view: Default plus every archived tier, in the order they were archived, earliest first, with the notice "Archived tiers don't price parts. Reactivate a tier and assign customers to use these rules." In the archived view, Same as previous tier follows the column directly to its left (Default for the first archived tier). The Price Part Simulator shows under the archived grid for the columns shown, priced the same way, so someone deciding whether to reactivate a tier can see how it would price parts against Default. Active grids never show archived tiers.
* S4-R32: In the archived view Default and the cost ranges are read-only (tooltip "Default prices live parts, so it can't be changed in the archived view."), and Save never asks S4-R16, S4-R18 or S4-R30.
* S4-N1: Default's picker offers only + $, Markup % and Margin %; its cells can still mix those types.
* S4-E3: A tier created while the grid is in edit appears after Save or Cancel, as Same as previous tier.
* Error: a failed save shows today's error toast and keeps the grid in edit with every change.

## Acceptance Criteria

- [ ] Given a matrix with Default and 5 active tiers, when its page opens, then the grid shows Cost Range, Default and Tiers 2–6 by number, one row per cost range, with no "How it's priced" row.
- [ ] Given a 1512-wide screen and 20 tiers, when the grid shows, then Cost Range stays pinned, columns are 128px, at least Default and 3 tiers show, and the rest scroll sideways; given 6 columns at 1920 wide, then each column is 176px and the spare width stays at the right.
- [ ] Given a tier name longer than its column, then it is cut short with "…" and shows in full on hover; columns can't be resized.
- [ ] Given a cell, when in view, then it shows its rule in short ("10% off", "$5 off", "Cost + $5", "35% markup", "30% margin"), and a Same as previous tier column reads "Uses previous tier".
- [ ] Given the grid in edit, when the user changes one value and changes it back, then the bar reads "No changes yet"; when they add a range, then it counts as one change; gray auto-filled values and cells that follow another column don't count.
- [ ] Given a tier's header picker, when the user picks Markup %, then every range of that column becomes Markup % with empty values.
- [ ] Given a From cost column, when the user picks Margin % on one range's % symbol, then only that range changes, its value clears, and the header picker and the view read "Mixed rules".
- [ ] Given a column with one type and different values, then its one-label summary reads the type alone ("% markup"); given one value everywhere, then it reads "35% markup".
- [ ] Given range 1 is + $ and range 2 is Markup % 40, when range 2 is typed, then ranges 3 and below fill in gray with Markup % 40; a gray value typed over stays as typed; Save keeps the gray values.
- [ ] Given focus in a value, when the user presses Tab, then focus moves to the next range of the same tier, and from the last range to the first range of the next column; Shift+Tab goes back; Alt+Down on a From cost value opens its rule picker.
- [ ] Given a tier set to Same as previous tier, when the grid is edited, then its cells show the previous tier's values; saved unchanged, it still reads "Uses previous tier"; with one value changed, it saves as the tier's own rules.
- [ ] Given a renamed Default ("Retail"), then the column, the "Off Retail price" group and the price details say Retail, and the badge still reads "Default".
- [ ] Given Tiers 3–5 price from Default in this matrix, when the user changes a Default value or a range end and saves, then "Change Default's Prices?" lists Tier 3, Tier 4 and Tier 5 one per line; with no such tier, nothing extra is asked.
- [ ] Given a matrix used by 3 categories, when the user saves, then "Change Prices in 3 Categories?" lists the three categories one per line with Cancel / Change All, and Change All saves for all three.
- [ ] Given the General Matrix, when the user saves, then "Save the General Matrix?" shows the number of categories without a matrix of their own, and Change All is never asked.
- [ ] Given a save, then the toast reads "<matrix> saved" with what changed and "Parts already on work orders keep their prices.", the grid returns to view, and changed cells stay highlighted until the user leaves.
- [ ] Given an archived tier's Pricing tab, when Edit is clicked on a matrix, then the archived view shows Default plus archived tiers in the order they were archived, earliest first, with the notice; Default and ranges are read-only with their tooltip; saving asks none of the three questions.
- [ ] Given Default's header picker, then only + $, Markup % and Margin % are offered.
- [ ] Given a tier created while the grid is in edit, when the grid is saved or cancelled, then the new tier appears as Same as previous tier.
- [ ] Given a save that fails, then today's error toast shows and the grid stays in edit with every change kept.
