2. 3. Credits (RPT-S5-R2, RPT-S1-E8, R-D36): a category's Parts Credits come only from credit lines that name a part line in that category, and every category opens to Priced By rows (Default, each tier, Fixed price, Fixed line total, Manual, Before tiers); there is no "Credits not tied to a part" row.
