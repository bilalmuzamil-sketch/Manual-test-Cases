# SV-12458 Tiered Pricing - Story 7 - Categories: every category's pricing at a glance

## Description

## Summary

The Categories page shows every category's matrix and every tier's price in one list, and each category opens as a page, so a parts manager can find and fix a category's margins without opening dialogs one by one.

## Context

* Role: user with 'Settings — Parts' to open Categories, and 'See Financial Data' to see the pricing columns and edit pricing. Desktop only (settings).
* Today Edit Category is a dialog with the name, QuickBooks Products and Services (edit only, when QuickBooks is connected) and Tax Exempt; this story replaces it with a page that keeps every field.
* Uncategorized is a system category that always uses the General Matrix (S8-R4).

## Requirements

* S7-R1: Settings › Categories lists every category, including one with no sales or parts: Category, Pricing Matrix, Default, then one column per active tier by number with its number and name. Uncategorized is first. The General Matrix shows its Default badge.
* S7-R2: Each Default and tier cell shows its Work Order Matrix rule in short (S4-R31), or "Uses previous tier", with the full rule on hover: each cost range on its own line ("$0.00 to $25.00: 35% markup"), or, for a Same as previous tier cell, "Uses previous tier, 3 · Fleet. Priced by 2 · Wholesale's rule."
* S7-R4: Search matches category and matrix names; sort by Category or Pricing Matrix with Uncategorized always first; first load is Uncategorized, then A to Z. The list loads like the work order list, more as the user scrolls. Search and sort are kept on return. No match: 'No categories match the search "…".' with Clear Search.
* S7-R6: Clicking a row opens the category's page (never a dialog), breadcrumb Settings › Categories › <category>: name renamed in place, Pricing Matrix picker, QuickBooks Products and Services (only when QuickBooks is connected), Tax Exempt, New Matrix, Delete in the page's ⋯ menu, then the matrix's tier grid read-only, with no simulator.
* S7-R13: Edit opens the matrix page in edit when only this category uses the matrix. When the matrix prices more than one category (the General Matrix included), Edit is grayed with "Can't edit here. The <matrix> matrix prices <n> categories, so edit it from the matrix." and a link "Go to the <matrix> matrix" opens the matrix in edit; the breadcrumb leads back to the category.
* S7-R15: Above the grid: "The <matrix> matrix also prices <n> other categories: <A> · <B>." For the General Matrix: "The General Matrix also prices every other category without a matrix of its own (<n>)."
* S7-R14: Settings › Parts lists Categories, then Pricing, then Bin Locations (today: Pricing, Bin Locations, Categories).
* S7-R12: The name, QuickBooks mapping, Tax Exempt and Pricing Matrix pick each save as soon as they change.
* S7-R9: Picking a different Pricing Matrix moves the category at once, shows that matrix's grid, and confirms "<category> now uses <matrix>" / "Parts already on work orders keep their prices."
* S7-R11: New Matrix opens a new matrix page with this category already picked.
* S7-N1: Without 'Settings — Parts' there is no Categories page, as today.
* Error: a failed load shows "Ooooops! An error occurred" with Try again, keeping search and sort; a failed save keeps everything typed.

## Out of Scope

* Showing the Part Sale rule in a Categories cell (open question for the design authority).

## Acceptance Criteria

- [ ] Given a client with categories and 5 active tiers, when Settings › Categories opens, then Uncategorized is first, then A to Z, with Category, Pricing Matrix, Default and Tiers 2–6 columns, and the General Matrix shows its Default badge.
- [ ] Given a user with 'Settings — Parts' but not 'See Financial Data', then the pricing columns don't show and pricing can't be edited.
- [ ] Given a category on a matrix where Tier 3 is 10% off in every range, then its Tier 3 cell reads "10% off"; given Tier 4 is markup with different values, then "% markup"; given mixed types, then "Mixed rules"; given Same as previous tier, then "Uses previous tier"; hover shows the full sentence.
- [ ] Given more categories than one load, when the user scrolls, then more load as on the work order list.
- [ ] Given a search for "brak", then categories and matrices whose names match show and Uncategorized stays first; given no match, then 'No categories match the search "…".' with Clear Search.
- [ ] Given a search and a sort, when the user opens a category and comes back, then the search and sort are kept.
- [ ] Given a category row, when clicked anywhere, then its page opens with the breadcrumb Settings › Categories › <category> and the fields listed in S7-R6; the tier grid is read-only and there is no simulator.
- [ ] Given QuickBooks isn't connected, then QuickBooks Products and Services doesn't show on the category page.
- [ ] Given a category whose matrix prices only it, when Edit is clicked, then the matrix page opens in edit; given a matrix pricing 3 categories, then Edit is grayed with the tooltip naming the matrix and 3 categories, and "Go to the <matrix> matrix" opens the matrix in edit, and the breadcrumb leads back to the category.
- [ ] Given Tires on the Tread Plus matrix with Tires, Retread, then the line above the grid reads "The Tread Plus matrix also prices 1 other category: Tires, Retread."; given a category on the General Matrix, then the General Matrix line shows the count.
- [ ] Given the name, QuickBooks mapping or Tax Exempt is changed, then it saves at once with no Save button.
- [ ] Given a different Pricing Matrix is picked, then the category moves at once, the grid shows the new matrix, and "<category> now uses <matrix>" / "Parts already on work orders keep their prices." shows.
- [ ] Given New Matrix on a category page, then a new matrix page opens with that category picked.
- [ ] Given Settings, then the Parts group lists Categories, Pricing, Bin Locations in that order.
- [ ] Given a user without 'Settings — Parts', then there is no Categories page.
- [ ] Given the list fails to load, then "Ooooops! An error occurred" shows with Try again, and search and sort are kept.
