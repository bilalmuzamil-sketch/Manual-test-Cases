# SV-12747 Verify: shared filter chips gain opt-in All labels, plain-when-all, search focus and new messages (Phase 4)

## Description

**Covers:** RPT-S3-R1–R5, R7–R10, R12, N1, E1; RPT-UF2; decisions R-D15, R-D16, R-D24

**Checklist**

1. Nothing changes elsewhere (R-D15): on Sales by Customer, Parts Velocity and another report with a filter bar, chip colors, chip summaries, search focus, the 50-value cap and the "Clear all filters" button behave as before, and a too-long range still reads "Range: N days (max 366)". The shared filter test ids (`filter_all_in_scope_{key}`, `filter_option_{key}_{value}`, `filter_clear_selection_{key}`) are unchanged.
2. Chip color on Sales by Tier (RPT-S3-R12): Date range and Location are always blue; Priced By, Category and Sales Type are plain when everything is selected and blue on a subset; Customer is plain when empty.
3. Chip text (RPT-S3-R5, R-D16): a closed chip reads "All" when everything is picked, the one option when one is picked, or "None"; Sales Type reads "Sales Type: All", "Sales Type: Part Sales", "Sales Type: Work Orders" or "Sales Type: None". A chip's X restores All.
4. Search focus (RPT-S3-R10, RPT-S3-E1): on desktop, opening any filter's dropdown puts the cursor in its search box (mobile doesn't, so the keyboard doesn't pop up); a search with no match shows no options and keeps the current picks.
5. The cap (RPT-S3-R1, R-D24): "All" counts nothing toward the shared 50-value cap. On a client with more than 50 categories, untick one category and tick it again in another order: the selection is accepted as All, not refused.
6. Over a year (RPT-S3-R1, R-D16): picking a range longer than one year shows "Choose a date range of one year or less." in these reports' date panel.
7. Empty state button (RPT-S3-N1, RPT-UF2): with filters that match nothing, the button reads "Clear All Filters" on these reports, while other reports keep "Clear all filters".
