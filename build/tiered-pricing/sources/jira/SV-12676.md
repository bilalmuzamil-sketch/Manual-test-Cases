# SV-12676 Verify: grid editing, New Matrix, save questions, archived-view editing and the discard guard (Phase 13)

## Description

**Covers:** TP-S1-E11, E12; TP-S3-R5, R6, R8, R9, R12, R13, R16, R18, R20, R21, R23, R25–R28, R30–R32, N3, N4, E3, E4; TP-S4-R1, R3–R5, R7, R10, R12, R15, R16, R18–R20, R22, R26–R32, N1, E3; TP-S7-R11; TP-S19-R1, R3, R5–R10, R12–R15, R18, R20–R23, E2; decisions D21, D30, D36

**Checklist**

1. Edit per tab (TP-S3-R18, TP-S3-R25, TP-S4-R4): Edit makes every cell editable, and the edit bar shows "No changes yet" or "<n> changes" with only Cancel and Save. Each tab has its own Edit, Save and Cancel. Switching tabs with unsaved changes asks "Discard these changes?": Keep Editing stays on the tab, Discard Changes drops that tab's draft and switches. Leaving the page asks the same question, and with no changes it leaves at once. The Part Sale switch is disabled only while the Part Sale grid is in edit. Edit from the Matrices list, a tier's page or a category's page opens the Work Order tab in edit.
2. Pickers and keyboard (TP-S4-R5, TP-S4-R28, TP-S4-R29, TP-S4-N1, TP-S19-R6): a tier's header picker lists Previous tier; Off <Default's name> price: % Off, $ Off; From cost: + $, Markup %, Margin %. Default's lists only From cost. Picking a type clears the column's values. A From cost cell's symbol is its own picker, opened with Alt+Down, and % Off and $ Off cells have no symbol picker; mixed types show "Mixed rules" as the header's value, never as a choice. Tab moves down a column and on to the next column's first range; Shift+Tab goes back.
3. Auto-fill and follows (TP-S4-R26, TP-S4-R10, TP-S3-R23, D21): typing a value fills the empty ranges below it in gray, following the nearest typed range above; a gray value typed over is left alone. The last range follows the range above ("Same as the rule above") until edited to differ, stays its own rule after saving and reopening, and follows again when edited back. Choosing Previous tier fills in the previous tier's values; saved unchanged, the column still reads "Uses previous tier".
4. Ranges (TP-S3-R16, TP-S3-R20, TP-S3-R32, TP-S1-E12): ranges are entered by their end; the first starts at $0.00 and each next one $0.01 above the previous end; the last reads "<start> and up" and can't be removed; Add Range adds a range before the last; the delete button ("Remove this range") merges a range into the one above. A migrated matrix whose first range started above $0.00 starts at $0.00 after its first save, and no price changes.
5. Validation (TP-S3-R5, TP-S3-R6, TP-S1-E11): Save is blocked, with the cells highlighted and the messages "Enter an end above <start>", "Enter a value", "Use at most two decimals", "Enter a margin from 0 to 99.99", "Enter a % from 0 to 99.99" and "<tier>: enter $0.00 or more in every range." No value may be negative, but 0% markup or margin, + $0.00, 0% off and $0.00 off save. Ranges from before release with a gap or overlap block Save until fixed.
6. Change count and toast (TP-S4-R4, TP-S4-R12, TP-S4-R20): a value changed and changed back doesn't count, and gray auto-filled values don't count. The toast reads "<matrix> saved" with "1 change: Tier 5 is 28% margin." and "Parts already on work orders keep their prices."; with more than three changes it names three, then "and <n> more". Changed cells stay highlighted until you leave the page.
7. Save questions (TP-S4-R16, TP-S4-R18, TP-S4-R22, TP-S4-R30, TP-S3-R12): a matrix used by one category saves without asking; one used by several asks "Change Prices in <n> Categories?", listing each category, with Cancel / Change All; the General Matrix asks "Save the General Matrix?" with "This changes prices for <n> categories without a matrix of their own."; a Default change with tiers that price from Default lists those tiers ("Change Default's Prices?" alone, or inside the other two questions).
8. Two sessions (TP-S19-E2): save the same matrix side from two browser sessions. The second is refused inline with "<matrix> was changed by someone else. Reload to see their changes." and a Reload action, and everything typed stays. Saving the Work Order tab never makes the Part Sale tab's next save stale.
9. New Matrix (TP-S3-R30, TP-S19-R14, TP-S7-R11): opens in edit with an empty name, one range from $0.00, an empty Default cell and every tier on Previous tier, with Cancel and Create Matrix in the page head. A name that is empty, under 3 or over 127 characters, or taken ignoring case shows an inline error under the name. Cancel creates nothing. Opened from a category's page, that category is already picked.
10. Archived-view editing (TP-S4-R19, TP-S4-R32, TP-S4-E3, D36): only the archived columns are editable; Default and the ranges are read-only, and Default shows "Default prices live parts, so it can't be changed in the archived view."; the notice reads "Archived tiers don't price parts. Reactivate a tier and assign customers to use these rules."; saving asks none of the save questions; the simulator follows unsaved archived edits. A later save from the active view leaves those archived columns as saved. A tier created while a grid is in edit appears, as Previous tier, after the grid is saved or cancelled.
