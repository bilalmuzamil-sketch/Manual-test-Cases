# SV-12754 Verify: the four downloads, their caps, header lines and column headers (Phase 12)

## Description

**Covers:** RPT-S1-R13, R14; RPT-S4-R1–R7, N1, N2, E1, EH1; RPT-UF4, RPT-UF5, RPT-UF6; NFR-R5; decisions R-D14, R-D16, R-D28, R-D31, R-D32

**Checklist**

1. Menu (RPT-S4-R1): the ⋯ menu on both reports offers "Download Summary (PDF)", "Download Expanded View (PDF)", "Download Summary (CSV)" and "Download Expanded View (CSV)". Files are built on the server, and CSVs go through the shared CSV-injection guard.
2. Content (RPT-S4-R2, RPT-S4-R3, RPT-S1-R14): Summary has the rows and the Totals; Expanded has every level, down to invoices and credits, whatever is open on screen. Both use the current filters, sort and shown columns (hide Parts Margin and it isn't in the file), and show Priced By in plain text with tier numbers and "(archived)" as on screen.
3. Header lines (RPT-S4-R7, R-D32): every download starts with the report's title ("Sales by Tier" or "Sales by Category"); "Date Range: <from> – <to>"; "Locations: All locations" or the location names; then "Sales Type: All", "Sales Type: Part Sales", "Sales Type: Work Orders" or "Sales Type: None"; "Category: All categories" or the picked names; "Priced By: All" or the picked labels ("2 · Fleet", "(archived)"); and "Customer: All customers" or the picked names. A narrowed list is comma-separated in filter order, and an empty pick reads "None". The PDF shows the client's logo.
4. Column headers (RPT-S4-R6, R-D31): "Customer", "Invoice #", "Date", "Location", "Parts Invoiced", "Parts Margin", "Parts Margin %", and "Totals" on the Totals row; the added columns read "Priced By", "Category", "Priced For", "Parts Cost", "Parts Credits", "Parts Net" and "% of Total". Re-check the shared headers against Sales by Customer's export code at build time (it says "Margin %"; these reports say "Parts Margin %").
5. Priced For (RPT-S4-R4, RPT-S1-E1, R-D16): the Expanded download names the customer a line was priced for when it differs from the invoice's customer, in a "Priced For" column, with "Multiple" when a row spans several.
6. Caps (RPT-S4-R5, RPT-S4-N1, RPT-UF4, NFR-R5, R-D14): a PDF over 2,000 rows or a CSV over 50,000 is refused with "This report is too large to export. Choose a shorter date range, then try again." and no file is made; the rows are counted before they are fetched; a 50,000-row CSV finishes within the 30-second PHP-FPM CPU limit.
7. Empty and failure (RPT-S4-N2, RPT-S4-EH1, RPT-UF5, RPT-UF6): a download with no rows shows the existing "Empty export" notice and makes no file; a failed download shows "Ooooops! An error occurred" with "Contact support for more information" in the error toast.
8. Negative amounts (RPT-S4-E1, RPT-S1-R13): PDFs show negatives as on screen ("−$12.40"); CSV numbers stay plain negative numbers ("-12.40").
