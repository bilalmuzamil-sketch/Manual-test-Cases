# SV-3411 BE: Fixed Sell Price of Part

## Description

* ~~IF a part is a fixed sell price, and you go into edit the part, and you remove the fixed sell price from the sell price field, and you click ‘tab’, it should re-calculate the sell price right there within the Edit Inventory Part modal, using the matrix. Currently, you need to clear the field, and then save, in order to see what the new sell price is. It should just auto calculate if you focus out of the field, after you cleared the field.~~   This is frontend issue, but keeping it here for reference. We figured out we have `api/pricing-rules/calculate-sell-price` endpoint which we can use here. Find BE problems below the screenshot.

    [image]

Seems like it’s not possible to save changed made to Category and Manufacturer on BE. Even though I send a new id for category and manufacturer, BE never saves the change. Another thing I noticed is we can’t change is `is_fixed_price` property - it is either `true`, if we send some value, or `false`, if we leave field empty.

### Acceptance criteria

* When category is changed in the inventory, it should mirror that change in the catalog. The catalog and the inventory item should always have the same _category_.
* In the case of multi location, the same applies, all inventory items in all locations, and catalog, should have mirrored _category_.
* On category change recalculate price only if part doesn’t have fixed price, otherwise do not overwrite the price in the input field
