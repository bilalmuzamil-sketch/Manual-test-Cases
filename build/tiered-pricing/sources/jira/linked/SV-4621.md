# SV-4621 Add Optional Cost Field for Found Parts

## Description

**Customer :** GL-Mécanique
**Number of Users:** 11
**Feature Request:** Ability to add a cost to Found Parts
**Date Requested:** October 3, 2025

**Detailed Description:**
Currently, Found Parts in ShopView assume a cost of $0. This design works well when the part truly has no cost, such as old bulbs, donor parts, or miscellaneous bolts found in the shop. However, some shops also use Found Parts for in-house fabricated parts or miscellaneous parts where they _do_ know the cost.

In such cases, not being able to add a cost creates inaccurate reporting, since the system assumes 100% margin.

**Requested Enhancement:**

* Allow users to optionally enter a cost for a Found Part.
* If no cost is entered, the system should continue to assume $0 (and 100% margin).
* If a cost is entered, that value should be factored into margin and reporting calculations, ensuring accuracy in the “Stats” section.

**Customer Note:**
They do not want to create catalogue parts for these items. The flexibility of entering a cost only when known would cover their workflow without adding unnecessary catalog clutter.
