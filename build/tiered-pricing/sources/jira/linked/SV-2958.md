# SV-2958 Customer setting - default matrix for parts

## Description

Many shops have agreements with their customers that they will sell them parts at a specific markup. Currently, we are training them to make a Category as the customer name, creating a Matrix for that category and setting up the pricing. Problem with this is when they create a WO they are having to manually change the category of all the parts on the WO to be the customers category.

Would like to build out a default matrix setting in the edit customer modal:

Add a field to the edit customer modal.

Default Part Matrix → this will be a dropdown menu that is pulled from the Pricing settings under administration

[image] [image]

Always default this drop down to the default matrix unless the user manually changes it to another matrix.

If another matrix is selected in the customer file all parts on WOs made for that customer will have this pricing structure.

Shown here:

[image] [image] [image]

What happens if the customer already has open WO → leave the original parts pricing, do not change on any WO in any status.

What happens if the customer has invoiced WO → do not change anything, leave it as it was when it was invoiced

Only have this change take effect on new WO opened after the setting has been changed.
