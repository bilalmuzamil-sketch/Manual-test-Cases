# SV-3398 Amplify Fixed Sell Price

## Description

Currently, the user is able to set a fixed price rule for inventory parts. This will ignore the matrix so that the sell price of the part is not using the parts matrix, and it will always sell for the fixed price.

Currently, once there is a fixed sell price set, the sell price goes Green. We want to aplify this so the user more clearly knows that it is set to a fixed sell price.

To do:

* Add ‘Fixed sell price’ underneath the sell price in the column. Keep the text in green.
