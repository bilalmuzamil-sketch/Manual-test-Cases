# SV-12670 Verify: Change Customer dialog pricing copy, amber tier note and lines-priced notice (Phase 7)

## Description

**Covers:** TP-S13-E1; TP-S14-R2–R5, N1, E1; NFR-003; decisions D20, D21

**Checklist**

1. As `admin`, open Change Customer on a work order: under today's gray caption it adds "Parts already on the work order keep their prices, and new parts keep this work order's pricing." On a Part Sale it adds "Parts already on the Part Sale keep their prices, and new parts keep this Part Sale's pricing." (TP-S14-R4)
2. Pick a customer on another tier (the work order keeps Default, the new customer is on Fleet Plus): an amber note reads "This work order keeps Default pricing. Fleet Plus applies to new work orders, or split this one to use it." On a Part Sale: "This Part Sale keeps Default pricing. Fleet Plus applies to new Part Sales, or split this one to use it." Nothing is red. Picking a customer on the same tier shows no note (TP-S14-R5, TP-S14-E1).
3. Save the change on a work order with three Default-priced lines: the notice reads "3 lines priced at Default for the previous customer", placed as design 14.8 shows. With lines priced by two tiers, it reads "5 lines priced for the previous customer" with no tier name. Manual, Fixed price, Fixed line total and Before tiers lines aren't counted, and with nothing counted no notice shows (TP-S14-R2).
4. After the change no price moved, those lines show no Manual icon, and their price details read "Priced by Fleet for Acme Freight" (the customer they were priced for). A part added afterwards is priced by the work order's tier, not the new customer's (TP-S14-R3).
5. Repeat on a Part Sale: the same notice and the same behavior (TP-S13-E1).
6. As a user without 'See Financial Data', Change Customer shows no notice, and the response has no `linesPricedForPreviousCustomer` key (D20, NFR-003). A work order with deposits still can't change customer, as today (TP-S14-N1).
