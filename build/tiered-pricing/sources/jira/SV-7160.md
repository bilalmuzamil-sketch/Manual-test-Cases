# SV-7160 Changing part category does not apply fixed pricing rule — sell price changes incorrectly with category selection

## Description

**Environment:**  
Production and Staging  
  
**Issue Description:**

When requesting a part on a Work Order, the sell price initially displays correctly as per the fixed pricing rule. However, when the category is changed, the sell price changes according to the selected category instead of applying the fixed rule. Furthermore, reselecting the original category that matches the fixed rule does not restore the correct sell price — the fixed rule is ignored entirely once the category has been changed.

---

**Steps to Reproduce:**

1. Navigate to Settings > Pricing > Pricing Matrix and add a new Fixed Rule.
2. Confirm the fixed rule is reflected in Parts > Inventory.
3. Create a new Work Order and request a part by entering the part number — verify the correct sell price is displayed as per the fixed rule.
4. Change the category on the part — observe that the sell price changes according to the newly selected category instead of the fixed rule.
5. Reselect the original category that matches the fixed rule.
6. Observe that the sell price does not revert to the fixed rule price and continues to change with each category selection.

---

**Expected Behavior:**

When a fixed pricing rule is in place, the sell price should always follow the fixed rule regardless of the category selected. Changing the category should not override the fixed rule pricing. If the category is changed back to the one matching the fixed rule, the fixed rule price should be applied correctly.

---

**Actual Behavior:**

The sell price changes according to whichever category is selected, ignoring the fixed pricing rule. Reselecting the category that matches the fixed rule does not restore the correct sell price — the fixed rule is not applied once the category has been changed.
