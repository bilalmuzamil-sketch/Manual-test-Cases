# SV-5744 Bug: "Fixed-price $0 parts incorrectly adopt matrix pricing after category change

## Description

**Environment:**  
Staging  
Production  
  
**Issue Summary:**   Fixed-price parts set to $0 incorrectly display a non-zero sell price on the work order when the part category is changed and then reverted.

**Steps to Reproduce (STR):**

1. Ensure a fixed-price part is set to $0 in **Parts → Inventory**.
2. Request the same part on a work order line.

    * **Expected:** Price appears as “0”.
    
3. Change the category of the part to a different category.

    * **Observed:** Price updates to the matrix price (greater than 0).
    
4. Change the category back to the original category.

    * **Observed:** Price remains at the matrix price instead of reverting to “0”.
    

**Expected Behavior:**   When a fixed-price part is set to $0, the sell price should consistently remain $0 on the work order, regardless of category changes.

**Actual Behavior:**   Changing the category causes the part to adopt matrix pricing, and reverting the category does not restore the $0 fixed price.
