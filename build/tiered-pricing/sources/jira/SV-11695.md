# SV-11695 Tiered Pricing - Story 3 - Matrices and rules

## Description

## Summary

Each matrix is a page with a Work Order Matrix tab and an optional Part Sale Matrix tab, shared cost ranges for Default and every tier, the new % Off, $ Off and + $ rules, categories assigned from the matrix, and Duplicate and Delete. A parts manager prices Default and every tier of a matrix in one place.

## Context

* Role: user with 'Settings — Parts' and 'See Financial Data'. Desktop only (settings).
* What must be true first: the matrix library (Story 1) and tiers (Story 2). The grid itself (columns, cells, editing) is Story 4; the Price Part Simulator under it is Story 5.
* Covers SV-7857 and SV-9492.

## Requirements

* S3-R18: A matrix opens as a page, never a dialog, from the Matrices list, a tier's page and a category's page, replacing today's matrix editor dialog. Its name is renamed in place and saves when the field loses focus; blank, under 3 or over 127 characters, or taken shows the inline error and keeps the old name (a new matrix's name saves with the matrix). A Categories line shows the categories it prices ("All categories without a matrix (n)" for the General Matrix). Two tabs, Work Order Matrix and Part Sale Matrix, each with the grid and the simulator. Each tab has its own Edit, Save and Cancel; switching tabs with unsaved changes asks "Discard these changes?" with Keep Editing and Discard Changes. The three-dot menu has Audit Log.
* S3-R25: The matrix's name on the Matrices list opens it in view. Edit on the Matrices list, a tier's page, or a category's page whose matrix prices only that category opens it in edit. Cancel discards every change and returns to view, asking only when something changed.
* S3-R26: Breadcrumbs, with no separate Back link: Settings › Pricing › Matrices › <matrix>; Settings › Categories › <category> › <matrix> from a category; Settings › Pricing › Tiers › <tier> › <matrix> from a tier. From a link or bookmark, the Matrices breadcrumb.
* S3-R13: Categories are assigned from the matrix's Categories line (multi-select picker with search and Select all) or from a category's matrix picker. A category on another matrix shows "Now: <matrix>" and moves here when the matrix is saved; a category removed moves to the General Matrix when saved. Uncategorized isn't listed.
* S3-R28: A matrix with at least one category is Active (the General Matrix always is); with none it is Inactive, prices nothing, keeps its rules and can be saved that way. Adding or removing categories changes this at once. The Matrices list shows an Active or Inactive badge; the matrix page shows Inactive as gray text beside the name and nothing when Active.
* S3-R5: A rule is a cost range (both ends inclusive) with one calculation: Off default price, in tier columns only (% Off, $ Off, taken off Default's sell price), or From cost (+ $ per unit, Markup %, Margin %). No value is negative. A matrix can mix calculations across its columns.
* S3-R20: A matrix side has one set of cost ranges shared by Default and every tier. Adding, removing or moving a range end changes every column; % Off and $ Off values stay with their range.
* S3-R6: Save is blocked, with the cells highlighted and a message naming them, when a range's end isn't above its start ("Enter an end above <start>"); a value, Default's included, is empty ("Enter a value") or has more than two decimals ("Use at most two decimals"); a margin is 100% or more ("Enter a margin from 0 to 99.99"); a % Off isn't 0 to 99.99 ("Enter a % from 0 to 99.99"); a $ Off is below $0.00 ("<tier>: enter $0.00 or more in every range."); ranges carried from before release leave a gap or overlap; or a new matrix's name is empty, under 3 or over 127 characters, or taken, ignoring case. Zero values (0% markup or margin, + $0.00, 0% off, $0.00 off) are allowed.
* S3-R16: Ranges are entered by their end. The first starts at $0.00; each later range starts $0.01 above the previous end ("$25.01 to \[end\]"). The last has no end ("$10,000.01 and up") and can't be removed. Add Range adds a range before the last one.
* S3-R32: Each range except the last has a delete button at its left ("Remove this range"); removing a range merges it into the range above, which takes its end.
* S3-R23: In every column the last range copies the rule of the range above and follows it ("Same as the rule above"). Edited to differ, it becomes its own rule and stays that way after save; edited back to match, it follows again. A one-range matrix has nothing to follow.
* S3-R30: A new matrix opens in edit with an empty name, one range from $0.00 with an empty Default cell, and every tier on Same as previous tier. Nothing is created until Save.
* S3-R21: The Part Sale Matrix tab has a "Separate Part Sale pricing" switch, off by default. Off, the tab shows only the switch and an info tooltip saying Part Sales use the work order prices, with no grid and no Edit.
* S3-R31: Switching it on saves at once and starts the Part Sale side as a copy of the Work Order Matrix's current rules, every tier included. Off and on again starts a fresh copy.
* S3-R27: Switching it off asks "Turn Off Part Sale Pricing?" with "Turning off the separate Part Sale matrix will revert the pricing to the work order matrix." (Cancel / Turn Off); on confirm the Part Sale rules are deleted.
* S3-R8: Duplicate makes "<name> (copy)" ("(copy 2)" and so on when taken) with the same rules on both sides and every tier, and no categories, and opens it. It has no tie to the original.
* S3-R9: Deleting a matrix asks first, naming its categories; on delete they move to the General Matrix. Prices already on lines don't change.
* S3-R12: Only a grid Save asks Change All (matrix used by more than one category). The General Matrix confirms instead; a Default change also names the tiers that price from Default. Renaming, changing categories and turning the Part Sale switch on save without asking; turning it off asks first. A matrix used by one category or none saves without asking.
* S3-N3: The General Matrix can't be deleted: Delete is disabled with "The General Matrix can't be deleted. You can edit it."
* S3-N4: The General Matrix's categories can't be picked.
* S3-E3: Costs are rounded to the cent, half away from zero, before a rule is chosen ($10.005 is $10.01).
* S3-E4: On release day every range keeps its rule; an existing last range that differs from the one above becomes its own rule, one that matches follows. Opening or saving without editing rules never changes a price.
* Error: a failed save shows today's error toast and keeps the grid in edit with everything typed. Change All saves for every category or for none.

## Acceptance Criteria

- [ ] Given a matrix, when it is opened from the Matrices list, a tier's page or a category's page, then it opens as a page (not a dialog) with its name as the title, a Categories line, Work Order Matrix and Part Sale Matrix tabs, and Audit Log in its three-dot menu.
- [ ] Given the General Matrix, then its Categories line reads "All categories without a matrix (n)" and its categories can't be picked.
- [ ] Given the matrix name is changed to a free name and the field loses focus, then it saves at once; given blank, "Ab", 128 characters or another matrix's name in other capitals, then the inline error shows and the old name is kept.
- [ ] Given the name on the Matrices list is clicked, then the page opens in view; given Edit on the Matrices list, a tier's page, or a category whose matrix prices only it, then it opens in edit.
- [ ] Given the grid in edit with changes, when Cancel is clicked, then "Discard these changes?" is asked and Discard returns to view with nothing saved; with no changes, it returns to view without asking.
- [ ] Given the matrix opened from the Matrices list, a category, a tier, or a bookmark, then the breadcrumb is the matching one in S3-R26 and there is no Back link.
- [ ] Given Tires on Tread Plus, when Tires is picked on Brakes Plus's Categories line, then it shows "Now: Tread Plus" and moves to Brakes Plus when the matrix is saved; given a category removed from the line, then on save it moves to the General Matrix; Uncategorized is never listed.
- [ ] Given a matrix whose last category is removed, then it shows Inactive (gray text on the page, a badge on the list), prices nothing and keeps its rules; adding a category makes it Active at once.
- [ ] Given a tier column, then its picker offers % Off, $ Off, + $, Markup % and Margin %; given Default's column, then % Off and $ Off aren't offered.
- [ ] Given a range end changed or a range added or removed, then every column uses the new ranges, and % Off and $ Off values stay with their range.
- [ ] Given a range end not above its start, an empty Default cell, 10.125, a 100% margin, 100% off, or -$1 off, when Save is clicked, then Save is blocked, the cells are highlighted, and the message names them ("Enter a % from 0 to 99.99", "<tier>: enter $0.00 or more in every range.").
- [ ] Given 0% markup, 0% margin, + $0.00, 0% off or $0.00 off, when saved, then it saves and sells at the base price.
- [ ] Given a new range, then it is entered by its end, starts $0.01 above the previous end, the first starts at $0.00, the last reads "$X and up" with no delete button, and Add Range inserts before the last.
- [ ] Given a middle range is removed with its delete button ("Remove this range"), then it merges into the range above, which takes its end.
- [ ] Given the range above the last changes, then the last range follows it with the tooltip "Same as the rule above"; given the last range is edited to differ, then it keeps its own rule after save and reopen; edited back to match, it follows again.
- [ ] Given New Matrix, then it opens in edit with an empty name, one range from $0.00 with an empty Default cell, and every tier as Same as previous tier; leaving without Save creates nothing.
- [ ] Given the Part Sale tab with the switch off, then only the switch and its tooltip show, with no grid and no Edit, and Part Sales use the Work Order Matrix.
- [ ] Given the switch is turned on, then it saves at once and the Part Sale grid is a copy of the work order rules, every tier included; turned off, "Turn Off Part Sale Pricing?" is asked and Turn Off deletes the Part Sale rules; turned on again, it starts as a fresh copy.
- [ ] Given Brakes, when Duplicate is clicked, then "Brakes (copy)" opens with the same rules on both sides and no categories; when duplicated again, "Brakes (copy 2)".
- [ ] Given a matrix pricing Tires and Retread, when Delete is clicked, then the question names Tires and Retread; on delete both move to the General Matrix and prices on lines don't change.
- [ ] Given a matrix used by 3 categories, when only its name, categories or Part Sale switch (on) changes, then it saves without Change All.
- [ ] Given the General Matrix, then Delete is disabled with "The General Matrix can't be deleted. You can edit it."
- [ ] Given a part costing $10.005, then it is priced as $10.01 in exactly one range.
- [ ] Given a matrix carried over from before release, when it is opened and saved without editing rules, then no price changes.
- [ ] Given a save that fails, then today's error toast shows and the grid stays in edit; given Change All fails, then no category's matrix changes.
