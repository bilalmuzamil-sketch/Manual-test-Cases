# SV-11708 Tiered Pricing - Story 15 - The below-cost warning in the matrix

## Description

## Summary

A value in a matrix whose rule would sell a part for less than its cost shows a warning icon naming the lowest cost at which that happens. It never blocks saving, so an owner sees and fixes rules they didn't mean. It is the only warning in the matrix.

## Context

* Role: user viewing or editing a matrix ('Settings — Parts' and 'See Financial Data'). Desktop only (the grid is a settings screen).
* What must be true first: the tier grid (Story 4). Below-cost prices happen with % Off and $ Off, which take off Default's price; the Price Part Simulator shows the same icon (Story 5).

## Requirements

* S15-R5: A value in Default's or a tier's column whose rule sells a part below cost at any cost in its range shows the standard warning icon to the right of the value, in view and edit. For the last, open range, costs up to ten times its start or $10,000, whichever is higher, are checked. The tooltip reads "<tier> sells a <$cost> part below cost.", with the lowest such cost (in a $0.00 to $100.00 range with Default Cost + $10 and Fleet 20% off: "Fleet sells a $40.03 part below cost."). Always on, in every matrix and both sides, with no setting.
* S15-R2: The warning never blocks saving and never changes a price.
* S15-R3: The warning updates as the grid is edited.
* S15-N3: A "Uses previous tier" cell shows no warning of its own; the column it uses carries it.
* S15-N4: A price exactly at cost (0% markup, + $0.00) doesn't warn; a deeper discount does.
* S15-N5: A range that sells a costlier part for less than a part in the range before it shows no warning.

## Out of Scope

* A cost floor or a range floor that stops a price going below cost or below the range before it (a later release; SV-9314).

## Acceptance Criteria

- [ ] Given a $0.00 to $100.00 range with Default Cost + $10 and Fleet 20% off, then Fleet's value shows the warning icon to its right with "Fleet sells a $40.03 part below cost.", in view and in edit.
- [ ] Given Fleet $15 off where Default is Cost + $10, then Fleet's values warn; given Fleet $10 off, then no warning (exactly at cost).
- [ ] Given the last range starting at $10,000.01, then costs up to $100,000.10 are checked; given a last range starting at $500.00, then costs up to $10,000 are checked.
- [ ] Given a warning on the Part Sale side, then it shows there too; there is no setting to turn it off.
- [ ] Given a value with a warning, when Save is clicked, then it saves and no price changes because of the warning.
- [ ] Given the grid in edit, when Fleet's 20% off is changed to 5% off, then the warning disappears at once.
- [ ] Given Wholesale on Same as previous tier after a warning Fleet column, then Wholesale's "Uses previous tier" cells show no icon.
- [ ] Given Default 0% markup or a tier + $0.00, then no warning shows.
- [ ] Given a matrix where a $10.01 part sells for less than a $10.00 part in the range before it, but above its cost, then no warning shows.
