# SV-11697 Tiered Pricing - Story 9 - Putting customers on tiers

## Description

## Summary

Every customer has a work order tier and a Part Sales tier, set one customer at a time in Edit Customer or New Customer, or in bulk from a tier's Manage Customers. The customer page shows the customer's pricing, and work orders and Part Sales made from then on are priced by the chosen tier.

## Context

* Permissions: one customer needs 'Customers — Create & Edit'. In bulk from a tier: 'Settings — Parts', 'See Financial Data' and 'Customers — Create & Edit'. A tier's Customers tab also needs 'Customers — View'. The customer card's Pricing section needs 'View and Manage AP/AR Data'.
* Form factor: viewing and editing one customer's tiers works on a phone; the bulk tools are desktop only.
* What must be true first: at least one tier besides Default (Story 2); the tier fields stay hidden until then.
* Tiers are client-wide: a customer's tiers apply at every location.
* Covers SV-4027 and SV-2989.

## Requirements

* S9-R1: Each customer has a work order tier and a Part Sales tier, chosen independently from active tiers; archived tiers can't be picked.
* S9-R2: A new customer, imported ones included, starts on Default for both. New Customer shows both tier fields set to Default to users with 'Customers — Create & Edit'.
* S9-R3: Edit Customer shows Work Order Tier and Part Sales Tier directly under Default Shop Supplies, before Notes; no existing field moves.
* S9-R31: The tier fields show only when the client has more than one active tier.
* S9-R30: Tier pickers list active tiers by number as "4 · Fleet"; search matches the number or the name.
* S9-R12: The customer page's customer card (not the card on work orders, Part Sales or imported work orders) gets a read-only "Pricing" section under IBS: Labor Rate at the current location ("Varies by location" when it differs elsewhere); Shop Supplies ("No shop supplies", the customer's charge, or "Location default"); Tax (the name of the tax picked on the customer, exactly as the client named it in Settings, or "Default Tax Settings" when none is picked); Work Order Tier and Part Sales Tier with their numbers, only with more than one active tier.
* S9-R14: The card's edit icon opens Edit Customer.
* S9-R15: The whole Pricing section shows only with 'View and Manage AP/AR Data'; changing tiers in Edit Customer needs only 'Customers — Create & Edit'.
* S9-R16: The Pricing rows show even when the customer has no address.
* S9-R4: A tier's Customers tab lists its customers with their channel(s). Manage Customers opens at any time with Add Customers (everyone not on the tier for at least one channel) and Remove Customers (those on it, with the count); each row shows the customer's current tiers.
* S9-R17: Each Manage Customers tab explains itself in a tooltip on its title, with no message above the list.
* S9-R18: Ticking customers shows the design system's dark bulk action bar at the top of the dialog, above the search and the list, as on a work order's lines: "3 selected", Select All with the list's count (while not all are ticked), Work Orders and Part Sales checkboxes, and an X that clears. It is the design system's dark bulk action bar.
* S9-R19: A channel checkbox is checked when every ticked customer has that channel, mixed when some do; checking or clearing it sets that channel on every ticked customer. On Remove it sets the channels to take them off.
* S9-R20: A customer ticked afterwards starts with both channels it isn't on yet.
* S9-R21: Each ticked row has Work Orders and Part Sales chips; a chip is locked (greyed, name only) when its channel can't change.
* S9-R22: A removed customer goes back to Default for that channel.
* S9-R23: The footer sums up the change ("Adding 3 customers: 2 for both, 1 for Work Orders only."); the button names the count ("Add 3 Customers"; a red "Remove 2 Customers").
* S9-R24: Switching tabs clears the picks.
* S9-R5: Tiers change only by an explicit action. A row on a tier's Customers tab has no actions menu. One customer moves in Edit Customer; several in the other tier's Manage Customers, where adding for a channel takes them off their previous tier for it.
* S9-R7: Changing a customer's tier never changes work orders or Part Sales already made; the dialog says "Existing work orders and Part Sales keep their prices and tier."
* S9-R27: After a tier change, open work orders and Part Sales keep the tier they were made with for parts added later, show no Manual icon, and their price details name that tier and the customer's tier now, only on that channel.
* S9-R8: The built-in Counter Sale customer can be put on tiers; its tier fields show the tooltip "Every walk-in sale uses this tier." Only the Counter Sale customer ShopView created gets the tooltip.
* S9-R9: A tier's Customers tab has search by name, a channel filter (Work orders, Part Sales, Both), sort by name A to Z by default and a sortable channel column (ties by name), 50 a page; search, filters, sort and page are kept on return.
* S9-R10: The Manage Customers picker has the same sort; search matches the customer's name and their current tiers' names; no paging, 50 more load as the user scrolls; tab count and Select all cover every match, loaded or not.
* S9-R11: The Customers list is unchanged.
* S9-N1: A ticked customer with no channel shows "Pick Work Orders, Part Sales or both." and the button stays off; with nobody ticked, "No customers picked yet." and the button is off.
* S9-N3: Closing Manage Customers without saving changes nothing.
* S9-N6: Empty states: 'No customer matches "…".'; "Every customer is already on Fleet Platinum."; "No customer is on Fleet Platinum yet."
* S9-E2: Selecting all of a large list (for example 1,284) saves with the spinner, then the confirmation toast.
* S9-E3: Customer delete rules are unchanged; deleting a customer with no history removes their tier assignments.
* S9-E5: On Add, Select All with a channel checked leaves out customers already on the tier for every channel picked; the footer counts them ("12 skipped: already on Fleet Platinum for Work Orders."). They never block Save; a customer can still be ticked for a channel they aren't on.
* S9-E7: Remove works the same way for customers not on the tier for the channels picked; re-checking a channel skips again; a customer ticked by hand stays ticked for the channels they can still use.
* S9-E6: A bulk add or remove is all or nothing; on failure nothing saves and the picks are kept.
* Error: a failed save shows today's error toast; the dialog stays open with the picks kept.

## Acceptance Criteria

- [ ] Given a client with only Default, then New Customer, Edit Customer and the customer card show no tier fields; given a second active tier, then they show.
- [ ] Given Edit Customer, then Work Order Tier and Part Sales Tier sit under Default Shop Supplies and before Notes, and no other field moves.
- [ ] Given a customer, when the work order tier is set to Fleet, then the Part Sales tier is unchanged, and the other way round.
- [ ] Given the tier picker, then it lists active tiers as "4 · Fleet" by number, hides archived tiers, and typing "4" lists tier 4 first while "fle" finds Fleet.
- [ ] Given a new or imported customer, then both tiers are Default.
- [ ] Given a user with 'View and Manage AP/AR Data', when the customer page opens, then the customer card has a Pricing section under IBS with Labor Rate, Shop Supplies, Tax and both tiers; without that permission, the section doesn't show.
- [ ] Given a customer whose labor rate differs at another location, then Labor Rate shows the current location's rate with "Varies by location".
- [ ] Given a customer with no address, then the Pricing rows still show.
- [ ] Given the card's edit icon, then it opens Edit Customer; given 'Customers — Create & Edit' without 'View and Manage AP/AR Data', then the tier fields can still be changed in Edit Customer.
- [ ] Given Fleet's Customers tab, then it lists its customers with their channels, has search, a channel filter, name sort A to Z, a sortable channel column and 50 a page, rows have no actions menu, and the settings are kept on return.
- [ ] Given Manage Customers, then Add lists everyone not on Fleet for at least one channel, Remove lists those on it with the count, each row shows current tiers, and each tab's tooltip explains it.
- [ ] Given 3 customers ticked, then the bar shows "3 selected", Select All with the list count, the two channel checkboxes and the X; a channel checkbox is checked when all have it and mixed when some do.
- [ ] Given a customer already on Fleet for Work Orders, when ticked on Add, then the Work Orders chip is locked (greyed, "Work Orders" only) and Part Sales is picked.
- [ ] Given 2 customers added for both and 1 for Work Orders, then the footer reads "Adding 3 customers: 2 for both, 1 for Work Orders only." and the button "Add 3 Customers"; on Remove, a red "Remove 2 Customers".
- [ ] Given picks on Add, when the user switches to Remove, then the picks are cleared.
- [ ] Given a customer on Wholesale for work orders, when added to Fleet for Work Orders, then they leave Wholesale for work orders only.
- [ ] Given a customer removed from Fleet for Part Sales, then their Part Sales tier is Default.
- [ ] Given a ticked customer with no channel, then "Pick Work Orders, Part Sales or both." shows and the button is off; with nobody ticked, "No customers picked yet." and the button is off.
- [ ] Given Manage Customers closed without saving, then nothing changes.
- [ ] Given a search with no match, then 'No customer matches "…".'; given everyone on Fleet Platinum, then Add reads "Every customer is already on Fleet Platinum."; given nobody on it, then Remove reads "No customer is on Fleet Platinum yet."
- [ ] Given Select All on 1,284 customers, when saved, then the spinner shows, then the confirmation toast.
- [ ] Given Select All with Work Orders checked and 12 customers already on Fleet Platinum for Work Orders, then those 12 aren't ticked, the footer says "12 skipped: already on Fleet Platinum for Work Orders.", and Save isn't blocked.
- [ ] Given a bulk save where one customer fails, then nothing is saved, today's error toast shows, and the picks are kept.
- [ ] Given a customer with an open work order made on Default, when they are moved to Fleet, then the dialog says "Existing work orders and Part Sales keep their prices and tier."; a part added to that work order is priced by Default with no Manual icon; its price details name Default and that the customer is now on Fleet; their Part Sales are unaffected by a work order tier change.
- [ ] Given the Counter Sale customer ShopView created, then its tier fields show "Every walk-in sale uses this tier."; given a customer a client created named Counter Sale, then no tooltip shows.
- [ ] Given a customer with no work orders, vehicles, contacts, transactions, payments or credit, when deleted, then their tier assignments are removed.
- [ ] Given the Customers list, then it is unchanged.
