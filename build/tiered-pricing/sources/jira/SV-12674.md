# SV-12674 Verify: Settings › Pricing tabs, the Parts menu order and the Matrices list (Phase 11)

## Description

**Covers:** TP-S6-R1–R3, R6–R11; TP-S7-R14; TP-S3-R8, R9, N3; TP-S16-R2, R5, R6, R11, N1, N4; TP-S19-R7, R10, R19, R22; NFR-010; decision D2

**Checklist**

1. As `admin`, Settings' Parts group lists Categories, then Pricing, then Bin Locations (TP-S7-R14). `/administration/pricing` has Tiers, Matrices and Fixed Rules tabs, and the chosen tab stays in the URL and comes back on reload. Fixed Rules lists only fixed rules and works as today, with no new sorting (D2).
2. As a role with 'Settings — Parts' but not 'See Financial Data' (create it locally; quick-login has no such user), Settings › Pricing shows only the Fixed Rules tab, and opening `?tab=matrices` or a matrix's URL directly shows no tiers or matrices (TP-S16-R11). As a role without 'Settings — Parts', the Parts group is hidden, and a link to Pricing shows "Access restricted" with "Looks like you don't have access to this page. Reach out to your administrator to request access." and Go to home (TP-S16-N1).
3. Columns (TP-S6-R1, TP-S6-R7, TP-S6-R8, TP-S6-R10): Matrix; Status (an Active or Inactive badge, Inactive with "No categories use this matrix" on hover); Categories (up to three names, then "+N" with the full list on hover, "—" when none); Tiers ("All", or "1, 2, 4" with their names on hover, from the Work Order side only, never archived tiers); Work Order Matrix (Default's rules in short); Part Sale Matrix (On or Off). The General Matrix is first, with the Default badge and "All categories without a matrix (n)", where n counts Uncategorized too.
4. Sorting and search (TP-S6-R2, TP-S6-R3, TP-S6-R6, TP-S19-R22): 50 matrices a page, General Matrix first, then A to Z. Matrix and Categories sort, and Categories sorts by the number of categories, most first on the first click. Search matches matrix and category names. No match reads 'No matrices match the search "…".' with Clear Search; filters with no match read "No matrices match these filters" with Clear All Filters. Search, sort and page are kept after opening a matrix and coming back.
5. Row actions (TP-S6-R9, TP-S3-R8, TP-S3-R9, TP-S3-N3): Edit opens the matrix page in edit. More Actions › Duplicate creates "<name> (copy)" (then "(copy 2)") with no categories and opens it. Delete asks first, naming the categories, which then move to the General Matrix. The General Matrix's Delete is disabled with "The General Matrix can't be deleted. You can edit it." New Matrix opens a new matrix page.
6. Audit Log (TP-S19-R19): the list's three-dot menu opens "Audit Log: Matrices": today's history dialog with its search, no Line column, newest first, each change as "<label>: <old> → <new>", deleted matrices included, 50 at a time as you scroll, and "No history here. Yet." when empty.
7. Loading and errors (TP-S19-R7, TP-S19-R10): the list shows a loading skeleton; a failed load shows "Ooooops! An error occurred" with Try again and keeps the search, filters, sort and page.
