## Bottom line
- **All 3 are GAPS at the specific-regression level.** Our suites cover the *general* permission rules
  (VOM View grants Vendors; customer default-adjustments needs Customers C&E + AP/AR; WOL/part-menu gating)
  but **none has a case that asserts the exact regression each ticket describes.** New cases are needed later
  (separate authoring step — not done here): one negative for SV-8682 (Reports-independence), one clarification
  case for SV-8541 (once PM confirms WO→View gate), one page-load regression case for SV-8701.
- **Traceability (Rule 20/25):** each near-neighbor case above tests the cited permission/§. New cases should
  carry combined `refs` = `<TICKET> (<spec-anchor>)` — e.g. `SV-8682 (Custom Roles §Vendor & Order Management)`,
  `SV-8541 (SV-8183 §9 / Custom Roles "Cores OK/Not Ok = WO→View")`, `SV-8701 (SV-8289 S13-R9)`.
