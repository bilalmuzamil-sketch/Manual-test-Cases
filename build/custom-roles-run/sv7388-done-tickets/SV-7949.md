# SV-7949 — Sales Representative | Reports That Are Not Available Are Still Visible

- **Type:** Story Defect - Archive
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-25  **Updated:** 2026-07-08T01:03
- **Link:** https://shopview.atlassian.net/browse/SV-7949

## Description

**Environment:**   
Staging

‌

The Reports menu displays reports that are not intended to be accessible by the Sales Representative role.

Examples include:

* Timesheets (returns **"Missing required parameter"**)
* Follow Up (returns **"Ooops! An error occurred"**)

These reports are not usable by this role and should not be displayed.

‌

**Expected Result:**  
Only reports that are supported by the Sales Representative role should be visible.

‌

**Actual Result:**  
Reports that cannot be accessed are still displayed and result in application errors when opened.
