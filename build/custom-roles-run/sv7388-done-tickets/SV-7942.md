# SV-7942 — Technician Sees Only Assigned Work Orders While "My Work Orders" Toggle Is Still Displayed

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-25  **Updated:** 2026-07-13T06:53
- **Link:** https://shopview.atlassian.net/browse/SV-7942

## Description

**Affected Role:**  
Technician (configured with all permissions/CRUD as per the specification)

**Description:**  
The Technician role is restricted to viewing only Work Orders assigned to them in the Work order section.  
  
**Note:** There is a **"My Work Orders"** toggle is still displayed on the Work Orders page.

Since the list is already filtered to the technician's assigned Work Orders, the toggle becomes redundant and misleading because there is no alternate view to switch to.

**Steps to Reproduce (STRs):**

1. Log in as a **Technician** configured according to the specifications.
2. Navigate to **Work Orders section**.
3. Observe that only Work Orders assigned to the logged-in Technician are displayed.
4. Observe the **"My Work Orders"** toggle in the top-right corner.

**Actual Result:**

* Only assigned Work Orders are displayed.
* The **"My Work Orders"** toggle is still visible despite there being no broader Work Order view available.

**Expected Result:**  
Product clarification is required:

* **Option 1:** Hide the **"My Work Orders"** toggle for roles that are permanently restricted to their assigned Work Orders.
* **Option 2:** If the toggle is intended to remain visible, it should provide meaningful functionality by allowing the user to switch between "My Work Orders" and another permitted view.
