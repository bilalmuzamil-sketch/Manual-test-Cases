# SV-8015 — Editing a Catalog Part and Changing Its Category Fails with Application Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-29  **Updated:** 2026-07-06T09:56
- **Link:** https://shopview.atlassian.net/browse/SV-8015

## Description

**Affected Role:**  
Administrator (or any role with permission to edit Catalog Parts)

**Description:**  
When editing an existing Catalog Part, changing its **Category** from the category dropdown and saving the changes results in an unexpected application error.

Instead of updating the Catalog Part successfully, the application displays an error message and the category change is not saved.

**Steps to Reproduce (STRs):**

1. Navigate to **Parts → Catalog**.
2. Open any existing **Category**.
3. Click the **Edit** icon in the top-right corner of a Catalog Part.
4. Change the **Category** using the category dropdown.
5. Save the changes.

**Actual Result:**  
The application displays the following error and the category is not updated:

> **Include your request ID: \[90054b22-f574-4075-97e0-84e08d573e93\]**

**Expected Result:**  
The Catalog Part's category should be updated successfully without any errors.

**Impact:**  
Users are unable to reassign Catalog Parts to different categories, preventing proper catalog organization and maintenance.
