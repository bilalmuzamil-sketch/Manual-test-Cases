# SV-7504 — Financial Data Confirmation Modal

- **Type:** Story
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-02  **Updated:** 2026-07-13T03:58
- **Link:** https://shopview.atlassian.net/browse/SV-7504

## Description

When enabling any Part Sales or Invoicing CRUD checkbox (View, Edit, or Delete) while See Financial Data is OFF, a confirmation modal appears: "\[Area\] requires 'See Financial Data' to be enabled. Enable it?" Confirm auto-enables See Financial Data and applies the checkbox change. Cancel reverts the checkbox to its previous state.
