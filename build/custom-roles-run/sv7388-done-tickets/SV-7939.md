# SV-7939 — Technician Receives 403 Error When Filtering Work Orders by Imported Status

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-25  **Updated:** 2026-07-06T08:18
- **Link:** https://shopview.atlassian.net/browse/SV-7939

## Description

**Affected Role:**  
Technician configured with permissions as **per spec**

**Description:**  
When a Technician applies the **Work Order Status** filter for **Imported**, the system returns a **403 access error**.

**Steps to Reproduce:**

1. Log in as a **Technician** role configured according to the specification.
2. Navigate to **Work Orders**.
3. Open the **Status** filter.
4. Select **Imported**.

**Actual Result:**  
A **403 error** is returned.

**Expected Result:**  
The Technician should either be able to filter Work Orders by **Imported** status, or the **Imported** filter option should not be visible if the role is not permitted to access it.
