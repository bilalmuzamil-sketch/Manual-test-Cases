# SV-8079 — Vendor & Order Management: View + Create & Edit role can EDIT/change cost (Total Cost) on Vendor Invoices with See Financial Data OFF — beyond visibility, financial values are modifiable by a role that shouldn't see them

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-07T08:35
- **Link:** https://shopview.atlassian.net/browse/SV-8079

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388

**Environment:** Staging 

**Preconditions:**

* Custom role with Parts Department ON, **Vendor & Order Management: View + Create & Edit ON**
* **See Financial Data: OFF**; no other permissions enabled

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Go to Parts → Vendor Invoices → open a vendor invoice
3. Observe the **Total Cost** column is visible
4. Attempt to **change/edit the cost** value

**Expected Result:**  
With See Financial Data OFF, financial data must be hidden across every page (§6a) — cost values should be neither visible nor editable for this role.

**Actual Result:**

* Total Cost is **visible** on Vendor Invoices (this visibility is already tracked in SV-8077).
* Additionally, the user can **change/edit the cost** value — financial data is modifiable despite See Financial Data being OFF.

**Scope / Notes:**

* The **visibility** of Total Cost in Vendor Invoices is a duplicate of **SV-8077** (View-only). This ticket concerns the **editability** — a write capability, not just a view leak — which SV-8077 does not cover and which requires Create & Edit.
* Same See-Financial-Data-OFF leak family (SV-7957 / SV-7956 / SV-7965), escalated to modification.
