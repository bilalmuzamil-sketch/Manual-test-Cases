# SV-8062 — "Access restricted" appears on login for a Catalog & Inventory: View role — persists regardless of Reports permission

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-08T08:25
- **Link:** https://shopview.atlassian.net/browse/SV-8062

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388  
**Environment:** Staging

**Preconditions:**

* Custom role with Parts Department **ON**, Catalog & Inventory: View **ON**
* See Financial Data OFF; no other permissions enabled
* Reproduces with Reports both **ON** and **OFF**

**Steps to Reproduce:**

1. Enable Catalog & Inventory: View (Parts Department ON); assign the role to a user
2. Log in → "Access restricted" appears and keeps showing after clicking the Parts tab / ShopView logo
3. Refresh → "Access restricted" appears again
4. Enable Reports, re-login → "Access restricted" still appears (Reports makes no difference)

**Expected Result:**  
With a valid Catalog & Inventory: View config, the user should land in a usable state (no "Access restricted"), regardless of Reports.

**Actual Result:**  
"Access restricted" appears on login and persists after clicking Parts / ShopView logo; refresh re-triggers it. Behavior is consistent whether Reports is enabled or disabled.
