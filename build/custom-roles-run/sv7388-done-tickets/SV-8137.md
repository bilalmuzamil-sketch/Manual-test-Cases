# SV-8137 — WO View role cannot see License Plate (should be viewable with Work Orders: View)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-08T10:38
- **Link:** https://shopview.atlassian.net/browse/SV-8137

## Description

Split from SV-7929 per Sasha's comment (3 Jul 2026).

**What should happen (per PM ruling on SV-7929, 3 Jul):**

* Work Orders: View should let the user see the License Plate information (read-only).

**What happens on the build:**

* With Work Orders: View only, the License Plate is not visible.

**Steps to reproduce:**

1. Log in as a role with Work Orders = View only (e.g. Parts Technician).
2. Open a work order that has a license plate set.
3. Look for the License Plate.

**Expected:** the License Plate is visible (read-only) with Work Orders: View.

**Actual:** the License Plate is not shown.

**Spec references:**

* Custom Roles and Permissions, page 565116952, v39.
* Section 1b, Work Order Lines Create & Edit: "edit license plate" (editing needs Create & Edit).
* PM ruling: SV-7929 comment, 3 Jul 2026 — View is required to view the License Plate.

**Related:** SV-7929 (parent clarification), SV-8134 (Mileage / Engine Hours — same View-visibility pattern).
