# SV-8297 — Service Manager template should have Work Orders → Delete enabled (per current spec)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-13  **Updated:** 2026-07-14T15:20
- **Link:** https://shopview.atlassian.net/browse/SV-8297

## Description

On validating the Service Manager template against the current Custom Roles and Permissions specification, the Service Manager should have the **Delete** permission for **Work Orders**.

Per the specification's Permission Matrix, Service Manager = **View / Create & Edit / Delete** on Work Orders. The Delete CRUD level should be checked (ON) for the Service Manager template.

**Steps to Reproduce:**

1. Navigate to Settings → Roles & Permissions.
2. Edit the Service Manager role (or reset it to the Service Manager template).
3. Locate the Work Orders permission group.
4. Observe the CRUD permissions.

**Expected Result:**  
Service Manager has Work Orders = View / Create & Edit / **Delete** (Delete ON).

**Actual Result:**  
Work Orders → Delete is not checked for the Service Manager template.

**Spec reference:** <custom data-type="smartlink" data-id="id-0">https://shopview.atlassian.net/wiki/spaces/PM/pages/565116952</custom>  — Permission Matrix, Work Orders row (Svc Mgr = V/E/D).

### Milomir Kotlajic — 2026-07-14T12:38

Fix in PR [#2089](https://github.com/ShopView/shopview/pull/2089) (branch `SV-8297-service-manager-wo-delete`, off `develop`).

Root cause: SV-8093 (PR #1902, merged) removed `workOrdersDelete` from the Service Manager template when spec v33 had Delete OFF. The current Permission Matrix flips it back to View / Create & Edit / **Delete**, so this restores it.

Added `workOrdersDelete` to the ServiceManager block in `RoleFePermissionMappings` — the single source of truth for **both** the system default role (`app:insert-default-roles`) and the global template snapshot the FE "reset to template" picker reads (`app:insert-role-template-bundles`). So it's true for the system role **and** the related template, per Sasha's note. Matrix unit test updated (green).

**Post-deploy ops reconcile required** (existing orgs + template snapshot): run `app:insert-default-roles` then `app:insert-role-template-bundles`.
