# SV-7750 — FE/BE - Reset to Template Does Not Restore Role Permissions

- **Type:** Story Defect - Archive
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-17  **Updated:** 2026-07-06T07:27
- **Link:** https://shopview.atlassian.net/browse/SV-7750

## Description

The **Reset to Template** functionality is not working as expected. After modifying a custom role and attempting to reset it back to its original template, the role permissions are not restored.

---

### **Steps to Reproduce (STRs):**

1. Navigate to **Settings → Custom Roles**.
2. Create a custom role from any template.
3. Modify one or more permissions in the role.
4. Save the changes.
5. Reopen the role for editing.
6. Click **Reset to Template**.
7. Confirm the action (if prompted).

---

### **Actual Result:**

* The role permissions remain unchanged.
* The template permissions are not restored.
