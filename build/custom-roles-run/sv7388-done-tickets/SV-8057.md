# SV-8057 — Password reset fails with server error when saving new password

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-07T15:56
- **Link:** https://shopview.atlassian.net/browse/SV-8057

## Description

**Description:**  
After requesting a password reset and opening the email link, entering a new password and submitting returns a server error, so the reset never completes.

**Steps to Reproduce:**

1. Use Forgot Password and open the reset link from the email.
2. Enter and repeat a new password.
3. Click Login/Save.

**Expected Result:**  
Password is updated and the user is signed in.

**Actual Result:**  
Request fails with a 500 error; password not reset.
