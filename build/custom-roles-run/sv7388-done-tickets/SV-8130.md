# SV-8130 — Parts Technician can pick, order, and receive parts but cannot mark a core OK/Not-OK or request a part — please confirm if this is intended

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-13T13:52
- **Link:** https://shopview.atlassian.net/browse/SV-8130

## Description

Spec: Custom Roles and Permissions, page 565116952, version 39

What happens now (this is correct per the current spec, not a bug):

Parts Technician has Work Order Lines set to View only. They do not have Create & Edit on Work Order Lines. **Because of that, they cannot:**

* **Mark a core OK or Not-OK on a line.**
* **Request or manage a part request on a line.**

Both of these actions are tied to Work Order Lines Create & Edit in the spec (section 1b).

**But the same role can already do the rest of the parts work on a work order:**

* **Pick Parts is ON** — they can pull parts from inventory onto a line.
* **Order Parts is ON** — they can place purchase orders and receive part deliveries onto the work order.

These two only need Work Orders View, so the role has them.

The problem being raised:

The Parts Technician can already source, order, and receive parts on a work order, including cores. It does not make sense that the same role cannot mark a core OK/Not-OK or request a part, since those are part of the same parts workflow they already handle. Right now those two actions are blocked because they need Work Order Lines Create & Edit, which the role does not have.

**Questions for PM:**

1. Is it intended that Parts Technician cannot request a part on a work order line, even though they have Pick Parts and Order Parts turned on?
2. Should marking a core OK/Not-OK and requesting a part be separated from Work Order Lines Create & Edit for a role that has Pick Parts and Order Parts (or added to Parts Technician directly), so they can finish the parts workflow they can already start?
3. If the current setup is intended, please confirm so QA can lock the expected result. If not, please tell us the correct gate.

Spec references:

* Section 1b, Work Order Lines Create & Edit: "manage part requests on lines" and "Mark a core OK or Not OK on a line."
* Section 1a, Order Parts: "Also controls receiving parts deliveries onto a work order." And the note: users do not need Work Orders Create & Edit to pick parts or order parts.
* Role matrix, Parts Technician: Work Order Lines = View, Pick Parts = ON, Order Parts = ON.
