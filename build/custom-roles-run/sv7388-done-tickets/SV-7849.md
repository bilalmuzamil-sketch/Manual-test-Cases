# SV-7849 — FE - Technician can edit and cancel a part request on an approved WO line

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-23  **Updated:** 2026-06-27T05:36
- **Link:** https://shopview.atlassian.net/browse/SV-7849

## Description

**Description:** On an approved work order line, a Technician can open a part request, edit it, and cancel (delete) it — the part is removed. An approved line should be read-only for this role, so editing and cancelling parts shouldn't be allowed.

**Steps to Reproduce:**

1. Log in as a Technician.
2. Open WO S3-14971 → line 1 (Approved) → on a part, open Edit Part Request.
3. Click Cancel Order.

**Expected Result:** Part request edit/cancel is blocked on the approved line; the Technician cannot remove the part.

**Actual Result:** The modal is editable and Cancel Order deletes the part (Parts count 3 → 1). No permission error.
