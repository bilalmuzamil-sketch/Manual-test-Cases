# SV-7805 — Incorrect “Deposit Covers Full Invoice Amount” Message Displayed When Invoice Still Has Remaining Balance

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-20  **Updated:** 2026-07-07T15:35
- **Link:** https://shopview.atlassian.net/browse/SV-7805

## Description

**Affected Roles:**  
All roles that have permission to **add deposits** and **create invoices**.  
**Environment**: [https://sleep.qa.shopview.com/?app=sv5319&api=sv5319](https://sleep.qa.shopview.com/?app=sv5319&api=sv5319)

---

### **Description:**

After adding a deposit that covers only a portion of the invoice balance, the system incorrectly displays a message indicating that the deposit covers the full invoice amount and that the invoice has been automatically marked as paid.

However, a remaining balance is still due on the invoice.

---

### **Steps to Reproduce (STRs):**

1. Create a **Work Order**.
2. Create and complete a **Work Order Line**.
3. Add a **deposit equal to approximately half of the invoice balance**.
4. Review the Work Order.
5. Click **Create Invoice**.

---

### **Actual Result:**

The system displays the following message:

> **"Deposit covers the full invoice amount. Invoice has been automatically marked as paid and payment created."**

Despite this message, the invoice still has an outstanding balance remaining to be paid.
