# SV-7912 — Clarify the Manage AP/AR dependency for reversing vendor transactions

- **Type:** Task
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-25  **Updated:** 2026-06-28T10:37
- **Link:** https://shopview.atlassian.net/browse/SV-7912

## Description

Per the spec, a role with **Vendor and Order Management: Delete** can reverse vendor transactions.  
In the build, the **reverse action lives inside the Unpaid Invoices / Payments tabs** on the vendor detail page, which **only appear when Manage Accounts Payable and Receivable is ON**.  
  
The tab-visibility is in the spec, but the combined requirement — that reversing a vendor transaction also needs Manage AP/AR ON — is not.

**Example role — Parts Technician:**

| Aspect | Detail (per spec, page 565116952) |
| --- | --- |
| Permission the role HAS | Vendor and Order Management = View / Create and Edit / Delete |
| Function the spec says is executable | "Reverse vendor transactions" (Vendor and Order Management → Delete) |
| Function blocked in build | Reversing a vendor transaction (action unreachable) |
| Dependency that actually gates it | Manage Accounts Payable and Receivable = ON (the reverse action lives in the AP/AR-gated Payments tab) |
| Does the role have that dependency? | NO — Parts Technician has Manage AP/AR = OFF |
| Is the dependency in the spec? | PARTIAL — the spec says Manage AP/AR controls those tabs' visibility, but does NOT state that reversing therefore requires it |

So the spec enables this role to reverse vendor transactions, but the function depends on Manage AP/AR being ON (because that's where the action lives) — which the role does not have, and which the spec does not state as a requirement for reversing.

Requesting clarification: is this dependency intended? If yes, the spec must document it and the build should prompt the user — when enabling Vendor and Order Management: Delete — to also enable Manage AP/AR in order to **reverse a vendor transaction**. If not, the build should be corrected so the action is reachable with Vendor and Order Management: Delete alone, and the spec should confirm that.
