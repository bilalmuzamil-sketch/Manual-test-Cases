# SV-8084 — Part Sales role with View + Create & Edit + Delete (See Financial Data ON) cannot reverse part sale invoices on Staging — Finance tab (the entry point for reversal) is missing; works in Production. Enabling Vendor & Order Management did not help

## Description

**Issue Type:** Bug  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging 

**Affected Area:** Part Sales — reverse part sale invoices

**Preconditions:**

* Custom role with **Parts Department ON**, **Part Sales: View + Create & Edit + Delete ON**
* **See Financial Data ON**
* (Also tested with **Vendor & Order Management: View + Create & Edit + Delete ON** — no change; see Notes)
* User assigned that custom role

**Steps to Reproduce:**

1. Log in as the custom role user
2. Go to Parts → Part Sales → open a part sale
3. Locate the Finance tab to create/reverse an invoice
4. Attempt to reverse a part sale invoice

**Expected Result:**  
Per spec, Part Sales: Delete grants "reverse part sale invoices" (§1e). The user should be able to reverse a part sale invoice. In Production this works: Part Sales has a **Finance tab** → create invoice → add payment → reverse (Production correctly prompts to delete the payment first before reversing the invoice — expected business logic).

**Actual Result:**

* On Staging, the user **cannot reverse part sale invoices** because the **Finance tab is missing** — the reversal workflow has no entry point.
* **Production comparison:** The same flow works in Production (Finance tab present; create invoice → add payment → reverse, with the "delete payment to reverse" prompt).

**Scope / Notes:**

* Root cause is the **missing Finance tab on Part Sales in Staging** (tracked in SV-8081 / SV-8082). This ticket specifically covers the resulting inability to **reverse part sale invoices**, which the spec explicitly grants to Part Sales: Delete (§1e) and which functions correctly in Production.
* **Vendor & Order Management theory ruled out:** In Production, reversing a paid invoice prompts "delete payment first" (expected). Since payment deletion can occur under Vendor & Order Management, that permission was enabled (View + Create & Edit + Delete) to test whether reversal depended on it — it did **not** restore the Finance tab or enable reversal. So reversing part sale invoices is **not** gated by Vendor & Order Management; the blocker is the missing Finance tab.

**Findings:**

* Part Sales (V/E/D) + See Financial Data, no Invoicing → no Finance tab; cannot create/reverse invoices.
* Adding **Invoicing & Payments: View** → Finance tab appears on Part Sales.
* Adding **Invoicing & Payments: Create & Edit** → can create part sale invoices; the Reverse option appears.
* Part sale invoices/payments correctly live on the **customer** side (AR). Reaching/reversing them required **Customers: View** (to see the customer-side payment) and **Manage AP/AR** (to view/delete the payment).

Conclusion: reversing part sale invoices is not gated by **Part Sales: Delete**, and the Finance tab was never "missing" — it correctly requires **Invoicing & Payments** (§1h). The original premise of this ticket (Part Sales: Delete → reverse, per §1e) is superseded by the 6/28 Change Log, which moved invoice reversal to **Work Orders: Delete**. Closing as Obsolete.
