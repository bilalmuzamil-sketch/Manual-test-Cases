## Description

**Description:** In a work order, using Move part to line and selecting a target Work Order fires a request to load that WO's lines, which fails with a 500 error — so the Target Line dropdown can't populate and the part can't be moved.

**Steps to Reproduce:**

1. Open a work order → on a part, choose Move part to line.
2. Select a target Work Order (S9-24917 \[New Test\]).
3. Open the Target Line dropdown.

**Expected Result:** The selected WO's lines load and can be picked as the target.

**Actual Result:** The request `GET /api/work-orders/lines/7a6b0b7f-9329-4c89-b2d4-8d288ca886c5` returns 500, so no target line loads and the move can't complete.
