# SV-8002 — "Add Customer" in New Work Order flow is gated by Customer Management Create+Edit permission

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-29  **Updated:** 2026-07-07T15:52
- **Link:** https://shopview.atlassian.net/browse/SV-8002

## Description

**Area:** Custom Roles & Permissions — Incorrect enforcement of Customer Management 

## What happens

A custom role can be configured with **Customers: View ON** but **Customers: Create + Edit OFF** the user is unable to add a customer during the create WO flow.

## Steps to reproduce

1. Log in as an Owner or Admin.
2. Go to **Settings → Roles & Permissions** and create a custom role with:

    * **Work Orders: Create + Edit** ON
    * **Customers: View** ON
    * **Customers: Create + Edit** OFF
    * (all other permissions off)
    
3. Assign the role to a user and log in as that user.
4. Go to **Work Orders → New Work Order**.
5. In the customer/asset step, select an existing customer.
6. Observe the **"Add” {Customer} button is missing**

## Expected result

With **Customers: Create + Edit OFF**, the user cannot create customer assets — the **"Add” {Customer}** button should be **visible**.

This should also be true if Customer → View is OFF. The user does not need any Customer CRUD settings.

## Actual result

The **"Add” {Customer}** button is **hidden**.

To create WOs, you need to be able to create customers and assets in the create WO flow.
