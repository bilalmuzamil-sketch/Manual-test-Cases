# SV-8166 — Spec Clarification: Should Technician See "Delete" for Imported Invoices When Settings → Parts Is Disabled?

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-06  **Updated:** 2026-07-08T05:41
- **Link:** https://shopview.atlassian.net/browse/SV-8166

## Description

**Description:**  
While validating Imported Invoice deletion, it was observed that the **Delete** action is visible to the Technician. However, attempting to delete an Imported Invoice results in a **403 Access Restricted** error because **Settings → Parts** is disabled for the role.

This raises a product/specification question regarding the intended permission model.

**Current Behavior:**

* Technician can see the **Delete** button for an Imported Invoice.
* Clicking **Delete** results in a **403 Access Restricted** error.
* The action appears to be gated by **Settings → Parts**, which is disabled for the Technician.

**Steps to Reproduce (STRs):**

1. Log in as a **Technician** configured as per the specification.
2. Navigate to an **Imported Invoice**.
3. Observe that the **Delete** button is available.
4. Click **Delete**.

**Actual Result:**  
A **403 Access Restricted** error is displayed.

**Expected Result / Clarification Needed:**

Please confirm the intended behavior:

* **If deleting Imported Invoices should require** `Settings → Parts`**:**

    * The **Delete** button should **not** be visible to the Technician.
    

**OR**

* **If Technicians are intended to be able to delete Imported Invoices:**

    * The **Delete** action should complete successfully without returning a **403** error.
    

**Impact:**  
The current implementation exposes an action that the Technician cannot execute, resulting in inconsistent permission enforcement and a confusing user experience.
