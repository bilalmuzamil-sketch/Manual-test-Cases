- **Resolution:** Done

## Description

Clicking the top-left logo opens the Dashboard, but it just keeps showing empty grey loading boxes and never loads. Other pages work fine.

**Steps to Reproduce**

1. Log in to QA as Admin.
2. Click the top-left logo.
3. Watch the Dashboard.

**Expected Result**  
The Dashboard loads and shows its content.

**Actual Result**  
It never loads — grey boxes stay forever. The request `GET /api/dashboard/config` fails with a **400 Bad Request**.
