# SV-8120 — New Line modal shakes/shifts when typing in “Why Are You Doing It?” field

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-14T14:49
- **Link:** https://shopview.atlassian.net/browse/SV-8120

## Description

## Env: Staging

‌

**Note:** `This is not reproducible on Prod`

## Product Area

**Work Orders → Lines → New Line modal**

## Affected Role

Users who can create Work Order lines.

## Description

When adding a new line to a Work Order, the **New Line** modal slightly shakes or shifts from its original position while the user is typing in the **“Why Are You Doing It?”** field.

The movement is visible in the attached video. The modal should remain stable while the user enters text.

## Environment

```
Environment: Staging
Area: Work Orders → Lines
Modal: New Line
Field affected: Why Are You Doing It?
Browser observed: Chrome
```

‌

## Steps to Reproduce

1.  Go to **Work Orders**. 
2.  Open any Work Order. 
3.  Go to the **Lines** tab. 
4.  Click **New Line**. 
5.  In the **New Line** modal, click into the field: 

```
Why Are You Doing It?
```

6.  Start typing text in the field. 
7.  Observe the modal position while typing. 

## Actual Result

The **New Line** modal slightly shakes/shifts from its original position while typing in the **“Why Are You Doing It?”** field.

## Expected Result

The modal should remain fixed/stable in its position while the user types.

Typing in the **“Why Are You Doing It?”** field should not cause the modal to move, shake, jump, or reposition.

## Impact

This creates a poor user experience when adding WO lines.

It may make the modal feel unstable and can be distracting while users are entering line details.
