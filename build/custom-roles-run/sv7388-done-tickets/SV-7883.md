# SV-7883 —  Create Custom Role page renders blank regardless of template selection path (Apply or Skip) — Edit (Existing System Role and Custom roles) also returns blank in staging

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-24  **Updated:** 2026-06-27T05:40
- **Link:** https://shopview.atlassian.net/browse/SV-7883

## Description

**Issue Type:** Bug

**Priority:** High

**Epic:** Custom Roles and Permissions (SV-7388)

**Environment:**

* Environment: Staging
* Area: Roles and Permissions → Create Custom Role/Edit existing roles (both System and Custom)

---

**Preconditions:**

* User is logged into the staging environment
* User has access to Roles and Permissions settings
* Custom Roles feature is enabled on the staging build

---

**Steps to Reproduce — Path A (With Template):**

1. Navigate to Settings --> Roles and Permissions
2. Click **Create Custom Role**
3. Select a template from the list
4. Click **Apply**
5. Observe the resulting page becomes blank

**Steps to Reproduce — Path B (Without Template):**

1. Navigate to Settings --> Roles and Permissions
2. Click **Create Custom Role**
3. Do not select a template
4. Click **Skip**
5. Observe the resulting page becomes blank again

**Steps to Reproduce — Path C (Edit Existing Role):**

1. Navigate to Settings → Roles and Permissions
2. Locate an existing role
3. Click **Edit**
4. Observe the resulting page becomes blank again

---

**Expected Result:**  
In all three paths, the role creation or edit page should load fully, displaying the role name field, permission toggles, and all relevant configuration options.

**Actual Result:**  
In all three paths, the page renders completely blank. No content, form fields, or error messages are displayed. The blank state is consistent whether a template is applied, skipped, or whether an existing role's Edit action is used.

---

**Scope / Notes:**

* The blank page is reproducible across **all entry points** into the role editor — this is not limited to a specific flow
* Both the "Apply template" and "Skip" paths result in the same blank outcome, ruling out template selection as the root cause
* Editing existing roles is equally affected, suggesting the role editor page/component itself fails to initialize or load data
* URL routing appears functional in both scenarios (correct URL is reached), pointing to a rendering or data-fetching failure at the page level
