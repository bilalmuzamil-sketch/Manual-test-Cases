# SV-8085 — Invoicing & Payments Incorrectly Requires Work Orders View Permission

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-14T14:50
- **Link:** https://shopview.atlassian.net/browse/SV-8085

## Description

**Preconditions:**

* Invoicing & Payments → View enabled
* See Financial Data enabled
* Work Orders → View disabled
* User assigned to the custom role

**Steps to Reproduce:**

1. Log in as the custom role user.
2. Try to access invoices or financial information.
3. Enable **Work Orders → View**.
4. Log in again and access the same area.

**Expected Behavior:**  
The user should be able to access invoices because **Invoicing & Payments → View** and **See Financial Data** are enabled.

**Current Behavior:**  
The user cannot access invoices unless **Work Orders → View** is also enabled.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §1h Invoicing, View row | "View invoices from work orders and part sales. Access the Finance tab." |
| 2 | §1h Invoicing, Financial gate | "Requires See Financial Data to be ON." |
| 3 | §6a See Financial Data, ON state | "User can see pricing, costs, margins, and financial columns throughout the app." |
