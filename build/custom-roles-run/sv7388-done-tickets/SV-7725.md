# SV-7725 — BE - Title: Role Search Returns Results Based on Description Instead of Role Name

## Description

**Description:**  
The **Search Role** field returns roles that do not match the entered role name because the search appears to be matching against the **Role Description** in addition to (or instead of) the **Role Name**.

This causes irrelevant roles to appear in the search results and makes it difficult to quickly locate the intended role.

---

### **Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles and Permission**
2. In the **Search Role** field, enter **"Technician"**.
3. Observe the filtered results.

---

### **Actual Result:**

* Roles unrelated to the role name **"Technician"** are displayed.
* For example, the **Foreman** role appears in the results because its **description contains the word "Technician"**.
