# SV-8135 — WO View role cannot create Work Order notes or Line notes (create should be allowed with Work Orders: View)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-07T16:03
- **Link:** https://shopview.atlassian.net/browse/SV-8135

## Description

Split from SV-7929 per Sasha's comment (3 Jul 2026). Covers both Work Order notes and Work Order Line notes (same rule).

**What should happen (per PM ruling on SV-7929, 3 Jul):**

* Work Orders: View lets the user create a note, and edit or delete their own note.
* Work Orders: Delete is required to edit or delete someone else's note.

**What happens on the build:**

* With Work Orders: View only, the user can only view notes — there is no option to add a note (Work Order note or Line note).

**Steps to reproduce:**

1. Log in as a role with Work Orders = View only (e.g. Office or Parts Technician).
2. Open a work order.
3. Try to add a Work Order note (Notes tab) and a Line note (on a WO line).

**Expected:** the user can create a Work Order note and a Line note, and edit/delete their own.

**Actual:** notes are view-only; there is no option to add a note.

**Spec references:**

* Custom Roles and Permissions, page 565116952, v39.
* Section 1a, Work Orders View: allows seeing the Notes tab and creating notes.
* Section 1a, Work Orders Delete: required to delete notes.
* PM ruling: SV-7929 comment, 3 Jul 2026 — View creates + edit/delete own; Delete edits/deletes others'.

**Note for PM:** spec v39 (Section 1a) currently says Work Orders: View allows editing ANY note, including others'; the SV-7929 comment says editing others' needs Delete. Please reconcile which is correct so the expected result can be locked.

**Related:** SV-8018 (notes spec clarification).
