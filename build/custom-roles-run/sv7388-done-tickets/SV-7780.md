# SV-7780 — BE - Service Manager role: Do not see the option to click "Customer portal" from the top right navigation.

- **Status:** Done
- **Resolution:** Done

## Description

The user with the “Service Manager” Role has no Customer Portal nav item.

* Customer portal is toggled OFF by default for the service manager role.  

**Steps to Reproduce:**

1. Log in as the Service Manager account ([mudassir.qamar+samm@shopview.com](mailto:mudassir.qamar+samm@shopview.com)).
2. Land on the app after login.
3. Look at the top navigation bar.
4. Check whether the Customer Portal item is present.
