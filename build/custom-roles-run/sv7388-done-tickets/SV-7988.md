# SV-7988 — Technician Receives 403 Error When Returning a Special Order Part

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-28  **Updated:** 2026-06-30T14:51
- **Link:** https://shopview.atlassian.net/browse/SV-7988

## Description

Technician (configured as per the specification)

**Description:**  
A Technician configured according to the specification receives a **403 Access Restricted** error when attempting to return a received Special Order Part.

The return workflow is exposed to the Technician, but the action fails with a 403 error instead of either completing successfully (if permitted) or being hidden if the Technician is not authorized to perform the action.

**Steps to Reproduce (STRs):**

1. Log in as a **Technician** configured as per the specification.
2. Create or open a Work Order.
3. Request a **Special Order Part (SPO)**.
4. Have an Administrator order and receive the part.
5. Refresh the Work Order as the Technician.
6. Open the received Special Order Part.
7. Click **Return**.

**Actual Result:**  
A **403 Access Restricted** error is displayed.
