# SV-8229 — Work Order Line Three-Dot Menu Intermittently Requires Multiple Clicks Before Opening

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-08  **Updated:** 2026-07-13T09:33
- **Link:** https://shopview.atlassian.net/browse/SV-8229

## Description

**Affected Roles:**  
Role/Permission independent (observed regardless of role configuration)

**Description:**  
The **three-dot (More Actions)** menu for a Work Order Line intermittently fails to respond on the first click.

In some cases, users must click the menu **two or three times** before it opens. The issue is intermittent and does not occur consistently, but it affects the responsiveness of the Work Order UI.

**Steps to Reproduce (STRs):**

1. Log in as any user.
2. Open any **Work Order** containing one or more Work Order Lines.
3. Click the **three-dot (More Actions)** menu for a Work Order Line.
4. Repeat the action multiple times across different lines/work orders.

**Actual Result:**  
Intermittently, the three-dot menu does not open on the first click and may require up to **three clicks** before responding.

**Expected Result:**  
The three-dot menu should open immediately on the first click every time.

**Impact:**  
The delayed response creates the impression that the UI is unresponsive or frozen, negatively impacting usability and slowing down common Work Order operations.
