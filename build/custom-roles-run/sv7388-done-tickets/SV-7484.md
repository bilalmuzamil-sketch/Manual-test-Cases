Replace the \~12 hand-rolled `in_array(ROLE_PRICING::VIEW, getRoles())` pricing-masking sites with a single centralized chokepoint. This fixes the legacy "Time Clock saw pricing" bug-class.

* Primary: a `PricingVisibilityProvider` + a `pricing` serialization group on price/cost/margin properties, added to the serialization context only when granted — pricing fields drop out of the payload centrally.
* Backstop: a query/PDF-path stripper for endpoints that bypass the serializer (PDF controllers, `LinesDetailProvider`).
* Migrate the \~12 sites (canonical `ListingController.php:21,37`) off inline checks. **Never FE-only.**

## Dependencies
