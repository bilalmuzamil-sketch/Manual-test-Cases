# SV-7976 — Custom Role with Work Orders View Only Permission Gets "Failed to Load Work Order Lines" Error When Opening a Work Order

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-27  **Updated:** 2026-06-30T15:32
- **Link:** https://shopview.atlassian.net/browse/SV-7976

## Description

**Issue Type:** Bug

**Environment:** Staging

**Affected Area:** Custom Roles & Permissions — Work Orders - View

**Preconditions:**

* Custom role has only **Work Orders: View** enabled.
* All other permissions are disabled, including Work Order Lines.
* View Mode - Tech view and Full view

**Steps to Reproduce:**

1. Create a custom role with only **Work Orders: View** enabled and all other permissions off.
2. Assign this role to a user.
3. Log in as that user.
4. Navigate to the Work Orders tab.
5. Open any Work Order.
6. Observe the error at bottom right corner of the screen 
7. The user will be redirected to the WO list page again

**Expected Result:**  
A user with Work Orders View permission should be able to open a work order and view its contents without any errors. If Work Order Lines are not part of their permission set, the lines section should either be hidden or gracefully handled — not trigger an error.

**Actual Result:**  
When opening a work order, an error toast appears in the bottom right corner of the screen with the message:

> _"Failed to load work order lines. Error fetching work order lines."_

**Notes:**

* The error appears to be triggered because the role does not have Work Order Lines permission enabled, but the system still attempts to fetch work order lines regardless.
* This may indicate that Work Order Lines are being loaded unconditionally when a work order is opened, without checking the user's permissions first.
* The system should either suppress the lines section or silently skip the fetch if the role does not have the required permission — not surface a raw error to the user.
* There is no **Work Order Lines - View** option in custom role settings now.
