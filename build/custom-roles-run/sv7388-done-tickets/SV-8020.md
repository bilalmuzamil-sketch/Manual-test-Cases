# SV-8020 — Service Advisor Cannot Reopen Completed Inspections from Work Order Line — Reopen Button Missing and Read-Only Access Shown

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-29  **Updated:** 2026-07-07T08:01
- **Link:** https://shopview.atlassian.net/browse/SV-8020

## Description

**Issue Type:** Bug

**Environment:** Staging

**Affected Area:** Digital Inspections — Service Advisor Role / Completed Inspection / Reopen

**Preconditions:**

* User is logged in as a **Service Advisor** (System Role)
* A completed inspection exists on a Work Order line.

**Steps to Reproduce:**

1. Log in as a Service Advisor.
2. Navigate to a Work Order that has a completed inspection on a WO line.
3. Open the completed inspection from the Work Order line.
4. Observe that the bottom right corner for the **Reopen** button shows **"Read-only · You have view access"**
5. Observe the top right corner of the inspection.

**Expected Result:**  
As per the Digital Inspections spec, a Service Advisor should be able to reopen completed inspections from the Work Order line. The **Reopen** button should be visible and functional in the bottom right, and the inspection should not display as read-only for this role.

**Actual Result:**  
When a Service Advisor opens a completed inspection from a Work Order line:

* The **Reopen** button is **missing** from the bottom right.
* The top right displays **"Read-only · You have view access"**, indicating the Service Advisor is being treated as a view-only user for completed inspections.
* The Service Advisor is unable to reopen the inspection.

**Notes:**

* The Read-only state and missing Reopen button suggest the Service Advisor role is not being granted the correct permission level for completed inspections.
* Per spec, the ability to reopen completed inspections is explicitly listed as a Service Advisor capability — this is a spec deviation.
