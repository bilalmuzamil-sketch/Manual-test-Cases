# SV-8042 — Technician Receives 403 Error When Completing a Work Order Line via "Set Line Status

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-30  **Updated:** 2026-07-09T07:25
- **Link:** https://shopview.atlassian.net/browse/SV-8042

## Description

**(Technician): → Permission:** Work order line Create & Edit

(configured with all permissions/CRUD as per the specification)

**Description:**  
A Technician configured according to the specification receives a **403 Access Restricted** error when attempting to complete a Work Order Line using the **Set Line Status** action.

The **Complete** status is available in the **Set Line Status** menu, but selecting it results in a backend authorization error.

**Steps to Reproduce (STRs):**

1. Log in as a **Technician** configured as per the specification.
2. Open a Work Order containing an approved Work Order Line.
3. Select the Work Order Line by placing a checkmark next to it.
4. Click the **three-dot menu** in the top-left corner of the Work Order.
5. Click **Set Line Status**.
6. Select **Complete**.

**Actual Result:**  
A **403 Access Restricted** error is displayed, and the Work Order Line is not marked as **Complete**.
