# SV-8200 — Reviewed action shows beside New Line on a freshly created WO before it's reviewable

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-07  **Updated:** 2026-07-08T04:38
- **Link:** https://shopview.atlassian.net/browse/SV-8200

## Description

**Description:** The Reviewed action appears in the WO line toolbar (next to New Line) right after creating a work order and adding a line, when the WO isn't in a reviewable state yet.

**Steps to Reproduce:**

1. Create a new Work Order.
2. Click New Line and add a line.
3. Look at the left side beside New Line.

**Expected Result:** No Review control at this stage — it should appear only when the WO reaches a reviewable state.

**Actual Result:** A Review control shows beside New Line on the just-created WO.
