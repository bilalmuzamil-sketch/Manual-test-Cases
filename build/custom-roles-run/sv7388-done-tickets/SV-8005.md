### **Description:**

On Work Order page  the **Shop Coach Analysis** results are now **not** automatically Expanding.  
You have to click each result separately to expand it.

---

### **Steps to Reproduce (STRs):**

1. Log in as an Admin (For QAs: Also test the same for Technician too).
2. Open a **Work Order**.
3. Create a **Work Order Line**.
4. Add Part
5. Click **Shop Coach Analysis** → Wait for the analysis to finish  
  **Observe:** After the analysis the suggestions will not be automatically expanded rather you will have to click the suggestions to expand them.
