# SV-8237 — Reverse Invoice option is visible on part sales with only Invoicing & Payments: Create & Edit — it should be hidden until Invoicing & Payments: Delete/Reverse is enabled (action is correctly blocked, but the button should not show)

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-09  **Updated:** 2026-07-12T15:42
- **Link:** https://shopview.atlassian.net/browse/SV-8237

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388

**Environment:** Staging

**Affected Area:** Part Sales Finance tab — Reverse Invoice option visibility

**Preconditions:**

* Custom role: Parts Department ON, Part Sales (V/E/D), See Financial Data ON
* Invoicing & Payments: **View + Create & Edit** (NO Delete/Reverse)
* User is assigned to that custom role

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Part Sales → open a part sale → Finance tab → create an invoice
3. Observe the Reverse Invoice option

**Expected Result:**  
Per §1i, reversing invoices / deleting payments is granted by Invoicing & Payments: Delete/Reverse. With only View + Create & Edit, the Reverse Invoice option should be hidden (consistent with SV-7186 — destructive actions hidden, not shown-but-disabled, when the permission is off).

**Actual Result:**

* With Invoicing & Payments: View + Create & Edit (no Delete/Reverse), the Reverse Invoice option is **visible** on the part sale.
* The action itself is correctly blocked — clicking Reverse prompts to delete the payment first, and payment deletion is not possible until Invoicing & Payments: Delete is enabled — so this is a **visibility** issue, not a privilege bypass.

**Scope / Notes:**

* The full gating IS correct for the _action_; the defect is only that the Reverse **button is shown** before Delete/Reverse is enabled.
* Directly maps to SV-7186 (FE: Destructive Actions Toggle — hide Reverse/Delete/Void buttons when the toggle is OFF).

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §1i Invoicing, Delete row | "Delete payments (including customer payments), void transactions, deleting a Part Sale return." |
| 2 | §1i Invoicing, Create and Edit row | "Create invoices, process payments directly from work orders and part sales, manage invoice fields and collect deposits." |
