# SV-7978 — Changing Quantity of a Picked Inventory Part Without Core Throws an Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-27  **Updated:** 2026-07-08T11:28
- **Link:** https://shopview.atlassian.net/browse/SV-7978

## Description

**Affected Roles:**  
Administrator (configured as per the specification) or any role with the **Pick Parts** permission enabled.

**Description:**  
After an inventory part **without a core** has been picked onto a Work Order Line, attempting to change its quantity results in an error when saving.

**Steps to Reproduce (STRs):**

1. Log in as an **Administrator** (or any role with **Pick Parts** permission enabled).
2. Create or open a Work Order.
3. Request an **Inventory Part without a Core**.
4. Pick the part.
5. Open the picked part for editing.
6. Change the **Quantity**.
7. Click **Save & Close**.

**Actual Result:**  
Admin (Configured as per the spec): An error is displayed and the updated quantity is not saved.  
Technician (Configured as per the spec): Throws 403 error

**Expected Result:**  
The quantity of the picked inventory part should be updated successfully without any errors.
