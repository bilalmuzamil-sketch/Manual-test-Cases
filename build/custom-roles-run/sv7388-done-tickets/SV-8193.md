# SV-8193 — Technician and Parts Manager can delete a completed inspection without having WO Line delete permission.

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-07  **Updated:** 2026-07-07T23:19
- **Link:** https://shopview.atlassian.net/browse/SV-8193

## Description

**What's happening**  
When an inspection is already completed, the remove (bin) button still appears for the Technician and Parts Manager roles.  
  
**Note:**  
**These roles have "View and Edit" on Work Order Lines but do NOT have "Delete",** But they can, and the completed inspection is actually deleted.

**Steps to reproduce**

1. Log in as a Technician (then repeat as a Parts Manager).
2. Open a work order line that has a completed inspection.
3. Click the remove (bin) button on the inspection row.

**Actual result**  
The remove (bin) button is shown, and clicking it actually deletes the completed inspection — confirmed for both roles even though neither has the Delete permission.

* Technician — TestRail test: [https://shopview.testrail.io/index.php?/tests/view/1561707](https://shopview.testrail.io/index.php?/tests/view/1561707)
