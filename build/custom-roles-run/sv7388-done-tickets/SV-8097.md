# SV-8097 — My Timesheets menu visibility is reversed — missing for Admin, showing for Parts Manager

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-02  **Updated:** 2026-07-09T08:02
- **Link:** https://shopview.atlassian.net/browse/SV-8097

## Description

**Description:**  
The My Timesheets item in the profile menu does not match the Timesheets permission. Admin has Timesheets enabled but the item is missing, while Parts Manager has Timesheets disabled but the item still shows.

**Steps to Reproduce:**

1. Log in as Admin (Timesheets enabled) — open the profile menu. My Timesheets is absent.
2. Log in as Parts Manager (Timesheets disabled) — open the profile menu. My Timesheets is present.

**Expected Result:**  
My Timesheets visibility follows the Timesheets permission consistently across roles.

**Actual Result:**  
Reversed — hidden for Admin (enabled), shown for Parts Manager (disabled).

Analysis — root cause is not an inverted condition, and this is FE-only

The "My Timesheets" nav entries are not gated on the Timesheets permission — they gate on the per-staff clockable flag (userService.isUserAbleToClock() → details.clockable, restored by SV-7946 to gate the clock-in/out controls). Admin is clockable=false (admins don't punch a clock) → hidden; Parts Manager is clockable=true → shown. So clockable is behaving correctly; the defect is that the navigation link was tied to it at all.

Per the SV-8060 decision (Sasha, 2026-07-06 — "My Timesheets stays visible for all roles"), the target is: the link is visible/reachable for every role, ungated.

Scope: FE-only. The coupled BE 403 is handled by SV-8149, which de-gates the individual-punch-clock endpoint to IS_AUTHENTICATED (the "all roles" form) — no separate controller change is needed for this ticket.

FE changes required (decouple the nav links from clockable; leave the DailyClockedHours clock widget gated as-is):

1. app/src/components/ts/navigation/ProfileMenu.vue — remove v-if="isUserAbleToClock" from the My Timesheets q-item (\~line 84). Keep the gate on the DailyClockedHours block (lines 14–18) and keep the isUserAbleToClock const (the widget still uses it).
2. app/src/components/ts/navigation/mobile/MobileMenu.vue — remove the gate on the Timesheets item (line 45).
3. app/src/components/ts/navigation/desktop/DesktopMenu.vue — remove the gate on the Timesheets link (line 57); leave the DailyClockedHours widget at line 104 gated.
4. app/src/router/routes.ts — remove beforeEnter: onlyClockableUsers from the Timesheets route (\~line 1315); otherwise non-clockable roles see the item but get redirected to WorkOrders on click. Check onlyClockableUsers (lines 73–80) for other uses before deleting the helper.
5. app/src/components/ts/navigation/tests/ProfileMenu.spec.ts (lines 377–432) — flip the clockable-gating assertions ("hides for non-clockable" → "shows regardless of clockable").

Merge-order dependency: this FE change must not reach develop before the SV-8149 BE de-gate, or all-roles users will still get a 403 when clicking My Timesheets. Ship/merge them together.
