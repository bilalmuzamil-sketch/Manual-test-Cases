# SV-7986 — Part Technician with Work Order View Only Cannot See "Lead Technician" as "Unassigned" While "Service Advisor" appears as unassigned correctly

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-28  **Updated:** 2026-07-07T08:42
- **Link:** https://shopview.atlassian.net/browse/SV-7986

## Description

**Affected Role:**  
Part Technician (configured as per the specification)

**Description:**  
A Part Technician configured with **Work Order = View Only** experiences inconsistent behavior in the Work Order summary panel.

When **no Service Advisor** is assigned, the application correctly displays **"Service Advisor: Unassigned"** in read-only mode.   
However, when **no Lead Technician** is assigned, the **Lead Technician** field is not displayed at all.

For consistency, both assignment fields should behave the same way.

**Steps to Reproduce (STRs):**

1. Configure a **Part Technician** role as per the specification (**Work Order = View Only**).
2. Create a Work Order without assigning a **Lead Technician**.
3. Open the Work Order as the Part Technician.
4. Observe the Work Order summary panel.

**Actual Result:**

* **Service Advisor** is displayed in read-only mode and correctly shows **"Unassigned"** when no Service Advisor is assigned.
* **Lead Technician** is not displayed when no Lead Technician is assigned. (Only shown when lead technician is assigned)

**Expected Result:**  
The **Lead Technician** field should always be displayed in read-only mode. When no Lead Technician is assigned, it should display **"Unassigned"**, matching the behavior of the **Service Advisor** field.

**Impact:**  
The Work Order summary presents inconsistent behavior for similar assignment fields. Users can clearly identify when a Service Advisor is unassigned, but cannot determine whether the Lead Technician is unassigned or simply unavailable due to permissions, resulting in an inconsistent and confusing user experience.
