# SV-7793 — ShopCoach Suggest Story Returns No Response and Fails with "Work Order Not Found" Server Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-19  **Updated:** 2026-06-29T15:12
- **Link:** https://shopview.atlassian.net/browse/SV-7793

## Description

**Description:**  
The **ShopCoach Suggest Story** feature does not generate a suggested technician story when invoked from a Work Order Line.

The request is sent successfully with valid **workOrderId** and **lineId**, but the backend returns a server error indicating that the Work Order cannot be found.

As a result, no story is generated and the Tech Story field remains empty.

---

### **Steps to Reproduce (STRs):**

1. Create a **Work Order (WO)**.
2. Create a **Work Order Line (WOL)**.
3. Click **Add Tech Story for this line**.
4. Click **ShopCoach Suggest Story**.
5. Observe the result and inspect the network request.

---

### **Actual Result:**

* No suggested story is generated.
* The Tech Story field remains blank.
* Network response returns:

```
{
  "status": "ServerError",
  "isError": true,
  "message": "Work order not found",
  "messageCode": "assistant.server_error"
}
```

*  Response data contains: 

```
{
  "text": null
}
```

---

### **Expected Result:**

*  ShopCoach should successfully generate a technician story based on the Work Order Line. 
*  The generated story should populate the Tech Story field. 
*  No server error should occur. 

---

### **Additional Information:**

The request payload contains valid identifiers:

```
{
  "assistant": "suggest-story",
  "workOrderId": "7a631930-6f0f-44a4-8d38-a2ac9ff01295",
  "lineId": "25a23497-1ce7-4f8f-bd91-f0c12cd9513e"
}
```

However, the backend responds with:

> **"Work order not found"**

indicating a potential issue with ShopCoach's Work Order lookup or context resolution.
