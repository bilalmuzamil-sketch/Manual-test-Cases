# SV-7930 — Service Advisor Field Displays Blocked Icon but Still Allows Service Advisor to Be Changed

- **Type:** Task
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-25  **Updated:** 2026-07-06T07:48
- **Link:** https://shopview.atlassian.net/browse/SV-7930

## Description

**Permission:** Workorder: Create&Edit Checked.  
  
The Work Order screen displays a **blocked/prohibited icon** next to the **Service Advisor** field, indicating that the field cannot be modified. However, despite the icon, users are still able to change the assigned Service Advisor using the dropdown.

This creates a contradiction between the UI and the actual application behavior.

**Steps to Reproduce (STRs):**

1. Open any Work Order.
2. Locate the **Service Advisor** field in the left-hand panel.
3. Observe the blocked/prohibited icon displayed next to the field.
4. Click the Service Advisor dropdown.
5. Select a different Service Advisor.

**Actual Result:**

* A blocked/prohibited icon is displayed, implying that the Service Advisor cannot be changed.
* Despite this, the application allows the user to change the Service Advisor successfully.

**Expected Result:**  
The UI and behavior should be consistent:  
  
When->   
WorkOrder: View&Edit Is checked:

* Either the blocked icon should not be displayed if changing the Service Advisor is allowed.
