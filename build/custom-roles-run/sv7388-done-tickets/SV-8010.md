# SV-8010 — Creating a New Inventory Part Fails with Application Error After Entering Quantity

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-29  **Updated:** 2026-07-06T09:14
- **Link:** https://shopview.atlassian.net/browse/SV-8010

## Description

**Affected Role:**  
Administrator (or any role with permission to create Inventory Parts)

**Description:**  
Creating a new Inventory Part fails after entering the required information and specifying the initial quantity.

Instead of creating the inventory item successfully, the application displays an unexpected error.

**Steps to Reproduce (STRs):**

1. Navigate to **Parts → Inventory**.
2. Click **New Inventory**.
3. Fill in all the required fields.
4. Enter an initial **Quantity**.
5. Click **Save**.

**Actual Result:**  
The inventory item is not created, and the following error is displayed:

> **ID: \[06c5b085-21cb-49b4-a880-cf809200731d\]** when reaching out for faster assistance.

**Expected Result:**  
The inventory item should be created successfully, and the user should be redirected back to the Inventory list without any errors.

**Impact:**  
Users are unable to create new inventory items, blocking inventory setup and parts management workflows.

**Error ID:**  
ID: \[06c5b085-21cb-49b4-a880-cf809200731d\] when reaching out for faster assistance.
