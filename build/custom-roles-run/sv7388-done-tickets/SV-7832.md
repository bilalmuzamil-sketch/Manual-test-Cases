# SV-7832 — No Validation Prompt When Work Order Create/Edit Requires Full View Permission

- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-22  **Updated:** 2026-07-09T01:07

## Description

<custom data-type="mention" data-id="id-0">@Sasha Grosman</custom> **Clarification Required please.**

---

The **Work Orders → Create/Edit** permission is dependent on **Work Order View Mode = Full View**, but the system does not inform users about this dependency.

When a user enables **Create/Edit** for Work Orders without selecting **Full View**, the permission appears to be enabled, but the user still cannot actually create or edit Work Orders.  
  
**(Must Read the Note from the bottom)**

---

### **Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles & Permissions**.
2. Edit or create a custom role.
3. Enable **Work Orders → Create/Edit**.
4. Do not select **Work Order View Mode = Full View**.
5. Save the role and assign it to a user.
6. Log in as that user and attempt to create/edit a Work Order.

---

‌

### **Actual Result:**

* The system allows **Create/Edit** to be selected without warning.
* User is not informed that **Full View** is also required.
* The assigned user cannot create/edit Work Orders as expected.

**Note:**

Enabling the **Work Order Create & Edit** with **Tech View** permission allows the user to perform the following actions:

* Change the **Lead Technician** → Same behavior as Production for technician
* Change the **Service Advisor** → Currently restricted on Production for technician
* Change **Customer**→ Same behavior as Production for technician
* Change **Asset** → Same behavior as Production for technician
* Set **Engine Hours** and **Mileage** → Same behavior as Production for technician

If this permission (**Work Order Create & Edi**) is disabled, the user is not able to perform any of the above actions.
