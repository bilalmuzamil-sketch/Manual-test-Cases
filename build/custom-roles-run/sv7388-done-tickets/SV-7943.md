# SV-7943 — Invoiced/Paid Work Order status filters unavailable for custom role unless "See Financial Data" is enabled, despite invoiced/paid work orders being visible in the list

## Description

**Issue Type:** Bug  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging

**Preconditions:**

* A custom role with all permissions enabled except "See Financial Data." (Invoicing & Payments and Part Sales depend on ‘See Financial Data’, but that dependency is not a factor here — enabling "See Financial Data" by itself restores the Invoiced and Paid filters.)
* View mode - Full view
* User is assigned to that custom role 

**Steps to Reproduce:**

1. Log in as the above mentioned custom role
2. Go to Work Orders → **By Status** tab
3. Confirm that invoiced and paid work orders **are visible** in the list
4. Open the **All Statuses** filter dropdown and review the available options
5. Note that **Invoiced** and **Paid filter options are missing**
6. Enable **See Financial Data** on the role, then repeat steps 2–4
7. Observe that the **Invoiced** and **Paid** filters are available in All Statuses dropdown

**Expected Result:**  
The user can see invoiced and paid work orders in the By Status list (correct — work order status is not permission-gated, 1a). Because those records are visible, the corresponding **Invoiced** and **Paid filter options should also be available** so the user can filter to view them separately — regardless of the See Financial Data toggle. The ‘See Financial Data' is specified to control financial _data visibility_ (6a), not status-_filter_ availability.

**Actual Result:**

* With **See Financial Data OFF:** the All Statuses dropdown is missing the **Invoiced** and **Paid** filter options, even though invoiced/paid work orders are visible in the By Status list. The custom role cannot filter to view them separately.
* With **See Financial Data ON:** the Invoiced and Paid filters appear and the user can filter by them.
* Confirmed root cause: Invoiced/Paid filter availability is gated behind the See Financial Data toggle.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | 1a Work Orders, View row | "See work orders in the work order list and open work order detail pages." |
| 2 | 6a See Financial Data, ON state | "User can see pricing, costs, margins, and financial columns throughout the app." |
| 3 | 6a See Financial Data, OFF state | "All financial data is hidden across every page. Dollar amounts, rates, costs, margins, and totals are not displayed. The user can still perform their CRUD actions, but they cannot see pricing information." |
