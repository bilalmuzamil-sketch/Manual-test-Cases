### parth fadadu — 2026-07-07T00:59

<custom data-type="mention" data-id="id-0">@Bilal Muzamil</custom> For Info  

I just investigated this issue and found the root cause of why the user is unable to **Clock In**. The issue is on the backend side.  
**Production:**

* When the **Time Clock** toggle is changed for the currently logged-in user, the backend expires the user’s session, so the user is automatically logged out.
* This behavior is implemented in the **main** branch.

**Staging:**

* When the **Time Clock** toggle is changed for the currently logged-in user, the backend does **not** expire the session, so the user remains logged in.
* This behavior is missing from the **develop** branch, but it should match the production behavior.
