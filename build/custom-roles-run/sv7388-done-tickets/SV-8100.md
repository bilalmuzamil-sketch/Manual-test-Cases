# SV-8100 — Invoices/Payments/Deposits tabs show on customer/vendor pages when AP/AR is off

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-02  **Updated:** 2026-07-08T09:41
- **Link:** https://shopview.atlassian.net/browse/SV-8100

## Description

**Description:**  
With AP/AR access off, the Invoices, Payments and Deposits tabs should be hidden on customer and vendor pages. They still show.

**Steps to Reproduce:**

1. Log in as a role with AP/AR off (e.g. Service Advisor).
2. Open a customer.
3. See the Invoices, Payments and Deposits tabs.

**Expected Result:**  
Those tabs are hidden when AP/AR is off.

**Actual Result:**  
The tabs still show.
