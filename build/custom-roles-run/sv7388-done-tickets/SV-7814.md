# SV-7814 — Spec Clarification Required: Junior Service Advisor Loses Access to Vendor Unpaid Invoices and Payments Unless AP/AR Permission Is Enabled

- **Type:** Task
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-21  **Updated:** 2026-06-28T15:02
- **Link:** https://shopview.atlassian.net/browse/SV-7814

## Description

In the QA branch, users with the **Junior Service Advisor** role cannot see the **Vendor Unpaid Invoices** and **Vendor Payments** sections unless **View and Manage AP/AR Data** is enabled.

This differs from the current Production behavior, where users with the same role can access these vendor-related sections.

**Because there may be existing customers using the Junior Service Advisor role in Production, this change could remove access to functionality they currently use.**

---

### **Steps to Reproduce (STRs):**

1. Log in as a user with the **Junior Service Advisor** role.
2. Ensure **View and Manage AP/AR Data** is disabled.
3. Navigate parts → Vendors → Click any Vendor from the list
4. Observe the Unpaid invoice and payment section is missing (unlike the behavior on production)
5. Enable **View and Manage AP/AR Data** for the same role.
6. Log in again and compare visibility.

---

### **Actual Result:**

* With **View and Manage AP/AR Data = OFF**:

    * Vendor **Unpaid Invoices** tab is hidden.
    * Vendor **Payments** tab is hidden.
    
* With **View and Manage AP/AR Data = ON**:

    * Both sections become visible.
    

---

**Clarification required from Product/Development:**

‌

1. Is the QA behavior intentional?
2. Do we need to maintain backward compatibility with Production to avoid removing access from existing users?
3. Should Vendor Unpaid Invoices and Vendor Payments be governed by AP/AR permissions at all?
