# SV-8114 — Timesheet Activities Report Exposes Internal UUID/GUID Values Without a Column Header

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-07T10:42
- **Link:** https://shopview.atlassian.net/browse/SV-8114

## Description

Role: Parts Manager (Configured as per the Specs)  
**Reports =** ON   
**Timesheets =** OFF (Parts Manager default) and not required — per spec, the Timesheet Activities report is reachable whenever Reports is ON, regardless of the Timesheets permission.  
  
The **Timesheet Activities** report displays internal **UUID/GUID** values in the far-right column of the report.

These values appear to be backend record identifiers and are displayed without any column header or user-facing purpose. If these identifiers are intended for internal system use only, they should not be exposed in the UI. If they are intentionally displayed, they should appear under a properly labeled column with a clear business purpose.

**Steps to Reproduce (STRs):**

1. Navigate to **Reports → Timesheet Activities**.
2. Observe the far-right column of the report.

**Actual Result:**

* The report displays internal **UUID/GUID** values (e.g., `00642ce8-c672-471e-9d98-a475fd7faed0`) in the far-right column.
* The column has no header and provides no meaningful information to end users.

**Expected Result:**  
One of the following should occur:

* The internal UUID/GUID values should **not be exposed** in the report if they are intended for backend use only.
* If these values are intentionally displayed, they should appear under a properly labeled column with a documented business purpose.
