# SV-8110 — Service Advisor (Manage AP/AR OFF) can still see Customer Unpaid Invoices / Payments / Credits tabs (should be hidden)

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-06T01:14
- **Link:** https://shopview.atlassian.net/browse/SV-8110

## Description

Per the Custom Roles spec, when Manage Accounts Payable and Receivable is OFF, the Unpaid Invoices, Payments, and Credits tabs are hidden on both Customer and Vendor detail pages. Service Advisor (system-jsa) has Manage AP/AR = OFF per the spec matrix.

Verified in build: the Service Advisor role has the Manage AP/AR cross-cutting toggle OFF (correct per spec), but the Customer → Unpaid Invoices / Payments (/ Credits) tabs are still visible and accessible.

**Expected (per spec):** With Manage AP/AR OFF, the Unpaid Invoices, Payments, and Credits tabs are hidden on Customer (and Vendor) detail pages.

**Actual (build):** With Manage AP/AR OFF, the Service Advisor can still see the Customer Unpaid Invoices / Payments tabs.

**Spec references** (<custom data-type="smartlink" data-id="id-0">https://shopview.atlassian.net/wiki/spaces/PM/pages/565116952</custom> ):

* Toggles matrix → See AP/AR row: Service Advisor = OFF
* Manage AP/AR → OFF behavior: "Unpaid Invoices tabs, Payments tabs, and Credits tabs are hidden on both Customer and Vendor detail pages."

**Related:** Likely the same incomplete-AP/AR-gating class as the finding that the customer detail page leaks Credit Term / Credit Limit with AP/AR OFF (TestRail C26549). A single fix may cover both — worth checking together.

**Environment:** Staging (specify build/URL).
