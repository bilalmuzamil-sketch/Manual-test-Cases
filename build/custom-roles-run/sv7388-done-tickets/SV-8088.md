# SV-8088 — Invoicing: Delete/Reverse (+ See Financial Data + Manage AP/AR) does not offer Reverse Invoice or Delete Payment on a paid invoice — only Issue Store Credit / Issue Refund; spec grants "reverse invoices, delete payments" under Delete/Reverse

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-02T08:03
- **Link:** https://shopview.atlassian.net/browse/SV-8088

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging

**Affected Area:** Invoicing & Payments — Reverse invoice / Delete payment

**Preconditions:**

* Custom role with **Work Orders: View ON**, **Invoicing & Payments: View + Create & Edit + Delete/Reverse ON**
* **See Financial Data ON**
* **Manage AP/AR ON** (tested — see Notes)
* User is assigned to that custom role

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Open a completed work order → create an invoice
3. Make a payment on the invoice (invoice becomes fully paid)
4. Look for options to **Reverse the invoice** and **Delete the payment**

**Expected Result:**  
Per spec, Invoicing: Delete/Reverse grants "Reverse invoices, delete payments (including customer payments), void transactions" (§1h). With this permission (plus See Financial Data and Manage AP/AR), the user should have Reverse Invoice and Delete Payment options available.

**Actual Result:**

* On a fully paid invoice, the only options offered are **Issue Store Credit** and **Issue Refund**.
* **No "Reverse Invoice" option** and **no "Delete Payment" option** are available.
* Because the payment cannot be deleted, the invoice cannot be returned to a reversible state either — the reverse workflow is fully blocked.

**Scope / Notes:**

* **Manage AP/AR ruled out:** enabling Manage Accounts Payable and Receivable (View and Manage AP/AR data) did **not** make Reverse Invoice or Delete Payment appear — same result.
* No permission combination tested (Invoicing: Delete/Reverse + See Financial Data + Manage AP/AR) enables reversing invoices or deleting payments, contradicting §1h.
* Related to the AP/AR reverse/delete dependency clarifications (SV-7913, SV-7871, SV-7812), but distinct: here the capabilities are missing even with AP/AR ON.
* **Separate issue noted during testing (to be filed separately):** "Create Invoice" is available even when a work order does not have a line added — invoice creation should be gated on line completion (will raise this separately)

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §1h Invoicing, Delete/Reverse row | "Reverse invoices, delete payments (including customer payments), void transactions." |
| 2 | §1h Invoicing, Create and Edit row | "Create invoices, process payments, manage invoice fields, collect deposits, send payments to terminal." |
| 3 | §6b Manage AP/AR | "The Unpaid Invoices, Payments, and Credits tabs… require Manage Accounts Payable and Receivable ON." |
