# SV-8018 — Office / WO View role can see notes but cannot add them — WO View should allow creating notes per spec

- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-29  **Updated:** 2026-07-07T15:23
- **Link:** https://shopview.atlassian.net/browse/SV-8018

## Description

Office / WO View role can see notes but cannot add them — WO View should allow creating notes per spec

The logic:

* Per spec v39, **Work Orders View grants:** the ability to see the Notes tab, create notes, and edit any note (in-note collaboration).
* **Office has Work Orders View,** so Office should be able to add and edit notes on a work order.
* **On the build, Office can only see notes** — there is no option to add a note. That contradicts the spec.

Steps to reproduce:

1. Log in as Office.
2. Open a work order.
3. Go to the Notes tab.
4. Try to add a note.

**Expected:** Office can create a note (and edit existing notes, including others'), because Work Orders View grants create/edit of notes per spec v39.

**Actual:** Office can only view notes; no option to add a note.

**Spec reference:**

* **Work Orders View:** "see the Notes tab, create notes, and edit any note (including notes created by others)."
* W**ork Orders Delete:** "Delete any note, including notes created by other users."
