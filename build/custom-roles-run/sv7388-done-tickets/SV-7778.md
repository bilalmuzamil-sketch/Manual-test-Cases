# SV-7778 — FE - Delete Role Message Does Not Display Number of Assigned Users

- **Type:** Story Defect - Archive
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-19  **Updated:** 2026-07-06T10:15
- **Link:** https://shopview.atlassian.net/browse/SV-7778

## Description

**Description:**  
When attempting to delete a role that has users assigned to it, the warning message does not display the number of users currently assigned to the role.

As shown in the screenshot, the message currently reads:

> "This role is assigned to users. Remove users from this role before deleting it."

However, according to the specification, the message should include the actual number of assigned users.

---

### **Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles & Permissions**.
2. Assign one or more users to a custom role.
3. Open the role for editing.
4. Hover over or attempt to use the **Delete** action.
5. Observe the warning message.

---

### **Actual Result:**

The message displays:

> "This role is assigned to users. Remove users from this role before deleting it."

No user count is shown.

---

### **Expected Result:**

The message should display the number of assigned users, as defined in the specification:

> "This role is assigned to {{count}} user(s). Reassign them to another role before deleting."

Example:

> "This role is assigned to 3 user(s). Reassign them to another role before deleting."
