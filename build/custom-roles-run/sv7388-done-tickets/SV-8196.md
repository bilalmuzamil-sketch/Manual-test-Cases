# SV-8196 — Main Administrator Cannot Be Assigned to Departments After the NEW Organization Setup

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-07  **Updated:** 2026-07-09T05:03
- **Link:** https://shopview.atlassian.net/browse/SV-8196

## Description

**Affected Role:**  
Administrator (Main Admin)

**Description:**  
After creating a new organization and setting up departments, the **Main Administrator** cannot be enrolled into any department.

Although the departments are successfully created and appear under **Settings → Departments**, no departments are available in the department selection dropdown when editing the Main Administrator's staff record.

Additionally, each department shows **0 Members**, indicating that users cannot be assigned to them.

**Steps to Reproduce (STRs):**

1. Create a **new organization** and complete the initial setup.
2. Create one or more **Departments**.
3. Navigate to **Settings → Staff**.
4. Edit the **Main Administrator**.
5. Attempt to assign the user to a department.
6. Observe the department selection dropdown.
7. Navigate to **Settings → Departments**.
8. Observe the created departments.

**Actual Result:**

* No departments are available in the department selection dropdown for the Main Administrator.
* The departments exist under **Settings → Departments**.
* Each department shows **0 Members**.

**Expected Result:**

* The created departments should be available for selection when editing the Main Administrator (and other staff members).
* The Main Administrator should be able to be assigned to one or more departments.
* After assignment, the department's **Members** count should update accordingly.
