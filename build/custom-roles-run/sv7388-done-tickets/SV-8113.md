# SV-8113 — Saving Custom Role Permission Changes Throws 403 Access Restricted Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-09T05:30
- **Link:** https://shopview.atlassian.net/browse/SV-8113

## Description

**Affected Role:**  
Administrator (or any role with permission to manage Roles & Permissions)

**Description:**  
When modifying any permission within a Custom Role and clicking **Save**, the application throws a **403 Access Restricted** error instead of saving the updated permission configuration.

This occurs regardless of whether permissions are being enabled or disabled.

**Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles & Permissions**.
2. Edit any Custom Role.
3. Toggle any permission **ON** or **OFF**.
4. Click **Save**.

**Actual Result:**  
A **403 Access Restricted** error is displayed, and the permission changes are not saved.

**Expected Result:**  
The updated permission configuration should be saved successfully without any authorization error.
