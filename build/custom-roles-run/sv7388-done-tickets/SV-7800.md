# SV-7800 — User Is Logged Out When Accessing Time Clock After Role Is Changed to Time Clock User

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-20  **Updated:** 2026-07-06T10:20
- **Link:** https://shopview.atlassian.net/browse/SV-7800

## Description

A user who is actively clocked into a Work Order Line is unexpectedly logged out after their role is changed from **Administrator** to **Time Clock User**.

After logging back in with the updated role and attempting to access the **Time Clock** widget, the system immediately logs the user out instead of opening the Time Clock interface.

---

### **Steps to Reproduce (STRs):**

1. Log in as a user with the **Administrator** role.
2. Clock into a **Work Order Line**.
3. Change the user's role to **Time Clock User**.
4. Log out that user after downgrading their role.
5. Log back in as the same user with Time Clock role now.
6. Click the **Time Clock** widget from the top-right corner of the application.

---

### **Actual Result:**

* The system immediately logs the user out after clicking the **Time Clock** widget.
* The Time Clock screen is never displayed.

---

### **Expected Result:**

* The user should be able to access the **Time Clock** interface successfully.
* Existing clocked-in sessions should not cause the user to be logged out after a role change.
