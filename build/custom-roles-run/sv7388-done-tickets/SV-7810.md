# SV-7810 — Finance Permission Incorrectly displays "Imports" Section When Data Import Permission Is Disabled

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-21  **Updated:** 2026-07-07T15:35
- **Link:** https://shopview.atlassian.net/browse/SV-7810

## Description

Precondition:  
Create a New role with only Finance section toggled on.  
  
When the **Finance** page access permission is enabled for a custom role, the user gains access to Finance-related settings as expected under “Integrations“ section.   
  
However, the **Imports** section also becomes visible(No sub sections) even when the **Data Import** permission remains disabled.

This results in users seeing the Imports section despite not having permission to access Data Import functionality.

---

### **Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles & Permissions**.
2. Create or edit a **Custom Role**.
3. Under **Page Access**:

    * Enable **Finance**.
    * Ensure **Data Import** remains **disabled/off**.
    
4. Save the role.
5. Assign the role to a user.
6. Log in as that user.
7. Navigate to **Settings**.

---

### **Actual Result:**

* The user correctly gains access to **Finance**-related settings and gets Integration section enabled (As defined in Specs).
* The **Imports** section also becomes visible in the left navigation menu despite **Data Import** being disabled.

---

### **Expected Result:**

* The **Imports** section should only be visible when the **Data Import** permission is enabled.
* Enabling **Finance** should not automatically expose the **Imports** menu.
* Visibility of **Finance** and **Imports** should be controlled independently according to their respective permissions.
