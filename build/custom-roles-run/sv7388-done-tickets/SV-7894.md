# SV-7894 — Parts Top Navigation Tab Does Not Show Active/Selected State

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-24  **Updated:** 2026-07-07T14:32
- **Link:** https://shopview.atlassian.net/browse/SV-7894

## Description

**Environment:**  
QA / Staging

---

### **Description:**

When navigating to the **Parts** module, the **Parts** tab in the top navigation does not visually indicate that it is the currently selected page.

Unlike other top navigation tabs, the **Parts** tab does not receive the expected active-state background styling, making it appear unselected even when the user is currently within the Parts module.

---

### **Steps to Reproduce (STRs):**

1. Navigate to the **Parts** module.
2. Observe the **Parts** tab in the top navigation bar.
3. Compare its appearance with other selected top navigation tabs throughout the application.

---

### **Actual Result:**

* The **Parts** tab does not show the active/selected background state.
* It appears the same as an unselected navigation item.

---

### **Expected Result:**

* The **Parts** tab should display the active/selected background styling when the user is within the Parts module.
* The selected state should be visually consistent with the other top navigation tabs.
