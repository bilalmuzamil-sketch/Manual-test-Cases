# SV-7872 — Canned Lines Cannot Be Created by Admin and Tech Users

- **Type:** Story Defect - Archive
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-24  **Updated:** 2026-07-07T06:35
- **Link:** https://shopview.atlassian.net/browse/SV-7872

## Description

Admin and Tech users are unable to create Canned Lines because the line name is missing from the selection dropdown.

**Steps to Reproduce:**

1. Navigate to a Work Order.
2. Click **New Line**.
3. Select **Canned Line** and **Save** it.
4. Observe.

**Actual Result:**  
The canned line name is missing, preventing users from identifying and selecting the desired canned line.

**Expected Result:**  
The canned line name should be displayed in the dropdown, allowing Admin and Tech users to identify and create the appropriate canned line.

**Affected Roles (so far):**

* Admin
* Tech
