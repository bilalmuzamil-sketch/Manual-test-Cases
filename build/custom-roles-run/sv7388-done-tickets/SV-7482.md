## Scope

* `DefaultRoleNameEnum`: rename existing `ServiceAdvisor` → Senior SA semantics (value change = DB data migration on `v2_role.name`), add `JuniorServiceAdvisor` + `SalesRepresentative`. Net 12.
* Update Role helper arrays (`createDefaultRolesForOrganization`, `getTechnicianRoles`, `getServiceAdvisorRoles`, `getRolesRestrictedFromPartHistory`, `getUndeletableRoles`, `getUneditableRoles` — add Office).
* Replace `InsertDefaultRolesCommand` (creates empty roles today) with an **idempotent permissioned seeder**: resolve `RoleFePermissionMappings::getMappings()[role]` → `FEPermission` entities and attach; set `templateId`/`viewMode`; per-org transaction; reconcile existing rows (do NOT create a duplicate "Owner" for orgs that already have the 10 empty roles).
