# SV-8134 — WO View role cannot see Mileage and Engine Hours (should be viewable with Work Orders: View)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-08T08:17
- **Link:** https://shopview.atlassian.net/browse/SV-8134

## Description

Split from SV-7929 per Sasha's comment (3 Jul 2026).

**What should happen (per PM ruling on SV-7929, 3 Jul, and spec v39):**

* Work Orders: View should let the user SEE mileage and engine hours (read-only).
* Work Orders: Create & Edit is required to add or edit mileage and engine hours.

**What happens on the build:**

* With Work Orders: View only, mileage and engine hours are not visible at all.

**Steps to reproduce:**

1. Log in as a role with Work Orders = View only (e.g. Parts Technician).
2. Open a work order that has mileage and engine hours set.
3. Look for mileage and engine hours on the work order / line.

**Expected:** mileage and engine hours are visible (read-only) with Work Orders: View.

**Actual:** mileage and engine hours are not shown.

**Spec references:**

* Custom Roles and Permissions, page 565116952, v39.
* Section 1b, Work Order Lines Create & Edit: "edit mileage, edit engine hours" (editing needs Create & Edit).
* PM ruling: SV-7929 comment, 3 Jul 2026 — View is required to view mileage / engine hours; Create & Edit to edit.

**Related:** SV-7929 (parent clarification), SV-7938 (Technician operational edits).
