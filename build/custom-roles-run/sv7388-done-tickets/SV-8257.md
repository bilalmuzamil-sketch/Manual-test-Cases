## Description

**Description:**  
On the A/R Aging report, the Print button doesn't always work on the first click. Sometimes nothing happens, then clicking again 2–3 times finally opens/downloads the PDF. Every click returns 200 (no error).

**Steps to Reproduce:**

1. Open Reports › A/R Aging (Collection)
2. Click the Print icon
3. If nothing happens, click 1–2 more times

**Expected:** Print opens/downloads the PDF on the first click, every time.

**Actual:** First click(s) do nothing; PDF opens on the 2nd or 3rd try. Happens on and off.
