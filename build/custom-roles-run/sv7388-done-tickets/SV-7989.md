# SV-7989 — Technician Cannot View Work Order Line Log Despite Being Configured as per the Specification

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-28  **Updated:** 2026-07-09T01:13
- **Link:** https://shopview.atlassian.net/browse/SV-7989

## Description

Technician (configured with all permissions/CRUD as per the specification)

**Description:**  
A Technician configured according to the specification is unable to view the **Work Order Line Log**.

The Line Log is not available to the Technician despite the role being configured as defined in the specification.

**Steps to Reproduce (STRs):**

1. Log in as a **Technician** configured as per the specification.
2. Open a Work Order containing one or more Work Order Lines.
3. Right Click the WO Line.
4. Attempt to view the **Line Log**.

**Actual Result:**  
The Technician cannot access or view the **Work Order Line Log**.
