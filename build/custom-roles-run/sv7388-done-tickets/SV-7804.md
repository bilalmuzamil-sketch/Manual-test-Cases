# SV-7804 — Labor Quantity and Rate Columns Are Empty on Work Order Invoices (All applicable Roles)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-20  **Updated:** 2026-06-29T14:47
- **Link:** https://shopview.atlassian.net/browse/SV-7804

## Description

**Description:**  
The **Quantity** and **Rate** columns for Labor are not being populated on Work Order invoices.  
**Because they get toggled off/not enabled by default. (Intermittently happening)**

### **Steps to Reproduce (STRs):**  
Precondition:   
Log in as with the user having Admin role

1. Create a **Work Order (WO)**.
2. Create a **Work Order Line**.
3. Set the **Estimated Hours** to **5**.
4. Complete the line.
5. Navigate to the **Finance** tab.
6. Review the invoice details.

---

### **Actual Result:**

* The **Quantity** column for Labor is empty.
* The **Rate** column for Labor is empty.
* The same issue is present on:

    * Downloaded invoices
    * Printed invoices
    * Emailed invoices
    

But this issue gets resolved for the time being when we toggle on the Labor rate and Labor hours.  
  
But then they become auto toggled off again. (Intermittently happening)

---

### **Expected Result:**

* The Labor line should display:

    * **Quantity** (e.g., 5.00 hours)
    * **Rate** (applicable labor rate)
    
* The same values should be consistently displayed in:

    * Finance tab invoice view
    * Downloaded invoices
    * Printed invoices
    * Emailed invoices
