# SV-7991 — Purchase Order Total Cost Remains $0.00 Despite Adding Line Item Cost

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-28  **Updated:** 2026-07-08T09:29
- **Link:** https://shopview.atlassian.net/browse/SV-7991

## Description

Administrator (configured with all permissions as per the specification)

**Description:**  
When creating a new Purchase Order, the **Total Cost** is not updated after adding a line item with a valid cost.

Although a line item with a cost of **$500** is added successfully, the Purchase Order continues to display a **Total Cost of $0.00** both during creation and after saving. The same incorrect total is shown again when opening the Purchase Order to receive it.

> **Note:** The Administrator has **See Financial** enabled, so this is not a permissions issue.

**Steps to Reproduce (STRs):**

1. Log in as an **Administrator**.
2. Navigate to **Parts → Purchase Orders**.
3. Click **New PO**.
4. Fill in the Purchase Order details.
5. Add a line item with **Cost = $500**.
6. Click **Add**.
7. Observe the **Total Cost**.
8. Click **Save & Close**.
9. Navigate back to **Parts → Purchase Orders**.
10. Open the Purchase Order and click **Receive**.
11. Observe the **Total Cost** again.

**Actual Result:**

* The **Total Cost** remains **$0.00** after adding the item.
* The **Total Cost** is still **$0.00** when reopening the Purchase Order for receiving.
