# SV-7983 — Custom Role: Access Restricted and Tabs in the top Navigation Sporadically Disappear

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-27  **Updated:** 2026-06-30T15:36
- **Link:** https://shopview.atlassian.net/browse/SV-7983

## Description

**Issue Type:** Bug

**Environment:** Staging

**Affected Area:** Custom Roles & Permissions — Reports / Navigation / Access Control

**Preconditions:**

* Custom role has all permissions enabled **except Reports**.
* Related issues previously reported in SV-7977 and the Reports login dependency ticket.

**Steps to Reproduce:**

1. Create a custom role with **all permissions enabled except Reports**.
2. Assign this role to a user and log in.
3. Observe the **Access Restricted** error appears immediately after login.
4. Note that the top navigation bar tabs are intermittently missing.
5. Refresh the page — tabs may reappear, but the Access Restricted error can reappear as well.
6. Disable Reports permission again on the role (if it was enabled) — confirm the problem reproduces consistently.
7. Enable the **Reports** permission on the role.
8. Log in again — observe that the top navigation tabs are now visible and Access Restricted no longer appears on login.

**Note:** **The issue with the navigation bars being disappeared is with all the custom roles who do not have Reports enabled.**

**Expected Result:**  
All top navigation tabs permitted by the role's permissions should be consistently visible at all times, regardless of whether the Reports permission is enabled. Tabs should never disappear sporadically, and a page refresh should not cause Access Restricted to reappear.

**Actual Result:**  
When Reports is disabled, the following issues occur:

* **Access Restricted** error appears immediately after login (Already reported in SV-7977)
* Top navigation bar tabs **intermittently disappear**.
* Refreshing the page sometimes restores the tabs, but the Access Restricted error can reappear on refresh.
* Disabling Reports consistently reproduces the problem.
* Enabling Reports resolves both issues — tabs are visible and Access Restricted no longer appears on login.
