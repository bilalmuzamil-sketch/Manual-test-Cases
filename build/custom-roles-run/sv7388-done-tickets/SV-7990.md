# SV-7990 — Roles & Permissions: Work Order Lines Section Is Missing the "View" Permission Checkbox

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-28  **Updated:** 2026-06-28T13:34
- **Link:** https://shopview.atlassian.net/browse/SV-7990

## Description

The **Work Order Lines** permission group in **Settings → Roles & Permissions** does not provide a **View** permission checkbox.

This is inconsistent with other permission groups that expose separate **View**, **Create/Edit**

**Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles & Permissions**.
2. Edit any role.
3. Locate the **Work Order Lines** permission section.
4. Observe the available permission checkboxes.

**Actual Result:**  
The **View** permission checkbox is missing from the **Work Order Lines** permission group.

**Expected Result:**  
The **Work Order Lines** permission group should include a **View** permission checkbox (if View is intended to be configurable independently), consistent with the permission model and other permission groups.
