# SV-7973 — Receive Part Modal Exposes Financial Information When Financial Permissions Are Disabled

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-27  **Updated:** 2026-07-07T08:13
- **Link:** https://shopview.atlassian.net/browse/SV-7973

## Description

Having Order Part Enabled Exposes the part financials.

**Affected Roles:**  
Any role with **Order Parts** enabled but **Financial permissions disabled**

**Description:**  
Users who are allowed to **Order Parts** but **do not have permission to view financial information** can still access the **Receive Part** modal, which exposes financial data such as cost/pricing.

Receiving a part should not expose financial information to users whose role does not include financial access.

**Steps to Reproduce (STRs):**

1. Configure a role with:

    * **Order Parts = ON**
    * **Financial permissions = OFF**
    
2. Assign the role to a user.
3. Request and order a **Special Order Part**.
4. Click **Receive**.

**Actual Result:**

* The **Receive Part** modal displays financial information (e.g., cost/pricing) even though the role is not permitted to view financial data.

**Expected Result:**

* Users without financial permissions should not see financial information within the **Receive Part** modal.
* Financial fields should be hidden or omitted based on the user's permissions.

**Impact:**

* Sensitive financial information is exposed to users without financial access.
* Violates role-based visibility and least-privilege principles.
