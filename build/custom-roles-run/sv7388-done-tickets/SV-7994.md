# SV-7994 — Time Picker Closes After Selecting Hour, Preventing Minute Selection When Editing a Timesheet

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-28  **Updated:** 2026-07-07T08:55
- **Link:** https://shopview.atlassian.net/browse/SV-7994

## Description

When editing a timesheet entry, the time picker modal closes immediately after selecting the **hour**, preventing the user from selecting the **minutes**.

The time picker should remain open until both the hour and minute have been selected.

**Steps to Reproduce (STRs):**

1. Open any **Work Order** that has recorded time punches.
2. Click the **three-dot menu** in the top-right corner.
3. Click **Timesheets**.
4. Click the **Edit** icon for any timesheet entry.
5. Click the **time field** (as shown in the screen recording).
6. Click the **clock** icon to open the time picker.
7. Select any value in the **Hour** section.

**Actual Result:**

* The time picker closes immediately after selecting the hour.
* The user is not able to select the **minutes** from the same modal.

**Expected Result:**

* The time picker should remain open after selecting the **hour**.
* The user should then be able to select the **minutes** before the modal closes and the time is applied.
