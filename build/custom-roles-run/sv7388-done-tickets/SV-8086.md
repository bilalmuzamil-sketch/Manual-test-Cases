# SV-8086 — Cannot edit financial information on invoices even with Invoicing: Create & Edit + Manage AP/AR + See Financial Data all enabled — no edit option available; spec grants "manage invoice fields" under Invoicing: Create & Edit

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-14T03:34
- **Link:** https://shopview.atlassian.net/browse/SV-8086

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging

**Affected Area:** Invoicing & Payments — editing invoice financial information

**Preconditions:**

* Custom role with **Invoicing & Payments: View + Create & Edit ON**
* **See Financial Data ON**
* **Manage Accounts Payable and Receivable ON**
* **Work Orders: View ON** (to reach invoices/finance details)
* User is assigned to that custom role

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Open a work order / invoice and go to the finance/invoice details
3. Attempt to edit the **financial information** on the invoice

**Expected Result:**  
Per spec, Invoicing: Create & Edit grants "Create invoices, process payments, manage invoice fields, collect deposits, send payments to terminal" (§1h). With Invoicing: Create & Edit, See Financial Data, and Manage AP/AR all enabled, the user should be able to edit the invoice's financial information (or the spec should specify which permission governs this).

**Actual Result:**

* The user can view work orders, create invoices, complete/review work orders — but **cannot edit the financial information** on an invoice.
* The edit option for invoice financial information is **not available**, even with **Invoicing: Create & Edit + Manage AP/AR + See Financial Data all enabled**.

**Scope / Notes:**

* Tested incrementally: enabling Manage AP/AR (View and Manage AP/AR data) did **not** make the financial-information edit option appear — ruling out AP/AR as the missing gate.

**Open Question for PM (VIU):**  
The spec grants "manage invoice fields" under Invoicing: Create & Edit (§1h) but does not explicitly state which permission governs editing an invoice's **financial information** (amounts, tax, totals). Please confirm: which permission is intended to enable editing invoice financial information, and whether the current inability (with Invoicing: Create & Edit + Manage AP/AR + See Financial Data all on) is a defect or an undocumented gating requirement.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §1h Invoicing, Create and Edit row | "Create invoices, process payments, manage invoice fields, collect deposits, send payments to terminal." |
| 2 | §6b Manage AP/AR | "The Unpaid Invoices, Payments, and Credits tabs… require Manage Accounts Payable and Receivable ON." |
| 3 | §6a See Financial Data, ON state | "User can see pricing, costs, margins, and financial columns throughout the app." |
