# SV-7801 — Service Manager Cannot Access “Send to Portal” Unless Customer Portal Permission Is Enabled

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-20  **Updated:** 2026-07-07T14:10
- **Link:** https://shopview.atlassian.net/browse/SV-7801

## Description

Users with the **Service Manager** role cannot access the **Send to Portal** feature on a Work Order line requiring approval/authorization.

The **Send to Portal** icon should appear on the left side of the **New Line** button, but it is missing for the service manager role.

Enabling **Customer Portal** permission in the Service Manager role makes the icon appear, which suggests the visibility of **Send to Portal** is currently dependent on Customer Portal permission.  
  
As per the Specs the Send to portal should be available if the following conditions are met:

* **Full View = ON**
* **Review Work Orders = ON**
* **Can approve/manage WOLs**
* **Spec ties Send to Portal to Full View + WOL approval.**  
    
    
  See this ticket for more clarity: <custom data-type="smartlink" data-id="id-0">https://shopview.atlassian.net/browse/SV-7798</custom> 

---

### **Steps to Reproduce (STRs):**

1. Log in as a user with the **Service Manager** role.
2. Create a **Work Order**.
3. Create a **Work Order Line** that requires approval/authorization and is not approved.
4. Observe the area to the left of the **New Line** button.

---

### **Actual Result:**

* The **Send to Portal** icon is missing for Service Manager.

---

### **Expected Result:**

* The **Send to Portal** icon should be visible for Service Manager if the role is expected to use this feature.
* Permission dependency should match the approved spec.
