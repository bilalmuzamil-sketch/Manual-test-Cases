# SV-8136 — Cannot change quantity of an inventory part from the WO line with Pick Parts or Order Parts

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-14T00:24
- **Link:** https://shopview.atlassian.net/browse/SV-8136

## Description

Split from SV-7929 per Sasha's comment (3 Jul 2026).

**What should happen (per PM ruling on SV-7929, 3 Jul):**

* **User should only need WOL: Create & Edit** to manage the quantity of a part (for inventory or special order)

**What happens on the build:**

* If WOL=Less than Create and Edit → The user can not increase the quantity of the part

**Steps to reproduce:**

1. Log in as a role with Work Orders = View, Pick Parts (or Order Parts) ON, and **Work Order Lines = View only.**
2. Open a work order line that has an inventory part.
3. Try to increase or decrease the quantity of that part.

**Expected:** the quantity can be changed because Pick Parts / Order Parts is enabled.

**Actual:** the quantity cannot be changed.

**Spec references:**

* Custom Roles and Permissions, page 565116952, v39.
* Section 1a, Pick Parts: "Pick parts from inventory onto a work order line."
* PM ruling: SV-7929 comment, 3 Jul 2026 — Order or Pick Parts allows modifying the quantity of inventory parts from the WO line.

**Related:** SV-7963 (403 when reducing qty of a picked part with a core — backend), SV-8130 (Parts Tech core OK/Not-OK & part request).
