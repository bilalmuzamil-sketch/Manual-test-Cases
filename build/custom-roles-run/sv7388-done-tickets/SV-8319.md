# SV-8319 — Work Orders → View Permission Does Not Allow Editing Notes Created by Other

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-14  **Updated:** 2026-07-14T02:41
- **Link:** https://shopview.atlassian.net/browse/SV-8319

## Description

**Affected Permission:**
**Work Orders → View**

**Description:**
According to the Custom Roles specification, users with **Work Orders → View** should be able to edit **any note**, including notes created by other users, to support collaboration.

However, users configured with only the **Work Orders → View** permission are unable to edit notes created by other users.

**Specification Reference:**
**Work Orders → View** controls:

> _"Users can also see the Notes tab, create notes, and edit any note (including notes created by others) so people can collaborate within a single note..."_

**Steps to Reproduce (STRs):**

1. Configure a role with **Work Orders → View** enabled.
2. Log in as a user assigned to that role.
3. Open any Work Order.
4. Create a note using **User A**.
5. Log in as **User B** with the same permission configuration.
6. Open the same Work Order.
7. Attempt to edit the note created by User A.

**Actual Result:**
The user cannot edit the note created by another user.

**Expected Result:**
As documented in the specification, users with **Work Orders → View** should be able to edit notes created by other users.
