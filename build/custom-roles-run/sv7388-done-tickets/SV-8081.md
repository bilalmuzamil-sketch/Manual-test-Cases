# SV-8081 — Part Sales: View role (See Financial Data ON) — opening a part sale/part request loads briefly, shows financial info (bottom-left) but no Finance tab, then displays "Access restricted" on the part sale detail

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-08T08:18
- **Link:** https://shopview.atlassian.net/browse/SV-8081

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging

**Affected Area:** Part Sales — part sale detail / Finance tab visibility

**Preconditions:**

* Custom role with **Parts Department ON**, **Part Sales: View ON**
* **See Financial Data ON**
* User assigned that custom role

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Go to Parts → Part Sales
3. Click a part sale / part request to open its detail
4. Observe the detail page as it loads

**Expected Result:**  
With See Financial Data ON, the part sale detail should load and display financial data, including the Finance tab (subject to confirmation of the intended permission gate for the Finance tab). The page should not throw "Access restricted."

**Actual Result:**

* Opening a part sale / part request loads for a few seconds.
* **Financial Information is shown** (bottom-left of the detail).
* **No Finance tab** is present on the part sale detail.
* The page then shows **"Access restricted."**

**Scope / Notes:**

* Distinct from SV-8052 (which is the Access restricted on **login/landing** for a Part Sales: View role). This is on the **part sale detail** — the page partially renders (financial info visible) but lacks the Finance tab and resolves to Access restricted.
* The load-then-"Access restricted" pattern suggests the detail page begins rendering before an access/authorization check resolves and fails.

**Open Question / VIU:**  
The Finance tab is defined under Invoicing: View (§1h), not Part Sales: View. Please confirm whether the Finance tab is intended to appear on a part sale detail for a **Part Sales: View** role (with See Financial Data ON), or whether it requires Invoicing: View. Regardless, the detail page should not load financial info and then throw "Access restricted."

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §1e Part Sales, View row | "View part sales records, part returns, and part-related transactions." |
| 2 | §1h Invoicing, View row | "View invoices from work orders and part sales. Access the Finance tab." |
| 3 | §6a See Financial Data, ON state | "User can see pricing, costs, margins, and financial columns throughout the app." |
