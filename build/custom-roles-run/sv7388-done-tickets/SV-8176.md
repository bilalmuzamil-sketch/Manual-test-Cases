# SV-8176 —  Order Parts / See Financial Data dependency prompts not firing (enabling Order Parts with SFD OFF does not prompt; turning SFD OFF does not prompt to disable Order Parts)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-06  **Updated:** 2026-07-08T07:47
- **Link:** https://shopview.atlassian.net/browse/SV-8176

## Description

Per spec, Order Parts and See Financial Data (SFD) are now linked with two-way confirmation prompts. In the build, neither prompt fires.

**Expected (per spec, page 565116952):**

* Enabling the **Order Parts** sub-setting while **See Financial Data is OFF** triggers the Financial Data Confirmation Modal ("….requires 'See Financial Data' to be enabled. Enable it?") — Confirm auto-enables SFD, Cancel reverts.
* Turning **See Financial Data OFF** while Order Parts is ON prompts the user to disable the dependent settings (the prompt lists them, including Order Parts).

**Actual (build):**

* Enabling Order Parts with SFD OFF does **not** prompt to enable SFD (Order Parts enables without the modal).
* Turning SFD OFF with Order Parts ON does **not** prompt to disable Order Parts (Order Parts remains ON).

**Steps to Reproduce:**

1. Create/edit a custom role with See Financial Data OFF.
2. Enable the Order Parts sub-setting (under Work Orders) → observe no confirmation modal.
3. Separately: with Order Parts ON, turn See Financial Data OFF → observe no prompt to disable Order Parts.
