# SV-8170 — Enabling "Invoicing & Payments → Delete" While "Manage AP/AR" Is OFF SHOULD Prompt the User to Enable AP/AR

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-06  **Updated:** 2026-07-13T10:28
- **Link:** https://shopview.atlassian.net/browse/SV-8170

## Description

When configuring a role, enabling **Invoicing & Payments → Delete** while **Manage Accounts Payable & Receivable (AP/AR)** is disabled SHOULD prompt the user to enable **Manage AP/AR**.

According to the current Custom Roles specification, **Invoicing & Payments → Delete** independently controls the ability to:

* Reverse invoices
* Delete customer payments
* Void transactions

But the above is dependent on  **Manage AP/AR** being toggled on.

**Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles & Permissions**.
2. Edit any role.
3. Ensure **Manage Accounts Payable & Receivable** is **OFF**.
4. Enable **Invoicing & Payments → Delete**.

**Actual Result:**  
The system DOES NOT prompt the user to enable **Manage Accounts Payable & Receivable (AP/AR)**.

**Expected Result:**  
If **Manage AP/AR** is **not** a enabled, placing the check mark for  **Invoicing & Payments → Delete** should prompt the user to also enable **Manage AP/AR**
