## Scope

**AP/AR (7,** `api/src/Reporting/Dashboard/Infrastructure/Controller/`) — there is **no AP/AR atom today** (grep-confirmed). Add **2 net-new atoms** `ROLE_ACCOUNT_RECEIVABLE_REPORT::VIEW` + `ROLE_ACCOUNT_PAYABLE_REPORT::VIEW` (in `PermissionEnum.php`) and apply:

* `AgingSummaryController`, `AgingDetailController`, `CollectionsController`, `AccountReceivablePdfController` → `ROLE_ACCOUNT_RECEIVABLE_REPORT::VIEW`
* `ApUnpaidInvoicesController`, `ApAgingSummaryController`, `ApAgingDetailController` → `ROLE_ACCOUNT_PAYABLE_REPORT::VIEW`

**WO-history (3)** — atom `ROLE_WORK_ORDER_HISTORY::VIEW` already exists (`PermissionEnum.php:451`), just apply it to `WorkOrderHistoryViewController`, `LineHistoryViewController`, `StoryHistoryViewController`.

The 2 new atoms later back the `SEE_AP_AR_DATA` bundle; the history atom backs `VIEW_HISTORY_LOGS` (handled in mapping tickets). Granting them to the right roles is done in the role-defaults ticket — here we only **add + apply** the atoms.
