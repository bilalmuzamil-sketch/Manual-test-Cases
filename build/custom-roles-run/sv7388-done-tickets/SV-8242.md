# SV-8242 — Work Order Finance Action Bar Is Shifted to the Left

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-09  **Updated:** 2026-07-13T09:42
- **Link:** https://shopview.atlassian.net/browse/SV-8242

## Description

In the **Work Order → Finance** tab, the finance action controls have moved to the left side of the page instead of appearing in their expected position.

As shown in the screenshot, the highlighted action bar containing controls such as **Customer PO**, icons, **Add Deposit**, and **Reviewed** is incorrectly aligned to the left.

**Steps to Reproduce (STRs):**

1. Open any **Work Order**.
2. Navigate to the **Finance** tab.
3. Observe the finance action controls above the invoice preview.

**Actual Result:**  
The finance action controls are shifted to the left side of the page.

**Expected Result:**  
The finance action controls should appear in their correct aligned position, consistent with the expected layout.
