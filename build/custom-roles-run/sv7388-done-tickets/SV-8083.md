# SV-8083 — Part Sales role with View + Create & Edit + Delete (See Financial Data ON) cannot delete part sales — Delete shows confirmation, then "Access restricted" / "Part sale could not be deleted"; part sale is not deleted (approved and estimate)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-01  **Updated:** 2026-07-14T13:56
- **Link:** https://shopview.atlassian.net/browse/SV-8083

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging

**Affected Area:** Part Sales — Delete

**Preconditions:**

* Custom role with **Parts Department ON**, **Part Sales: View + Create & Edit + Delete ON**
* **See Financial Data ON**
* User assigned that custom role

**Steps to Reproduce:**

1. Log in as the custom role user
2. Go to Parts → Part Sales → open a part sale (by PO number)
3. Click the **three-dot menu** (top right) → **Delete**
4. In the confirmation modal ("Are you sure you want to delete this part sale? Deleting it will redirect you to the Part Sales list"), click **Delete** again
5. Repeat for a part sale in **Estimate** status

**Expected Result:**  
Per spec, Part Sales: Delete grants "Delete part sales, reverse part sale invoices" (§1e). The user should be able to delete the part sale successfully.

**Actual Result:**

* The three-dot menu shows Delete; clicking it opens the confirmation modal; confirming redirects to the Part Sales list.
* Clicking Delete then shows **"Access restricted"** and a toast **"_Part sale could not be deleted_."**
* The part sale is **NOT** deleted — it remains in the Part Sales list.
* Reproduced on both an **approved** part sale and an **Estimate**-status part sale — same result.

**Scope / Notes:**

* The delete action appears to hit a backend authorization gap (surfaced as "Access restricted") despite the role holding Part Sales: Delete.
* Consistent with the systemic "Access restricted" pattern seen elsewhere in this epic on permitted actions.
* Status-independent: fails for both approved and estimate part sales.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §1e Part Sales, Delete row | "Delete part sales, reverse part sale invoices." |
| 2 | §1e Part Sales, Create and Edit row | "Create part sales, create part returns, process part transactions." |
