# SV-7984 — Pressing Tab Clears "What Are You Doing?" Field Intermittently While Creating a New Work Order Line

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-27  **Updated:** 2026-07-06T08:05
- **Link:** https://shopview.atlassian.net/browse/SV-7984

## Description

**Affected Roles:**  
All Roles

**Description:**  
When creating a new Work Order Line, entering text into the **"What Are You Doing?"** field and then pressing the **Tab** key on Windows intermittently clears the entered text instead of preserving it and moving focus to the next field.

The issue is intermittent but occurs often enough to disrupt data entry.

**Steps to Reproduce (STRs):**

1. Log in as any user.
2. Open or create a Work Order.
3. Click **New Line**.
4. Type text into the **"What Are You Doing?"** field.
5. Press the **Tab** key on a Windows keyboard.

**Actual Result:**  
Intermittently, the text entered into the **"What Are You Doing?"** field is cleared when the **Tab** key is pressed.

**Expected Result:**  
Pressing **Tab** should move focus to the **"Why Are You Doing It?"** field while preserving the text entered into the **"What Are You Doing?"** field.
