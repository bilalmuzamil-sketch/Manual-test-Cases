## Description

**Description:**  
In Admin, opening **Edit Staff Member** (`/administration/staff`) renders the **Time Clock** toggle incorrectly (see screenshot). The toggle shows in this broken state for **all staff members**, regardless of their actual Time Clock setting — even before it's set to Yes. The toggle renders fine when **creating** a staff member; the UI **only breaks on edit**.

**Steps to Reproduce:**

1. Admin → Settings → Staff (`/administration/staff`).
2. Open any staff member → Edit.
3. Observe the **Time Clock** toggle in the modal.

**Expected Result:** The Time Clock toggle renders correctly and reflects the staff member's current state.

**Actual Result:** The Time Clock toggle is misrendered for all staff on edit; create is unaffected.
