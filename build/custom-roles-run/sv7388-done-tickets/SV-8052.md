# SV-8052 — "Access restricted" appears for a Part Sales: View role (both with and without See Financial Data)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-30  **Updated:** 2026-07-13T10:48
- **Link:** https://shopview.atlassian.net/browse/SV-8052

## Description

**Issue Type:** Bug  
**Priority:** Medium  
**Epic:** SV-7388

**Environment:** Staging

**Preconditions:**

* Custom role with Parts Department ON, Part Sales: View ON
* Tested with See Financial Data both OFF and ON

**Steps to Reproduce:**

1. Enable Part Sales: View (See Financial Data OFF) — observe no prompt to enable See Financial Data; role saves (Already reported - SV-7967)
2. Log in as the user → "Access restricted" appears and keeps on showing the same after clicking Parts tab/Shopview logo
3. Enable See Financial Data, re-login → "Access restricted" still appears but it will let you click the Parts tab

**Expected Result:**

* Enabling Part Sales: View while See Financial Data is OFF should trigger the confirmation modal to enable See Financial Data; the invalid combination should not save silently.
* With a valid Part Sales: View config, the user should land in a usable state (no "Access restricted").

**Actual Result:**

* Part Sales: View saves with See Financial Data OFF, **no prompt shown**. (Reported - SV7967)
* "Access restricted" appears on login **both** with See Financial Data OFF and ON.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | Financial Data Confirmation Modal | "User enables any Invoicing or Part Sales CRUD checkbox (View, Edit, or Delete) while See Financial Data is OFF." |
| 2 | §1e Part Sales, Financial gate | "Requires See Financial Data to be ON (part sales inherently involve pricing)." |
