# SV-8046 —  Summary: "Reviewed" button on Work Order is replaced by "AI ShopCoach Analysis" for custom role with WO View + Review Work Orders — button does not persist (both Full and Tech View)

- **Status:** Done
- **Resolution:** Done

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging 

**Affected Area:** Work Orders — Review Work Orders / ShopCoach

**Preconditions:**

* Custom role with **Work Orders: View ON** and **Review Work Orders ON**
* User is assigned to that custom role
* Reproduces in both **Full View** and **Tech View**

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Open a work order
3. Observe the top-right corner of the work order on load

**Expected Result:**  
Per spec, a role with Review Work Orders enabled should see the **Reviewed** button in the top right (Full View). The Reviewed button should remain visible and usable for the review action.

**Actual Result:**  
The **Reviewed** button appears briefly (about a second) in the top right, then is replaced by an **"AI ShopCoach Analysis"** button. Clicking "AI ShopCoach Analysis" starts the ShopCoach Review instead. The Reviewed button does not persist. Reproduces in both Full View and Tech View.

**Scope / Notes:**

* The Reviewed button flashes on load and is then overwritten by the AI ShopCoach Analysis control — suggesting a render/ordering issue where the ShopCoach control replaces the Reviewed button rather than coexisting with it.
* View Mode behavior to confirm with PM: in **Full View**, the Reviewed button should be present (spec deviation as described). In **Tech View**, the spec's Tech View restriction table lists the Review action as hidden — so the expected Tech View baseline differs. Flagging so the intended Tech View behavior for Review + ShopCoach is confirmed rather than assumed.

**Open Question for PM (VIU):**  
The spec defines the Review Work Orders capability and the Reviewed action, but does not describe the **"AI ShopCoach Analysis"** control or its interaction/precedence with the Reviewed button. Please confirm the intended behavior — whether both should be available, which takes precedence, and the expected Tech View handling.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §4 WO Sub-Settings, Review Work Orders | "These sub-settings only require Work Orders: View to be enabled." |
| 2 | §5 View Mode, Full View row | "All workflow actions available (approve, review, split etc...)." |
| 3 | §5 View Mode, Tech View restrictions | "Review WOs action hidden." |

Note: The issue is with Admin as well. The Reviewed button will show for a second and then AL ShopCoach Analysis replaces it.

### Nikola Milosevic — 2026-07-06T07:35

The Reviewed and AI ShopCoach Analysis buttons are independent — one wasn't replacing the other. On load, before the work order's lines finished fetching, the empty line list was mistakenly treated as "all lines resolved," so the Reviewed button showed for \~1 second. Once lines loaded and the criteria weren't met (unresolved lines remained), it correctly disappeared, while the ShopCoach button appeared on its own condition — making it look like a swap.   
  
The fix waits for lines to load before evaluating the Reviewed criteria, so it only shows when the work order genuinely qualifies (and still shows for line-less work orders, which remain reviewable).  
  
Will confirm once it is on stage.
