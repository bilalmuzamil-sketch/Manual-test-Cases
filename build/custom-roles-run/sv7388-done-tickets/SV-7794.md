# SV-7794 — ShopCoach Line Builder Returns No Response and Fails with "Vehicle Not Found" Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-19  **Updated:** 2026-06-29T15:15
- **Link:** https://shopview.atlassian.net/browse/SV-7794

## Description

The **ShopCoach Line Builder** does not generate any Work Order Lines when keywords are entered and **Build Lines** is clicked.

The request is triggered, but the backend returns a validation error indicating **“Vehicle not found”**, even though the Work Order has an associated vehicle.

---

### **Steps to Reproduce (STRs):**

1. Create a **Work Order (WO)**.
2. Do **not** create a new line.
3. In **ShopCoach Line Builder**, enter keywords, for example:

    * `Change Engine, Change lights, Change oil`
    
4. Click **Build Lines**.
5. Observe the response and network errors.

---

### **Actual Result:**

* No Work Order Lines are created.
* No response is shown in the UI.
* Network response shows:

```
{
  "status": "ValidationError",
  "isError": true,
  "message": "Vehicle not found",
  "messageCode": "assistant.validation_error"
}
```

---

### **Expected Result:**

*  ShopCoach Line Builder should generate Work Order Lines based on the entered keywords. 
*  No validation/server error should occur when the WO has an associated vehicle.
