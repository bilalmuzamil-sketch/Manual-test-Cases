# SV-7902 — Send to Terminal not visible for Parts Technician

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-25  **Updated:** 2026-07-08T03:03
- **Link:** https://shopview.atlassian.net/browse/SV-7902

## Description

Parts Technician does not see the Send to Terminal action. Per spec, "Send to Terminal" sits behind **Invoicing and Payments: Create and Edit**, which Parts Technician has ON.

‌

**Spec references:**

| Setting | What the spec says |
| --- | --- |
| Permission Matrix → Invoicing row | Parts Technician = View / Create and Edit |
| Invoicing → Create and Edit "Controls" | "Create invoices, process payments directly from work orders and part sales, manage invoice fields, collect deposits, **send payments to terminal**." |
| Open Question 4 (answered) | "Send to Terminal and Deposits… sit behind Invoice and Payments - Create and Edit." |

**Expected:** With Invoicing and Payments: Create and Edit ON (and See Financial Data ON, which Parts Technician has), Send to Terminal should be available.

**Actual:** Send to Terminal is not visible for Parts Technician.
