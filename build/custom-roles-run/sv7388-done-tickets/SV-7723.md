# SV-7723 — FE - Title: Custom Roles UI Does Not Match Figma Design (Action Column Header and Icon Placement)

- **Type:** Story Defect - Archive
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-17  **Updated:** 2026-07-06T04:04
- **Link:** https://shopview.atlassian.net/browse/SV-7723

## Description

**Description:**  
The **Custom Roles** page implementation in the QA branch does not match the approved Figma design. Several UI elements differ from the expected layout and behavior.

---

### **Issue #1: View-Only Roles Displayed Inside 3-Dot Menu Instead of Eye Icon**

**Figma Design:**

* Roles that cannot be edited display a visible **Eye (View) icon**.

**QA Branch:**

* Users must open the **3-dot menu** to access the Eye icon.

**Expected Result as per Figma:**

* The Eye icon should be displayed directly in the Actions area as shown in the Figma design.

---

### **Issue #2: Missing "Action" Column Header**

**Figma Design:**

* The last column is labeled **"Action"**.

**QA Branch:**

* The last column has **no header/title**.

**Expected Result as per Figma:**

* The last column should display the header **"Action"**.

---

### **Issue #3: Edit (Pencil) Icon Placement Does Not Match Design**

**Figma Design:**

* The **Edit (Pencil) icon** is displayed directly in the Action column.

**QA Branch:**

* The Edit option is hidden inside the **3-dot menu**.

**Expected Result as per Figma design:**

* The Edit (Pencil) icon should be displayed directly in the Action column as shown in the Figma design.
