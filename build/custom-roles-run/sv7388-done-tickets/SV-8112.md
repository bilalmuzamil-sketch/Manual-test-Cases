# SV-8112 — BE - Changing Staff Role Throws 403 Access Restricted Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-08T04:15
- **Link:** https://shopview.atlassian.net/browse/SV-8112

## Description

**Affected Role:**  
Administrator / any role with permission to manage Staff and Roles

**Description:**  
When attempting to change a staff member’s role, the system throws a **403 Access Restricted** error.

Users with the required permissions should be able to update a staff member’s assigned role without encountering an authorization error.

**Steps to Reproduce (STRs):**

1. Navigate to **Settings → Staff**.
2. Open any staff member.
3. Change the assigned role.
4. Save the changes.

**Actual Result:**  
A **403 Access Restricted** error is displayed, and the staff role is not updated.

**Expected Result:**  
The selected role should be saved successfully without any authorization error.

**Impact:**  
Admins/managers cannot update staff role assignments, blocking role management and Custom Roles validation.
