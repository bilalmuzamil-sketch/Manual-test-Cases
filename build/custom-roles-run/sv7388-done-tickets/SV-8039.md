# SV-8039 — Field border clips label on hover/focus (login + forgot-password)

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-30  **Updated:** 2026-07-09T05:26
- **Link:** https://shopview.atlassian.net/browse/SV-8039

## Description

**Description:**  
On the login and forgot-password screens, when a field is autofilled and then blurred (click outside), the field's top border renders over the floating label, cutting through the label text.

**Steps to Reproduce:**

1. Open /login (or /forgot-password)
2. Autofill the Email field
3. Click outside the field
4. Observe top border vs field label

**Expected Result:**  
Border and label render cleanly; label sits in the border gap.

**Actual Result:**  
Top border clips through the label text. Seen on both screens.
