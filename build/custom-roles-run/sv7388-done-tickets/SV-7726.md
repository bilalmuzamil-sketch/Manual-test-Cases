# SV-7726 — FE - Incorrect Delete Tooltip Displayed for System Roles in Edit Role Modal

- **Type:** Story Defect - Archive
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-17  **Updated:** 2026-07-06T04:08
- **Link:** https://shopview.atlassian.net/browse/SV-7726

## Description

**Description:**  
In the **QA Branch**, when editing a **system role** (e.g., **Parts Manager**) and hovering over the **Delete icon** within the **Edit Role modal**, the tooltip displays an incorrect message explaining why the role cannot be deleted.

The tooltip indicates that the role cannot be deleted because it is assigned to users, even when no users are assigned to the role.

---

### **Environment:**

* QA Branch

---

### **Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles and Permissions**.
2. Open the **Parts Manager** system role
3. Click **Edit**.
4. Hover over the **Delete icon**.

---

### **Actual Result:**

The tooltip displays:

> "This role is assigned to users - resolve roles before deleting it."

Even though:

* No users are assigned to the role.
* The actual reason the role cannot be deleted is because it is a **system role**.

---

### **Expected Result:**

The tooltip should explain the actual restriction, for example:

> "System roles cannot be deleted."

or

> "This is a system role and cannot be deleted."
