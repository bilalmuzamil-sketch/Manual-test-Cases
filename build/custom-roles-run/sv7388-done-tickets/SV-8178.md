# SV-8178 — Custom Roles: standardize system role display names — "Time Clock User", "Parts Technician", "Office User"

## Description

Three system roles display shortened names that should use their full canonical names. The correct display names are:

* Time Clock → **Time Clock User**
* Parts Tech → **Parts Technician**
* Office → **Office User**

These correct names should appear consistently everywhere the role is shown: the Roles & Permissions list, the "Choose a template" picker, the Staff role-assignment dropdown, and the Permission Summary.

**Expected:** The three roles display as "Time Clock User", "Parts Technician", and "Office User".

**Actual:** They display as "Time Clock", "Parts Tech", and "Office" (per the current spec Role Descriptions table and/or build).
