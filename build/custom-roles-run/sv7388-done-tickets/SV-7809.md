# SV-7809 — Open API Is Missing from Integrations Section and Has No Associated Permission

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-21  **Updated:** 2026-07-13T04:50
- **Link:** https://shopview.atlassian.net/browse/SV-7809

## Description

Enabling **Finance** under **Apps** makes both the **Integrations** and **Finance** sections appear in **Settings** for the user.

**Permission path used:**  
**Settings → Enable Apps → Enable Finance**

The current behavior is:

* Enabling **Settings → App Settings → Finance** displays the **Integrations** section.  
  **That makes Integration and Finance section BOTH to appear under the user’s settings section.**
* Under **Integrations**, only **QuickBooks** and **IBS** are available **Open API is missing.**
* The **Finance** section is also displayed, containing **Payment Methods**.

‌

**Steps to Reproduce (STRs):**

1. Navigate to **Settings → Roles & Permissions**.
2. Edit any role.
3. Under **Settings**, enable **Apps**.
4. Enable  **App settings** → Then enable **Finance**.
5. Save the role.
6. Log in as a user assigned to that role.
7. Navigate to **Settings**.

**Actual Result:**

* The **Integrations** section is displayed.
* **QuickBooks** and **IBS** are available under Integrations.
* The **Finance** section is displayed with **Payment Methods**.
* **Open API** is missing.

  
**Clarification Needed:** <custom data-type="mention" data-id="id-0">@Sasha Grosman</custom>   
Please clarify the intended behavior for the **Open API** feature:

* Should **Open API** appear under the **Integrations** section when **Settings → App Settings → Finance** is enabled?
