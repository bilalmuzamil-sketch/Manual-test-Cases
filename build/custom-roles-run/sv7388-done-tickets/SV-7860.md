# SV-7860 — BE - Send to Terminal" Fails with Error During Invoice Payment Process

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-23  **Updated:** 2026-07-13T08:27

## Description

**Affected Roles:**  
All roles/permissions configurations that allow users to:

* Create Invoices
* Make New PaymentsUnable to connect to the Customer Portal. Please try again.

---

### **Description:**

Users are unable to process payments through **Send to Terminal** from the Work Order Finance section.

When attempting to send a payment to the payment terminal after creating an invoice, the system throws an error and the payment process cannot continue.

---

### **Steps to Reproduce (STRs):**

1. Create a **Work Order**.
2. Create and complete a **Work Order Line**.
3. Navigate to the **Finance** tab.
4. Click **Create Invoice**.
5. Select **Send to Terminal** as the payment method.
6. Observe the Error.

    ```
    Unable to connect to the Customer Portal. Please try again.Unable to connect to the Customer Portal. Please try again.
    ```

---

### **Actual Result:**

* An error is displayed when **Send to Terminal** is selected.
* The payment is not sent to the terminal.
* The payment workflow cannot be completed.
