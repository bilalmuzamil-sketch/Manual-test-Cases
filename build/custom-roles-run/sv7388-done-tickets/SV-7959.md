# SV-7959 — Finance tab still shows when See Financial Data is OFF

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-26  **Updated:** 2026-06-29T13:15
- **Link:** https://shopview.atlassian.net/browse/SV-7959

## Description

**Description:** When a role has See Financial Data turned OFF, the work order should hide all pricing, including the Finance tab. Instead, the Finance tab and full invoice layout still show — only the dollar values are blank. The financial surface is exposed when it should be removed.

**Steps to Reproduce:**

1. Use a role whose permission summary shows See Financial Data = OFF.
2. Open a work order.
3. Open the Finance tab.

**Expected Result:** With See Financial Data OFF, pricing is hidden everywhere and the Finance tab isn't accessible.

**Actual Result:** The Finance tab and invoice layout still display; Rate / Amount / Total columns appear but with blank values.
