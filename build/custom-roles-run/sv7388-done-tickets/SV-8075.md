# SV-8075 — Vendor & Order Management: View role gets "Access restricted" when opening Purchase Orders under Parts; Returns, Vendor Invoices, and Vendors work — but Purchase Orders should be viewable per spec

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388

**Environment:** Staging

**Preconditions:**

* Custom role with Parts Department **ON**, Vendor & Order Management: View **ON** only
* No other permissions enabled

**Steps to Reproduce:**

1. Enable Vendor & Order Management: View (Parts Department ON); assign the role to a user and log in
2. Go to Parts
3. Open **Returns**, **Vendor Invoices**, and **Vendors** — confirm they load
4. Click **Purchase Orders**
5. Observe the result

**Expected Result:**  
Per spec, Vendor & Order Management: View allows viewing purchase orders. The Purchase Orders view should load, consistent with Returns, Vendor Invoices, and Vendors.

**Actual Result:**

* **Returns, Vendor Invoices, and Vendors** load correctly.
* Clicking **Purchase Orders** shows **"Access restricted"** and displays nothing.
