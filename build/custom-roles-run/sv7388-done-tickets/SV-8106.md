# SV-8106 — Part Sales: "Split Parts Order" Action Throws Application Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-02  **Updated:** 2026-07-08T09:37
- **Link:** https://shopview.atlassian.net/browse/SV-8106

## Description

**Affected Role:**  
Administrator (configured with all permissions enabled)

**Description:**  
When attempting to split a Parts Order from a Part Sale, the **Split Parts Order** action fails with an application error.

Instead of opening the split workflow or successfully splitting the selected part, the application displays an unexpected error message.

**Steps to Reproduce (STRs):**

1. Log in as an **Administrator** with all permissions enabled.
2. Navigate to **Parts → Part Sales**.
3. Open any existing **Part Sale** containing one or more parts.
4. Select a part by placing a checkmark next to it.
5. Click the **three-dot menu**.
6. Click **Split Parts Order**.

**Actual Result:**  
The application displays the following error:

> **Ooooops! An error occurred**  
> For more information, please contact support. Include your request ID: **\[8d1366dd-dadf-457e-8da2-a3fe3360c434\]** when reaching out for faster assistance.

The split operation is not performed.

**Expected Result:**  
The **Split Parts Order** action should open the split workflow (or complete the split operation) without any errors.
