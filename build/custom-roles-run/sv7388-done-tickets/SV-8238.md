# SV-8238 — Part sale invoice can be reversed with Invoicing & Payments: Delete but WITHOUT any Work Orders permission — per the 6/28 spec, reversing an invoice requires Work Orders: Delete (§1a); reversal should not be possible without it

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-09  **Updated:** 2026-07-10T04:05
- **Link:** https://shopview.atlassian.net/browse/SV-8238

## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388

**Environment:** Staging

**Affected Area:** Invoicing / Part Sales — invoice reversal permission gating

**Preconditions:**

* Custom role: Parts Department ON, Part Sales (V/E/D), See Financial Data **ON**
* Invoicing & Payments: **View + Create & Edit + Delete ON**
* Customers: View, **Manage AP/AR ON**
* **Work Orders: no permissions** (no View / Create & Edit / Delete)
* User is assigned to that custom role

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Part Sales → open a part sale → Finance tab → create an invoice → add a payment
3. Delete the payment (customer side), then reverse the part sale invoice

**Expected Result:**  
Per the 6/28 Change Log and §1a, reversing an invoice requires **Work Orders: Delete**. This role has no Work Orders permission, so it should **not** be able to reverse the part sale invoice — even though it can delete the payment (which correctly uses Invoicing: Delete).

**Actual Result:**

* With Invoicing & Payments: Delete and **no Work Orders permission at all**, the user **can reverse the part sale invoice.**
* Reversal is gated by Invoicing: Delete only; Work Orders: Delete is not required, contradicting the 6/28 spec change.

**Scope / Notes:**

* Payment deletion via Invoicing: Delete is **expected** (§1i). The defect is specifically that **invoice reversal** works without **Work Orders: Delete**, which the 6/28 change made a requirement.
* §1a explicitly separates these: Work Orders: Delete grants "Reverse Invoices" but "is not enough to delete payments" — reversal and payment-deletion are meant to be gated by different permissions (WO: Delete and Invoicing: Delete respectively).
* Related spec-accuracy issue: §1e Part Sales Delete row still reads "reverse part sales invoices," which also contradicts the 6/28 move to Work Orders: Delete — spec needs updating.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | Change Log 6/28/2026 | "Reversing an Invoice has been moved (for Work Orders and Part Sales). Previously: required Invoice & Payments → Delete. Now: requires Work Order → Delete." |
| 2 | §1a Work Orders, Delete row | "Delete work orders, Reverse Invoices as long as validation criteria is met… Note: this permission is not enough to delete payments." |
| 3 | §1i Invoicing, Delete row | "Delete payments (including customer payments), void transactions, deleting a Part Sale return." |

## Comments (3 of 3)

### Ayesha Khan — 2026-07-09T13:12

Isolation test confirms the reversal-gating asymmetry between work orders and part sales:

**Work orders (correct per 6/28):**

* With Invoicing & Payments: Delete/Reverse but NO Work Orders: Delete → cannot reverse a work order (customer) invoice, cannot delete the work order.
* Reversing a WO invoice and deleting the WO both require **Work Orders: Delete**. Invoicing: Delete alone does not reverse WO invoices. This matches the 6/28 Change Log.

**Part sales (defect — this ticket):**

* With Invoicing & Payments: Delete/Reverse and NO Work Orders: Delete → **can** reverse the part sale invoice.
* Part sale invoice reversal is still gated by Invoicing: Delete, not Work Orders: Delete.

Conclusion: the 6/28 change ("reversing an invoice — for Work Orders and Part Sales — now requires Work Order: Delete") was applied to **work orders but not part sales**. Part sale reversal still follows the pre-6/28 path (Invoicing: Delete), consistent with the stale §1e wording ("Delete part sales and reverse part sales invoices"), which was never updated to match the 6/28 change.

Requesting: (1) fix part sale invoice reversal to require Work Orders: Delete (parity with work orders, per 6/28); and (2) update §1e to remove "reverse part sales invoices" so it aligns with the 6/28 Change Log.
