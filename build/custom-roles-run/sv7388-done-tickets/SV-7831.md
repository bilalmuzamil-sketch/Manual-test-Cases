# SV-7831 — Shop Coach Analysis Not Visible for Technician Despite All Required Permissions Being Enabled

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-22  **Updated:** 2026-06-29T12:35
- **Link:** https://shopview.atlassian.net/browse/SV-7831

## Description

**Affected Role:**  
Technician: All permissions enabled as per the Specs

---

### **Description:**

The **Shop Coach Analysis** option is not visible for users with the **Technician** role, even though all Technician permissions/CRUD settings are enabled as defined in the specification.

---

### **Steps to Reproduce (STRs):**

1. Ensure the **Technician** role has all permissions enabled as specified.
2. Log in as a Technician.
3. Open a **Work Order**.
4. Create a **Work Order Line**.
5. Observe the available actions on the Work Order at the top right side.

---

### **Actual Result:**

* **Shop Coach Analysis** is not displayed for the Technician.

**Affected Role:**  
Technician

---

### **Description:**

The **Shop Coach Analysis** option is not visible for users with the **Technician** role, even though all Technician permissions/CRUD settings are enabled as defined in the specification.

This prevents Technicians from accessing the Shop Coach Analysis feature.

---

### **Steps to Reproduce (STRs):**

1. Ensure the **Technician** role has all permissions enabled as specified.
2. Log in as a Technician.
3. Open a **Work Order**.
4. Create a **Work Order Line**.
5. Observe the available actions on the Work Order.

---

### **Actual Result:**

* **Shop Coach Analysis** is not displayed for the Technician.

---

### **Expected Result:**

* If the Technician role has all required permissions per spec, **Shop Coach Analysis** should be visible and accessible.
* Alternatively, if the feature is intentionally restricted, the specification should clearly indicate that Technicians are excluded from using Shop Coach Analysis.

---

### **Impact:**

* Technicians cannot access Shop Coach Analysis.
* Behavior does not align with the configured permissions.
* Potential mismatch between role permissions and feature visibility.
