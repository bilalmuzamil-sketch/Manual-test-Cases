# SV-7979 — Spec Clarification: Should Technician Be Able to See "Send to Portal"?

## Description

**Affected Role:**  
Technician (configured with all permissions/CRUD as per the specification)

**Description:**  
While validating the Technician role, it was observed that the **Send to Portal** action is **not available**.

This behavior appears to align with the current specification because the Technician role **does not have Work Order Full View**, which is one of the documented prerequisites for the feature.

However, prior to the Custom Roles implementation, Technicians were able to see the **Send to Portal** option. Clarification is required to determine whether this change is intentional or whether the specification should be updated.

**Specification Requirements for "Send to Portal":**

* **Work Order View Mode = Full View**
* **Ability to Create/Edit Work Order Lines**

The Technician role does **not** have **Full View** for Work Orders and therefore does not satisfy the documented requirements.

**Current Behavior:**

* Technician cannot see the **Send to Portal** action.

**Expected Result:**  
Please confirm whether this is the intended behavior.

* **If this is expected**, please mark this ticket as **Obsolete**
* **If Technicians are expected to have access to Send to Portal** (as they did before the Custom Roles implementation), then either:

    * the implementation should be updated, or
    * the specification should be revised to reflect the intended permission model.
    

**Question for Product:**  
Is the removal of **Send to Portal** from the Technician role an intentional change under the new permission model, or should the previous behavior be preserved?
