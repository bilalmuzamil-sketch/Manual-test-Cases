# SV-7807 — Service Manager Invoicing & Payments Permission Does Not Match Spec

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-21  **Updated:** 2026-07-07T09:28
- **Link:** https://shopview.atlassian.net/browse/SV-7807

## Description

For the **Service Manager** role, the **Create & Edit** permission under **Invoicing & Payments** is currently unchecked.

As per the spec, Service Manager should have **V/E** access for Invoicing, but the application only shows **View** enabled.

| Role | Area | Expected per Spec | Current App Behavior |
| --- | --- | --- | --- |
| Service Manager | Invoicing / Invoicing & Payments | V/E | View only |

**Expected Result:**  
Service Manager should have **Create & Edit** enabled for **Invoicing & Payments**, matching the spec.
