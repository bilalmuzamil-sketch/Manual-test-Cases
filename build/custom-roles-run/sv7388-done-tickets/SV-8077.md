## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging 

**Affected Area:** Vendor & Order Management — Returns / financial data visibility (See Financial Data OFF)

**Preconditions:**

* Custom role with **Parts Department ON** and **Vendor & Order Management: View ON** only
* **See Financial Data: OFF**
* No other permissions enabled
* User is assigned to that custom role

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Go to Parts → **Returns**
3. Observe the **Cost** and **Total Cost** columns
4. Toggle **"Show Cores only"**
5. Open Vendor Invoices and see **Total Cost** column
6. Open **Credits**

**Expected Result:**  
With See Financial Data OFF, all financial data must be hidden across every page — dollar amounts, rates, costs, margins, and totals are not displayed (§6a). The Cost / Total Cost columns, core cost data, and Credits financial values should not be visible to this role.

**Actual Result:**  
The Vendor & Order Management: View role, with See Financial Data OFF, can see in Returns & Vendor Invoices

* The **Cost** and **Total Cost** columns
* A **"Show Cores only"** toggle (core cost data)
* **Credits** (with financial values)

**Scope / Notes:**

* Financial-data leak in the **Returns** & **Vendor Invoices** view, contradicting §6a (financial data hidden when See Financial Data is OFF).
* Same class as the existing See-Financial-Data leaks (SV-7957 Inventory finance info; SV-7956 Part Sales accessible; SV-7965 Part Sales via URL) — but this is the **Returns** and **Vendor Invoices** view (Cost/Total Cost, Cores, Credits), which those tickets do not cover.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §6a See Financial Data, OFF state | "All financial data is hidden across every page. Dollar amounts, rates, costs, margins, and totals are not displayed." |
| 2 | §1g Vendor and Order Management, View row | "View vendors, purchase orders, deliveries, part history, and part return requests." |

**Related:** SV-7957, SV-7956, SV-7965 (See Financial Data OFF leaks in other areas)
