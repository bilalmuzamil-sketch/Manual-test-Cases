# SV-7796 — ShopCoach Labour Guide Returns No Response and Fails with "Work Order Not Found" Error

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-19  **Updated:** 2026-06-29T15:17
- **Link:** https://shopview.atlassian.net/browse/SV-7796

## Description

**Description:**  
The **ShopCoach Labour Guide** is not responding when triggered from the **Edit Line** modal. The request is sent, but no result is displayed in the UI, and the Network tab shows a server error.

---

### **Steps to Reproduce (STRs):**

1. Create a **Work Order (WO)**.
2. Click **New Line** and create a **Work Order Line (WOL)**.
3. Add the required line details.
4. Open/Edit the line.
5. Click **ShopCoach Labour Guide**.
6. Observe the UI and Network tab.

---

### **Actual Result:**

* No response is shown in the UI.
* Network response shows:

```
{
  "status": "ServerError",
  "isError": true,
  "message": "Work order not found",
  "messageCode": "assistant.server_error"
}
```

---

### **Expected Result:**

*  ShopCoach Labour Guide should return labor guidance successfully. 
*  No server error should occur when the Work Order exists.
