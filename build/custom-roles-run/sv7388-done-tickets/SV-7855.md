# SV-7855 — Sales Rep: report links clickable despite View OFF (3 pages)

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-23  **Updated:** 2026-07-13T07:36
- **Link:** https://shopview.atlassian.net/browse/SV-7855

## Description

**Description:** When a user with the **Sales Rep** role has view permissions turned OFF for areas like Customers, Work Orders, Vendors, or Invoices, any links to those pages inside reports should be plain text and completely non-clickable.

* Right now, across 3 different reports, these items are still clickable.
* For three of the reports, clicking just breaks the screen with an 403 error. But for the **A/P Aging Detail** report, clicking the Invoice number actually lets them open a WO page they are supposed to be blocked from seeing.

**Steps:**

1. Log in as a user with the **Sales Rep** role with report access ON
2. Go to **Reports** and click the links on these 3 pages:

    * **A/R Aging (Summary/Detail/Collection):** Click a Customer name.
    * **A/P Unpaid Invoices:** Click a vendor row.
    * **A/P Aging Detail:** Click an Invoice number.
    

**Expected:** All links are non-clickable plain text because the role's view permissions for those records are turned OFF.

* Pages they don't have permission to see should be locked and unreachable.

    **Actual:**    
    **A/R Aging, A/P Unpaid Invoices:** Links are clickable and lead to 403 or "Access Denied" error pages.  
    **A/P Aging Detail:** The Invoice link actually opens up a forbidden `/parts/delivery` page.
