# SV-8151 — Time Picker Does Not Automatically Close After Selecting Minutes When Editing a Timesheet

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-07-05  **Updated:** 2026-07-06T16:16
- **Link:** https://shopview.atlassian.net/browse/SV-8151

## Description

**Affected Permission:**  
**Reports →** View  
**Timesheet**: Create and Edit

**Description:**  
When editing a Timesheet entry, the time picker behaves inconsistently after selecting the minutes.

After selecting the **hour**, the time picker correctly opens the second view to allow minute selection. However, once the **minutes** are selected, the time picker does **not** automatically close as expected. Instead, the user must manually close the popup before continuing.

**Steps to Reproduce (STRs):**

1. Ensure the user has **Reports → Create & Edit Timesheet** permission enabled.
2. Navigate to **Reports → Timesheet Activities**.
3. Edit any existing Timesheet entry.
4. Click the **Clock In** or **Clock Out** time field.
5. Select an **hour**.
6. Select the **minutes**.

**Actual Result:**  
The selected time is applied, but the time picker remains open. The user must manually close the popup.

**Expected Result:**  
After selecting the **minutes**, the time picker should automatically close, completing the time selection without requiring the user to manually dismiss the popup.

**Impact:**  
The extra manual step interrupts the expected workflow, making time editing less intuitive and inconsistent with standard time picker behavior.
