# SV-8037 — Schedule block shows old Time Estimate after editing

- **Type:** Bug
- **Status:** OBSOLETE
- **Resolution:** Done
- **Created:** 2026-06-30  **Updated:** 2026-06-30T08:56
- **Link:** https://shopview.atlassian.net/browse/SV-8037

## Description

**Description:**  
Editing an appointment's Time Estimate saves correctly, but the schedule block/tooltip still shows the old value. The new value only appears when the modal is reopened.

**Steps to Reproduce:**

1. Schedule → open appointment 
2. Change Time Estimate 3.50 → 6.50 → Save & Close
3. Check block/tooltip → shows 3.50 (old)
4. Reopen modal → shows 6.50 (correct)

**Expected Result:**  
Block updates to new value after saving.

**Actual Result:**  
Block shows old value; correct value only on reopen.
