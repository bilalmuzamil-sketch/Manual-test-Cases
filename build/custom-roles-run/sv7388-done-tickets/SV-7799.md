## Description

**Environment:**  
QA – `sv5319.qa.shopview.com`

**Role:**  
Administrator

**Description:**  
Attempting to use the **Send to Portal** action results in an error and the operation cannot be completed.

---

### **Steps to Reproduce (STRs):**

1. Log in as an **Administrator**.
2. Navigate to a Work Order.
3. Click **Send to Portal**.
4. Observe the result.

---

### **Actual Result:**

An error is displayed and the Work Order is not sent to the portal.

Error Message:

> Request ID: **\[7b13ab8c-9758-4aea-96e3-3c889d0338cf\]**

---

### **Expected Result:**

The Work Order should be successfully sent to the Customer Portal without any errors.
