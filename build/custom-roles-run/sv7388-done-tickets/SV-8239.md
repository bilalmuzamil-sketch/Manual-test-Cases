# SV-8239 — First Work Order Line Is Not Displayed While Subsequent Lines Render Correctly

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-09  **Updated:** 2026-07-13T09:51
- **Link:** https://shopview.atlassian.net/browse/SV-8239

## Description

The first Work Order Line is intermittently hidden and does not render in the Work Order view, while the second and all subsequent lines are displayed correctly.

This causes the Work Order to appear incomplete even though the first line exists.

**Steps to Reproduce (STRs):**

1. Open a Work Order containing multiple Work Order Lines.
2. Observe the list of Work Order Lines.

**Actual Result:**

* The **first Work Order Line** is not displayed.
* The **second and subsequent Work Order Lines** appear correctly.

**Expected Result:**  
All Work Order Lines, including the first line, should be displayed in the correct order.
