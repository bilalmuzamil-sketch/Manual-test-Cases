# SV-8133 — Office user — Taxes missing from Vendor Overview card despite Manage AP/AR being ON

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-03  **Updated:** 2026-07-08T08:25

## Description

What the spec says (Office user):

* Office has Manage AP/AR ON and Vendor and Order Management: View.
* Per section 5b, when Manage AP/AR is ON the sensitive vendor fields — Credit Terms, Credit Limit, and Taxes — are visible on the Vendor Overview card.
* So for Office, all three (Credit Terms, Credit Limit, Taxes) should show on the Vendor Overview card.

What appears on the build (Office user):

* Credit Terms — visible (correct).
* Credit Limit — visible (correct).
* Taxes — not visible on the Vendor Overview card (does not match spec).

Steps to reproduce:

1. Log in as Office.
2. Open a vendor (Vendor Overview card / read-only detail; Office is View-only so the Edit modal is not available).
3. Look for Credit Terms, Credit Limit, and Taxes.

Expected: Credit Terms, Credit Limit, and Taxes all visible on the Vendor Overview card (Manage AP/AR ON, section 5b).

Actual: Credit Terms and Credit Limit visible; Taxes not shown.

Verify in UI: confirm the test vendor has a Taxes value set. If a tax value is set and still does not appear, it is a defect per spec. If no tax value is set, retest on a vendor that has one.

Spec reference:

* Section 5b, Manage Accounts Payable and Receivable (ON): controls visibility of sensitive Vendor fields on the Edit Vendor modal and the Vendor Overview card — Credit Terms, Credit Limit, Taxes.
