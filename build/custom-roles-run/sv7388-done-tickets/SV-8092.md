# SV-8092 — Service Manager (Configured as per specs): Receives 403 Error When Closing "New Customer Payment" Modal Without Completing Payment

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-07-02  **Updated:** 2026-07-08T05:12
- **Link:** https://shopview.atlassian.net/browse/SV-8092

## Description

**Description:**  
A Service Manager configured according to the specification receives a **403 Access Restricted** error when attempting to close the **New Customer Payment** modal without completing the payment.

Simply closing the modal using the **X** icon should dismiss the dialog without triggering any backend action or authorization error.

**Permission Configuration Confirmation (Service Manager, per Custom Roles Spec v33):**  
The Service Manager role was configured exactly as defined in the **Custom Roles and Permissions** specification (Page **565116952**). All permissions required to reach and use the **New Customer Payment** modal are enabled:

* **Work Orders** = **View / Create & Edit** ✓
* **Invoicing & Payments** = **View / Create & Edit** ✓
* **See Financial Data** = **ON** ✓
* **Manage Accounts Payable & Receivable** = **ON** ✓

**Steps to Reproduce (STRs):**

1. Log in as a **Service Manager** configured as per the specification.
2. Open any **Work Order**.
3. Navigate to the **Finance** tab.
4. Click **Create Invoice**.
5. When the **New Customer Payment** modal appears, do not proceed with the payment.
6. Click the **X** icon in the top-right corner of the modal.

**Actual Result:**  
A **403 Access Restricted** error is displayed when attempting to close the modal.

**Expected Result:**  
The **New Customer Payment** modal should close without any errors, returning the user to the previous screen.
