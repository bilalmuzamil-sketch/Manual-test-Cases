# SV-8016 — ShopCoach Parts Guide "Added Parts" Section Is Misaligned for Previously Added Parts

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-29  **Updated:** 2026-07-13T04:24
- **Link:** https://shopview.atlassian.net/browse/SV-8016

## Description

The **ShopCoach Parts Guide** displays the **Added Parts** section with incorrect alignment for parts that have already been added to the Work Order.

Compared to Production, the columns in the **Added Parts** table are shifted and do not align correctly with their respective headers, making the information difficult to read.

**Steps to Reproduce (STRs):**

1. Open a Work Order.
2. Create a Work Order Line.
3. Request part for the line
4. In the request part model click **ShopCoach Parts Guide**.
5. Add one or more recommended parts.
6. Reopen the **ShopCoach Parts Guide**.
7. Observe the **Added Parts** section.

**Actual Result:**  
The parts listed under **Added Parts** are misaligned. The values do not line up correctly under the **Part Name**, **Qty**, and **Type** column headers.

**Expected Result:**  
The **Added Parts** table should be aligned correctly, with each value displayed under its corresponding column header, matching the layout shown in Production.
