## Description

**Issue Type:** Bug  
  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging

**Affected Area:** Part Sales — Finance tab visibility on part sale detail

**Preconditions:**

* Custom role with **Parts Department ON**, **Part Sales: View + Create & Edit ON**
* **See Financial Data ON**
* **Invoicing: View NOT enabled**
* No other permissions enabled
* User assigned that custom role

**Steps to Reproduce:**

1. Log in as the custom role user
2. Go to Parts → Part Sales → open a part sale / part request
3. Observe the detail page (it opens without error)
4. Look for the Finance tab

**Expected Result:**  
With See Financial Data ON, the part sale detail should display financial data including the Finance tab (subject to confirmation of the Finance tab's intended permission dependency).

**Actual Result:**

* The part sale detail opens normally — **no "Access restricted"** this time.
* **Financial Information is visible** (bottom-left of the detail).
* **No Finance tab** is present on the part sale detail.

**Scope / Notes:**

* **Distinct from SV-8081**, which is the **Part Sales: View only** case where the part sale detail loads then throws **"Access restricted"**. In this ticket, the role has **View + Create & Edit**, the detail opens **without any error**, and the **only** problem is the missing Finance tab. This config usefully isolates the missing-Finance-tab symptom from the Access-restricted error.

**Open Question / VIU:**  
The spec defines "Access the Finance tab" under **Invoicing: View** (§1h), not Part Sales. This role has Part Sales (View + Create & Edit) but not Invoicing: View. Please confirm whether the Finance tab is intended to appear on a part sale detail for a **Part Sales** role when **See Financial Data is ON**, or whether it requires **Invoicing: View**. If it requires Invoicing: View, the current behavior is expected; if not, the missing Finance tab is a defect.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | §1h Invoicing, View row | "View invoices from work orders and part sales. Access the Finance tab." |
| 2 | §1e Part Sales, View / Create and Edit rows | "View part sales records… / Create part sales, create part returns, process part transactions." |
| 3 | §6a See Financial Data, ON state | "User can see pricing, costs, margins, and financial columns throughout the app." |
