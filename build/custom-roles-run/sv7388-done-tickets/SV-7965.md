# SV-7965 — Access restriction on Part Sales (See Financial Data OFF) is bypass able via URL manipulation — Financial data become accessible after editing the URL

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-26  **Updated:** 2026-07-07T08:13
- **Link:** https://shopview.atlassian.net/browse/SV-7965

## Description

**Issue Type:** Bug  
**Suggested Priority:** High (security — authorization bypass / data exposure)  
**Epic:** SV-7388 (Custom Roles and Permissions)

**Environment:** Staging

**Preconditions:**

* Custom role with **Parts Department: ON** and **Part Sales: View** enabled
* **See Financial Data: OFF**
* User is assigned to that custom role

**Steps to Reproduce:**

1. Log in as the custom role user mentioned above
2. Observe that the app correctly shows the **"Access restricted"** page right after you log in (expected, since See Financial Data is OFF — 6a)
3. Edit the browser URL to remove the `access-denied` segment
4. Observe that the system allows you to view Part Sales and the information with $ sign (**See Financial Data: OFF**)

**Expected Result:**  
The restriction must be enforced server-side. With See Financial Data OFF, Part Sales is inaccessible "regardless of their CRUD settings" (6a), and all financial data must remain hidden across every page (§6a, OFF state). Editing the URL must not grant access to the restricted page or its data.

**Actual Result:**  
Removing `access-denied` from the URL bypasses the restriction entirely — the user reaches the Part Sales page and can see its contents, including data that See Financial Data is meant to hide. The "Access restricted" page is enforced only at the routing/redirect (client-side) layer; the underlying page and data are still served when the URL is manipulated.

**Spec references:**

| # | Section | Verbatim quote |
| --- | --- | --- |
| 1 | 6a See Financial Data, Dependency | "If See Financial Data is turned OFF, those areas become inaccessible regardless of their CRUD settings." |
| 2 | 6a See Financial Data, OFF state | "All financial data is hidden across every page. Dollar amounts, rates, costs, margins, and totals are not displayed." |
| 3 | 1e Part Sales, Financial gate | "Requires See Financial Data to be ON (part sales inherently involve pricing)." |
