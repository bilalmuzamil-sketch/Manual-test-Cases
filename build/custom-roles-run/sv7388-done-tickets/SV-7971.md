# SV-7971 — Technician Role Cannot Access Fault Code Lookup from Work Order.

- **Status:** Done
- **Resolution:** Done

## Description

<custom data-type="mention" data-id="id-0">@Sasha Grosman</custom>  This requires some attention.  
**Affected Role:**  
Technician (configured with all permissions/CRUD as per the specification)  
**Reason:**  
Workroder: Create and Edit → Disabled  
**Solution**: Enabling Workorder Create & Edit solves the problem (But that over grants the permission to the technician)

**Description:**  
A Technician configured according to the specification is unable to use the **Fault Code Lookup** feature. Instead of displaying the lookup interface or results, the application displays **"Fault Code Service Temporarily Unavailable."**

**Steps to Reproduce (STRs):**

1. Log in as a **Technician** configured as per the specifications.
2. Open any **Work Order**.
3. Select an asset.
4. Locate the **Fault Code Lookup** section on the left panel.
5. Attempt to access the Fault Code Lookup.

**Actual Result:**  
Service is not available for the technician  to be able to do the fault code lookup.

**Operational Impact:**  
Technicians cannot use the Fault Code Lookup feature while diagnosing Work Orders, interrupting their normal workflow and making it unclear whether the issue is a permissions problem or a service failure.
