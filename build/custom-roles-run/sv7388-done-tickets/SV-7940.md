# SV-7940 — Technician Role Cannot View Contact Title on Customer Contacts

- **Type:** Bug
- **Status:** Done
- **Resolution:** Done
- **Created:** 2026-06-25  **Updated:** 2026-07-06T07:52
- **Link:** https://shopview.atlassian.net/browse/SV-7940

## Description

**Affected Role:**  
Technician (configured with permissions/CRUD as per the specification)

**Description:**  
A Technician user configured according to the specification cannot view the **Contact Title** field on customer contacts.

The contact information is displayed, but the **Title** field is missing, preventing the technician from viewing the contact's designation.

**Steps to Reproduce (STRs):**

1. Log in as a **Technician** (configured as per the specs).
2. Navigate to **Any work order**.
3. Look at the “Customer” card on the left side.

**Actual Result:**  
The **Contact Title** is not displayed for the contact

**Expected Result:**  
The Technician should be able to view the **Contact Title** field when viewing customer contacts, provided the role has the appropriate view permissions as defined in the specifications.
