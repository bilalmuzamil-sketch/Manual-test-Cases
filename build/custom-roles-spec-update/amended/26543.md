# TestRail Case 26543 — Amendment Record

**Case URL:** https://shopview.testrail.io/index.php?/cases/view/26543
**Reason:** Correct the editable/non-editable system-role rule. Prior case wrongly
expected the Administrator role to be non-editable. Confirmed with product owner:
among the system roles, ONLY **Office** and **Time Clock** are non-editable
(lock icon + eye / View Permissions only). Every other system role — **including
Administrator** — is editable (pencil + three-dot Edit). No system role is deletable.

---

## BEFORE

**Title:**
Non-editable system roles (Administrator, Office, Time Clock User) cannot be edited

**Preconditions:**
On Roles & Permissions list. All four non-editable roles visible.

**Steps:**
1. Locate the Administrator row.
2. Confirm the lock icon next to the role name.
3. Confirm the Actions column shows ONLY the eye icon (no pencil, no three-dot menu).
4. Click the eye icon to confirm read-only Permission Summary opens.
5. Repeat for Administrator, Office, Time Clock User.
6. Attempt to access the Edit URL for Administrator directly via the browser address bar.

**Expected:**
Steps 1-5: All four roles show lock icon + only eye icon in Actions. Permission Summary opens read-only — no editable controls.
Step 6: Direct URL access to the edit page is denied or redirects back to read-only view.

---

## AFTER

**Title:**
Only Office and Time Clock system roles are non-editable; all other system roles (including Administrator) are editable

**Preconditions:**
1. Log in as an Admin user.
2. Navigate to Administration > Roles & Permissions.
3. The Roles & Permissions list is displayed with all system roles visible.

**Steps:**
1. Open the Roles & Permissions list.
2. Inspect the Actions column / row controls for each SYSTEM role: Administrator, Service Manager, Senior Service Advisor, Service Advisor, Foreman, Technician, Parts Manager, Parts Technician, Office, Sales Representative, Time Clock.
3. For Office and Time Clock, confirm the lock icon and that the only available action is the eye / View Permissions.
4. Click the eye / View Permissions on Office (and Time Clock) to confirm a read-only Permission Summary opens.
5. For every other system role (including Administrator), confirm a pencil / Edit action and a three-dot menu that offers Edit.
6. Confirm that no system role offers a Delete action.

**Expected:**
1. Only the Office and Time Clock system roles are NON-editable: they show a lock icon and only the eye / View Permissions action (no Edit). The eye opens a read-only Permission Summary with no editable controls.
2. Every other system role — including Administrator — is editable: it shows a pencil / Edit and the three-dot menu with Edit.
3. No system role can be deleted (Delete is not offered for system roles).
4. Custom roles (if any) remain fully editable and deletable.
