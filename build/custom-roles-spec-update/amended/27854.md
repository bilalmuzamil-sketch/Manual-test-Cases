## BEFORE (verbatim)

**Title:**
```
Verify Office cannot edit or delete another user's work order note
```

**Preconditions (custom_preconds):**
```
Log in to ShopView as a user assigned the Office role. (edit/delete ALL notes requires Work Orders: Delete; Office has Work Orders View only).
A work order exists with a note created by a DIFFERENT user.
```

**Steps to Reproduce (custom_steps):**
```
1. Open the work order's Notes tab and locate another user's note.
2. Try to edit the note.
3. Try to delete the note.
```

**Expected Results (custom_expected):**
```
Both actions are BLOCKED: hidden/disabled controls or a permission error. (Known failure SV-8018 was raised when this was allowed - retest.)
```

## AFTER (as stored)

**Title:**
```
Verify Office can edit but cannot delete another user's work order note
```

**Preconditions (custom_preconds):**
```
1. Log in as a user with the Office role.
2. The role has Work Orders > View turned ON.
3. The role has Work Orders > Delete turned OFF.
4. A work order exists that already has a note written by a DIFFERENT user (e.g., an Admin).
```

**Steps to Reproduce (custom_steps):**
```
1. Open the work order.
2. Click the Notes tab.
3. Find the note written by the other user.
4. Click the note's menu and choose Edit.
5. Change the text and click Save.
6. Look for a Delete option on that same note.
```

**Expected Results (custom_expected):**
```
1. The Edit option is available on the other user's note (Work Orders > View allows editing ANY note for team collaboration).
2. The edited text saves successfully with no permission error.
3. There is NO Delete option on the other user's note (deleting another user's note requires Work Orders > Delete, which this role does not have); attempting to delete is blocked.
4. Known failure SV-8018 was raised in this area - retest.
```
