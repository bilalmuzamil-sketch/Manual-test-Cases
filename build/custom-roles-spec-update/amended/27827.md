## BEFORE (verbatim)

**Title:**
```
Verify Technician can create and edit their own work order note
```

**Preconditions (custom_preconds):**
```
Log in to ShopView as a user assigned the Technician role. (own-note create/edit is gated by Work Orders: View, which this role has).
At least one work order exists.
```

**Steps to Reproduce (custom_steps):**
```
1. Open a work order and go to the Notes tab.
2. Add a note with the text "Tech test note" and save.
3. Edit the note to "Tech test note - edited" and save.
```

**Expected Results (custom_expected):**
```
The note is created and the edit saves; existing notes are viewable.
```

## AFTER (as stored)

**Title:**
```
Verify Technician can create and edit any work order note
```

**Preconditions (custom_preconds):**
```
1. Log in as a user with the Technician role.
2. The role has Work Orders > View turned ON.
3. The role has Work Orders > Delete turned OFF.
4. A work order exists that already has a note written by a DIFFERENT user (e.g., an Admin).
```

**Steps to Reproduce (custom_steps):**
```
1. Open the work order.
2. Click the Notes tab.
3. Add a new note with some text and click Save.
4. Edit the note you just created, change the text, and click Save.
5. Find the note written by the DIFFERENT user.
6. Click that note's menu and choose Edit.
7. Change the text and click Save.
```

**Expected Results (custom_expected):**
```
1. Your new note is created and appears in the Notes list.
2. Editing your own note saves successfully and shows the updated text.
3. The Edit option is also available on the other user's note (Work Orders > View now allows creating and editing ANY note for team collaboration).
4. The edit to the other user's note saves successfully with no permission error.
```
