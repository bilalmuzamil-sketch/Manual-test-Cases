## AFTER (as stored)

**Title:**
```
Catalog and Inventory Create and Edit enables create / edit / inventory adjustments (cost and price fields gated by See Financial Data)
```

**Preconditions (custom_preconds):**
```
1. Log in as a user assigned a custom role.
2. The role has Parts Department turned ON.
3. The role has Catalog and Inventory: Create and Edit (View + Edit) turned ON.
4. Be able to test the See Financial Data effect both ways: one run with See Financial Data ON and one run with See Financial Data OFF.
```

**Steps to Reproduce (custom_steps):**
```
1. Create a new catalog/inventory item.
2. Edit an existing catalog/inventory item.
3. Make an inventory adjustment.
4. With See Financial Data ON, open the new-item form and look at the cost and price fields.
5. With See Financial Data OFF, open the new-item form and look at the cost and price fields.
```

**Expected Results (custom_expected):**
```
1. Creating a new catalog/inventory item succeeds (enabled by Catalog and Inventory: Create and Edit).
2. Editing an existing item succeeds.
3. The inventory adjustment succeeds.
4. With See Financial Data ON, the cost and price fields are visible and editable on the new-item form.
5. With See Financial Data OFF, the cost and price fields are hidden/blank (not shown or not editable). The item can still be created, but its cost/price are gated by See Financial Data.
```
