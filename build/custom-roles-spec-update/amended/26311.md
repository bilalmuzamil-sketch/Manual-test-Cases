# TestRail Case 26311 — Amendment (eye-icon placement rule)

Case URL: https://shopview.testrail.io/index.php?/cases/view/26311

Correction confirmed by product owner: in the Roles & Permissions list "Actions"
column, a standalone Eye (View Permissions) icon appears ONLY for the
non-editable roles Office and Time Clock. For every other role (Administrator,
all other system roles, and any custom roles) there is no standalone eye icon —
those rows show the pencil/Edit icon and a 3-dot (kebab) menu, and View
Permissions is available only inside that 3-dot menu.

The prior version of this case expected a standalone eye icon on rows where it
does not appear; this amendment corrects it to the rule above.

Updated via `update_case/26311` — HTTP 200, verified via `get_case/26311`.

---

## BEFORE

**Title:**
Editable system role row shows pencil (edit), three-dot menu, and eye icons — no lock

**Preconditions (custom_preconds):**
```
On Roles & Permissions list page.
```

**Steps (custom_steps):**
```
1. Locate a row for an editable system role (e.g., Service Manager, Service Advisor, Foreman, Technician, Parts Manager, Parts Technician, Senior Service Advisor, Sales Representative).
2. Look at the Role Name column for a lock icon.
3. Look at the Actions column.
```

**Expected (custom_expected):**
```
Step 2: No lock icon appears next to the role name.
Step 3: Actions column shows pencil (edit), eye (view), and three-dot menu icons. The three-dot menu does NOT include a Delete option (system roles cannot be deleted).
```

---

## AFTER

**Title:**
Eye (View Permissions) icon shows in the Actions column only for Office and Time Clock; other roles access View Permissions via the 3-dot menu

**Preconditions (custom_preconds):**
```
1. You are logged in as an Admin.
2. You are on Administration > Roles & Permissions.
```

**Steps (custom_steps):**
```
1. Open Administration > Roles & Permissions.
2. Look at the Actions column for the Office and Time Clock rows.
3. Look at the Actions column for the other roles (Administrator, Service Manager, etc.).
4. For one of those other roles, click the 3-dot menu in the Actions column and look at the options.
```

**Expected (custom_expected):**
```
1. In the Actions column, a standalone Eye (View Permissions) icon appears ONLY for Office and Time Clock (the non-editable roles).
2. For every other role — including Administrator, all other system roles, and any custom roles — there is NO standalone eye icon in the Actions column; those rows show the pencil/Edit icon and a 3-dot menu.
3. For those other roles, the View Permissions (eye) option appears only after clicking the 3-dot menu (3-dot menu > View Permissions).
```
