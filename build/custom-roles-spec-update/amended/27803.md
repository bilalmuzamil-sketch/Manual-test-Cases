# TestRail Case 27803 — Amendment Audit Log

**Case URL:** https://shopview.testrail.io/index.php?/cases/view/27803
**Amended:** 2026-07-05
**Spec change:** #1 (Work Orders > View grants create + edit of ANY note — team collaboration) and #2 (Work Orders > Delete grants delete of ANY note). Only title (where changed), custom_preconds, custom_steps, custom_expected were updated. No other case was touched.

---

## BEFORE (verbatim)

**Title:**
```
Verify Service Advisor cannot edit or delete another user's work order note
```

**Preconditions (custom_preconds):**
```
Log in to ShopView as a user assigned the Service Advisor role. (edit/delete ALL notes requires Work Orders: Delete, which this role lacks).
Note: the role may display as 'Junior Service Advisor' in the build (the spec calls it 'Service Advisor').
A work order exists with a note created by a DIFFERENT user.
```

**Steps to Reproduce (custom_steps):**
```
1. Open the work order's Notes tab and locate another user's note.
2. Try to edit the note.
3. Try to delete the note.
```

**Expected Results (custom_expected):**
```
Both actions are BLOCKED: hidden/disabled controls or a permission error.
```

## AFTER (as stored)

**Title:**
```
Verify Service Advisor can edit but cannot delete another user's work order note
```

**Preconditions (custom_preconds):**
```
1. Log in as a user with the Service Advisor role.
2. The role has Work Orders > View turned ON.
3. The role has Work Orders > Delete turned OFF.
4. A work order exists that already has a note written by a DIFFERENT user (e.g., an Admin).
5. Note: this role may display as 'Junior Service Advisor' in the build (the spec calls it 'Service Advisor').
```

**Steps to Reproduce (custom_steps):**
```
1. Open the work order.
2. Click the Notes tab.
3. Find the note written by the other user.
4. Click the note's menu and choose Edit.
5. Change the text and click Save.
6. Look for a Delete option on that same note.
```

**Expected Results (custom_expected):**
```
1. The Edit option is available on the other user's note (Work Orders > View allows editing ANY note for team collaboration).
2. The edited text saves successfully with no permission error.
3. There is NO Delete option on the other user's note (deleting another user's note requires Work Orders > Delete, which this role does not have); attempting to delete is blocked.
```
