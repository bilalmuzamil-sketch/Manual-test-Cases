# TestRail Case 26489 — Amendment Audit Log

**Case URL:** https://shopview.testrail.io/index.php?/cases/view/26489
**Section:** Custom Roles - (Revised) > View History Logs (section 3546)
**Amended:** 2026-07-06
**Scenario:** View History Logs **OFF** (preserved).
**Correction (from product owner, with screenshot):** A prior amendment wrongly implied
that part sales and purchase orders have history logs. Corrected to reflect three facts:

1. View History Logs (work-order/line history) is for **WORK ORDERS ONLY** — work-order-level
   history + line-level (story) history.
2. **Part Sales has NO history.**
3. Part (**inventory**) history DOES exist as a **separate feature**: Parts > Inventory, click
   the **clock icon** next to a part (tooltip "Part History"). It is not part of the work-order
   View History Logs behavior this case tests.

Authorized single-case write (POST /api/v2/update_case/26489, HTTP 200). Only fields title,
custom_preconds, custom_steps, custom_expected were updated. No other case was touched; nothing
was created or deleted in TestRail.

## BEFORE (verbatim — the prior amended state)

**Title:**
```
View History Logs OFF: WO-level and line-level history hidden everywhere
```

**Preconditions (custom_preconds):**
```
1. Log in as a user assigned a custom role.
2. The role has the View History Logs toggle turned OFF.
3. The role otherwise has enough access to open work orders, work order lines, part sales, and parts orders.
4. There is a work order that has at least one line, plus a part sale and a parts order (PO), all with existing change history.
```

**Steps to Reproduce (custom_steps):**
```
1. Open a work order and look for the work-order-level history/audit log section.
2. Open an individual work order line and look for the line-level (line/story) history.
3. Open a part sale and look for its history.
4. Open a parts order (PO) and look for its history.
```

**Expected Results (custom_expected):**
```
1. The work-order-level history section is hidden. View History Logs governs this WO-level history and it is OFF.
2. The line-level (line/story) history section is also hidden on the individual line. View History Logs governs this line-level history too.
3. The part sale history section is hidden.
4. The parts order (PO) history section is hidden.
5. No history section, audit log, or change history appears anywhere for this user.
```

## AFTER (as stored)

**Title:**
```
View History Logs OFF: WO-level and line-level history hidden on work orders
```

**Preconditions (custom_preconds):**
```
1. Log in as a user assigned a custom role.
2. The role has the View History Logs toggle turned OFF.
3. The role otherwise has enough access to open work orders and work order lines.
4. There is a work order that has at least one line, both with existing change history.
```

**Steps to Reproduce (custom_steps):**
```
1. Open a work order and look for the work-order-level history/audit log section.
2. Open an individual work order line and look for the line-level (line/story) history.
3. (Context only) Note that View History Logs applies to work orders only. Part Sales has no history feature at all, and part (inventory) history is a separate feature reached from Parts > Inventory.
```

**Expected Results (custom_expected):**
```
1. View History Logs governs work-order-level history (the WO audit log / history) and line-level (story) history, for work orders only.
2. With View History Logs OFF, both the work-order history and the line-level history are hidden on work orders.
3. Part Sales has NO history.
4. Part (inventory) history is separate: it is seen under Parts > Inventory by clicking the clock icon next to a part (tooltip "Part History") — not via the work-order history this case covers.
```
