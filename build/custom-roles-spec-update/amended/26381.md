## AFTER (as stored)

**Title:**
```
Order parts requires Work orders View AND See Financial Data (not Create and Edit)
```

**Preconditions (custom_preconds):**
```
1. Log in as a user assigned a custom role.
2. The role has Work Orders: View turned ON (Work Orders: Create and Edit is turned OFF).
3. The role has See Financial Data turned ON (required for Order Parts).
4. The role has the Order Parts sub-toggle turned ON.
5. The role has Parts Department ON with Vendor and order management: View ON.
6. There is at least one open work order to use for the test.
```

**Steps to Reproduce (custom_steps):**
```
1. Log in as the test user and open an existing work order.
2. Locate the Order Parts action on the work order.
3. Start placing a purchase order (PO) for parts on the work order.
4. Save the PO.
5. Later, receive a parts delivery against the PO on the work order.
```

**Expected Results (custom_expected):**
```
1. The Order Parts action is available even though the role does NOT have Work Orders: Create and Edit (Order Parts requires only Work Orders: View, not Create and Edit).
2. Order Parts works because the role also has See Financial Data turned ON. Order Parts now requires BOTH Work Orders: View AND See Financial Data.
3. If See Financial Data were OFF, enabling Order Parts would prompt/require See Financial Data to be turned on first.
4. The PO is created and linked to the work order.
5. The parts receiving flow succeeds with no permission error.
```
