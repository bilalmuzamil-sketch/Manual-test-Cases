```
Verify Administrator can edit and delete another user's work order note
```


## AFTER (as stored)

**Title:**
```
Verify Administrator can edit and delete another user's work order note
```

**Preconditions (custom_preconds):**
```
1. Log in as a user with the Administrator role.
2. The role has Work Orders > View turned ON.
3. The role has Work Orders > Delete turned ON.
4. A work order exists that already has a note written by a DIFFERENT user (e.g., a Technician).
```

**Steps to Reproduce (custom_steps):**
```
1. Open the work order.
2. Click the Notes tab.
3. Find the note written by the other user.
4. Click the note's menu and choose Edit.
5. Change the text and click Save.
6. Open the note's menu again and choose Delete.
7. Confirm the deletion.
```

**Expected Results (custom_expected):**
```
1. The Edit option is available on the other user's note (Work Orders > View allows editing ANY note for team collaboration).
2. The edited text saves successfully with no permission error.
3. The Delete option is also available on the other user's note (Work Orders > Delete allows deleting ANY note, including other users').
4. The other user's note is deleted with no permission error.
```
