## AFTER (as stored)

**Title:**
```
Turning See Financial OFF auto-clears Part sales, Invoicing and Payments CRUDs, and the Order Parts sub-toggle
```

**Preconditions (custom_preconds):**
```
1. Log in as a user who can create and edit custom roles, and open the role editor for a custom role.
2. The role has See Financial Data turned ON.
3. The role has Part sales View, Edit, and Delete all turned ON.
4. The role has Invoicing and Payments View, Edit, and Delete all turned ON.
5. The role has the Order Parts sub-toggle turned ON.
```

**Steps to Reproduce (custom_steps):**
```
1. In the role editor, turn See Financial Data OFF (from the Cross-Cutting Toggles card).
2. Inspect the Part sales row checkboxes (View / Edit / Delete).
3. Inspect the Invoicing and Payments row checkboxes (View / Edit / Delete).
4. Inspect the Order Parts sub-toggle.
```

**Expected Results (custom_expected):**
```
1. All 6 checkboxes (Part sales View/Edit/Delete + Invoicing and Payments View/Edit/Delete) auto-uncheck.
2. The Order Parts sub-toggle is also auto-cleared (turned OFF), because Order Parts now requires See Financial Data.
3. No permission that depends on See Financial Data remains enabled once See Financial Data is turned OFF.
```
