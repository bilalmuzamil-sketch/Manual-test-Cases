How the slow case was made

Comparison only: on this test machine the list draws quickly, so production also opens normally unless the list is slowed down. To recreate what a slower PC does, I delayed the page's drawing of the list by 0.8 and 1.5 seconds in the test browser (the same condition the developer describes in the fix). This is not a ShopView feature. With that delay production fails every time and the QA branch works every time.

How to repeat it

  1. Open the QA branch sv11839 in Chrome on Windows with display scaling at 125% and the window at about 1536 × 936.

  2. At the top right, click the button that shows the current location name and your initials (or logo). In the menu that opens, under Change Location: click the blue location chip and pick another location, for example DVI Test.

  3. Reload the page (F5).

  4. Click that same top-right button again and click the blue DVI Test chip. The list of locations opens right under the chip. Pick another location: the page switches to it.
