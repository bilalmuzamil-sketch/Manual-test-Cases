# **Setup: The empty chart outline keeps the tile the same height**

Test case: [C351710](https://shopview.testrail.io/index.php?/cases/view/351710), Dashboard. Part 1 is for the manual QA tester. Part 2 is for a Claude session that prepares the case on its own. Both create the starting state listed in the test case's Preconditions; the numbers below match that list.

## **What must be true before you start**

1.  User: you are signed in as a user whose role has the Reports permission (for example Admin).
2.  Browser: you use a desktop browser window at least 1024 pixels wide (a maximised laptop or desktop window).
3.  Data: the Dash Shop data set exists, all created today in location ZZAUTOTEST Dash Shop, where nothing else is invoiced or clocked this month: work order 1 for customer ZZAUTOTEST Alpha Fleet, Service Advisor ZZAUTOTEST Advisor X, one labor line of 2.00 hours at $100.00 an hour with Tech Time 1.50 and technician ZZAUTOTEST Tech One, a part with Sell Price $50.00, and ZZAUTOTEST Tech One clocked exactly 2.50 hours on it; work order 2 for ZZAUTOTEST Bravo Fleet, Service Advisor ZZAUTOTEST Advisor Y, one labor line of 1.00 hour at $100.00 an hour with Tech Time 1.00 and technicians ZZAUTOTEST Tech One and ZZAUTOTEST Tech Two, a part with Sell Price $160.00, Tech One clocked exactly 0.25 hours and Tech Two exactly 0.75 hours on it. Neither work order has shop supplies, a fee or a discount; both are invoiced and not paid. Totals: invoices $250.00 and $260.00; 3.00 labor hours billed; 2.50 technician hours on the lines; 3.50 clocked hours; no internal (non work order) time.
4.  Timing: you run it on any day except the 1st of the month.

Each line says which precondition it sets up. Where a precondition is not listed, it needs no setup.

  - **For precondition 3:**

<!-- end list -->

1.  If ZZAUTOTEST Dash Shop already exists with exactly this data, reuse it.
2.  Otherwise: (a) location: profile icon \> Settings \> Locations \> New Location: Name ZZAUTOTEST Dash Shop, the address fields, Timezone, Telephone, Shop Supplies Charge 0 % \> Save & Close (if a location with this name already exists, reuse it only if it still matches the precondition).
3.  It then appears in your Change Location list
4.  To switch to it, click your profile icon (your initials, top right, beside the current location name) \> under Change Location: click the orange button showing the current location \> pick the location from the list. (b) staff: profile icon \> Settings \> Staff \> New Staff Member, four times: ZZAUTOTEST Tech One and ZZAUTOTEST Tech Two with Role Technician and Time Clock on, ZZAUTOTEST Advisor X and ZZAUTOTEST Advisor Y with Role Service Advisor
5.  Each with Location ZZAUTOTEST Dash Shop and a Department \> Save & Close.
6.  Give each technician an email address you can open: they must accept the invitation email and set a password so you can sign in as them in a private window. (c) customers: Customers \> New Customer \> Name \> Save, for ZZAUTOTEST Alpha Fleet and ZZAUTOTEST Bravo Fleet. (d) each work order: Work Orders \> Create Work Order \> in the New Work Order window pick the Customer and an Asset (Add beside either if needed) \> Save (if a Confirmation says the customer is over their credit limit, click Create)
7.  The New Line window opens: What Are You Doing? (any text), Add Technician = the technician(s), Labor Rate = EVR Travel to EVO ($100 an hour), Estimated Time and Tech Time as above, tick Line Approved \> Save & Close
8.  Set Service Advisor in the work order's left panel
9.  On the line click Add Part and add a part with the Sell Price above (it must show In stock, or be ordered and received, before you can invoice). (e) clocked time: sign in as each technician in a private window \> open the work order \> on the line's Labor row click Start, then Stop \> Clock Out
10. Then, as Admin, the three dots at the top right of the Lines tab \> Timesheets (n) \> edit the record's start and end (if it cannot be edited there or in Reports \> Timesheet Activities, keep the real time and use the hours Timesheet Activities shows). (f) on each work order: on the line click Story (Add tech story for this line) \> type a short story \> Update
11. Click Complete (if a Missing Details window asks for Mileage, enter one \> Complete All Lines)
12. Click Mark Reviewed
13. Finance tab \> Create Invoice
14. Close the New Customer Payment window without paying (do not send or pay the invoice).

# **Part 2. Setup for Claude session**

Prepare the same starting state by carrying out Part 1 in a browser with Playwright. Record the real values you used, the build marker and screenshots in the Manual-test-Cases repository, and judge pass or fail against the test case's Expected results only.

## **Environment**

  - Dashboard QA site: app https://sv490.qa.shopview.com, API https://sv490api.qa.shopview.com.
  - Record the build marker (app-version on the app page) before you start.
  - Browser: Chromium at /opt/pw-browsers/chromium through Playwright. Do not run "playwright install".

## **Access**

  - Sign in with the QA site's quick login: node build/testing-tools/qa-branch-boot.mjs (see build/APP-ACTIONS-PLAYBOOK.md section A). Carry the sv\_sso\_session cookie only, scoped to the host.
  - Keep cookies in /tmp only, with file mode 600. Never write a cookie into a document, a commit or a log.
  - Change location through the profile icon (your initials, top right) \> Change Location.

## **Test data**

Name anything you create with ZZAUTOTEST at the start. Leave all test data in place; nothing is deleted afterwards.
