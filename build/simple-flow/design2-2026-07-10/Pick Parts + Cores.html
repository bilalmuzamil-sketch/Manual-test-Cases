Picking and cores in one step

Both are inventory-part actions, so they share the Pick parts gate
1
Summary counts everything and flags how many carry a core — still one screen tall for any part count.
2
Pick all from default bins → the routine pick collapses to a green line. The cores are the exception, so only those rows stay open with OK / Not OK.
3
Resolve each core → collapses to a second green line; any Not OK notes the charge added to the invoice. Continue enables.
4
Review individually shows one list: every part has a bin + pick, and core parts add a core control beneath the row.
Why combine: a core is a property of a part you’re already picking — splitting it into its own step would make an advisor touch the same part twice.
