Dropdown Search bookmarklet

Install: show your bookmarks bar (Ctrl/Cmd+Shift+B), then drag this button onto it:

Dropdown search

Or create a bookmark by hand and paste this into its URL field:

Use

  1. On any page, click Dropdown search in the bookmarks bar. A search box opens at the top right.
  2. Type. Every matching option from the page's dropdowns is listed. Several words = all must match, in any order.
  3. For a custom dropdown (one that opens a pop-up list), open the dropdown first. The box searches it live and hides the options that do not match.
  4. ↓/↑ to move, Enter or a click to select, Esc to close. Drag the blue bar to move the box.
