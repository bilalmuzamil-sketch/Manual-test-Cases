## 6. THE TRAPS THAT COST TIME TODAY

Brief, so they are not re-learned.

1. **Editing a Jira description via the API destroys pasted images** whose media nodes are not
   carried forward into the new document — **and the changelog does not record it.** Cost: one image
   on SV-8818 (replaced). Playbook §J item 4.
2. **`update_case` re-renders any text field you OMIT from the payload** through its HTML pipeline —
   it wraps text in `<p>` and turns `\n` into `\r\n`. **Send all text fields on every payload.** This
   matters doubly on these projects because the markup is shown **literally to the tester**.
3. **A byte-check proves you wrote what you INTENDED — not that the intent was right.** A faithful
   write of a wrong payload passes every check. (This is how a duplicated provenance line got
   through: the writer's plain-text patterns did not match a raw-HTML case, so it appended instead of
   replacing, and the byte-check passed.)
4. **On this shared branch, staging and committing in one breath is NOT sufficient protection.**
   **Verify with `git show --stat` afterwards** that only your files landed. Other workers are
   committing on the same branch.
5. **The branches redeployed SEVEN TIMES today.** Any build marker written down is stale within
   hours — **re-read the marker at the moment you rely on it** (Rule 59), and never quote a marker
   from a note.
