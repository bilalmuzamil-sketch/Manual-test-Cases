h3. Description

On the *Parts* tab, a part whose name *begins* with the search text is treated the same as a part that merely *contains* it, so it receives no advantage in the ranking.

The rest of the scoring on that same search is correct: parts matched on their tag, their category or their manufacturer all receive exactly the score the PRD defines. Only matches on a part's own name are affected.

h3. Steps to Reproduce

# Open Global Search ({{Ctrl}}+{{K}})
# Search {{ZZVORTAC}}
# Open the *Parts* tab

!VORTAC-parts.png|width=760,height=749!

*Actual:* {{ZZVORTAC Brake Kit}}, whose name begins with the search text, and {{Heavy Duty ZZVORTAC Filter}}, where the search text sits in the middle, receive the same score. Which one appears first is then determined by the recency tie-break.

*Expected:* {{ZZVORTAC Brake Kit}} receives the higher of the two match scores and appears above {{Heavy Duty ZZVORTAC Filter}}.

{quote}Prefix match on primary name field → +0.70.{quote}
{quote}Whole-word match anywhere in indexed fields → +0.50.{quote}

Both parts show *0 Available*, share a bin location, have never been sold and have never been viewed, and their part numbers ({{PARITYPN-9001}} and {{PARITYPN-9002}}) contain no trace of the search text — so nothing other than the match itself can affect the result.

h3. Technical Finding

The same search returns three further parts, matched on fields other than the name. Each of those lands on exactly the figure PRD 6.1 computes:

|| Part || Matched on || What PRD 6.1 adds up to || Score returned ||
| `SPINDLE NUT` — 2 Available | tag | 0.50 whole-word + 0.20 in stock + 0.05 bin location | *0.75* |
| `PLATE STEEL 1/8"` — 0 Available | category | 0.50 whole-word + 0.05 bin location | *0.55* |
| `DOC 2 STAGE CLEANING` — 0 Available | manufacturer | 0.50 whole-word + 0.05 bin location | *0.55* |
| `ZZVORTAC Brake Kit` — 0 Available | *name (begins with)* | 0.70 prefix + 0.10 primary-display-name bonus = *0.80 expected* | *1.00* |
| `Heavy Duty ZZVORTAC Filter` — 0 Available | *name (middle)* | 0.50 whole-word + 0.10 primary-display-name bonus = *0.60 expected* | *1.00* |

A tag, a category and a manufacturer are secondary fields, so none of them receives the primary-display-name bonus, and all three land on their computed figure — including the in-stock signal, which is visibly working on the first row. The two matches on the part's own name do not: both reach the maximum score of 1.00.

The PRD names the part's description as the field shown as its name:

{quote}Parts (Inventory). Indexed: part number, description, category, tags, vendor name. Displayed: description (primary), part number, quantity on hand badge, bin location.{quote}

QA observed that a description beginning with the search text is recorded as a whole-word match rather than a prefix match. This is offered as an observation, not as the prescribed implementation.
