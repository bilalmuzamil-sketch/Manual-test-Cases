# Checks deliberately NOT automated, and why

Every check here **passed when run by hand** in TestRail run 415. None is failing. They are listed
because a spec for them would go red for its own reasons rather than the product's, and a test that
does that is worse than no test at all.

Before a check landed in this list, the suite tried to make it runnable: the specs **hunt** for
usable data, asking the API for the relevant records and trying the words those records are made
of as queries. These are what survived that.
