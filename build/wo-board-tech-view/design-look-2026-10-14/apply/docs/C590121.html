Setup: More actions button and menu on cards and rows look as in the design

Test case: C590121, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as {User-A} (for example Admin ShopView), an Owner or Admin user whose role has Work orders > View, Work orders > Create & Edit and See financial data, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is 1440 px wide, with the browser zoom at 100%.

• The design pictures DC-12-board-card-hover-button-light-1440.png, DC-12-board-card-menu-light-1440.png and DC-12-tech-row-menu-locked-light-1440.png are open beside the app at 100% zoom (actual size); they are attached to this case.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". This is {User-A}. To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on (the Admin role has full access, See financial data included).

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a screen at least 1440 px wide (1536 px or wider if the case names 1536 px). Set the browser zoom to 100% (Ctrl+0, or Cmd+0 on a Mac). To give the window an exact width without developer tools, use a window-size browser extension (for example Window Resizer for Chrome) and choose 1440 × 900; it shows the size it set.

4. Open this case in TestRail and download the design pictures named in the Preconditions from the case's attachments. Open each in an image viewer at 100% (actual size) and place it beside the browser window.

5. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example ZZAUTOTEST DC12 Rae Menu), an Email with ZZAUTOTEST in it, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-A}.

6. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST DC12 More Actions") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

7. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17834). This is {Work-order-1}. On {Work-order-1}'s page pick {Technician-A} in the Lead Technician dropdown; it saves at once (the dropdown shows once the work order is Approved).

8. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17835). This is {Work-order-2}. On {Work-order-2}'s page pick {Technician-A} in the Lead Technician dropdown; it saves at once (the dropdown shows once the work order is Approved).

9. Complete {Work-order-2}: on its Lines tab click the line's Complete button, type a Tech Story (fill any missing detail it asks for, for example Mileage) and click Complete Line. Then click Mark Reviewed, enter the VIN if asked and click Confirm Review; the status reads Complete. Then open the Finance tab and click Create Invoice; if a New Customer Payment window opens afterwards, close it. The status reads Invoiced.

10. Work Orders > All: open each filter in the filter bar and clear any selection, turn Assigned to me off, empty Search, and set density to Regular with the density button (the icon button with lines and an up-and-down arrow, to the left of the display switcher).

11. Check the setup worked: Board View shows {Work-order-1} and {Work-order-2} (Invoiced) in {Technician-A}'s column.

How to work

Prepare the same starting state by carrying out Part 1 in a browser with Playwright (or the faster route above, where one is given), then run the test case's steps in the same browser. Record the real value of every brace name, the build marker and screenshots in the case's verification folder in the Manual-test-Cases repository, and judge pass or fail against the test case's Expected results only. Facts below come from the team's recorded playbook (build/APP-ACTIONS-PLAYBOOK.md).

Environment

  • Work Orders QA site for this feature (epic SV-10043): app https://sv10043.qa.shopview.com, API https://sv10043api.qa.shopview.com. Use the site named in the test run if it differs.

  • Check access: GET /api/auth/me/fe-permissions answers 200. GET /api/staff/my-workplaces lists the locations and their ids; switch location with your initials (top right) > Change Location.
