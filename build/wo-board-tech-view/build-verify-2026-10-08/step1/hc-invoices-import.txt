Import Invoices

To do a invoices import you need to have a csv file with following columns: Shop Location, Customer, VIN, Year, Make, Model, Unit #, Unit Type, Mileage, Hours, Invoice Number, Invoice Date, PO, Service Advisor, Item, Line Title - What are you doing, Line Description - Why are you doing it, Tech Story, Part #, Part Description, Qty, Rate, Total, Tax Amount.

Your file's first row must contain these columns. Also, new line separator is used for new row, comma for columns.

Your rows must contain valid values for all required columns, otherwise all rows associated with that invoice will be skipped.
