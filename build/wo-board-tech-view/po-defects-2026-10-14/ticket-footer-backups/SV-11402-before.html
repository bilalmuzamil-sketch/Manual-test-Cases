What

In Tech View, dragging a pinned technician's group header opens the work order that sits where the header is released. Dragging a group header must only reorder technicians; it must never open a work order.

Steps

  1. Open Work Orders and switch to Tech View.

  2. Pin a technician (pin on their group header).

  3. Drag that pinned technician's group header up or down, across work order rows, and release it over a work order row.

Expected

The pinned technician moves within the pinned area only (S9-R9), or stays put if released outside it. No work order opens. A click opens a work order only when there was no drag (S2-R8).

PRD: Board View & Tech View PRD v55 (S9-R9, S2-R8).

Actual

The work order under the pointer at release opens, as if it had been clicked.

How to check

  • Drag a pinned technician's header and release it over a work order row: no work order opens; the order of pinned technicians updates or stays the same.

  • Repeat with an unpinned technician's header: no work order opens.

  • A plain click on a work order row still opens it.

Seen by Chris Ward on staging, 2026-10-15.
