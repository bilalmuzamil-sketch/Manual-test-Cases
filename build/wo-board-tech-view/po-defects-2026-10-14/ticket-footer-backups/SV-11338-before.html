Preconditions

  • Role: Admin.

  • A technician with no profile photo.

Environment

  • Staging — app.staging.shopview.com, Chrome 154 / Windows 10.

Steps to reproduce

  1. Select Tech View and find the group of a technician with no photo.

  2. Inspect the avatar in the group header and the header name.

  3. Select Board View and inspect the same technician's column header avatar.

  4. In the design file (Work Orders → Tech View and Board View), compare a header avatar for a technician without a photo.

Expected result

Per the design (Tech View and Board View headers, e.g. "BM" Brenda Martinez) and S2-R12 / S3-R12:

  • The avatar is a light-grey circle with dark initials.

  • The header name is ≈16px, weight 600 (estimated from the design file).

Actual result

In both views:

  • The avatar is a 28px circle with a solid blue background (class bg-primary, rgb 56, 116, 255) and white initials.

  • The header name is 14px, weight 600.
