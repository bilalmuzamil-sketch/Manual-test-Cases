What

The names behind avatars in an avatar group can be reached and read with the keyboard.

Expected

S11-R2: "Every control a mouse can use in Tech View and Board View is reachable with Tab and works with Enter or Space... Technician names behind avatars show on keyboard focus, the same as on hover." Names are the staff record name (S5-R11b).

PRD: Board View & Tech View PRD v55 (S11-R2).

Actual (origin/develop, 2026-10-15)

Avatar names are a hover tooltip only, with no focus stop or accessible label, so a keyboard user cannot get them. The rest of Story 11 is already built (one Tab stop per view, arrow keys, Enter, focus return).

How to check

  • With the keyboard alone, reach an Assigned Techs avatar group (Tech View) and a card's avatars (Board View) and hear or see each technician's name.

  • Also confirm the Columns menu options and the x on a filter chip are reachable with Tab and work with Enter or Space.

From the PRD v54/v55 rulings on Bilal's and Slavcho's questions, 2026-10-15.
