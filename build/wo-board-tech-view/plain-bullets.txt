# ---------- Story 1: Switch between display options ----------
S1-R1 ::= The Work Orders toolbar shows three display-option controls: List, Tech View, and Board View.
S1-R9 ::= The control for the display you are currently viewing is clearly marked as the active one.
S1-R2 ::= For a brand-new user who has never chosen a display, the page opens in List.
S1-R3 ::= Switching the display re-lays out the same work orders instantly; the filter tab, search text, and filters do not change.
S1-R4 ::= Your chosen display is remembered and comes back after logging out and in, on another device, and at another location.
S1-R5 ::= A user with Work Orders view permission sees the All, Work Orders, Estimates, and Completed filter tabs.
S1-R10 ::= Work Orders is the filter tab that is selected by default.
S1-R11 ::= Search, filter persistence, and which results appear behave the same in List, Tech View, and Board View.
S1-R7 ::= When you return to List, the List sort you had saved is restored.
S1-R8 ::= Using the browser Back button restores both the up/down and the left/right scroll position of the Work Orders page.
S1-R12 ::= Opening a filter tab directly by its link starts you at the top-left of the page.
S1-N1 ::= When filters match nothing, every display shows the existing "No work orders match your filters" empty state with a Clear filters action.
S1-N2 ::= If your saved display preference cannot be loaded, the page falls back to List.
S1-N3 ::= If saving your display preference fails, your previously saved preference is kept.
S1-N4 ::= A failed preference save does not stop you switching displays or trying the save again.
S1-N5 ::= If you change the preference in two tabs at once, the last request is the one that sticks.
S1-E1 ::= With "Assigned to me" on, you see only the work that matches the existing assignment-filter rules.
S1-E2 ::= Changing location opens that location's existing default page.
S1-E3 ::= "Assigned to me" turns itself off when you change location, exactly as it does today.

# ---------- Story 4: Reassign / unassign lead ----------

# ---------- Story 12: Analytics ----------

S12-R13 ::= Repeated events from one user do not count that user more than once.

S12-R15 ::= Analytics reuses the existing analytics identity and adds no new customer identifier.
S12-N1 ::= An analytics failure, opt-out, or unavailability never blocks loading, preference changes, or reassignment.
