Setup: Tech View offers List's columns plus Assigned Techs in its own Columns menu

Test case: C96927, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.

• Technician {Technician-A} (for example Esther Howard) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.

• Approved work order {Work-order-1} (for example S10043-17601) for customer {Customer-A} (for example "ZZAUTOTEST F2 Tech Columns") is led by {Technician-A} and has one approved line, {Line-1} (for example "Service - Full grease service").

• In Tech View's Column Selection, Assigned Techs is on, and On Site, VIN/Serial # and Lead Technician are off, as they start for a new user.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on.

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a desktop browser window at least 1024 px wide (narrower windows show only the List, with no display switcher).

4. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example Esther Howard), an Email, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-A}.

5. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST F2 Tech Columns") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

6. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17601). This is {Work-order-1}. Its line is {Line-1}.

7. On {Work-order-1}'s page pick {Technician-A} in the Lead Technician dropdown; it saves at once (the dropdown shows once the work order is Approved).

8. Work Orders > All > click Tech View in the display switcher > Column Selection: turn Assigned Techs on and turn On Site, VIN/Serial # and Lead Technician off. Close the menu.

9. Check the setup worked: Work Orders > All > Search the name of {Customer-A}: {Work-order-1} shows with Lead Technician {Technician-A}. In Tech View the Assigned Techs column shows and On Site, VIN/Serial # and Lead Technician do not.

Part 2. Setup for Claude session

• Goal: one Approved work order {Work-order-1} led by {Technician-A}, then compare List's and Tech View's column menus and turn columns on and off in Tech View.

• Create {Customer-A}, {Work-order-1} and the lead on screen as in Part 1 and record {Work-order-1}.

• Read both column menus with Playwright as exact strings (the List column selector has data-test-id button_column_selection; the Tech View one is UNVERIFIED: record its selector). Compare the two lists as sets: Tech View's must be List's plus Assigned Techs.

• List's saved state (columns, filters, tab, sort) is the user preference GET/PUT /api/users/me/preferences/work-orders-list (playbook, Work Orders filters section); filter state persists on the server across browser contexts. The preference keys for Tech View's columns and Board View's fields are UNVERIFIED: record them from the network requests when you change a column.

• Cleanup: after the case, turn On Site, VIN/Serial # and Lead Technician off again in Tech View and leave Assigned Techs on, so the user is back at the new-user starting columns for the next case.

• Evidence: a screenshot after each step that has an expected result, the build marker, and the real value of every brace name.

How to work

Prepare the same starting state by carrying out Part 1 in a browser with Playwright (or the faster route above, where one is given), then run the test case's steps in the same browser. Record the real value of every brace name, the build marker and screenshots in the case's verification folder in the Manual-test-Cases repository, and judge pass or fail against the test case's Expected results only. Environment

  • Work Orders QA site for this feature (epic SV-10043): app https://sv10043.qa.shopview.com, API https://sv10043api.qa.shopview.com. Use the site named in the test run if it differs.

Access

  • Check access: GET /api/auth/me/fe-permissions answers 200. GET /api/staff/my-workplaces lists the locations and their ids; switch location with your initials (top right) > Change Location.

Cleanup
