Setup: The technician field is blank only with no lead and no line technician

Test case: C96996, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.

• Technician {Technician-A} (for example Esther Howard) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.

• Technician {Technician-B} (for example Ralph Edwards) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.

• Customer {Customer-A} (for example "ZZAUTOTEST F3 Blank Technician") has exactly three work orders, all Approved, each with one approved line.

• Work order {Work-order-1} (for example S10043-17608) has no lead technician and its line {Line-1} (for example "Service - Full grease service") has no technician.

• Work order {Work-order-2} (for example S10043-17609) has no lead technician and its line {Line-2} (for example "Service - Full grease service") is given to {Technician-B}.

• Work order {Work-order-3} (for example S10043-17610) is led by {Technician-A} and its line {Line-3} (for example "Service - Full grease service") has no technician.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on.

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a desktop browser window at least 1024 px wide (narrower windows show only the List, with no display switcher).

4. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example Esther Howard), an Email, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-A}.

5. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example Ralph Edwards), an Email, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-B}.

6. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST F3 Blank Technician") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

7. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17608). This is {Work-order-1}. Its line is {Line-1}. Leave Lead Technician empty and give the line no technician.

8. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17609). This is {Work-order-2}. Its line is {Line-2}. Leave Lead Technician empty.

9. On {Work-order-2}'s Lines tab open {Line-2} (Edit Line) > Technicians > pick {Technician-B} > save the line.

10. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17610). This is {Work-order-3}. Its line is {Line-3}. Give the line no technician.

11. On {Work-order-3}'s page pick {Technician-A} in the Lead Technician dropdown; it saves at once (the dropdown shows once the work order is Approved).

12. Check the setup worked: Work Orders > All > List > Search the name of {Customer-A}: exactly {Work-order-1}, {Work-order-2} and {Work-order-3} show, all Approved; only {Work-order-3} has a Lead Technician ({Technician-A}); on {Work-order-2}'s Lines tab {Line-2} shows {Technician-B}.

Part 2. Setup for Claude session

• Goal: three work orders (nobody; line technician only; lead only), then read the line technicians field in Board View and the Assigned Techs cell in Tech View.

• Read each card's and row's technician area as text and as an avatar count with Playwright; record whether blank renders empty or as "-".

• Evidence: a screenshot after each step that has an expected result, the build marker, and the real value of every brace name.
