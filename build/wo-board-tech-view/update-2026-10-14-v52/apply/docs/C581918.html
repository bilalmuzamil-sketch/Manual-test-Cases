Setup: List ignores the Technician choice and Tech View brings it back

Test case: C581918, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.

• Technician {Technician-A} (for example Esther Howard) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.

• Technician {Technician-B} (for example Ralph Edwards) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.

• Customer {Customer-A} (for example "ZZAUTOTEST NT4 Technician Filter Memory") has exactly three Approved work orders: {Work-order-1} (for example S10043-17630) led by {Technician-A}, {Work-order-2} (for example S10043-17631) led by {Technician-B}, and {Work-order-3} (for example S10043-17632) with no lead.

• On the Work Orders page nothing is chosen in any filter, Assigned to me is off and Search is empty. Asset on Site has nothing selected.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on.

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a desktop browser window at least 1024 px wide (narrower windows show only the List, with no display switcher).

4. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example Esther Howard), an Email, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-A}.

5. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example Ralph Edwards), an Email, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-B}.

6. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST NT4 Technician Filter Memory") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

7. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17630). This is {Work-order-1}.

8. On {Work-order-1}'s page pick {Technician-A} in the Lead Technician dropdown; it saves at once (the dropdown shows once the work order is Approved).

9. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17631). This is {Work-order-2}.

10. On {Work-order-2}'s page pick {Technician-B} in the Lead Technician dropdown; it saves at once (the dropdown shows once the work order is Approved).

11. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17632). This is {Work-order-3}. Leave Lead Technician empty.

12. Work Orders > All: open each filter in the filter bar and clear any selection (Clear selection), turn Assigned to me off and empty Search. Make sure Asset on Site has nothing selected.

13. Check the setup worked: Work Orders > All > List > Search the name of {Customer-A} shows exactly {Work-order-1} (lead {Technician-A}), {Work-order-2} (lead {Technician-B}) and {Work-order-3} (no lead), all Approved. Then empty Search.

Part 2. Setup for Claude session

• Goal: three work orders of {Customer-A} (two leads and one unassigned), then choose {Technician-A} in Tech View, switch to List and back, then compare how the Technician choice and an Asset on Site choice survive a reload.

• The other filters' memory today: filter state persists on the server in the user preference GET/PUT /api/users/me/preferences/work-orders-list (playbook, Work Orders filters section; Asset on Site options have data-test-ids filter_option_vehicleHere_1 (Yes) and filter_option_vehicleHere_0 (No)). Read that preference before and after the reload and record whether the Technician choice is stored in the same place (UNVERIFIED).

• UNVERIFIED: the Technician filter's on-screen label and data-test-id; record them.

• Cleanup: clear the Technician filter and Asset on Site at the end.

• Evidence: a screenshot after each step that has an expected result, the build marker, and the real value of every brace name.
