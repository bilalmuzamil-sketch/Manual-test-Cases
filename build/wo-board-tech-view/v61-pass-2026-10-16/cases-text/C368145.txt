TITLE: A work order created with a lead keeps its normal place, not the bottom

=== PRECONDITIONS ===
Setup (manual QA tester and Claude session)

Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- Technician {Technician-A} (for example ZZAUTOTEST Ben Bravo) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.
- Customers {Customer-A}, {Customer-B} and {Customer-C} are used by this case only, their names start with the same words (for example "ZZAUTOTEST F3 Created With Lead") and end, in name order, with Bravo Co, Charlie Co and Delta Co.
- Approved work orders {Work-order-1} (for {Customer-A}) and {Work-order-2} (for {Customer-C}) (for example S10043-17741 and S10043-17742) are led by {Technician-A}. {Customer-B} has no work order yet; the one created in step 5 is {Work-order-3}.
- Nobody has reordered {Technician-A}'s work at {Location-A}.
- On the Work Orders page nothing is ticked in Status, Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip), Assigned to me is off and Search is empty.

=== STEPS ===
- Open Work Orders from the top menu and click the All tab.
- Type the shared start of the customer names (for example ZZAUTOTEST F3 Created With Lead) in Search.
- Click Board View in the display switcher.
- Read {Technician-A}'s column.
- Click Create Work Order, pick {Customer-B} and its asset, choose {Technician-A} as Lead Technician in that window and create it. If the New Work Order window has no Lead Technician field, split a line of {Work-order-1} off into a new work order instead (it keeps {Technician-A} as lead) and write down which way you used. The new work order is {Work-order-3}.
- Go back to Work Orders > All > Board View with the same search and read {Technician-A}'s column.

=== EXPECTED ===
Expected results
- Step 4: {Technician-A}'s column reads {Work-order-1}, {Work-order-2}.
- Step 6: {Work-order-3} sits in its customer-name place: {Technician-A}'s column reads {Work-order-1}, {Work-order-3}, {Work-order-2}, and {Work-order-3} is not at the bottom. If you used Split, the split-off work order also takes its customer-name place, not the bottom.

Exact quotes from the source (for reproducibility)
- S9-R14: “A work order that gets a new lead from the Reassign lead technician dialog or from its detail page goes to the bottom of the new technician’s work, for everyone at the location, in both views. A work order dragged to a technician goes where it is dropped. Removing the lead from the Reassign lead technician dialog or the detail page puts the work order in Unassigned in the initial sort, not at the bottom, so it is not lost behind every other unassigned work order. Going to the bottom applies only to work moved onto a technician. A work order created or split off with a lead keeps the initial sort (S9-R3).”
- S9-R3: “Once anyone at the location has reordered a technician’s work orders, use that saved order instead of the initial sort. Once a user has reordered technician groups/columns, use their saved order instead of the initial technician sort.”
- S2-R6: “Before a manual order is saved, use the List’s default work order sort, ties included, exactly as the List sorts today: work orders for the same customer go by start date, newest first. The List itself does not change. A work order that gets a new lead after it was created goes to the bottom of that technician’s work instead (S9-R14).”
