TITLE: Board View's Fields to display applies to cards and is saved per user

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 2 browsers · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- A second location [Loc-2] you can switch to (your initials at the top right > Change Location) (e.g. "Staging Lethbridge - 4310"); your user is enrolled at both.
- One technician at this location: [Tech-A] (e.g. "Esther Howard"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Board Fields Saved" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location. The asset has a VIN (e.g. "1FD0W5HY2EEA05499").
- One Approved work order for that customer, [WO-1], led by [Tech-A].
- A second browser or computer is available. Board View's Fields to display starts with Customer on and VIN/serial off (turn them back if needed).
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff > New Staff Member, enter First Name and Last Name (e.g. "Esther Howard") and an email. Pick a Role that is not Office User or Time Clock User (e.g. "Technician"), pick at least one Department (required), set Location to this location and turn Time Clock on, then click Save & Close. Record as [Tech-A].
- Create a customer used only by this case so a search shows only its work orders: top menu Customers > New Customer, Name "ZZAUTOTEST F2 Board Fields Saved" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then VIN/Serial # (e.g. "1FD0W5HY2EEA05499"), Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create the work order: Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Board Fields Saved" and its Asset > Save, and record its number as [WO-1] (e.g. "S1-702"). The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close.
- Once the work order is Approved, pick the technician in the Lead Technician dropdown on the work order page and choose [Tech-A] (e.g. "Esther Howard"). (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.)
- Check the setup worked: Work Orders > All tab > Search ZZAUTOTEST F2 Board Fields Saved > Board View — the [WO-1] card shows the customer and Lead technician [Tech-A] and no VIN. If Customer is off or VIN/serial is on in Fields to display, set them back before starting.

=== STEPS ===
- Open Work Orders, pick Tech View and note where its Column Selection menu sits in the toolbar and how it works.
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type ZZAUTOTEST F2 Board Fields Saved in Search.
- Open Fields to display (in the same toolbar spot) and read how it works.
- Turn Customer off and VIN/serial on.
- Read the [WO-1] card.
- Log out, log back in and open Board View.
- In the second browser sign in as the same user and open Board View.
- Switch to [Loc-2] and open Board View.

=== EXPECTED ===
Expected results
- Board View has its own Fields to display picker, in the same toolbar position and working the same way (a list of fields you tick on or off) as Tech View's column chooser.
- Optional fields can be turned on and off: the card stops showing the customer and starts showing the VIN.
- The choice (Customer off, VIN/serial on) is still in force after logging back in, in the second browser and at the second location.
- Each saved field change is also recorded for the product team's usage reports. This part cannot be checked by hand; write 'usage recording not checked by hand' in the result comment (the Usage analytics folder covers it).
