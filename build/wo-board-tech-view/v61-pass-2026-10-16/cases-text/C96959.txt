TITLE: Column and group counts change straight after a reassign

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] "Esther Howard" and [Tech-B] "Ralph Edwards". A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Header Counts" (used by this case only) with exactly 4 Approved work orders: [WO-1], [WO-2] and [WO-3] led by [Tech-A], [WO-4] led by [Tech-B]; none unassigned.
- The two technician names are used in the expected results and stay as written; the numbers are examples. What must hold: with the search applied, the headers start at 3, 1 and 0.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Esther Howard" (use exactly this name: the expected results name it), [Tech-B] = "Ralph Edwards" (use exactly this name: the expected results name it).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Header Counts" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Header Counts": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (e.g. S1-702): Lead Technician = [Tech-A].
- [WO-2] (e.g. S1-698): Lead Technician = [Tech-A].
- [WO-3] (e.g. S1-691): Lead Technician = [Tech-A].
- [WO-4] (e.g. S1-687): Lead Technician = [Tech-B].

- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Header Counts" shows exactly 4 work orders: [WO-1], [WO-2], [WO-3] led by [Tech-A] and [WO-4] led by [Tech-B]. If not, fix the leads (this customer is used by this case only, so it has no other work orders; if it has, create a new customer for this case with a different name and do the setup again) before starting; then clear the search.

=== STEPS ===
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Header Counts" in Search.
- Read the count in [Tech-A]'s, [Tech-B]'s and Unassigned's column headers.
- Drag one of [Tech-A]'s cards (e.g. [WO-1]) into [Tech-B]'s column.
- If a "Clear …'s scheduled shifts?" prompt opens, click Keep shifts.
- Read the three header counts again without reloading the page.
- Open [Tech-B]'s card [WO-4] More actions > Reassign lead technician, pick Unassigned and confirm.
- If a "Clear …'s scheduled shifts?" prompt opens, click Keep shifts.
- Read the three header counts again without reloading.
- Pick Tech View in the display switcher and read the three group header counts.

=== EXPECTED ===
Expected results
- Before the change the headers read Esther Howard 3, Ralph Edwards 1, Unassigned 0.
- Straight after the drag, with no reload: Esther Howard 2 (3 − 1), Ralph Edwards 2 (1 + 1), Unassigned 0.
- Straight after the dialog change: Ralph Edwards 1 (2 − 1), Unassigned 1 (0 + 1), Esther Howard still 2. Tech View shows the same three numbers in its group headers.
