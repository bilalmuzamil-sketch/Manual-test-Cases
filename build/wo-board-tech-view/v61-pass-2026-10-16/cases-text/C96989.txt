TITLE: One density choice is shared by Tech View and Board View and kept

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 2 browsers · a second location · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Customer "ZZAUTOTEST F1 Density Shared" (used by this case only) with one Approved work order [WO-1] with no lead (it sits in Unassigned).
- A second browser or computer, and a second location you can switch to (your initials at the top right > Change Location).
- Density starts at something other than Comfortable (e.g. Regular), so the change in step 1 is a real change.
- Names are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Density Shared" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Density Shared": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Leave Lead Technician empty.- [WO-1] (e.g. S1-702): no lead.

- Make sure you have a second browser or computer, and a second location you can switch to (your initials at the top right > Change Location shows it).
- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Density Shared" shows [WO-1]; in Tech View the Density control is not on Comfortable (if it is, pick Regular). Then clear the search.

=== STEPS ===
- Open Work Orders, pick Tech View and set density to Comfortable.
- Pick Board View and read the selected density.
- Log out, log back in and open Tech View.
- In the second browser sign in as the same user and open Board View.
- Switch to the second location and open Tech View.

=== EXPECTED ===
Expected results
- Board View is already Comfortable after the change in Tech View (one shared choice).
- Comfortable is still selected after logging back in, in the second browser and at the second location.
