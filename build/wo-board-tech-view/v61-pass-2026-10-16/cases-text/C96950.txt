TITLE: An empty column says 'Drag a work order here' only to users who can reassign

=== PRECONDITIONS ===
Preconditions
- Needs: 2 users · 2 browsers · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- [User-B]: a role with Work orders > View only (Create & Edit off), signed in in a second browser or a private window.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location. Both users use it.
- Two technicians at this location: [Tech-A] (e.g. "Esther Howard") leads exactly 1 work order for the customer below; "Jenny Wilson" (the expected results name her, so keep this name) leads none. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Empty Columns" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location. Every one of its work orders has a lead technician, so Unassigned is empty for this customer.
- What must hold: one technician with work, one without, no unassigned work order for this customer.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard); "Jenny Wilson" (keep this name, the expected results use it).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Empty Columns" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Empty Columns" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for one work order only; record its number as [WO-1] (e.g. S1-702) (numbers on this site look like "S10043-17581").
- Set the leads: on an Approved work order pick the technician in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned. Here: [WO-1] = [Tech-A].
- Settings > Roles & Permissions > Create Custom Role (e.g. "ZZAUTOTEST F2 WO view only") > turn on Work Orders view, leave Work Orders create and edit off > Save.
- Settings (your initials at the top right > Settings) > Staff > New Staff Member with an email you can open (e.g. "ZZAUTOTEST F2 Viewer"), role = the new role, at least one Department (required), with this location picked in Location > Save & Close, then accept the invitation and set a password. Record this user as [User-B] and keep it signed in in a second browser (or a private window).
- Check the setup worked: as [User-A], Work Orders > All tab > Search ZZAUTOTEST F2 Empty Columns — exactly [WO-1] shows, led by [Tech-A]. If any work order for this customer has no lead, set one before starting.
