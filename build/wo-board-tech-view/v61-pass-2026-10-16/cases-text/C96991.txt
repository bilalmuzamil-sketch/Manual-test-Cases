TITLE: If the saved density can't load, Regular is used

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 10 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Customer "ZZAUTOTEST F1 Density Load Fail" (used by this case only) with one Approved work order [WO-1] with no lead (it sits in Unassigned).
- This case needs the saved density to fail to load. That cannot be caused from the product. Run step 3 only where a developer has made it fail; otherwise write 'load failure not checked by hand'.
- Names are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Density Load Fail" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Density Load Fail": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Leave Lead Technician empty.- [WO-1] (e.g. S1-702): no lead.

- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Density Load Fail" shows [WO-1]. Then clear the search.

=== STEPS ===
- Open Work Orders, pick Tech View and set density to Comfortable.
- Reload and confirm Comfortable is kept (normal load).
- (Only with a forced load failure) reload Tech View and Board View and read the density.

=== EXPECTED ===
Expected results
- When the saved density cannot be loaded, both views use Regular. Without a forced failure only the normal load (step 2) can be seen.
