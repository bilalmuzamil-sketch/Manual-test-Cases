TITLE: Each Board column scrolls on its own and technicians are never hidden

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 45 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- At least 8 technicians at this location, including "Esther Howard" (the expected results name her, so keep this name). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field. Count every eligible technician at the location (Settings > Staff) and record the number as [Tech-count] (the expected results give "8" as the example).
- Customer "ZZAUTOTEST F2 Column Scroll" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Work orders for that customer: about 25 with no lead, about 20 led by Esther Howard, a few for each other technician.
- What must hold: Unassigned and Esther Howard's columns are taller than the screen and the board is wider than the window.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as "Esther Howard" (keep this name, the expected results use it); at least seven more (e.g. Ralph Edwards, Jenny Wilson, Kristin Watson, Theresa Webb, Dana Ortiz, Brenda Martinez, Cameron Williamson).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Column Scroll" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Column Scroll" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for about 25 + 20 + one per other technician (numbers on this site look like "S10043-17581").
- Set the leads: on an Approved work order pick the technician in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned. Here: about 25 with no lead; about 20 = Esther Howard; one or more each for the other technicians.
- Check the setup worked: Work Orders > All tab > Search ZZAUTOTEST F2 Column Scroll > Board View — the Unassigned and Esther Howard columns do not fit on the screen and a sideways scroll bar shows. If not, add more work orders or technicians.

=== STEPS ===
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- Click Search and type ZZAUTOTEST F2 Column Scroll so only this test's work orders show.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Scroll down inside the Unassigned column.
- Watch the neighbouring columns and the headers.
- Try to scroll the whole page down with the mouse over the empty area below a short column.
- Scroll down inside Esther Howard's column.
- Scroll the board sideways to the far right and back.
- Count the technician columns you passed and compare with [Tech-count].

=== EXPECTED ===
Expected results
- Scrolling inside Unassigned moves only its cards: the next columns and every header stay where they are.
- The page itself does not scroll down: only the content inside a column scrolls.
- Esther Howard's column scrolls on its own the same way.
- Sideways scrolling reaches every technician: the number of technician columns equals the number of eligible technicians (e.g. 8). None is hidden automatically.
