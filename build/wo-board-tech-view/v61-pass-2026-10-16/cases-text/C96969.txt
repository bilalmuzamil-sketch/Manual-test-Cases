TITLE: Choosing the current lead again changes nothing and shows no message

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] "Esther Howard" and [Tech-B] (e.g. "Ralph Edwards"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Same Lead Again" (used by this case only) with one Approved work order [WO-1] led by [Tech-A], with a second line "Line 2" whose Labor row reads Unassigned.
- Esther Howard is named in the expected results and stays as written; the other name, the number and the line name are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Esther Howard" (use exactly this name: the expected results name it), [Tech-B] (e.g. Ralph Edwards).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Same Lead Again" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Same Lead Again": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (e.g. S1-702): Lead Technician = [Tech-A]; then add a second line "Line 2" after the lead is set and clear its technician (Labor row > More actions > Edit labor) so its Labor row reads Unassigned.

- Line names in this case (such as "Line 1") are only labels for you: the New Line form's "What Are You Doing?" box only offers ready-made lines (typed text finds no results), so pick any ready-made line for each one (e.g. "Replace - Brake pot") and write down which is which.
- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Same Lead Again" shows [WO-1] with Lead Technician [Tech-A]; on its Lines tab Line 2's Labor row reads Unassigned. If not, fix it on the work order page before starting; then clear the search.

=== STEPS ===
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Same Lead Again" in Search.
- Hover the card in [Tech-A]'s column, click More actions and choose Reassign lead technician.
- Pick [Tech-A] (the current lead) and confirm.
- Watch the bottom of the screen for 10 seconds.
- Open the work order, read Lead Technician and Line 2's Labor row, and open its change history.

=== EXPECTED ===
Expected results
- No "Lead technician updated" message (or any reassignment message) appears.
- Nothing changes: Lead Technician is still Esther Howard, Line 2 still reads Unassigned (it is not given to Esther Howard), and no new history entry is added.
