TITLE: The dialog's open count is the technician's Approved to Complete work

=== PRECONDITIONS ===
Preconditions
- Needs: 2 users · 1 browser · optional second location · about 50 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] "Esther Howard" and [Tech-B] "Nina Newtech". A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- "Nina Newtech" must be a technician created for this case (no other work), so the expected number is known.
- Customer "ZZAUTOTEST F1 Open Count" (used by this case only), with a contact person, and eight work orders led by [Tech-B]: 1 Estimate, 1 Approved, 1 In Progress, 1 Review, 1 Complete, 1 Invoiced, 1 Paid, 1 Declined; plus 1 Approved work order led by [Tech-A] where [Tech-B] is only the technician on a line.
- Optional: if [Tech-B] is also enrolled at a second location, 1 Approved work order there led by her.
- Esther Howard and Nina Newtech are named in the expected results and stay as written.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Esther Howard" (use exactly this name: the expected results name it), [Tech-B] = "Nina Newtech" (use exactly this name: the expected results name it). Nina Newtech must be newly created for this case: if a staff member with that name already has work orders, the expected count will not match.
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Open Count" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- How to reach each status (standard steps): Estimate = a new work order whose lines are not approved. Approved = approve its lines. In Progress = a technician clicks Start time clock on an approved line's Labor row. Review = set the work order to Ready for Review with its status control. Complete = enter a tech story on every line, complete each line, then complete the work order. Invoiced = Finance tab > Create Invoice (the work order needs a contact person). Paid = record a full payment on that invoice. Declined = decline the estimate.
- Create these work orders for "ZZAUTOTEST F1 Open Count" with Lead Technician [Tech-B] (set the lead while they are open; while a work order is an Estimate its lead is set from Board View: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign): 1 Estimate, 1 Approved, 1 In Progress, 1 Review, 1 Complete, 1 Invoiced, 1 Paid, 1 Declined.
- Create 1 more Approved work order for "ZZAUTOTEST F1 Open Count" led by [Tech-A] where [Tech-B] is only the technician on a line (Edit Line > Technicians = [Tech-B]).
- If [Tech-B] is also enrolled at a second location, create 1 Approved work order there led by her; otherwise write 'second location not checked' in the result comment.
- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Open Count" shows the eight work orders led by [Tech-B] in the eight statuses listed and the one led by [Tech-A]; [Tech-B] leads no other work order at this location. If not, fix the status or lead before starting, then clear the search.

=== STEPS ===
- Open Work Orders, click the Work Orders tab (so Estimates, Invoiced and Paid are filtered out of the page) and pick Board View.
- Hover any card in [Tech-A]'s column, click More actions and choose Reassign lead technician.
- Find [Tech-B] in the dialog and read her open count (e.g. "4 open").
- Click Cancel.

=== EXPECTED ===
Expected results
- Nina Newtech's count reads 4 open: Approved 1 + In Progress 1 + Review 1 + Complete 1 = 4.
- Estimate, Invoiced, Paid and Declined are not counted (8 work orders led, 4 counted), her line-only work order on Esther Howard's work order is not counted, any work at another location is not counted, and the page's tab or filters do not change the number.
