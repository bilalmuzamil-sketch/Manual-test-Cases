TITLE: A reassign is refused if the work order was just invoiced elsewhere

=== PRECONDITIONS ===
Preconditions
- Needs: 2 users · 2 browsers · about 25 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- [User-B]: a second user with create and edit and invoicing permission (e.g. "Sam Second", Admin role) in a second browser.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] "Esther Howard" and [Tech-B] (e.g. "Ralph Edwards"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Invoiced Elsewhere" (used by this case only), with a contact person, and one Complete work order [WO-1] led by [Tech-A], so it can be invoiced.
- Esther Howard is named in the expected results and stays as written; the other names and the number are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Esther Howard" (use exactly this name: the expected results name it), [Tech-B] (e.g. Ralph Edwards).
- A second user with create and edit and invoicing permission (e.g. "Sam Second", Admin role): Settings > Staff > New Staff Member with an email you can open, Role Admin, at least one Department (required), this location in Location > Save & Close; accept the invitation and set a password. Record this user as [User-B] and sign in as [User-B] in a second browser.
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Invoiced Elsewhere" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- How to reach each status (standard steps): Estimate = a new work order whose lines are not approved. Approved = approve its lines. In Progress = a technician clicks Start time clock on an approved line's Labor row. Review = set the work order to Ready for Review with its status control. Complete = enter a tech story on every line, complete each line, then complete the work order. Invoiced = Finance tab > Create Invoice (the work order needs a contact person). Paid = record a full payment on that invoice. Declined = decline the estimate.
- Create these work orders for "ZZAUTOTEST F1 Invoiced Elsewhere": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (e.g. S1-420): Lead Technician = [Tech-A]; then take it to Complete (enter a tech story on every line, complete each line, then complete the work order).

- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Invoiced Elsewhere" shows [WO-1] with status Complete and Lead Technician [Tech-A]. If not, fix the status or lead before starting; then clear the search.

=== STEPS ===
- In browser 1 open Work Orders, click the All tab, pick Board View and search for "ZZAUTOTEST F1 Invoiced Elsewhere". The card shows Complete.
- In browser 2 open [WO-1] and invoice it (Finance tab > Create Invoice). Its status is now Invoiced.
- In browser 1, without reloading, drag [WO-1] from [Tech-A]'s column into [Tech-B]'s column.
- Read where the card ends up and the alert, then close the alert.
- Reload browser 1 and read the card's column.

=== EXPECTED ===
Expected results
- The drop is refused: the card goes back to Esther Howard's column and the lead stays Esther Howard.
- An alert reads "Failed to update lead technician, please try again." and also explains the status (e.g. that the work order is now Invoiced). Write down the explanation. The status cannot be changed in the middle of a single drag by hand; a board that still shows the old status is the same situation for the user.
