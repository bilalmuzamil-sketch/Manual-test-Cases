TITLE: Clicking a Tech View row opens the work order, a tiny mouse slip does not drag

=== PRECONDITIONS ===
Dev-layer test — fe-unit. Existing coverage: WorkOrderTableRow.spec.ts:185; WorkOrdersTechViewDisplay.spec.ts:1916; WorkOrderMoreActions.spec.ts:321

Preconditions
- Needs: 1 user · 1 browser · about 10 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- One technician at this location: [Tech-A] (e.g. "Esther Howard"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Row Click" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- One Approved work order for that customer, [WO-1], led by [Tech-A].
- Names and numbers are examples.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Row Click" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Row Click" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for one work order only; record its number as [WO-1] (the expected results call it "S1-702") (numbers on this site look like "S10043-17581").
- Set the leads: on an Approved work order pick the technician in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned. Here: [WO-1] = [Tech-A].
- Check the setup worked: Work Orders > All tab > Search ZZAUTOTEST F2 Row Click — [WO-1] shows with Lead Technician [Tech-A]. If not, set the lead before starting.

=== STEPS ===
- Open Work Orders, click the All tab, click Search and type ZZAUTOTEST F2 Row Click.
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Click on the customer name in the [WO-1] row.
- Press the browser Back button.
- Click on an empty part of the same row (e.g. between the Lines and Created on cells).
- Press the browser Back button.
- Press the mouse button on the row, move the pointer by one or two pixels, and release.
- Press the browser Back button.
- Hover the row and click its more-actions button (three dots) if it shows one.
- Press Escape.
- Press the mouse button on the row and move the pointer well away (a few centimetres) before releasing it back in place.

=== EXPECTED ===
Expected results
- Clicking anywhere on the row (customer name or empty space) opens work order S1-702.
- A press with a tiny movement still opens the work order and does not start a drag.
- Clicking the row's own more-actions button opens its menu and does not open the work order.
- Only a clear movement of the pointer starts a drag (the row lifts and follows the pointer).
