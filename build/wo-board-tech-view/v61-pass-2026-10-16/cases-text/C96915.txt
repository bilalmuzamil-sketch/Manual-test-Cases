TITLE: Going back to List uses the List sort you chose, never the dragged order

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · Schedule access · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- [Tech-A]: one eligible technician at this location. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 List Sort" (used by this case only) with three Approved work orders [WO-1], [WO-2] and [WO-3], all led by [Tech-A], created at different times (the example has them created on different days) so the Created on sort puts them in a fixed order.
- None of these work orders has a shift on the Schedule for [Tech-A].
- Names and numbers are examples; what must hold: three work orders with the same lead and different creation times, no shifts.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location. Create everything below in this location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (the expected results call it "Esther Howard").
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 List Sort" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 List Sort": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (the expected results call it "S1-702"): Lead Technician = [Tech-A]; created last (newest).
- [WO-2] (the expected results call it "S1-698"): Lead Technician = [Tech-A]; created second.
- [WO-3] (the expected results call it "S1-644"): Lead Technician = [Tech-A]; created first (oldest).

- Make sure the work orders you will drag have no shift on the Schedule for their lead technician (Schedule > check the technician's row). If a "Clear … scheduled shifts?" prompt appears anyway, click Keep shifts.
- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 List Sort" shows [WO-1], [WO-2] and [WO-3], each with lead [Tech-A]; [Tech-A]'s row on the Schedule has no shift on them. If not, fix the lead or delete the shift before starting.

=== STEPS ===
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- In List, click the Created on column header to sort by created date (click again if needed so the newest is first).
- Write down the order of your three work orders in List (e.g. [WO-1], [WO-2], [WO-3]).
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Under [Tech-A], drag the last of your three work orders to the top of the group and let go.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Look at [Tech-A]'s column.
- In the display switcher, click List (tooltip "List").
- Read the List order and the sort indicator on the Created on column.

=== EXPECTED ===
Expected results
- In Tech View and Board View, Esther Howard's work orders show your dragged order (the moved work order first).
- Back in List the table is still sorted by Created on, in the same direction you chose (e.g. S1-702, S1-698, S1-644), and the sort indicator is still on Created on.
- The dragged order does not appear in List.
