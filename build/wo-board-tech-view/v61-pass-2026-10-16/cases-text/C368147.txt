TITLE: A user without Work Orders create and edit cannot drag work orders

=== PRECONDITIONS ===
Preconditions
- Needs: 2 users (Admin for setup, a view-only user for the steps) · 1 browser · about 15 minutes
- Build: the Work Orders QA build (sv10043). Desktop browser window at least 1024 px wide (narrower windows show only the List, without the display switcher).
- Setup user: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView".
- [User-B]: a view-only user (e.g. "ZZAUTOTEST Viewer") whose role (e.g. "ZZAUTOTEST WO View Only") has under Work orders only View ticked, at the test location.
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location. Every technician and work order below belongs to this location.
- Technicians (examples, the expected results call them by first name or full name): "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo". A staff member counts as a technician when, in Settings > Staff > the staff member's edit icon > Edit Staff Member, they are Active, Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customers (used by this case only, each with one contact and one asset): "ZZAUTOTEST F3 No Drag Permission Alpha Co", "ZZAUTOTEST F3 No Drag Permission Bravo Co". The steps and expected results call them by the end of the name ("Alpha Co", "Bravo Co").
- Work orders (Approved), lead Ana: Alpha Co, Bravo Co (Ana's column reads Alpha Co, Bravo Co).
- None of these technicians has a shift on the Schedule for these work orders (check the Schedule page). If a window titled "Clear … scheduled shifts?" still appears during a move, click "Keep shifts".
Setup
- Settings (your initials at the top right > Settings) > Staff: confirm "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo" exist and count as technicians at this location (edit icon > Edit Staff Member). To add one: New Staff Member with those settings (at least one Department is required) (e.g. first name "ZZAUTOTEST Ana", last name "Alpha") > Save & Close.
- Create a view-only user (skip if one exists): Settings > Roles & Permissions > Create Custom Role > Skip > Role Name (e.g. "ZZAUTOTEST WO View Only") > under Work orders tick only View > Create. Then Settings (your initials at the top right > Settings) > Staff > New Staff Member (e.g. "ZZAUTOTEST Viewer", an email inbox you can open) with that role at the test location, and finish the invite so the user can sign in. Record this user as [User-B]; sign this user in later in a second browser or a private window.
- Create this case's customers: "ZZAUTOTEST F3 No Drag Permission Alpha Co", "ZZAUTOTEST F3 No Drag Permission Bravo Co". For each: top menu Customers > New Customer, Name > Save; on the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact); then the Assets tab > New Asset > pick the Contact, then Year, Make, Model (e.g. 2022, Freightliner, M2) > Save. Make is required; Unit can be left empty.
- Create each work order listed in the Preconditions: Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. Move it to the status named: a new work order starts as Estimate (it opens with the New Line form: pick a ready-made line and Save & Close); for Approved turn on Line Approved on its line; for In Progress click Start on the line's Labor row (stop the clock afterwards with Stop > Clock Out); for Review click the line's Complete button, type a Tech Story (fill any missing detail it asks for, e.g. Mileage) and click Complete Line (the List shows "Ready For Review"); for Complete then click Mark Reviewed, enter the VIN if asked and click Confirm Review; for Declined save the line with Line Approved off and click Decline on it (it must be the work order's only line); for Invoiced complete and review it first, then Finance tab > Create Invoice; for Paid, after invoicing, Finance tab > New Payment for the full amount > Make Payment. Set the lead technician before invoicing. Once the work order is Approved, pick the technician in the Lead Technician dropdown on the work order page (leave it as Unassigned for an unassigned one). (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Write down each work order number as you create it (e.g. S1-801); the steps call each work order by the end of its customer name (e.g. "Alpha Co").
- Check the setup worked: Work Orders > All tab > List > type "ZZAUTOTEST F3 No Drag Permission" in Search — (as Admin) exactly 2 work orders show, both Approved and led by Ana: Alpha Co, Bravo Co. Sign out before step 1. If anything differs, correct that work order (status or Lead Technician) before starting.

=== STEPS ===
- Sign in as the view-only user [User-B].
- Open Work Orders from the top menu and click the All tab.
- Type "ZZAUTOTEST F3 No Drag Permission" in Search so only this case's work orders show.
- Click Board View in the display switcher (tooltip "Board View").
- Try to drag the Bravo Co card above Alpha Co inside Ana's column and release.
- Try to drag the Alpha Co card into Ben's column and release.
- Hover the Alpha Co card and look for a more-actions (…) button.
- Click Tech View in the display switcher at the right of the toolbar (tooltip "Tech View").
- Try to drag the Alpha Co row into Ben's group and release.
- Refresh, then open Alpha Co and read Lead Technician.

=== EXPECTED ===
Expected results
- Steps 5 and 6: the cards cannot be moved, neither within Ana's column nor to Ben. They stay where they were and no message appears.
- Step 7: no Reassign lead technician action is offered to this user.
- Step 9: rows cannot be dragged in Tech View either.
- Step 10: the order is still Alpha Co, Bravo Co and Alpha Co still has Lead Technician Ana Alpha.
