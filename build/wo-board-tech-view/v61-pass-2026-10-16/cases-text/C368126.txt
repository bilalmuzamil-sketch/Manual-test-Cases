Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as "Esther Howard", "Jenny Wilson", "Kristin Watson" and "Ralph Edwards" (keep these names).
- Settings > Staff > New Staff Member > First Name and Last Name, an email you can open, Role "Admin", at least one Department (required), Location = this location, Time Clock off > Save & Close. Accept the invitation from that email and set a password. Record this user as [User-B].
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Tech Pin Order" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Tech Pin Order" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for five work orders in all (numbers on this site look like "S10043-17581").
- Set the leads: on an Approved work order pick the technician in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned. Here: one work order each for the four technicians; one with no lead.
- Check the setup worked: sign in as [User-B], Work Orders > All tab > Search ZZAUTOTEST F2 Tech Pin Order > Tech View — Unassigned and the four technician groups each hold one row, and no header shows a filled pin. If someone is pinned, unpin them before starting.
