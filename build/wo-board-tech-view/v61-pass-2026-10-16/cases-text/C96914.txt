TITLE: Search, filters and saved filters give the same results in all three displays

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · Schedule access · about 20 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- [Tech-A], [Tech-B] and [Tech-C]: three eligible technicians at this location. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Same Results" (used by this case only) with three assets whose units are [Unit-1], [Unit-2] and [Unit-3] - unit numbers no other asset on the site uses.
- Three Approved work orders for that customer: [WO-1] for [Unit-1] led by [Tech-A], [WO-2] for [Unit-2] led by [Tech-B], [WO-3] for [Unit-3] with no lead. They must differ on at least one filter (e.g. Asset on Site on for [WO-1] only).
- Names and numbers are examples; what must hold: a search for [Unit-1] finds only [WO-1].
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location. Create everything below in this location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard), [Tech-B] (e.g. Ralph Edwards), [Tech-C] (e.g. Jenny Wilson).
- Pick three unit numbers no other asset on the site uses: Work Orders > All tab > Search each one and check nothing is found (e.g. "TRK-118", "TRL-904", "TRL-903"; if one is found, choose another). Record them as [Unit-1], [Unit-2] and [Unit-3].
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Same Results" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, Unit = [Unit-1]) > Save. Make is required. Add two more assets the same way with Unit = [Unit-2] and Unit = [Unit-3].
- Create these work orders for "ZZAUTOTEST F1 Same Results": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (the expected results call it "S1-702"): Lead Technician = [Tech-A]; asset with [Unit-1]; in the New Work Order window leave Asset Here? on (it is on by default).
- [WO-2] (e.g. S1-691): Lead Technician = [Tech-B]; asset with [Unit-2]; in the New Work Order window switch Asset Here? off (it is on by default).
- [WO-3] (e.g. S1-352): no lead (Lead Technician left empty); asset with [Unit-3]; in the New Work Order window switch Asset Here? off (it is on by default).

- Check the setup worked: Work Orders > All tab > Search [Unit-1] shows only [WO-1]; Search "ZZAUTOTEST F1 Same Results" shows [WO-1] (lead [Tech-A]), [WO-2] (lead [Tech-B]) and [WO-3] (no lead). If not, fix the asset or lead before starting, then clear the search.

=== STEPS ===
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- In List, click Search and type [Unit-1].
- Write down the work orders shown (with this setup: [WO-1] only).
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Write down the work orders shown.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Write down the work orders shown.
- Clear the search, then turn on Asset on site = Yes (or another filter your work orders differ on) and repeat steps 4 to 7.
- Leave the filter on, open Schedule from the top navigation, then click Work Orders in the top navigation.
- Note whether the filter is still applied, then do the same round trip once more while in List.

=== EXPECTED ===
Expected results
- The same work orders appear in List, Tech View and Board View for the same search (example: S1-702 only, 1 result in each).
- The same work orders appear in all three displays for the same filter.
- Coming back from Schedule, the filter is kept or cleared in Tech View and Board View exactly as it is in List.
