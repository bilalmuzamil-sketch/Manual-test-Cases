TITLE: Collapsed technician groups stay collapsed after refresh, new tab and sign-in

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Three technicians at this location: [Tech-A] (e.g. "Esther Howard"), [Tech-B] = "Ralph Edwards" (the expected results name this technician, so keep this name) and [Tech-C] (e.g. "Jenny Wilson"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Collapse Memory" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Three Approved work orders for that customer: [WO-1] led by [Tech-A], [WO-2] led by [Tech-B], [WO-3] led by [Tech-C].
- All groups start expanded for [User-A] (expand any collapsed group before starting). Numbers are examples; names marked "keep this name" stay as they are.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard); [Tech-B] = "Ralph Edwards" (keep this name, the expected results use it); [Tech-C] (e.g. Jenny Wilson).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Collapse Memory" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Collapse Memory" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for three work orders in all; record the numbers as [WO-1], [WO-2] and [WO-3] (numbers on this site look like "S10043-17581").
- Set the leads: on an Approved work order pick the technician in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned. Here: [WO-1] = [Tech-A]; [WO-2] = [Tech-B]; [WO-3] = [Tech-C].
- Check the setup worked: Work Orders > All tab > Search ZZAUTOTEST F2 Collapse Memory > Tech View — groups for [Tech-A], [Tech-B] and [Tech-C] each show one row and all are expanded. If a group is collapsed, click its expand arrow before starting.

=== STEPS ===
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- Click Search and type ZZAUTOTEST F2 Collapse Memory so only this test's work orders show.

- Open Work Orders in a new browser tab.
- Close all Work Orders tabs, then open Work Orders again.
