TITLE: Pinned technicians can only be reordered among the pinned technicians

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 25 minutes
- Build: the Work Orders QA build (sv10043). Desktop browser window at least 1024 px wide (narrower windows show only the List, without the display switcher).
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders). This user is the dispatcher.
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location. Every technician and work order below belongs to this location.
- Technicians (examples, the expected results call them by first name or full name): "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo", "ZZAUTOTEST Cal Charlie", "ZZAUTOTEST Dan Delta". A staff member counts as a technician when, in Settings > Staff > the staff member's edit icon > Edit Staff Member, they are Active, Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customers (used by this case only, each with one contact and one asset): "ZZAUTOTEST F3 Pinned Reorder Alpha Co", "ZZAUTOTEST F3 Pinned Reorder Bravo Co", "ZZAUTOTEST F3 Pinned Reorder Charlie Co", "ZZAUTOTEST F3 Pinned Reorder Delta Co". The steps and expected results call them by the end of the name ("Alpha Co", "Bravo Co", "Charlie Co", "Delta Co").
- Work orders (Approved): lead Ana — Alpha Co; lead Ben — Bravo Co, Charlie Co; lead Cal — Delta Co; Dan leads none (counts with the example data: Ana 1, Ben 2, Cal 1, Dan 0).
- Pins (yours): Ana and then Ben are pinned, nobody else. The order is now Unassigned, Ana, Ben (pinned), Cal, Dan.
- None of these technicians has a shift on the Schedule for these work orders (check the Schedule page). If a window titled "Clear … scheduled shifts?" still appears during a move, click "Keep shifts".
Setup
- Settings (your initials at the top right > Settings) > Staff: confirm "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo", "ZZAUTOTEST Cal Charlie", "ZZAUTOTEST Dan Delta" exist and count as technicians at this location (edit icon > Edit Staff Member). To add one: New Staff Member with those settings (at least one Department is required) (e.g. first name "ZZAUTOTEST Ana", last name "Alpha") > Save & Close.
- Create this case's customers: "ZZAUTOTEST F3 Pinned Reorder Alpha Co", "ZZAUTOTEST F3 Pinned Reorder Bravo Co", "ZZAUTOTEST F3 Pinned Reorder Charlie Co", "ZZAUTOTEST F3 Pinned Reorder Delta Co". For each: top menu Customers > New Customer, Name > Save; on the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact); then the Assets tab > New Asset > pick the Contact, then Year, Make, Model (e.g. 2022, Freightliner, M2) > Save. Make is required; Unit can be left empty.
- Create each work order listed in the Preconditions: Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. Move it to the status named: a new work order starts as Estimate (it opens with the New Line form: pick a ready-made line and Save & Close); for Approved turn on Line Approved on its line; for In Progress click Start on the line's Labor row (stop the clock afterwards with Stop > Clock Out); for Review click the line's Complete button, type a Tech Story (fill any missing detail it asks for, e.g. Mileage) and click Complete Line (the List shows "Ready For Review"); for Complete then click Mark Reviewed, enter the VIN if asked and click Confirm Review; for Declined save the line with Line Approved off and click Decline on it (it must be the work order's only line); for Invoiced complete and review it first, then Finance tab > Create Invoice; for Paid, after invoicing, Finance tab > New Payment for the full amount > Make Payment. Set the lead technician before invoicing. Once the work order is Approved, pick the technician in the Lead Technician dropdown on the work order page (leave it as Unassigned for an unassigned one). (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Write down each work order number as you create it (e.g. S1-801); the steps call each work order by the end of its customer name (e.g. "Alpha Co").
- Pin Ana and then Ben: Work Orders > Board View > click the pin button in each column header (the pin icon beside the technician's name in the column header). If any other technician is pinned, unpin it first (and pin it back after the case).
- Check the setup worked: Work Orders > All tab > List > type "ZZAUTOTEST F3 Pinned Reorder" in Search — 4 work orders show, all Approved, with the leads above. In Board View the columns read Unassigned, Ana, Ben (pinned), Cal, Dan. If anything differs, correct that work order (status or Lead Technician) before starting.

=== STEPS ===
- Open Work Orders from the top menu and click the All tab.
- Type "ZZAUTOTEST F3 Pinned Reorder" in Search so only this case's work orders show.
- Click Board View in the display switcher (tooltip "Board View").
- Write down each column header count (with the example data: Ana 1, Ben 2, Cal 1, Dan 0).
- Drag Ben's column (by its header drag handle) before Ana's column and release.
- Drag Ben's column to after Cal's column (outside the pinned area) and release there.
- Click Tech View in the display switcher at the right of the toolbar (tooltip "Tech View").
- Try to drag Ana's group header below Cal's group and release there.
- Read every header count again, then open the Bravo Co work order and read Lead Technician.

=== EXPECTED ===
Expected results
- Step 5: Ben moves before Ana. The order is Unassigned, Ben, Ana, Cal, Dan.
- Step 6: Ben cannot leave the pinned area. He stays among the pinned technicians and Cal and Dan stay after them.
- Step 8: in Tech View the pinned groups come right after Unassigned, in the same pinned order, and Ana cannot be dropped among the unpinned groups.
- Step 9: the counts are unchanged (Ana 1, Ben 2, Cal 1, Dan 0) and Bravo Co still has Lead Technician Ben Bravo: moving technicians changed no work order.
