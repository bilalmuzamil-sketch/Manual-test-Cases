TITLE: The clear-shifts question shows its exact title, text and buttons

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · Schedule access · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] "Esther Howard" and [Tech-B] (e.g. "Ralph Edwards"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Prompt Wording" (used by this case only) with one Approved work order [WO-1] led by [Tech-A].
- A shift for [Tech-A] on [WO-1] tomorrow 8:00–12:00 (entire work order).
- Esther Howard is named in the expected results and stays as written; the other name and the number are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Esther Howard" (use exactly this name: the expected results name it), [Tech-B] (e.g. Ralph Edwards).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Prompt Wording" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Prompt Wording": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (e.g. S1-702): Lead Technician = [Tech-A].

- On the Schedule, give [Tech-A] a shift on the work order tomorrow 8:00–12:00: Schedule > go to that day > drag the work order from the work order list onto [Tech-A]'s row at the start time > in the picker choose Entire work order > set the end time > save.
- Check the setup worked: on the Schedule for tomorrow, [Tech-A]'s row has the 8:00–12:00 shift on [WO-1], and [WO-1] shows Lead Technician [Tech-A]. If not, fix it before starting.

=== STEPS ===
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Prompt Wording" in Search.
- Drag the card from [Tech-A]'s column into [Tech-B]'s column.
- Read the prompt's title, its text and the labels of its buttons, word for word.
- Click Keep shifts.

=== EXPECTED ===
Expected results
- The title reads exactly: Clear Esther Howard's scheduled shifts?
- The text reads exactly: Esther Howard has shifts scheduled for this whole work order. Clearing removes shifts that haven't started and ends one that's under way now. Shifts on individual lines and recorded time don't change.
- The buttons read exactly Keep shifts, Clear shifts and Cancel (3 buttons).
- When there is no name to show the title must read: Clear the lead technician's scheduled shifts? A technician without a name cannot be set up by hand; write 'no-name title not checked by hand' in the result comment. A straight or curly apostrophe is not a difference; any other word difference is a failure.
What you should see today (build v26.40.8-7a95011, 10/8/2026): changing the lead (by dragging the card or with Reassign lead technician) shows no question about scheduled shifts, even when the outgoing lead has a shift booked for the entire work order. The lead changes at once with the "Lead technician updated" (or "Lead technician removed") message, and the outgoing lead's shift stays on the Schedule. (1) If you see exactly that, mark the case Failed and raise nothing new. (2) If it fails in a different way, that is a new problem: report it. (3) If it behaves as the expected results above say, the change has shipped: mark it Passed and tell the QA lead.
