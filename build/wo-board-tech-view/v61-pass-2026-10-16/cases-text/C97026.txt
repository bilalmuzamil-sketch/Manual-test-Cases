TITLE: Default and saved settings show as separate groups in the reports

=== PRECONDITIONS ===
Preconditions
- Needs: about 20 minutes, on one day.
- Desktop browser window at least 1024 px wide; Admin sign-in for the setup (on a QA branch: the Admin quick-login button).
- Work in one location throughout, shown next to the bell in the top bar (e.g. "Staging Heavy Duty - 9919"); to change it click your initials (top right) > Change Location. Create everything in that location.
- No Google Analytics access is needed: you read what the page sends in the browser's developer tools (Chrome or Edge). Press F12 > Network tab > tick Preserve log > type collect in the filter box. Click a collect request > Payload tab. Each event lists en (event name), ep.element_location (list, tech_view or board_view), ep.element_label (the field or density), ep.setting_value (on or off), ep.setting_source (default = never changed, saved = chosen earlier) and uid (the user). One request can hold several events, one per line.
- Turn off any ad blocker for this site, and use a new private window for each user so their messages are not stopped or mixed up.
Setup
- Settings > Staff > New Staff Member: a brand-new user "ZZAUTOTEST Newbie" at this location with a role that has Work Orders View; finish the invite so they can sign in. Do not open Work Orders as this user before the steps. If the name was used before, use a new name and read the expected results with it.
- As Admin (the dispatcher): Work Orders > Board View > Density > pick Comfortable. Then sign out.

=== STEPS ===
- In a new private window open the browser tools as described in the Preconditions (F12 > Network > Preserve log > filter collect).
- Sign in as ZZAUTOTEST Newbie, open Work Orders and click Board View. Wait 10 seconds.
- Click each collect request and find the work_orders_field_load and work_orders_density_load events. For each write down ep.element_label, ep.setting_source and uid.
- Sign out and close the window. In a new private window open the browser tools the same way, sign in as Admin (your dispatcher), open Work Orders and click Board View. Wait 10 seconds.
- Find the work_orders_density_load event and write down ep.element_label, ep.setting_source and uid.
- Put your notes into two groups by ep.setting_source: default and saved. Write down which user (uid) falls in which group.

=== EXPECTED ===
Expected results
- Step 3: ZZAUTOTEST Newbie's field and density events show ep.setting_source = default (they never changed them).
- Step 5: the dispatcher's density event shows ep.element_label = comfortable and ep.setting_source = saved.
- Step 6: default and saved come out as separate groups, with ZZAUTOTEST Newbie (their uid) under default and the dispatcher's density (the dispatcher's uid) under saved. Each user keeps the same uid on every event.
- A fallback (a setting that could not be loaded) cannot be caused by hand. Write "fallback: not checked by hand" in the result comment.
- The report page itself is built by the report owner inside Google Analytics, outside ShopView, and is not part of this test (QA lead's decision below).
