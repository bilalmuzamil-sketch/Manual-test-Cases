TITLE: Density changes spacing and size only, never what is shown

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- [Tech-A]: one eligible technician at this location. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Density Content" (used by this case only) with one Approved work order [WO-1] led by [Tech-A].
- Names are examples; what must hold: one card and one row with values to compare.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Density Content" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Density Content": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (e.g. S1-702): Lead Technician = [Tech-A].

- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Density Content" shows [WO-1] with Lead Technician [Tech-A]. If not, fix it on the work order page before starting; then clear the search.

=== STEPS ===
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Density Content" in Search.
- Open Fields to display and turn on estimated hours and total price.
- Write down every field and value on the card.
- Set density to Compact, then Regular, then Comfortable, reading the card each time.
- Repeat steps 3 to 5 in Tech View with its columns and the row's values.

=== EXPECTED ===
Expected results
- Each density changes only spacing and the size of rows, cards and their parts (Compact tighter, Comfortable roomier).
- The same fields, columns and values are shown at every density (e.g. estimated hours and total price stay on the card in Compact).

PRD §4 Key decision "Fields vs. density are separate controls". Design export of 8 Oct 2026 (Claude Design project 787fef1a, Work Orders.dc.html): the design's Compact card hides hours, progress and totals; the PRD is followed. Source-verified 8 October 2026.
