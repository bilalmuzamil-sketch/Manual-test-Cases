TITLE: No labels overlap in the toolbar and headers from 1024 to 1920 px wide

=== PRECONDITIONS ===
Setup (manual QA tester and Claude session)

Preconditions
- You are signed in as {User-A} (for example Admin ShopView), an Owner or Admin user whose role has Work orders > View, Work orders > Create & Edit and See financial data, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your screen is at least 1920 px wide, or you can set the browser window to 1024, 1280, 1366, 1440, 1536 and 1920 px wide, with the browser zoom at 100%.
- The design pictures DC-17-tech-view-1024-light.png and DC-17-board-view-1280-light.png are open beside the app at 100% zoom (actual size); they are attached to this case.
- In the design pictures the names, numbers, dates and amounts are sample data, and the rank numbers (1, 2, 3 …) beside rows and cards are left out of this release, so do not compare those.
- Technician {Technician-A} (for example ZZAUTOTEST DC17 Maximiliana Abernathy-Kowalczyk) is an active technician at {Location-A} with a long name.
- Customer {Customer-A} (for example "ZZAUTOTEST DC17 Widths") is used by this case only.
- Approved work order {Work-order-1} (for example S10043-17848) for {Customer-A} is led by {Technician-A}.
- On the Work Orders page nothing is chosen in any filter (if the Asset on Site chip shows Yes or No, click the x on the chip), Assigned to me is off, Search is empty and density is Regular (the default).

=== STEPS ===
- Open Work Orders, click the All tab and click Tech View in the display switcher.
- Set the window to 1024 px wide and look at the toolbar and the column header row.
- Set the window to 1280 px wide and look again.
- Set the window to 1366 px wide and look again.
- Set the window to 1440 px wide and look again.
- Set the window to 1536 px wide and look again.
- Set the window to 1920 px wide and look again.
- Click Board View in the display switcher and look at the toolbar and the column headers.
- Set the window to 1536 px wide and look again.
- Set the window to 1440 px wide and look again.
- Set the window to 1280 px wide and look again.
- Set the window to 1024 px wide and look again.

=== EXPECTED ===
Expected results
- Steps 2 to 7: at every width no label in the toolbar or in the column header row touches or overlaps another. Where the toolbar runs out of room, its buttons move onto a second line, as in the 1024 px design picture, instead of running into the filters. Where the table is wider than the window it scrolls sideways.
- Steps 8 to 12: at every width no label in the toolbar or in the column headers touches or overlaps another; {Technician-A}'s long name ends with "…" before the pin icon instead of running into it or the count, and the board scrolls sideways, as in the 1280 px design picture.

Exact quotes from the source (for reproducibility)
- S2-R21: “Tech View’s column header labels are 12px, medium weight (500), in the secondary text color, as in the design. Labels never overlap a neighboring label.”
- S1-R14: “The display options follow the same screen-width switch the List uses in production today. The switch is by screen width only; the app never detects the device type.”
