TITLE: Analytics events carry no work order details, names or amounts

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser (private window) · Google Analytics DebugView access · about 15 minutes
- Build: the Work Orders QA build (sv10043). Desktop browser window at least 1024 px wide (narrower windows show only the List, without the display switcher).
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders). This user is the dispatcher.
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location. Every technician and work order below belongs to this location.
- Analytics access: you can open Google Analytics for the property the QA build reports to, at Admin > DebugView. The QA build runs analytics in debug mode, so each event appears in DebugView within a few seconds under your user. If you cannot open DebugView, the event checks in this case cannot be done by hand: write "not checked by hand" in the result comment and pass or fail on what you can see on the Work Orders page.
- Event names to look for in DebugView: work_orders_display_view (a display was shown), work_orders_field_load and work_orders_density_load (the fields and density you have, once per display per session), work_orders_field_toggle and work_orders_density_change (a saved change).
- Technician (example): "ZZAUTOTEST Ana Alpha". A staff member counts as a technician when, in Settings > Staff > the staff member's edit icon > Edit Staff Member, they are Active, Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST Bravo Co" (kept as named: the expected results check that "Bravo Co" and the search text "ZZAUTOTEST Bravo" never appear in an event), with one contact and one asset.
- Work order [WO-1] for "ZZAUTOTEST Bravo Co": Approved, with a lead technician and a total price.
Setup
- Settings (your initials at the top right > Settings) > Staff: confirm "ZZAUTOTEST Ana Alpha" exist and count as technicians at this location (edit icon > Edit Staff Member). To add one: New Staff Member with those settings (at least one Department is required) (e.g. first name "ZZAUTOTEST Ana", last name "Alpha") > Save & Close.
- Top menu Customers > New Customer, Name "ZZAUTOTEST Bravo Co" > Save (skip if it already exists). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty. Record the customer as [Cust-1].
- Create a work order with one line: Work Orders > Create Work Order > in New Work Order pick Customer [Cust-1] and its Asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line, turn Line Approved on (this makes the work order Approved) > Save & Add Line for the next line or Save & Close. Record the number shown as [WO-1]. Pick any ready-made line (e.g. "Replace - Brake pot"); then pick Lead Technician "ZZAUTOTEST Ana Alpha".
- Start a fresh analytics session: close every browser window, open a new private window and sign in.
- Check the setup worked: Work Orders > All > search "ZZAUTOTEST Bravo" shows [WO-1], Approved, with a lead technician and a dollar amount in the Total price column (Column Selection > Total price). Google Analytics > Admin > DebugView shows your device. If the total is zero, the dollar-amount part of the check cannot be made: give the work order a priced line first.

=== STEPS ===
- Open Work Orders, search "ZZAUTOTEST Bravo", and click Tech View, then Board View.
- Open Fields to display and turn VIN/Serial on, then change the density.
- In DebugView, open each Work Orders event from this session and read every parameter.

=== EXPECTED ===
Expected results
- Every parameter holds only a field or setting name and its value (for example board_view, total_price, on, compact, default).
- No event contains a customer name (Bravo Co), a technician name, a work order number, a VIN, the search text "ZZAUTOTEST Bravo" or a dollar amount.
