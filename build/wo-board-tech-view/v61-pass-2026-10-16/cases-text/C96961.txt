TITLE: Removing the lead returns only lines that followed it to Unassigned

=== PRECONDITIONS ===
Preconditions
- Needs: 2 users · 2 browsers · about 30 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- [Tech-A] can also sign in (a staff record with an email you can open and an accepted invite), in a second browser.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Three eligible technicians at this location: [Tech-A] "Esther Howard", [Tech-B] (e.g. "Ralph Edwards"), [Tech-C] "Dana Ortiz". A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Remove Lead Lines" (used by this case only) with one work order [WO-1], created on this build, Approved, Lead Technician [Tech-A], and six lines: Line 1 Unassigned (no technician) · Line 2 Implicit (follows the lead) · Line 3 Explicit (its own technician [Tech-C]) · Line 4 Complete (follows the lead, status Complete) · Line 5 Logged (follows the lead, has logged labor) · Line 6 Clocked (follows the lead, [Tech-A]'s time clock running, no earlier labor).
- The technician names are used in the expected results and stay as written; the line names are only labels, and the number is an example.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Esther Howard" (use exactly this name: the expected results name it), [Tech-B] (e.g. Ralph Edwards), [Tech-C] = "Dana Ortiz" (use exactly this name: the expected results name it). Give [Tech-A] an email you can open, accept the invite and set a password, so [Tech-A] can sign in.
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Remove Lead Lines" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create a new work order on this build (lines created before this release follow the old rule): Work Orders > Create Work Order > pick Customer "ZZAUTOTEST F1 Remove Lead Lines" and an Asset > Save. Record its number as [WO-1] (e.g. "S1-702").
- Line names in this case (such as "Line 1") are only labels for you: the New Line form's "What Are You Doing?" box only offers ready-made lines (typed text finds no results), so pick any ready-made line for each one (e.g. "Replace - Brake pot") and write down which is which.
- On the Lines tab add four lines with no technician: "Line 2 Implicit", "Line 4 Complete", "Line 5 Logged", "Line 6 Clocked".
- Add "Line 3 Explicit", click its name to open the Edit Line dialog and choose Technicians = [Tech-C] (a line given its own technician).
- Click Approve (check) on these five lines so the work order reads Approved (the Lead Technician dropdown only appears once the work order is Approved).
- Once the work order is Approved, pick the technician in the Lead Technician dropdown on the work order page and choose [Tech-A]. Lines 2, 4, 5 and 6 now show [Tech-A] in their Labor row (they follow the lead).
- Add "Line 1 Unassigned". If its Labor row shows a technician, use the Labor row's More actions > Edit labor to clear it, so it reads Unassigned. Click Approve (check) on it too, so all six lines are approved (the work order reads Approved).
- Line 4: enter a tech story (e.g. "Done") and complete the line, so its status is Complete.
- Line 5: in a second browser signed in as [Tech-A], click Start time clock on Line 5's Labor row, wait at least 1 minute, then click Stop time clock, so Line 5 has logged labor.
- Line 6: still as [Tech-A], click Start time clock on Line 6's Labor row and leave it running (no earlier labor on this line).
- Check the setup worked: write down each line's Labor technician: Line 1 Unassigned, Line 2 [Tech-A], Line 3 [Tech-C], Line 4 [Tech-A], Line 5 [Tech-A], Line 6 [Tech-A] (clock running); Line 4 is Complete; Search "ZZAUTOTEST F1 Remove Lead Lines" on Work Orders > All shows [WO-1] in [Tech-A]'s column. If any line differs, fix it as described above (or create a fresh work order) before starting.

=== STEPS ===
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Remove Lead Lines" in Search.
- Hover [WO-1]'s card in [Tech-A]'s column, click More actions and choose Reassign lead technician.
- Pick Unassigned and confirm ([Tech-A] is still clocked in on Line 6).
- If a "Clear …'s scheduled shifts?" prompt opens, click Keep shifts.
- Open the work order and go to the Lines tab.
- Read each line's Labor technician and whether Line 6's clock is still running.

=== EXPECTED ===
Expected results
- The lead is removed even though Esther Howard is clocked in: the card is in the Unassigned column and the work order has no lead technician.
- Line 2 Implicit now reads Unassigned (it was following the outgoing lead). Line 1 still reads Unassigned.
- Line 3 Explicit still shows Dana Ortiz, Line 4 Complete and Line 5 Logged still show Esther Howard.
- Line 6 Clocked still shows Esther Howard and her clock is still running, although she was assigned only by following the lead and had no earlier labor on it.
