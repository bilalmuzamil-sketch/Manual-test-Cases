TITLE: Narrowing the window below 1024 px does not change your chosen display

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 resizable desktop browser (or a tablet you can turn) · about 5 minutes
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders). This user is the dispatcher.
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location. Every technician and work order below belongs to this location.
- A desktop browser you can resize (or a tablet you can turn). The build: the Work Orders QA build (sv10043).
- At least one work order at this location.
Setup
- Open Work Orders > All and confirm at least one work order is listed; if none, create one: Work Orders > Create Work Order > pick a Customer and its Asset > Save.
- Check the setup worked: at full width (1024 px or wider) the display switcher shows List, Tech View and Board View. If it does not, widen the window.

=== STEPS ===
- Open Work Orders at full width (1024 px or wider).
- Click Board View in the display switcher (tooltip "Board View").
- Narrow the browser window to about 900 px wide.
- Look for the display switcher, the density control and the Fields to display picker.
- Refresh the page while it is still narrow.
- Widen the window back to full width.

=== EXPECTED ===
Expected results
- Steps 3 and 4: below 1024 px the page shows the phone List exactly as today, with no display switcher, no density control and no field picker.
- Step 5: after the refresh it is still the phone List.
- Step 6: back at full width the page opens in Board View again. The narrow visit did not change your saved choice.
- At 1024 px and wider, List, Tech View and Board View are all offered.
Source — where this behaviour comes from
Epic SV-10043; Work Orders Board View & Tech View Display Options Technical Implementation Plan (revised 24 Sep 2026, uploaded 8 Oct 2026), Phase 4 (mobile guard). Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S1-R14, read 8 Oct 2026. The tech plan calls this an interim state before phone designs. Since then the PRD (S1-R14) and Review Decisions DR-34 (28 Sep 2026) made the 1024 px switch the final rule.
Exact quotes from the source (for reproducibility)
- S1-R14: “The display options follow the same screen-width switch the List uses in production today. On a screen narrower than 1024px, the Work Orders page shows List exactly as it does today (the phone card layout), with no display switcher. At 1024px and wider, Tech View and Board View are offered, whatever the device: a tablet held sideways at 1024px or wider gets them too. The switch is by screen width only; the app never detects the device type.”
- Tech plan Phase 4 mobile guard: “Below the desktop breakpoint the existing mobile List always renders; switcher, density control and pickers are hidden; nothing writes `display`, so a phone visit cannot strand a user in a display they cannot see.”
