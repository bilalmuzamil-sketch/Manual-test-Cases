TITLE: Switcher tooltips read List, Tech View, Board View and open above it

=== PRECONDITIONS ===
Setup (manual QA tester and Claude session)

Preconditions
- You are signed in as {User-A} (for example Admin ShopView), an Owner or Admin user whose role has Work orders > View, Work orders > Create & Edit and See financial data, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is 1440 px wide, with the browser zoom at 100%.
- For the steps that name 1536 px, your screen lets you widen the window to 1536 px.
- The design picture DC-02-tech-view-header-row-1440.png is open beside the app at 100% zoom (actual size); it is attached to this case.
- The design picture shows the column header row that must stay readable; the design has no tooltip of its own on the switcher, so where the tooltip opens comes from the PRD.
- Technician {Technician-A} (for example ZZAUTOTEST DC02 Ben Tooltip) is an active technician at {Location-A}.
- Customer {Customer-A} (for example "ZZAUTOTEST DC02 Switcher Tooltip") is used by this case only.
- Approved work order {Work-order-1} (for example S10043-17805) for {Customer-A} is led by {Technician-A}.
- On the Work Orders page nothing is chosen in any filter (if the Asset on Site chip shows Yes or No, click the x on the chip), Assigned to me is off, Search is empty and density is Regular (the default).

=== STEPS ===
- Open Work Orders, click the All tab and click Tech View in the display switcher.
- Hover the List button of the display switcher and wait until its tooltip shows.
- Hover the Tech View button and wait until its tooltip shows.
- Hover the Board View button and wait until its tooltip shows.
- Click Board View in the display switcher.
- Hover each of the three switcher buttons in turn, waiting for each tooltip.
- Widen the window to 1536 px.
- Click Tech View in the display switcher.
- Hover each of the three switcher buttons in turn, waiting for each tooltip.

=== EXPECTED ===
Expected results
- Steps 2 to 4: each tooltip opens above the switcher, between the switcher and the tabs above it, never below it. While it shows, the table's column header row (Status, Waiting On Parts, Number …) stays fully readable, as in the design picture: no part of the tooltip lies over it. The tooltips read List (step 2), Tech View (step 3) and Board View (step 4).
- Step 6: in Board View each tooltip also opens above the switcher, reads List, Tech View or Board View, and covers none of the column headers (technician names and counts).
- Step 9: at 1536 px each tooltip still opens above the switcher and leaves the column header row fully readable.
