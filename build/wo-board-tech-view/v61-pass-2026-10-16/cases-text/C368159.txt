TITLE: Toggling On Site from a stale page does not undo another user's lead change

=== PRECONDITIONS ===
Preconditions
- Needs: 2 users · 2 browsers · about 10 minutes
- Build: the Work Orders QA build (sv10043). Desktop browser window at least 1024 px wide (narrower windows show only the List, without the display switcher).
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders). This user is the dispatcher.
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location. Every technician and work order below belongs to this location.
- [User-B]: a second browser signed in as another dispatcher at the same location (e.g. "ZZAUTOTEST Dispatcher Two", a role with Work Orders View and Create & Edit).
- Technicians (examples, the expected results call them by first name or full name): "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo". A staff member counts as a technician when, in Settings > Staff > the staff member's edit icon > Edit Staff Member, they are Active, Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customers (used by this case only, each with one contact and one asset): "ZZAUTOTEST F3 Stale On Site Site Co". The steps and expected results call them by the end of the name ("Site Co").
- Work order Site Co: Approved, lead Ana.
Setup
- Settings (your initials at the top right > Settings) > Staff: confirm "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo" exist and count as technicians at this location (edit icon > Edit Staff Member). To add one: New Staff Member with those settings (at least one Department is required) (e.g. first name "ZZAUTOTEST Ana", last name "Alpha") > Save & Close.
- Settings (your initials at the top right > Settings) > Staff > New Staff Member (e.g. "ZZAUTOTEST Dispatcher Two"; skip if one exists) with a role that has Work Orders View and Create & Edit at this location. Record as [User-B] and sign them in in browser 2.
- Create this case's customers: "ZZAUTOTEST F3 Stale On Site Site Co". For each: top menu Customers > New Customer, Name > Save; on the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact); then the Assets tab > New Asset > pick the Contact, then Year, Make, Model (e.g. 2022, Freightliner, M2) > Save. Make is required; Unit can be left empty.
- Create each work order listed in the Preconditions: Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. Move it to the status named: a new work order starts as Estimate (it opens with the New Line form: pick a ready-made line and Save & Close); for Approved turn on Line Approved on its line; for In Progress click Start on the line's Labor row (stop the clock afterwards with Stop > Clock Out); for Review click the line's Complete button, type a Tech Story (fill any missing detail it asks for, e.g. Mileage) and click Complete Line (the List shows "Ready For Review"); for Complete then click Mark Reviewed, enter the VIN if asked and click Confirm Review; for Declined save the line with Line Approved off and click Decline on it (it must be the work order's only line); for Invoiced complete and review it first, then Finance tab > Create Invoice; for Paid, after invoicing, Finance tab > New Payment for the full amount > Make Payment. Set the lead technician before invoicing. Once the work order is Approved, pick the technician in the Lead Technician dropdown on the work order page (leave it as Unassigned for an unassigned one). (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Write down each work order number as you create it (e.g. S1-801); the steps call each work order by the end of its customer name (e.g. "Alpha Co").
- Check the setup worked: Work Orders > All tab > List > type "ZZAUTOTEST F3 Stale On Site" in Search — exactly 1 work order shows: Site Co, Approved, lead Ana. [User-B] is signed in in browser 2 at the same location. If anything differs, correct that work order (status or Lead Technician) before starting.

=== STEPS ===
- In browser 1, open Work Orders > All, search "ZZAUTOTEST F3 Stale On Site", click List and leave the page open.
- In browser 2, open Site Co and change Lead Technician to Ben Bravo on the work order page.
- In browser 1, without refreshing, click Site Co's On Site toggle.
- In browser 1, refresh and open Site Co. Read Lead Technician.

=== EXPECTED ===
Expected results
- Step 4: Lead Technician is Ben Bravo. Browser 1's older page did not put Ana back when it saved On Site, and the On Site change is kept.
