TITLE: Assigning a lead to unassigned work moves only open unassigned lines

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 20 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] "Ralph Edwards" and [Tech-B] "Dana Ortiz". A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Assign Unassigned Lines" (used by this case only) with one work order [WO-1], created on this build, Approved, no lead technician, with three lines: Line 1 Unassigned (no technician) · Line 2 Explicit (its own technician [Tech-B]) · Line 3 Complete (no technician, status Complete).
- The technician names are used in the expected results and stay as written; the line names are only labels and the number is an example.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Ralph Edwards" (use exactly this name: the expected results name it), [Tech-B] = "Dana Ortiz" (use exactly this name: the expected results name it).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Assign Unassigned Lines" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Line names in this case (such as "Line 1") are only labels for you: the New Line form's "What Are You Doing?" box only offers ready-made lines (typed text finds no results), so pick any ready-made line for each one (e.g. "Replace - Brake pot") and write down which is which.
- Create a new work order on this build for "ZZAUTOTEST F1 Assign Unassigned Lines" with no lead technician: Work Orders > Create Work Order > pick the Customer and its Asset > Save. Record its number as [WO-1] (e.g. "S1-710").- Add "Line 1 Unassigned" with no technician.
- Add "Line 2 Explicit" and in Edit Line set Technicians = [Tech-B].
- Add "Line 3 Complete" with no technician, approve it, enter a tech story and complete it.
- Approve the other lines (the work order reads Approved).
- Write down each line's Labor row: Line 1 Unassigned, Line 2 [Tech-B], Line 3 Unassigned (Complete).

- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 Assign Unassigned Lines" shows [WO-1] in the Unassigned column (Board View) with status Approved; its Lines tab matches what you wrote down. If not, fix the line or create a fresh work order before starting; then clear the search.

=== STEPS ===
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Assign Unassigned Lines" in Search.
- Hover the card in the Unassigned column, click More actions > Reassign lead technician.
- Pick [Tech-A] and confirm.
- Open the work order's Lines tab and read each line's Labor row.

=== EXPECTED ===
Expected results
- The card moves to Ralph Edwards' column with "Lead technician updated".
- Line 1 now shows Ralph Edwards. Line 2 still shows Dana Ortiz. Line 3 (Complete) still reads Unassigned. So 1 of 3 lines moved.
