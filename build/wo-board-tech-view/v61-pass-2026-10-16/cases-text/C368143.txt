TITLE: A line with no labor and no scheduled technician still reads Unassigned

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · Schedule access · about 20 minutes
- Build: the Work Orders QA build (sv10043). Desktop browser window at least 1024 px wide (narrower windows show only the List, without the display switcher).
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Technicians: 3 eligible technicians at this location, named as the expected results name them: "Jenny Wilson", "Ralph Edwards", "Dana Ortiz". A technician is eligible when Time Clock is on, the staff member is active (not deactivated), the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F3 Unassigned Labor Row" (used by this case only), with one contact and one asset.
- Work order [WO-1] for this customer: status Approved, no lead technician, three lines approved for repair, none with a labor technician: "Line 1", "Line 2", "Line 3".
- Schedule shifts on [WO-1] tomorrow: Jenny Wilson 8:00–10:00 on Line 2; Ralph Edwards 10:00–12:00 on Line 3; Dana Ortiz 13:00–15:00 on Line 3. Line 1 has no shift.
- The work order number and line names are examples.
Setup
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below exists and is eligible, or add them with New Staff Member: First Name and Last Name ("Jenny Wilson", "Ralph Edwards", "Dana Ortiz") and an email; a Role that is not Office User or Time Clock User (e.g. "Technician"); at least one Department (required); Location = this location; Time Clock on > Save & Close.
- Top menu Customers > New Customer, Name "ZZAUTOTEST F3 Unassigned Labor Row" > Save (skip if it already exists). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty. Record the customer as [Cust-1].
- Create a work order with three lines, all approved for repair and none with a labor technician: Work Orders > Create Work Order > in New Work Order pick Customer [Cust-1] and its Asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line, turn Line Approved on (this makes the work order Approved) > Save & Add Line for the next line or Save & Close. Record the number shown as [WO-1] (the steps call the lines "Line 1", "Line 2", "Line 3"). Leave Lead Technician Unassigned. Line names in this case (such as "Line 1") are only labels for you: the New Line form's "What Are You Doing?" box only offers ready-made lines (typed text finds no results), so pick any ready-made line for each one (e.g. "Replace - Brake pot") and write down which is which.
- On the Schedule, give "Jenny Wilson" a shift on [WO-1] tomorrow 8:00–10:00: Schedule > go to that day > drag the work order from the work order list onto Jenny Wilson's row at the start time > in the picker choose Choose lines and tick Line 2 > set the end time > save.
- On the Schedule, give "Ralph Edwards" a shift on [WO-1] tomorrow 10:00–12:00 the same way, ticking Line 3.
- On the Schedule, give "Dana Ortiz" a shift on [WO-1] tomorrow 13:00–15:00 the same way, ticking Line 3.
- Check the setup worked: Work Orders > All tab > List > type "ZZAUTOTEST F3 Unassigned Labor Row" in Search — exactly [WO-1] shows, Approved, no lead; its Lines tab shows Line 1, Line 2, Line 3 with no labor technician; the Schedule shows the three shifts tomorrow (Jenny Wilson on Line 2; Ralph Edwards and Dana Ortiz on Line 3). If it does not match, fix the work order (or create it again) before starting.

=== STEPS ===
- Open the work order [WO-1] and click the Lines tab.
- Read Line 1's Labor row.
- Give Line 1 a labor technician (Labor row > More actions > Edit labor > "Ralph Edwards") and read the row again.

=== EXPECTED ===
Expected results
- Line 1, with neither a labor technician nor a scheduled technician, reads "Unassigned".
- Once a labor technician is set, the row shows that technician (Ralph Edwards) as it does today.
