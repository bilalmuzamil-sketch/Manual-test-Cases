TITLE: Pinned columns sit after Unassigned in the order they were pinned

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · about 20 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Four technicians at this location: "Esther Howard", "Jenny Wilson", "Kristin Watson", "Ralph Edwards" (the expected results name them, so keep these names). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Board Pin Order" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Five Approved work orders for that customer: one led by each technician and one with no lead.
- [User-A] starts with no pins and no saved technician order.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as "Esther Howard", "Jenny Wilson", "Kristin Watson" and "Ralph Edwards" (keep these names).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Board Pin Order" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Board Pin Order" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for five work orders in all (numbers on this site look like "S10043-17581").
- Set the leads: on an Approved work order pick the technician in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned. Here: one work order each for the four technicians; one with no lead.
- Check the setup worked: Work Orders > All tab > Search ZZAUTOTEST F2 Board Pin Order > Board View — Unassigned and the four technician columns each hold one card, no header shows a filled pin, and the four technicians appear in A-Z order. If someone is pinned, unpin them; if the order is not A-Z, run the case as a new user (Settings > Staff > New Staff Member, Role "Admin", at least one Department, this location, Time Clock off; accept the invitation and set a password).

=== STEPS ===
