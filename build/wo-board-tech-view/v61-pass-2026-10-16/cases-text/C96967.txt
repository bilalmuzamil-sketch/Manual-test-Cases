TITLE: A user without create and edit cannot drag or reassign work orders

=== PRECONDITIONS ===
Preconditions
- Needs: 2 users · 2 browsers · about 20 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- [User-B] = "Vera Viewonly": a second user whose role has Work Orders view but not Work Orders create and edit, with this location picked in Location.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] "Esther Howard" and [Tech-B] (e.g. "Ralph Edwards"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 View Only No Drag" (used by this case only) with one Approved work order [WO-1] led by [Tech-A].
- Vera Viewonly and Esther Howard are named in the expected results and stay as written; the role name and number are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] = "Esther Howard" (use exactly this name: the expected results name it), [Tech-B] (e.g. Ralph Edwards).
- A second user whose role has Work Orders view but not Work Orders create and edit ("Vera Viewonly"): Settings > Roles & Permissions > Create Custom Role (e.g. "ZZAUTOTEST F1 WO View Only") with Work Orders view only > Save, then Settings > Staff > New Staff Member (at least one Department is required): add "Vera Viewonly" with that role and an email, with this location picked in Location > Save & Close. Accept the invitation and set a password. Record this user as [User-B].
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 View Only No Drag" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 View Only No Drag": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (e.g. S1-702): Lead Technician = [Tech-A].

- Check the setup worked: Work Orders > All tab > Search "ZZAUTOTEST F1 View Only No Drag" shows [WO-1] with Lead Technician [Tech-A]; Settings > Staff shows Vera Viewonly with the view-only role. If not, fix it on the work order page before starting; then clear the search.

=== STEPS ===
- In a second browser sign in as [User-B] and pick the same location.
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 View Only No Drag" in Search.
- Try to drag the card from [Tech-A]'s column into [Tech-B]'s column.
- Try to drag the card to a different position within [Tech-A]'s column.
- Hover the card and look for More actions and Reassign lead technician.
- Repeat steps 4 to 6 in Tech View.
- In your first browser (your own user) open the work order and read Lead Technician.

=== EXPECTED ===
Expected results
- Vera Viewonly cannot drag the card to another technician or within the column; it stays where it was and the lead stays Esther Howard.
- Vera Viewonly is not offered Reassign lead technician (no More actions button, or the action is missing or disabled).
