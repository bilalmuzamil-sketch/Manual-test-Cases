TITLE: Clear shifts keeps ended shifts, removes future ones, trims a running one

=== PRECONDITIONS ===
Preconditions
- Needs: 1 user · 1 browser · Schedule access · about 25 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] (e.g. "Esther Howard") and [Tech-B] (e.g. "Dana Ortiz"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Shift Trim" (used by this case only) with one Approved work order [WO-1] led by [Tech-A].
- Three whole-work-order shifts for [Tech-A] on [WO-1]: yesterday 8:00–12:00 (already ended), tomorrow 8:00–12:00 (not started), and today from 1 hour before you run the test to 2 hours after (running).
- Names, the number and the clock times are examples; what must hold: one ended, one running and one future shift for the lead on this work order.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard), [Tech-B] (e.g. Dana Ortiz).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Shift Trim" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Shift Trim": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. Write down the number the build gives the work order (on a QA branch they look like "S10043-17581"). Then pick the lead in the Lead Technician dropdown on the work order page; it saves at once. (While a work order is an Estimate its Lead technician is read-only on the work order page; give an Estimate its lead from Board View instead: the card's More actions (…) > Reassign lead technician > pick the technician > Reassign.) Leave Lead Technician empty on the ones that should sit in Unassigned.- [WO-1] (e.g. S1-702): Lead Technician = [Tech-A].

- On the Schedule, give [Tech-A] a shift on this work order yesterday 8:00–12:00 (already ended): Schedule > go to that day > drag the work order from the work order list onto [Tech-A]'s row at the start time > in the picker choose Entire work order > set the end time > save.
- On the Schedule, give [Tech-A] a shift on this work order tomorrow 8:00–12:00 (not started): Schedule > go to that day > drag the work order from the work order list onto [Tech-A]'s row at the start time > in the picker choose Entire work order > set the end time > save.
- On the Schedule, give [Tech-A] a shift on this work order today, starting 1 hour before you run the test and ending 2 hours after (e.g. 9:00–12:00 when you test at 10:00): Schedule > go to that day > drag the work order from the work order list onto [Tech-A]'s row at the start time > in the picker choose Entire work order > set the end time > save.
- Check the setup worked: on the Schedule, [Tech-A]'s row has the three shifts on [WO-1] (yesterday 8:00–12:00, today's running one, tomorrow 8:00–12:00), and [WO-1] shows Lead Technician [Tech-A]. If one is missing, add it before starting; start the steps within the hour after today's shift began.

=== STEPS ===
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Shift Trim" in Search.
- Note the exact time on your clock (e.g. 10:00).
- Drag the card from [Tech-A]'s column into [Tech-B]'s column.
- In the prompt click Clear shifts.
- Open the Schedule and read [Tech-A]'s shifts on this work order for yesterday, today and tomorrow.

=== EXPECTED ===
Expected results
- Yesterday's 8:00–12:00 shift is unchanged.
- Tomorrow's 8:00–12:00 shift is gone.
- Today's shift now ends at the time of the change: e.g. 9:00–12:00 now reads 9:00–10:00 (3 hours before, 1 hour after). The part already under way stays on the Schedule and the rest is removed, just as Jeremy's 8:00–12:00 shift becomes 8:00–10:00 when the lead changes to Dana at 10:00.
What you should see today (build v26.40.8-7a95011, 10/8/2026): changing the lead (by dragging the card or with Reassign lead technician) shows no question about scheduled shifts, even when the outgoing lead has a shift booked for the entire work order. The lead changes at once with the "Lead technician updated" (or "Lead technician removed") message, and the outgoing lead's shift stays on the Schedule. (1) If you see exactly that, mark the case Failed and raise nothing new. (2) If it fails in a different way, that is a new problem: report it. (3) If it behaves as the expected results above say, the change has shipped: mark it Passed and tell the QA lead.
