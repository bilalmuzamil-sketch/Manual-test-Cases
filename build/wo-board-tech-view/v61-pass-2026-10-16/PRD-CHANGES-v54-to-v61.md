# PRD changes v54 → v61 (verbatim lines; the v61 file is the source of truth)

OLD (v54): - A minimap or overview of Board View’s columns. It is in neither this PRD nor the design.
NEW (v61): - The design’s minimap: the floating overview at the bottom right, one block per technician column, that appears while the view scrolls sideways. It is not part of this release.

OLD (v54): - Collapse all and Expand all controls for the technician groups. Groups collapse one at a time (S2-R5, S2-R13).

OLD (v54): - **S1-R9a:** The switcher uses the design’s icons at 20px: List is Lucide `list`, Tech View is `user-round`, Board View is `square-kanban`. In Tech View and Board View these icons are the design’s: density (`row-height` in Tech View, `card-height` in Board View, custom icons in the design system’s icon set), collapse chevron (`chevron-down`), pin and unpin (`pin` / `pin-off`), Invoiced or Paid lock (`lock`), Unassigned avatar (`user-round`) and the empty state when there are no work orders at all (`clipboard-list`). The filtered no-results state is the List’s, magnifier included (S1-N1). The filter chips and Search use the design file’s icons in every display option, List included, each exactly as the design file draws it; this is the only change to List. Every other List icon is unchanged.
NEW (v61): - **S1-R9a:** The switcher uses the design’s icons at 20px: List is Lucide `list`, Tech View is `user-round`, Board View is `square-kanban`. In Tech View and Board View these icons are the design’s: density (`row-height` in Tech View, `card-height` in Board View, custom icons in the design system’s icon set), collapse chevron (`chevron-down`), pin and unpin (`pin` / `pin-off`), Invoiced or Paid lock (`lock`), Unassigned avatar (`user-round`) and the empty state when there are no work orders at all (`clipboard-list`). The filtered no-results state is the List’s, magnifier included (S1-N1). The filter chips and Search use the design file’s icons in every display option, List included, each exactly as the design file draws it. The display switcher (new on every view, List included) shows the design’s slate icons in every view, so it keeps one color as the user moves between views. These are the only changes to List. Every other List icon is unchanged.

OLD (v54): - **S1-R8:** In Tech View and Board View, browser Back restores both vertical and horizontal scroll position. Horizontal position comes back exactly. Vertically, the row or card that was at the top of the view comes back at the top, fully shown; it may sit up to one row or card from the exact pixel position. List behaves as it does today.
NEW (v61): - **S1-R8:** In Tech View and Board View, browser Back restores both vertical and horizontal scroll position. Horizontal position comes back exactly, and so do the filter view (tab) and filters that were on screen, in Tech View and Board View. List’s Back behavior is unchanged in this release. Vertically, the row or card that was at the top of the view comes back at the top, fully shown; it may sit up to one row or card from the exact pixel position. List behaves as it does today.

NEW (v61): - **S1-N1c:** When no filter and no search are active and the filter view has no work orders at all, Tech View and Board View show the design’s first-run state: the clipboard-list icon in a grey circle, “No work orders yet”, then “Create a work order and assign a technician to see it here.”, with a Create Work Order button that does the same as the page’s Create Work Order button. List keeps its production empty state.

NEW (v61): - **S2-R13a:** As in the design, Tech View’s top-left header cell, above the grip column, holds one chevron button. While any group is expanded it reads “Collapse all” (chevron pointing down) and collapses every group, Unassigned included; when every group is collapsed it reads “Expand all” (chevron pointing right) and expands every group. The result is saved the same way as each group’s own collapse (S2-R13), and a group’s own chevron still works on its own afterwards. Board View has no such button.

OLD (v54): - **S2-R20:** Tech View’s cells follow the design: the work order number shows as a link in the accent color; Progress shows as a thin bar with the percentage beside it, with no hours line under it at any density (S6-R6); Service Advisor shows the advisor’s avatar before the name. Clocked In keeps List’s display (S5-R11).
NEW (v61): - **S2-R20:** Tech View’s cells follow the design: the work order number shows as a link in the design system’s link color (#175CD3), which meets accessible contrast on white; Progress shows as a thin bar with the percentage beside it, with no hours line under it at any density (S6-R6); Service Advisor shows the advisor’s avatar before the name. Clocked In keeps List’s display (S5-R11).

OLD (v54): - **S2-R22:** Tech View’s table runs edge to edge on white, with no side gutter and no card or panel around it, as in the design. When the columns are wider than the screen, the table scrolls sideways, as in the design; columns keep the design’s minimum widths and are never squeezed or clipped.
NEW (v61): - **S2-R22:** Tech View’s table runs edge to edge on white, with no side gutter and no card or panel around it, as in the design. When the columns are wider than the screen, the table scrolls sideways, as in the design; columns keep the design’s minimum widths and are never squeezed or clipped. The Status column is the one exception: it has no minimum width and sizes to its widest pill on the page, because its pills keep the List’s production widths (S6-R2a). With Ready for Review on the page that is about the design’s 132px; with only short statuses it is narrower.
NEW (v61): - **S2-R23:** In Tech View and Board View, as in the design: a technician avatar without a photo is a light-grey circle (--sv-grey-100, #EEF2F6) with initials in --sv-grey-600 (#4B5565) in light mode, which meets accessible contrast (6.7:1; the design file’s #697586 is 4.2:1); dark mode uses the design’s dark colors; group and column header names are 14px, weight 600, in the design’s slate text color (#364152), with the design’s smaller, lighter initials; Board card customer and total price are weight 500; toolbar and switcher icons are the design’s slate color (the switcher in List too, S1-R9a). Technician avatars, and the Service Advisor avatar, follow density in Tech View as in the design: 20px, 24px and 32px on rows and 24px, 28px and 36px on group headers at Compact, Regular and Comfortable; Board View card avatars stay 24px. The Progress bar is 48 by 4px at Compact, as in the design. The name bubble on hover over a technician avatar on a row or card (the +N included) opens above the avatar, in both views; group and column header avatars keep the browser’s plain name tip, because the name is printed beside them. In Tech View, Status, Waiting On Parts and Progress are left-aligned. The Density and Columns tooltips open above their button, like the switcher’s (S1-R9b), and are hidden while their menu is open. List is unchanged.

NEW (v61): - **S2-R11a:** The pin on each Tech View technician group header is always shown, styled as on Board View’s column headers: grey when unpinned, blue when pinned, and dimmed on unpinned technicians once three are pinned (S3-R8).

NEW (v61): - **S3-R20d:** A lead technician whose Time Clock is turned off (not deleted) keeps their own column on Board View and group in Tech View, under their name, while they still lead work orders. Nothing can be dropped onto it, the same as S3-R20c. Once they lead no work orders, the column or group is no longer shown.
NEW (v61): - **S3-R20e:** Work orders whose lead technician was deleted in Settings → Staff (the name no longer exists) sit in one column on Board View and one group in Tech View labeled “Deleted technician”, with the inactive marker and no drag grip. Work orders can be dragged out of it; nothing can be dropped onto it. List shows the Lead Technician as blank for these work orders, as today.

OLD (v54): - **S11-R1:** Tab moves focus onto each work order row (Tech View) or card (Board View); the focused row or card shows a visible focus ring.
OLD (v54): - **S11-R3:** Tab and Shift+Tab move through rows or cards and group or column headers in on-screen order: top to bottom in Tech View; in Board View, column by column, left to right, and top to bottom within each column.
NEW (v61): - **S11-R1:** Each view is a single Tab stop. Tab lands on one work order row (Tech View) or card (Board View), the one last focused, or the first one when none has been (never a group or column header while a work order is shown; when every group is collapsed, Tab lands on the first group header; after the user arrows onto a header and tabs out and back in, Tab returns to a work order row while any row is shown; on Board View, if the last-focused card has scrolled out of view in its column, Tab lands on the first card in view); the focused row or card shows a visible focus ring.
NEW (v61): - **S11-R3:** Inside a view the arrow keys move focus: Up and Down move between rows and group headers in Tech View, and between cards and the column header within a Board View column; Left and Right move between Board View columns. Tab from a focused row, card or header reaches its own controls (more actions, pin, collapse) in order, then leaves the view. Tab never stops on every row.
