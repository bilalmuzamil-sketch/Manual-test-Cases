Setup: Technician names and avatar hover names match the staff record in both views

Test case: C581895, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.

• Technicians {Technician-A} (for example ZZAUTOTEST Staffname Ana) and {Technician-B} (for example ZZAUTOTEST Staffname Ben) are active staff members at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.

• Where the site allows it, each technician's staff record name differs from the name on their sign-in account (for example staff record ZZAUTOTEST Staffname Ana, account ZZAUTOTEST Account Ana). On staging the two names cannot differ, because renaming either one renames both, so there every name simply has to match Settings > Staff.

• Customer {Customer-A} (for example "ZZAUTOTEST S5R11b Staff Names") is used by this case only.

• Approved work order {Work-order-1} (for example S10043-17791) for {Customer-A} is led by {Technician-A} and has two approved lines, {Line-1} and {Line-2} (for example "Service - Full grease service" twice).

• {Line-2}'s technician is {Technician-B}, set through Edit Line.

• List shows the Lead Technician column, Board View's Fields to display has Lead technician and Line technicians on, and Tech View shows the Assigned Techs column (it is on by default).

• On the Work Orders page nothing is ticked in Status, Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip), Assigned to me is off and Search is empty.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on.

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a desktop browser window at least 1024 px wide (narrower windows show only the List, with no display switcher).

4. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example ZZAUTOTEST Staffname Ana), an Email, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-A}.

5. Your initials > Settings > Staff. Reuse a staff member only if they are active, have Time Clock on, {Location-A} in Location and a Role other than Office User or Time Clock User. Otherwise click New Staff Member and enter First Name and Last Name (for example ZZAUTOTEST Staffname Ben), an Email, Role Technician, at least one Department (required), Location {Location-A}, turn Time Clock on, then Save & Close. This is {Technician-B}.

6. Names: on a QA site, compare each technician's name in Settings > Staff with the name their own account shows after they sign in (their initials > Edit Profile). If you can find two technicians whose two names differ, use them as {Technician-A} and {Technician-B}. On staging the names never differ; use any two technicians.

7. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST S5R11b Staff Names") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

8. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. The status reads Approved. Write down the number shown at the top left (for example S10043-17791). This is {Work-order-1}. On {Work-order-1}'s page pick {Technician-A} in the Lead Technician dropdown; it saves at once (the dropdown shows once the work order is Approved).

9. On {Work-order-1}'s Lines tab the first line is {Line-1}. Click New Line, type "grease", pick "Service - Full grease service", turn Line Approved on and click Save & Close: this is {Line-2}. On {Line-2} click Edit Line, pick {Technician-B} as its technician and save.

10. Work Orders > All > List > Column Selection: turn Lead Technician on. Board View > Fields to display: turn Lead technician and Line technicians on. Tech View: check the Assigned Techs column shows (it is on by default).

11. Work Orders > All: clear any Status selection, click the x on the Asset on Site chip if it shows Yes or No, turn Assigned to me off and empty Search.

12. Check the setup worked: Work Orders > All > List > Search the name of {Customer-A} shows {Work-order-1} with Lead Technician {Technician-A}. Then empty Search.

Part 2. Setup for Claude session

• Goal: one work order led by {Technician-A} with {Technician-B} on a line; compare every name shown in the two views with Settings > Staff.

• Record each technician's staff record name and account name, and every rendered name (visible text and the hover text) on the List, the card, the column header, the group header and both avatar groups.

• Evidence: a screenshot after each step that has an expected result, the build marker, and the real value of every brace name.

How to work

Prepare the same starting state by carrying out Part 1 in a browser with Playwright (or the faster route above, where one is given), then run the test case's steps in the same browser. Record the real value of every brace name, the build marker and screenshots in the case's verification folder in the Manual-test-Cases repository, and judge pass or fail against the test case's Expected results only. Environment

  • Work Orders QA site for this feature (epic SV-10043): app https://sv10043.qa.shopview.com, API https://sv10043api.qa.shopview.com. Use the site named in the test run if it differs.

Access

  • Check access: GET /api/auth/me/fe-permissions answers 200. GET /api/staff/my-workplaces lists the locations and their ids; switch location with your initials (top right) > Change Location.
