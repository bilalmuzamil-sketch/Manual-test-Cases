Setup: A card's estimated hours match Total Hours on the work order page

Test case: C581894, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Owner or Admin user whose role has Work orders > View, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.

• Customer {Customer-A} (for example "ZZAUTOTEST S5R11a Card Hours") is used by this case only, and {Work-order-1} below is its only work order.

• Work order {Work-order-1} (for example S10043-17661) for {Customer-A} has four lines with an Estimated Time: three approved lines {Line-1} (for example 0.30 hours), {Line-2} (for example 1.50 hours) and {Line-3} (for example 0.40 hours), and a declined line {Line-4} (for example 2.00 hours).

• On the Work Orders page nothing is ticked in Status, Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip), Assigned to me is off and Search is empty.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on.

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a desktop browser window at least 1024 px wide (narrower windows show only the List, with no display switcher).

4. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST S5R11a Card Hours") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

5. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", set its Estimated Time to 0.30 hours (for example), turn Line Approved on and click Save & Add Line. Add two more lines the same way (for example "Service - Adjust clutch" with 1.50 hours and "Replace - Brake pot" with 0.40 hours), each with Line Approved on. Add a fourth line (for example "Service - Full grease service" again) with Estimated Time 2.00 hours (for example), leave Line Approved off, click Save & Close, then click Decline on that fourth line so it reads Declined. Write down the number shown at the top left (for example S10043-17661). This is {Work-order-1}, with approved {Line-1}, {Line-2}, {Line-3} and declined {Line-4}.

6. Do not create any other work order for {Customer-A}.

7. Check the setup worked: {Work-order-1}'s Lines tab shows three approved lines and {Line-4} Declined, with the Estimated Time you typed on each. Write down the expected figure: the sum of the three approved lines (2.20 with the example values). If a line kept a different time, change it back before you start.

Part 2. Setup for Claude session

• Goal: one work order whose approved lines carry known estimated times and whose declined line carries a large one, so a total that counts the declined line is easy to tell apart.

• Create {Customer-A}, its contact and asset, and {Work-order-1} on screen as in Part 1. Record {Work-order-1 id} and {Line-1 id} to {Line-4 id}.

• UNVERIFIED on the Work Orders QA site: the label of the line's estimate field (Jira SV-11106 calls it Estimated Time) and whether a ready-made line brings its own estimate that must be overwritten. Record the label and the saved value of every line.

• Compute the expected figure yourself from the four saved line estimates: the sum of the three approved lines only. With the example values 0.30 + 1.50 + 0.40 = 2.20 hours; a figure that includes the declined line would be 4.20.

• Step 4: read Total Hours on the work order page exactly as shown (for example "2.2 hrs"). Step 10: read the card's estimated hours exactly. Pass when the card is within 0.1 hours of Total Hours and Total Hours equals your computed figure within 0.1 hours.

• Context: the developer reported on 12 Oct 2026 (SV-11106, build e84b3d1) that cards leave out declined lines. That is not evidence about the build you test; judge only what you see.

• Evidence: a screenshot after each step that has an expected result, the build marker, and the real value of every brace name.
