Setup: Cards and headers show the technician's staff record name, as the List does

Test case: C581895, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.

• Technician {Technician-A} (for example ZZAUTOTEST Staffname Ana) is an active technician at {Location-A} with a sign-in account, and the staff record was renamed after the account was made, so the name in Settings > Staff differs from the account name (for example ZZAUTOTEST Account Ana).

• Technician {Technician-B} (for example ZZAUTOTEST Staffname Ben) is an active technician at {Location-A} with a sign-in account, and the staff record was renamed after the account was made, so the name in Settings > Staff differs from the account name (for example ZZAUTOTEST Account Ben).

• Customer {Customer-A} (for example "ZZAUTOTEST S5R11b Staff Names") is used by this case only.

• Approved work order {Work-order-1} (for example S10043-17671) for {Customer-A} is led by {Technician-A} and has two approved lines, {Line-1} (for example "Service - Full grease service") and {Line-2} (for example "Service - Adjust clutch").

• {Line-2} has {Technician-B} as its technician, set through Edit Line.

• In Board View, Fields to display has Lead technician and Line technicians turned on.

• The List shows the Lead Technician column.

• On the Work Orders page nothing is ticked in Status, Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip), Assigned to me is off and Search is empty.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on.

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a desktop browser window at least 1024 px wide (narrower windows show only the List, with no display switcher).

4. Your initials > Settings > Staff > New Staff Member: First Name and Last Name (for example ZZAUTOTEST Account Ana), an Email you can open, Role Technician, a Department, Location {Location-A}, Time Clock on > Save & Close. Accept the invitation email and set a password, so the person has a sign-in account. Then open the staff record again (edit icon) and change First Name and Last Name to a different name (for example ZZAUTOTEST Staffname Ana) > Save. This is {Technician-A}.

5. Do the same for a second person (for example created as ZZAUTOTEST Account Ben, renamed ZZAUTOTEST Staffname Ben). This is {Technician-B}.

6. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST S5R11b Staff Names") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

7. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Add Line. In the next New Line form type "clutch" and pick the ready-made line "Service - Adjust clutch", turn Line Approved on and click Save & Close. Write down the number shown at the top left (for example S10043-17671). This is {Work-order-1}, with {Line-1} and {Line-2}.

8. Click {Line-2}'s name to open Edit Line, choose Technicians {Technician-B} and save.

9. On the work order page pick the technician in the Lead Technician dropdown; it saves at once. Choose {Technician-A}.

10. Work Orders > All > Board View > Fields to display: turn on Lead technician and Line technicians. Then click List and, if the Lead Technician column is not shown, turn it on in the List's column chooser.

11. Check the setup worked: Settings > Staff shows {Technician-A} and {Technician-B} under their new names. Work Orders > All > List with {Customer-A}'s name in Search shows {Work-order-1} with a Lead Technician. If a person could not be renamed, the case cannot start: mark it Blocked and write why. Clear the search before you start.
