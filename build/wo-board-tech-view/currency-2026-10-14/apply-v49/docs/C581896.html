Setup: Opening Board View with Imported already selected opens List instead

Test case: C581896, WO Board and Tech View. Part 1 is for a manual QA tester. Part 2 is for a Claude session that prepares and runs the case on its own. Both create the starting state listed in the test case's Preconditions.

How to read this document: a name in braces, such as {Part-A} or {Line-1}, stands for a record you create or pick. Every brace name is defined before it is used. Wherever a value is given "for example", you may use any other value: the example is not a record that already exists in the app. Write down the real value you used for each brace name, because the test steps refer to it.

What the setup creates (the test case's Preconditions)

• You are signed in as an Owner or Admin user whose role has Work orders > View, at {Location-A} (for example Staging Heavy Duty - 9919).

• Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.

• You know the address of the site under test, {Site-A} (for example https://sv10043.qa.shopview.com).

• Imported work order {Work-order-1} (for example ZZIMP-S1R13C-1) exists at {Location-A} for customer {Customer-A} (for example "ZZAUTOTEST S1R13c Imported"); it came from an invoice import, so it is listed only when Imported is ticked in Status.

• Ordinary work order {Work-order-2} (for example S10043-17681) for {Customer-A} exists at {Location-A}.

• Your saved display on the Work Orders page is List.

• On the Work Orders page nothing is ticked in Status, Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip), Assigned to me is off and Search is empty.

Part 1. Setup for manual QA tester

1. Sign in as an Owner or Admin user. On a QA site click the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". To check the permissions: your initials (top right) > Settings > Roles & Permissions > Admin > Work orders: View and Create & Edit are on.

2. Pick one location for the whole case; it is shown in the top bar next to the bell (to change it: your initials > Change Location). This is {Location-A} (for example Staging Heavy Duty - 9919). Create everything below at {Location-A}.

3. Use a desktop browser window at least 1024 px wide (narrower windows show only the List, with no display switcher).

4. Write down the site's address as shown in the address bar up to and not including /workorders (for example https://sv10043.qa.shopview.com). This is {Site-A}.

5. Top menu Customers > New Customer > Name (for example "ZZAUTOTEST S1R13c Imported") > Save. This is {Customer-A}; use it for this case only. On the customer page click Contacts > New Contact > First Name and Last Name (for example ZZAUTOTEST Contact) > Save. Then Assets > New Asset > pick the contact, Year (for example 2022), Make (type "Freight" and pick Freightliner), Model (for example M2), Unit (for example TRK-118) > Save. Contact and Make are required.

6. Create the Imported work order from an invoice import: your initials > Settings > Invoices (in the IMPORTS group; on some builds Settings > Data Import > Invoices) > Download Template. Fill one row and keep the heading row (the columns marked * are required): Shop Location = the name of {Location-A}, Customer = the name of {Customer-A}, Invoice Number (for example ZZIMP-S1R13C-1), Invoice Date as month/day/year (for example 10/14/2026), Item Labor, a Line Title (for example ZZAUTOTEST labor), Qty 1, Rate 100, Total 100, Tax Amount 5.

7. Save the file as .csv, click Select CSV File, pick the file and click Import Invoices. The message reads "All invoices have been imported successfully." The imported work order's number is the Invoice Number you typed. This is {Work-order-1}.

8. Work Orders > Create Work Order > in the New Work Order window pick {Customer-A} and its asset > Save (if a Confirmation about the credit limit appears, click Create). The work order opens on its Lines tab with the New Line form. In What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service", turn Line Approved on and click Save & Close. Write down the number shown at the top left (for example S10043-17681). This is {Work-order-2}.

9. Go to Work Orders > All tab and click List in the display switcher (this makes List your saved display). Click Status and, if anything is ticked, click "Clear selection". Turn Assigned to me off and clear Search.

10. Check the setup worked: with Status > "Imported" ticked in List, {Work-order-1} is listed; click "Clear selection" again. Then open {Site-A}/workorders?tab=all&status=imported in the address bar: List opens with "Imported" ticked. Click "Clear selection" once more and check {Work-order-1} is no longer listed. If no Imported work order can be made, or the address does not tick Imported, the case cannot start: mark it Blocked and write why.

Part 2. Setup for Claude session

• Goal: an Imported work order, a saved display of Board View, then the page opened two ways with Imported selected: by a link, and by the saved filters.

• Create {Customer-A}, then the import file as in Part 1. UNVERIFIED on the Work Orders QA site: whether the import also creates a customer that does not exist yet; create {Customer-A} first so it does not matter.

• The link form workorders?tab=all&status=imported was observed on the Filters QA site sv8785 in August 2026 (build/filters/finish-2026-08-12/). UNVERIFIED on the rebuilt Work Orders List: that the address still carries status=imported. Part 1's check proves it before the steps.

• Saved state: the List's filters are saved per user on the server (GET/PUT /api/users/me/preferences/work-orders-list on the Filters QA site, August 2026; UNVERIFIED on this build, and the display may be a separate preference). Before step 15, read the saved preferences and record that the display is Board View and the filters hold Imported. If ticking Imported in the second tab also wrote the display back to List, record it: step 16 then cannot tell the rule apart from that, and step 11 remains the check of the kept display.

• Steps 7 and 8: hover each display button with Playwright and read the tooltip text exactly; compare it character for character with "Not available while Imported is selected."

• After step 6, read the saved preferences: opening the link must not have put Imported into the saved filters (production keeps a link's filters apart from the user's own, with a Back To My Saved Filters button on the Filters QA site in August 2026). If it did, record it: step 11 then opens List under the same rule, and the result is a question for the QA lead rather than a pass or fail.

• After the test: in List click Status > "Clear selection", so Imported is not left in your saved filters, and set the display you want to keep.

• Evidence: a screenshot after each step that has an expected result, the build marker, and the real value of every brace name.

How to work
