# C368195 — A new user's List hides the five optional columns by default
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3792516

## Preconditions
Preconditions
- Needs: 2 users · 2 browsers · about 10 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011), desktop browser, window at least 1024 px wide.
- Role: Owner/Admin. On the sign-in page click the Admin quick-login button (you appear as Admin ShopView). The Admin role has Work orders > View and Create & Edit (check: your initials (top right) > Settings > Roles & Permissions > Admin > edit).
- Location: Staging Heavy Duty - 9919 for the whole case (shown next to the bell; change it with your initials > Change Location).
- View: on Work Orders the new user shows the List (click List in the display switcher at the right of the toolbar; its tooltip reads "List").
- A brand-new user [User-N] who has never opened Work Orders, with a role that can see work orders (e.g. Technician). Name is an example ("Nora New").
Setup
- Settings > Staff > New Staff Member: First Name, Last Name, an Email you can open > Role = Technician > Departments = Service > Location = Staging Heavy Duty - 9919 > Save & Close. The new user accepts the invitation from that email and sets a password. Record the user as [User-N] (the case calls this user "Nora New").
- Check the setup worked: Settings > Staff lists [User-N]; [User-N] has not signed in or opened Work Orders before step 1.

## Steps
- As [User-N], open Work Orders, click List in the display switcher and click the All tab.
- Write down every column heading.
- Click Column Selection and read which columns are off.

## Expected (source quote — judge against this, never change it)

- Invoiced Date, Days open, Parts, Returns and Waiting On Parts are not shown (5 columns off).
- Every other column shows as it does in production today.
