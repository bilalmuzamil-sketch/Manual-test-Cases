# C97000 — No new required-story marker replaces the old check mark
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481944

## Preconditions
Preconditions
- Needs: 2 users · 2 browsers · about 15 minutes
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- [User-B]: a user whose role uses the Tech View work order mode from Roles & Permissions (e.g. a "Technician" role, Settings > Roles & Permissions > the role > Work orders > View mode = Tech view), signed in in a second browser. This is the Simple Flow tech view mode, not the Tech View display on the Work Orders page.
- Customer "ZZAUTOTEST F3 No Story Marker" (used by this case only), with one contact and one asset.
- Work order [WO-1] for this customer: status Approved, two lines — "Line 1" with a tech story and "Line 2" without one.
- Line names and story text are examples.
Setup
- Top menu Customers > New Customer, Name "ZZAUTOTEST F3 No Story Marker" > Save (skip if it already exists). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty. Record the customer as [Cust-1].
- Create a work order with two lines: Work Orders > Create Work Order > in New Work Order pick Customer [Cust-1] and its Asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line, turn Line Approved on (this makes the work order Approved) > Save & Add Line for the next line or Save & Close. Record the number shown as [WO-1]. Line names in this case (such as "Line 1") are only labels for you: the New Line form's "What Are You Doing?" box only offers ready-made lines (typed text finds no results), so pick any ready-made line for each one (e.g. "Replace - Brake pot") and write down which is which.
- Enter a tech story on Line 1 (any text) and save. Leave Line 2 without a story.
- Confirm [User-B]'s role: Settings > Roles & Permissions > the role > Work orders > View mode = Tech view. Sign [User-B] in in the second browser at the same location.
- Check the setup worked: on [WO-1]'s Lines tab, Line 1 shows its story and Line 2 has none; [User-B] can open [WO-1] in the second browser. If not, fix it before starting.

## Steps
- Open the work order [WO-1] and click the Lines tab.
- Look at both lines for any marker about the tech story (an icon, badge or colour).
- Repeat in the second browser (Tech View work order mode, as [User-B]).
