# C614717 — Design: Name bubbles show above row and card avatars, headings keep a plain tip
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/4006369

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role at {Location-A}.
For example: {Location-A} is Staging Heavy Duty - 9919.
- Six technicians are active at {Location-A} with the "Technician" role: {Technician-A}, {Technician-B}, {Technician-C}, {Technician-D}, {Technician-E} and {Technician-F}.
For example: {Technician-A} to {Technician-F} are ZZAUTOTEST N4 Ana, Ben, Cal, Dee, Eve and Fay.
- Customer {Customer-A} has an Approved work order {Work-order-1}, led by {Technician-A}, with five approved lines whose technicians are {Technician-B} to {Technician-F}, so its avatars end in "+N". Board View's "Fields to display" has "Line technicians" on.
For example: {Customer-A} is ZZAUTOTEST N4 Name Bubbles and {Work-order-1} is S10043-17931.
- Starting screen: "Work Orders" > "All" tab, "Tech View" shown, the name of {Customer-A} in "Search", no filter chosen, "Assigned to me" off, in a browser window at least 1024 px wide.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Hover the first avatar in the "Assigned Techs" cell of the row for {Work-order-1}.
- Hover the "+N" at the end of that cell.
- Hover the avatar in {Technician-A}'s group header.
- Click "Board View" in the display switcher.
- Hover the first technician avatar on the card for {Work-order-1}.
- Hover the "+N" on that card.
- Hover the avatar in {Technician-A}'s column header.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: a name bubble with {Technician-A}'s name opens above the avatar.
- Step 2: a name bubble listing the remaining names opens above the "+N".
- Step 3: the browser's plain name tip shows {Technician-A}'s name, not the bubble.
- Step 4: Board View shows the card for {Work-order-1} with its technician avatars.
- Step 5: a name bubble with {Technician-A}'s name opens above the avatar.
- Step 6: a name bubble listing the remaining names opens above the "+N".
- Step 7: the browser's plain name tip shows {Technician-A}'s name, not the bubble.
Source — where this behaviour comes from
Epic SV-10043; stories SV-10045 (Story 2, Tech View), SV-10046 (Story 3, Board View), SV-10050 (Story 7, Line technicians); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 61 (16 Oct 2026, Chris Ward), S2-R23, S7-R6 and S2-R10, read 16 Oct 2026. The name-bubble sentence of S2-R23 was added in versions 60 and 61 on 16 Oct 2026 (Chris Ward rulings on the QA triage of SV-11395, SV-11397, SV-11422 and SV-11421). Source-verified 16 October 2026.
Exact quotes from the source (for reproducibility)
- S2-R23: “In Tech View and Board View, as in the design: a technician avatar without a photo is a light-grey circle (--sv-grey-100, #EEF2F6) with initials in --sv-grey-600 (#4B5565) in light mode, which meets accessible contrast (6.7:1; the design file’s #697586 is 4.2:1); dark mode uses the design’s dark colors; group and column header names are 14px, weight 600, in the design’s slate text color (#364152), with the design’s smaller, lighter initials; Board card customer and total price are weight 500; toolbar and switcher icons are the design’s slate color (the switcher in List too, S1-R9a). Technician avatars, and the Service Advisor avatar, follow density in Tech View as in the design: 20px, 24px and 32px on rows and 24px, 28px and 36px on group headers at Compact, Regular and Comfortable; Board View card avatars stay 24px. The Progress bar is 48 by 4px at Compact, as in the design. The name bubble on hover over a technician avatar on a row or card (the +N included) opens above the avatar, in both views; group and column header avatars keep the browser’s plain name tip, because the name is printed beside them. In Tech View, Status, Waiting On Parts and Progress are left-aligned. The Density and Columns tooltips open above their button, like the switcher’s (S1-R9b), and are hidden while their menu is open. List is unchanged.”
- S7-R6: “Keep every involved technician discoverable by name.”
- S2-R10: “Hovering a technician header or avatar reveals the technician’s name.”
