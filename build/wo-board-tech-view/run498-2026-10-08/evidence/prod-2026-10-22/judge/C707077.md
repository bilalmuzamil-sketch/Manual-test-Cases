# C707077 — The Lines tab and Edit Line name the technician by their staff record name
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/4101036

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role at {Location-A}, in a browser window at least 1024 px wide.
For example: {Location-A} is Staging Heavy Duty - 9919.
- Technician {Technician-A} is active at {Location-A}, and the name on their staff record differs from the name on their login account.
For example: the staff record reads ZZAUTOTEST C11577 Ana Staff and the login account reads ZZAUTOTEST C11577 Ana Login.
- Work order {Work-order-1} is Approved, led by {Technician-A}, and has one approved line, {Line-1}, with {Technician-A} as its technician.
For example: {Work-order-1} is S2-37701 and {Line-1} is "Service - Full grease service".
- Starting screen: {Work-order-1} is open on its "Lines" tab.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Read the technician name in {Line-1}'s Labor text.
- Read the technician name in {Line-1}'s technician list (roster).
- Click {Line-1}'s name to open Edit Line.
- Read the technician name under Technicians.
- Click "Cancel".
- Open "Work Orders", click the "All" tab and click "Board View".
- Read the technician name on {Work-order-1}'s card and its column header.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: the Labor text names the technician by their staff record name, for example ZZAUTOTEST C11577 Ana Staff.
- Step 2: the roster shows the same staff record name, not the login account name.
- Step 3: Edit Line opens.
- Step 4: Technicians shows the same staff record name.
- Step 5: Edit Line closes and nothing changes.
- Step 6: Board View shows.
- Step 7: the card and the column header show the same staff record name.
Known problem (SV-11577, In Progress; this release if it fits, otherwise a fast follow): the roster and Edit Line show the login account name while the Labor text shows the staff record name, so one person appears under two names.
