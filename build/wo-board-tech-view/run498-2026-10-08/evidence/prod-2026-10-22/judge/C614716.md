# C614716 — Design: Density and Columns tips show above their buttons, hidden while open
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/4006368

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in as an Admin user (the "Admin" role, which has Work orders > View and Create & Edit) at {Location-A}.
For example: {Location-A} is Staging Heavy Duty - 9919.
- The browser window is 1440 px wide with the zoom at 100%.
- Customer {Customer-A} has an Approved work order {Work-order-1}, led by technician {Technician-A}.
For example: {Customer-A} is ZZAUTOTEST N3 Tooltips, {Work-order-1} is S10043-17921 and {Technician-A} is ZZAUTOTEST N3 Tia.
- Starting screen: "Work Orders" > "All" tab, "Tech View" shown, the name of {Customer-A} in "Search", no filter chosen, "Assigned to me" off.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Hover the density button.
- Click the density button.
- Press Escape.
- Hover the "Column Selection" button.
- Click the "Column Selection" button.
- Press Escape.
- Hover the "Tech View" button in the display switcher.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: the density button's tooltip opens above the button and does not cover the table's column header row.
- Step 2: the density menu opens and no tooltip shows while it is open.
- Step 3: the menu closes.
- Step 4: the "Column Selection" button's tooltip opens above the button.
- Step 5: the column menu opens and no tooltip shows while it is open.
- Step 6: the menu closes.
- Step 7: the switcher's tooltip opens above it too, the same way as the two buttons' tooltips.
Source — where this behaviour comes from
Epic SV-10043; story SV-10045 (Story 2, Tech View); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 61 (16 Oct 2026, Chris Ward), S2-R23 and S1-R9b, read 16 Oct 2026. The tooltip sentence of S2-R23 was added in version 55 on 15 Oct 2026 (Chris Ward ruling on Slavcho Mitrov's v54 follow-up questions). Source-verified 16 October 2026. Last checked against build v26.40.19-1493c63 (staging) on 10/16/2026.
Exact quotes from the source (for reproducibility)
- S2-R23: “In Tech View and Board View, as in the design: a technician avatar without a photo is a light-grey circle (--sv-grey-100, #EEF2F6) with initials in --sv-grey-600 (#4B5565) in light mode, which meets accessible contrast (6.7:1; the design file’s #697586 is 4.2:1); dark mode uses the design’s dark colors; group and column header names are 14px, weight 600, in the design’s slate text color (#364152), with the design’s smaller, lighter initials; Board card customer and total price are weight 500; toolbar and switcher icons are the design’s slate color (the switcher in List too, S1-R9a). Technician avatars, and the Service Advisor avatar, follow density in Tech View as in the design: 20px, 24px and 32px on rows and 24px, 28px and 36px on group headers at Compact, Regular and Comfortable; Board View card avatars stay 24px. The Progress bar is 48 by 4px at Compact, as in the design. The name bubble on hover over a technician avatar on a row or card (the +N included) opens above the avatar, in both views; group and column header avatars keep the browser’s plain name tip, because the name is printed beside them. In Tech View, Status, Waiting On Parts and Progress are left-aligned. The Density and Columns tooltips open above their button, like the switcher’s (S1-R9b), and are hidden while their menu is open. List is unchanged.”
- S1-R9b: “The switcher’s hover tooltip opens above the switcher, so it never covers the table’s column header row. The tooltips read List, Tech View and Board View.”
