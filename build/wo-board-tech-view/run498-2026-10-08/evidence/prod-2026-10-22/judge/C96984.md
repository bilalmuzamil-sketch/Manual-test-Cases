# C96984 — No unit number shows the asset instead, and a real zero still shows
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481928

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 20 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- One technician at this location: [Tech-A] (e.g. "Esther Howard"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Unit Fallback" (used by this case only), with one contact and the assets below (the expected results name "TRK-118" and "1999 Ford Explorer", so keep them).
- Four work orders for that customer, all led by [Tech-A]:- (a) [WO-a]: asset with unit "TRK-118" and "2022 Freightliner M2".
- (b) [WO-b]: asset with no unit number and "1999 Ford Explorer".
- (c) asset with no unit number and no year, make or model (this cannot be made by hand on this test site: the New Asset form will not save without a Make; skip (c) and write "(c) not built - an asset needs a Make" in the result comment).
- (d) [WO-d]: a work order with no lines (0 lines, $0.00 total, 0% progress).
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Unit Fallback" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit 2022, Freightliner, M2, TRK-118 > Save. Make is required; Unit can be left empty. Add a second asset: Year 1999, Make Ford, Model Explorer, Unit left empty > Save.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Unit Fallback" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "W

## Steps
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type ZZAUTOTEST F2 Unit Fallback in Search.
- Open Fields to display and turn on line count, total price and progress (keep the defaults on).
- Read each card on the board (all four, or three if (c) could not be made; see the preconditions).

## Expected (source quote — judge against this, never change it)
Expected results
- (a) shows "TRK-118" and its asset. (b) shows "1999 Ford Explorer" where the unit would be.
- (c) shows neither a unit nor an asset line (nothing invented, no blank placeholder).
- (d) shows its zero values as values: line count 0, total price $0.00 and progress 0%, not left out.
Source — where this behaviour comes from
Epic SV-10043; story SV-10048 (Story 5, Fields to display (Board View) and columns (Tech View)); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S5-E1, S5-E5, S5-E4, read 8 Oct 2026. Review Decisions SQ-14 / DR-29. Source-verified 8 October 2026.
Exact quotes from the source (for reproducibility)
- S5-E1: “If unit number is missing, use available asset year/make/model in its place.”
- S5-E5: “If both unit number and fallback asset details are missing, omit that content.”
- S5-E4: “Do not treat a valid zero as a missing value.”
