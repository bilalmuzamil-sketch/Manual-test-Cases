## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- Technician {Technician-A} (for example Esther Howard) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.
- Customer {Customer-A} (for example "ZZAUTOTEST F1 Tabs") has exactly three work orders, all led by {Technician-A}: {Work-order-1} (for example S10043-17616) in Estimate, {Work-order-2} (for example S10043-17617) in Approved, and {Work-order-3} (for example S10043-17618) in Complete.

- Click the All tab and write down which of {Work-order-1}, {Work-order-2} and {Work-order-3} appear in {Technician-A}'s column.
- Click the Work Orders tab and write down which of {Work-order-1}, {Work-order-2} and {Work-order-3} appear in {Technician-A}'s column.

## Expected (source quote — judge against this, never change it)
Expected results
- Steps 3 to 16: all four tabs (All, Work Orders, Estimates, Completed) show in every display. Which tab opens first is not checked by this case: the default tab was taken out of scope and stays as production has it today.
- Steps 3, 8 and 13: All shows {Work-order-1}, {Work-order-2} and {Work-order-3}.
- Steps 4, 9 and 14: Work Orders shows {Work-order-2} only.
- Steps 5, 10 and 15: Estimates shows {Work-order-1} only.
- Steps 6, 11 and 16: Completed shows {Work-order-3} only.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 52 (14 Oct 2026, Chris Ward), Feature Overview (its filter sentence was reworded in version 52 to name the Technician filter as the second exception, after Imported; the tabs are unchanged, so the expected results are unchanged) and Key Decisions (Permissions), read 14 Oct 2026. PO decision Chris Ward, PRD footer comment 25 Sep 2026 ("The default-tab change is out too"). Review Decisions 853901313 DR-33. Source-verified 14 October 2026. Last checked against build v26.40.8-7a95011 on 10/8/2026.
Exact quotes from the source (for reproducibility)
- Feature Overview: “The existing filter views (the tabs on the left — All, Work Orders, Estimates, Completed) and the filter bar (search, status, assigned to me, and so on) apply the same way in every display option.”
- Feature Overview (the two exceptions): “Imported work orders are one exception: they open in List only (S1-R13a, S1-R13b). The Technician filter is the other: Tech View and Board View offer it and List does not (S1-R15).”
- Key Decisions: “Permissions. Work Orders view permits viewing all four filter tabs and reordering technician groups/columns.”
