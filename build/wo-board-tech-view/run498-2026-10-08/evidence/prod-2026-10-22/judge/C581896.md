# C581896 — Opening Board View with Imported already selected opens List instead
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3974852

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- You know the address of the site under test, {Site-A} (for example https://app.staging.shopview.com).
- Imported work order {Work-order-1} (for example ZZIMP-S1R13C-1) exists at {Location-A} for customer {Customer-A} (for example "ZZAUTOTEST S1R13c Imported"); it came from an invoice import, so it is listed only when Imported is ticked in Status.
- Ordinary work order {Work-order-2} (for example S10043-17681) for {Customer-A} exists at {Location-A}.
- Your saved display on the Work Orders page is List.
- On the Work Orders page nothing is ticked in Status, Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip), Assigned to me is off and Search is empty.

## Steps
- Open Work Orders from the top menu and click the All tab.
- Open a second browser tab and open {Site-A}/workorders in it.
- Go back to the first tab.
- Click Board View in the display switcher.
- Open a third browser tab and open {Site-A}/workorders?tab=all&status=imported in it.
- Read which display is shown and what is ticked in Status.
- Hover Board View in the display switcher and read its tooltip.
- Hover Tech View in the display switcher and read its tooltip.
- Close the third tab.
- Open a new browser tab and open {Site-A}/workorders in it.
- Read which display is shown.
- Close this tab.
- Go to the second tab, which still shows List.
- Click Status and tick "Imported".
- Open a new browser tab and open {Site-A}/workorders in it.
- Read which display is shown and what is ticked in Status.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 6: the page opens in List, not Board View. "Imported" is ticked in Status and {Work-order-1} is listed.
- Steps 7 and 8: Board View and Tech View are greyed out, each with the tooltip "Not available while Imported is selected."
- Step 11: without Imported the page opens in Board View, because opening the link did not change your saved display.
- Step 16: the page opens in List with "Imported" still ticked and {Work-order-1} listed, and Board View and Tech View are greyed out.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 49 (14 Oct 2026, Chris Ward), S1-R13c (added in version 49 from Chris Ward's answer 7 of 14 Oct 2026 to our question sheet) and S1-R13a, read 14 Oct 2026. Secondary: Work Orders Board View & Tech View Display Options Technical Implementation Plan (revised 24 Sep 2026, uploaded 8 Oct 2026), section 3.26. Source-verified 14 October 2026. Not yet checked against a build.
Exact quotes from the source (for reproducibility)
- S1-R13c: “A link or saved filter that opens Board View or Tech View with "Imported" selected opens the page in List instead, with Imported still selected and Board View and Tech View greyed out as in S1-R13a. The user's saved display is not changed, so their next visit without Imported opens it.”
- S1-R13a: “Imported work orders open in List only. While "Imported" is selected in the Status filter in List, the Board View and Tech View options are greyed out with the tooltip "Not available while Imported is selected."”
- Tech plan 3.26 Imported: “A saved filter that contains Imported opens in List.”
