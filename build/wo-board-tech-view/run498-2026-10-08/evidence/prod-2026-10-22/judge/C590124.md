# C590124 — Design: Hovering greys a row, darkens a card edge and shows dark name bubbles
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3995733

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as {User-A} (for example Admin ShopView), an Owner or Admin user whose role has Work orders > View, Work orders > Create & Edit and See financial data, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is 1440 px wide, with the browser zoom at 100%.
- The design pictures DC-15-tech-row-hover-light-1440.png, DC-15-board-card-hover-light-1440.png and DC-15-avatar-hover-light-1440.png are open beside the app at 100% zoom (actual size); they are attached to this case.
- In the design pictures the names, numbers, dates and amounts are sample data, and the rank numbers (1, 2, 3 …) beside rows and cards are left out of this release, so do not compare those.
- Technician {Technician-A} (for example ZZAUTOTEST DC15 Vic Hover) is an active technician at {Location-A}.
- Technician {Technician-B} (for example ZZAUTOTEST DC15 Wes Hover) is an active technician at {Location-A}.
- Customer {Customer-A} (for example "ZZAUTOTEST DC15 Hover Looks") is used by this case only.
- Approved work order {Work-order-1} (for example S10043-17844) for {Customer-A} is led by {Technician-A} and has one approved line, {Line-1} (for example "Service - Full grease service"), whose technician is {Technician-B}.
- In Board View, Fields to display has Line technicians turned on.
- On the Work Orders page nothing is chosen in any filter (if the Asset on Site chip shows Yes or No, click the x on the chip), Assigned to me is off, Search is empty and density is Regular (the default).

## Steps
- Open Work Orders, click the All tab and click Tech View in the display switcher.
- Hover {Work-order-1}'s row.
- Hover the first avatar in the row's Assigned Techs cell.
- Click Board View in the display switcher.
- Hover {Work-order-1}'s card.
- Hover the first avatar at the bottom left of the card.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 2: the row's background turns light grey; nothing in the row moves or grows, as in the row-hover design picture.
- Step 3: a small dark bubble with light text shows {Technician-A}'s name above the avatar, as in the avatar-hover design picture.
- Step 5: the card's border darkens and a soft shadow appears; the card does not grow or move, as in the card-hover design picture.
- Step 6: the same small dark bubble shows {Technician-A}'s name above the avatar.
Source — where this behaviour comes from
Epic SV-10043; stories SV-10045 (Story 2, Tech View), SV-10046 (Story 3, Board View), SV-10050 (Story 7, Line technicians); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 52 (14 Oct 2026, Chris Ward), S2-R10, S7-R2 and S3-R13, read 14 Oct 2026; Claude Design project "Work Orders" (Branko Cicovic), export of 14 Oct 2026, board "Work Orders.dc.html", states states__work-orders__tech-row-hover__light__1440, states__work-orders__board-card-hover__light__1440 and states__work-orders__tech-avatar-stack-hover__light__1440 (design pictures DC-15-tech-row-hover-light-1440.png, DC-15-board-card-hover-light-1440.png, DC-15-avatar-hover-light-1440.png, rendered from that export at the width in the name), read 14 Oct 2026. Where the PRD says nothing about the look, the design is the source. Source-verified 14 October 2026. Last checked against build v26.40.17-a5c4210 (staging) on 10/15/2026.
Exact quotes from the source (for reproducibility)
- S2-R10: “Hovering a technician header or avatar reveals the technician’s name.”
- S7-R2: “Use each visible avatar’s own visible area as its hover target.”
- S3-R13: “Reveal the card’s more-actions overlay on hover or keyboard focus.”
- Design — README.md (design library), hover: “Hover is a colour shift plus a lift (elev-1 → elev-2), never a scale.”
- Design — _ds_bundle.js (design library), avatar group: “Overlapping avatars, last one a +n counter. Hovering a circle names the tech; hovering +n lists the rest.”
- Design — _ds_bundle.js (design library), avatar group name bubble: “bottom: 'calc(100% + 6px)',”
- Design — Work Orders.dc.html, Tech View row hover: “style-hover="background: var(--sv-surface-hover);"”
