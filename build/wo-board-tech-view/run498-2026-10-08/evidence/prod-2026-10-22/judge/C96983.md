# C96983 — If saved field choices can't load, the defaults show and the next change saves
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481927

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- Approved work order {Work-order-1} (for example S10043-17603) for customer {Customer-A} (for example "ZZAUTOTEST F2 Saved Choice Failure") has one approved line, {Line-1} (for example "Service - Full grease service"), and no lead technician, so it shows in Unassigned.
- Created date is off in Board View's Fields to display.
- For steps 6 to 11 a developer has made your saved field and column choices fail to load on this test site; this cannot be caused from the product. If that has not been done, run steps 1 to 5 only and write "load failure not checked by hand" in the result comment.

## Steps
- Open Work Orders, click the All tab and click Board View in the display switcher.
- Click Fields to display and write down the fields that are on.
- Turn Created date on.
- Reload the page.
- Click Fields to display and read whether Created date is on.
- With the load failure in place, reload the page.
- Click Fields to display and write down the fields that are on.
- Click Tech View in the display switcher and write down the columns shown, left to right.
- Click Board View in the display switcher, click Fields to display and turn Created date on.
- When the developer has removed the load failure, reload the page.
- Click Fields to display and read whether Created date is on.

## Expected (source quote — judge against this, never change it)
Expected results
- Steps 4 and 5: Created date is still on after the reload (a normal save).
- Steps 6 and 7: Board View shows its default fields: lead technician name, work order number, customer, unit number, asset, progress, total price and status.
- Step 8: Tech View shows its starting columns, in this order: Status, Waiting On Parts, Number, Customer, Unit, Asset, Progress, Service Advisor, Clocked In, Lines, Assigned Techs, Created on, Total price.
- Steps 10 and 11: the field choice made after the failure (Created date on) was saved and is still on after the reload.
Source — where this behaviour comes from
Epic SV-10043; story SV-10048 (Story 5, Fields to display (Board View) and columns (Tech View)); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 54 (15 Oct 2026, Chris Ward), S5-N2, S5-N3, S5-R13 and S5-R4 (S5-R4 rewritten in version 51 on 14 Oct 2026 (Chris Ward ruling after Sasha Grosman's staging review: Tech View's default columns are the design's 13, and Assigned Techs is on by default); Tech View's starting columns were the List defaults before), read 15 Oct 2026. Technical Implementation Plan Phase 4 (after a failed preference load the next save re-reads and merges). Product owner answers: Chris Ward, WO Board and Tech View question sheet (https://docs.google.com/spreadsheets/d/1gBGmNB4B1bRrD2ZJvBn1tuvbfxFPjcsKddz_I5H3CvU), answer 14, read 15 Oct 2026. In version 54 S5-R4 gained one sentence (column headings use List's labels, for example Unit, and Assigned Techs); the default columns and their order are unchanged, so the expected results are unchanged. Source-verified 15 October 2026. Last checked against build v26.40.19-72f4f3b (staging) on 10/16/2026.
Exact quotes from the source (for reproducibility)
- S5-N2: “If field preferences cannot load, use Tech View’s starting columns (S5-R4) or Board View’s default fields for the current display.”
- S5-R13: “Board View’s default selection is lead technician name, work order number, customer, unit number, asset, progress, total price, and mandatory status, subject to financial permission.”
- S5-R4: “Until the user changes Tech View’s columns, Tech View shows these columns, in this order, as in the design: Status, Waiting On Parts, Number, Customer, Unit, Asset, Progress, Service Advisor, Clocked In, Lines, Assigned Techs, Created on, Total price (Total price subject to financial permission). On Site, VIN/Serial # and Lead Technician are off by default; each can be added with the column chooser (S2-R4). Column headings use the List’s labels for List columns (for example Unit, not Unit #) and Assigned Techs for the new column. List’s columns are unchanged.”
- S5-N3: “Save the user’s next field selection after a preference-load failure.”
