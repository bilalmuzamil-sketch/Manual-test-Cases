# C682445 — Two people reorder one column at once and each moved card keeps its place
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/4062446

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role at {Location-A} in two separate browsers (for example Chrome and a Chrome private window), each window at least 1024 px wide.
For example: {Location-A} is Staging Heavy Duty - 9919.
- Technician {Technician-A} is active at {Location-A}.
For example: ZZAUTOTEST C682445 Ana.
- Customer {Customer-A} has three Approved work orders led by {Technician-A}, and in Board View {Technician-A}'s column lists them in this order: {Work-order-1}, {Work-order-2}, {Work-order-3}.
For example: {Customer-A} is ZZAUTOTEST C682445 Two People, and the work orders are S2-37378, S2-37380 and S2-37377.
- Starting screen, in both browsers: "Work Orders" > "All" tab, "Board View" shown.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- In browser 1, type the name of {Customer-A} in "Search".
- In browser 2, type the name of {Customer-A} in "Search".
- In browser 1, drag {Work-order-3} to the top of {Technician-A}'s column.
- In browser 2, without refreshing, drag {Work-order-2} to the top of {Technician-A}'s column.
- Refresh browser 1.
- Refresh browser 2.
- In browser 1, click "Tech View".

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: {Technician-A}'s column reads {Work-order-1}, {Work-order-2}, {Work-order-3}.
- Step 2: browser 2 shows the same order: {Work-order-1}, {Work-order-2}, {Work-order-3}.
- Step 3: browser 1 shows {Work-order-3}, {Work-order-1}, {Work-order-2}. No message appears.
- Step 4: browser 2 shows {Work-order-2}, {Work-order-1}, {Work-order-3}. No message appears in either browser.
- Step 5: browser 1 shows {Work-order-2}, {Work-order-3}, {Work-order-1}, with no warning.
- Step 6: browser 2 shows the same order, {Work-order-2}, {Work-order-3}, {Work-order-1}, with no warning.
- Step 7: {Technician-A}'s group in Tech View lists {Work-order-2}, {Work-order-3}, {Work-order-1}.
