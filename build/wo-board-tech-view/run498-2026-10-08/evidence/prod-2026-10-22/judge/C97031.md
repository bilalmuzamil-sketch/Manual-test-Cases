# C97031 — Header counts change by exactly one after a move, with nothing counted twice
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481969

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 30 minutes
- Build: the Work Orders QA build (sv10043). Desktop browser window at least 1024 px wide (narrower windows show only the List, without the display switcher).
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders). This user is the dispatcher.
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location. Every technician and work order below belongs to this location.
- Technicians (examples, the expected results call them by first name or full name): "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo", "ZZAUTOTEST Cal Charlie". A staff member counts as a technician when, in Settings > Staff > the staff member's edit icon > Edit Staff Member, they are Active, Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customers (used by this case only, each with one contact and one asset): "ZZAUTOTEST F3 Count After Move Alpha Co", "ZZAUTOTEST F3 Count After Move Bravo Co", "ZZAUTOTEST F3 Count After Move Charlie Co", "ZZAUTOTEST F3 Count After Move Delta Co", "ZZAUTOTEST F3 Count After Move Echo Co", "ZZAUTOTEST F3 Count After Move Golf Co", "ZZAUTOTEST F3 Count After Move Hotel Co". The steps and expected results call them by the end of the name ("Alpha Co", "Bravo Co", "Charlie Co", "Delta Co", "Echo Co", "Golf Co", "Hotel Co").
- Exactly these work orders for this case:- Lead Ana: Alpha Co Approved, Bravo Co Approved, Charlie Co Estimate (3).
- Lead Ben: Delta Co In Progress, Echo Co Invoiced (2).
- Lead Cal: none (0).
- No lead: Golf Co Approved, Hotel Co Estimate (2).
- Total: 3 + 2 + 0 + 2 = 7.
- None of these technicians has a shift on the Schedule for these work orders (check the Schedule page). If a window titled "Clear … scheduled shifts?" still appears during a move, click "Keep shifts".
Setup
- Settings (your initials at the top right > Settings) > Staff: confirm "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo", "ZZAUTOTEST Cal Charlie" exist and count as technicians at this location (edit icon > Edit Staff Member). To add one: New Staff Member with those settings (at least one Department is required) (e.g. first name "ZZAUTOTEST Ana", last name "Alpha") > Save & Close.
- Create this case's customers: "ZZAUTOTEST F3 Count After Move Alpha Co", "ZZAUTOTEST F3 Count After Move Bravo Co", "ZZAUTOTEST F3 Count After Move Charlie Co", "ZZAUTOTEST F3 Count After Move Delta Co", "ZZAUTOTEST F3 Count After Move Echo Co", "ZZAUTOTEST F3 Count After Move Golf Co", "ZZAUTOTEST F3 Count After Move Hotel Co". For each: top menu Customers > New Customer, Name > Save

## Steps
- Open Work Orders from the top menu and click the All tab.
- Type "ZZAUTOTEST F3 Count After Move" in Search so only this case's work orders show.
- Click Board View in the display switcher (tooltip "Board View").
- Write down the counts (Unassigned 2, Ana 3, Ben 2, Cal 0, total 7).
- Drag Alpha Co from Ana to Cal and read the counts without reloading.
- Open Bravo Co's more-actions > "Reassign lead technician" > Unassigned. Read the counts.
- Drag Golf Co inside the Unassigned column above Hotel Co. Read the counts.
- Try to drag Echo Co (Invoiced) from Ben to Cal. Read the counts.
- Click Tech View in the display switcher at the right of the toolbar (tooltip "Tech View").
- Read every group count, then refresh and read them again.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 5: Ana 3 − 1 = 2, Cal 0 + 1 = 1, others unchanged. Total 7.
- Step 6: Ana 2 − 1 = 1, Unassigned 2 + 1 = 3. Total 7.
- Step 7 (reorder only): no count changes.
- Step 8 (refused move): no count changes.
- Steps 9 and 10: Tech View shows Unassigned 3, Ana 1, Ben 2, Cal 1 (3 + 1 + 2 + 1 = 7) before and after the refresh. Each count changed right after the move, with no reload.

- S9-R5: “Successful between-technician moves use Story 4’s feedback and count updates.”
