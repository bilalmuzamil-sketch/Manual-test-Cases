# C96940 — Board View has a column per technician plus Unassigned, counts match cards
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481884

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 20 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Three technicians at this location: "Esther Howard", "Ralph Edwards" and "Jenny Wilson" (the expected results name them, so keep these names). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Board Columns" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Seven work orders for that customer: Esther Howard leads three ([WO-1] Approved, [WO-2] Approved, [WO-3] Estimate); Ralph Edwards leads two ([WO-4], [WO-5]); Jenny Wilson leads none; [WO-6] and [WO-7] have no lead.
- What must hold: the counts Unassigned 2, Esther Howard 3 (2 Approved, 1 Estimate), Ralph Edwards 2, Jenny Wilson 0 for this customer.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as "Esther Howard" (keep this name, the expected results use it); "Ralph Edwards" (keep this name, the expected results use it); "Jenny Wilson" (keep this name, the expected results use it).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Board Columns" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Board Columns" and its asset > Save. The work order opens on its Lines tab with the New Line form open:

## Steps
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- Click Search and type ZZAUTOTEST F2 Board Columns so only this test's work orders show.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Read every column header: name, avatar and number.
- Count the cards in each column.
- Open the Status filter, tick Approved only and close it.
- Read Esther Howard's number and count her cards again.

## Expected (source quote — judge against this, never change it)
Expected results
- There is one column for each eligible technician (Esther Howard, Ralph Edwards, Jenny Wilson) plus an Unassigned column.
- Each header shows the name, the avatar (photo or initials) and a number equal to its cards: Unassigned 2, Esther Howard 3, Ralph Edwards 2, Jenny Wilson 0.
- After filtering to Approved, Esther Howard's header shows 2 and 2 cards are listed (3 - 1 Estimate = 2).
Source — where this behaviour comes from
Epic SV-10043; story SV-10046 (Story 3, Board View — board by lead technician); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S3-R1, S3-R12, read 8 Oct 2026. Design: Claude Design export of 8 Oct 2026 (Work Orders.dc.html), Board column header (count tooltip "N work orders"); on-screen labels only.
Exact quotes from the source (for reproducibility)
- S3-R1: “Show one Board View column per eligible technician under S2-R7, plus Unassigned.”
- S3-R12: “Each column header shows the technician’s name, avatar, and a count of the work orders currently shown in that column, after the filter view and filters are applied, so the count always matches the cards listed.”
