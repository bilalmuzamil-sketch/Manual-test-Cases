# C96939 — Up to three technician groups can be pinned in Tech View
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481883

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Five technicians at this location: "Esther Howard", "Ralph Edwards", "Jenny Wilson", "Theresa Webb", "Kristin Watson" (the expected results name four of them, so keep these names). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Tech Pin Limit" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Five Approved work orders for that customer, one led by each technician.
- Start with no pins for [User-A] (unpin anyone pinned).
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as "Esther Howard", "Ralph Edwards", "Jenny Wilson", "Theresa Webb" and "Kristin Watson" (keep these names).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Tech Pin Limit" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Tech Pin Limit" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for five work orders in all (numbers on this site look like "S100

## Steps
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- Click Search and type ZZAUTOTEST F2 Tech Pin Limit so only this test's work orders show.
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Click the pin control on Ralph Edwards' group header.
- Pin Theresa Webb.
- Pin Kristin Watson.
- Hover the pin control on Esther Howard's group header and try to click it.

## Expected (source quote — judge against this, never change it)
Expected results
- Each technician group header has a pin control.
- Ralph Edwards, Theresa Webb and Kristin Watson can all be pinned (3 pins).
- A fourth pin is not possible: Esther Howard's pin control is disabled.
- The design shows pin controls only on Board View columns: if Tech View has no pin control at all, it is a fail.
