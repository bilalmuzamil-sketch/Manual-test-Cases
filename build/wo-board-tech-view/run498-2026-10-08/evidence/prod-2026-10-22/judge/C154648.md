# C154648 — Tech View and Board View are unavailable while Imported is selected
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481974

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- Imported work order {Work-order-1} (for example ZZIMP-154648-1) exists at {Location-A} for customer {Customer-A} (for example "ZZAUTOTEST C154648 Imported"); it came from an invoice import, so it is listed only when Imported is ticked in Status.
- Ordinary work order {Work-order-2} (for example S10043-17581) for {Customer-A} exists at {Location-A}.
- On the Work Orders page nothing is ticked in the Status filter and Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip).

## Steps
- Open Work Orders from the top menu and click the All tab.
- Click List in the display switcher at the right of the toolbar.
- Click Status and tick "Imported".
- Hover the Tech View button in the display switcher and read its tooltip.
- Click the Tech View button.
- Hover the Board View button in the display switcher and read its tooltip.
- Click the Board View button.
- Click Status and click "Clear selection".
- Click Tech View in the display switcher.
- Click Status.
- Hover the "Imported" option and read its tooltip.
- Try to tick "Imported".
- Click Board View in the display switcher.
- Click Status.
- Hover the "Imported" option and read its tooltip.
- Try to tick "Imported".

## Expected (source quote — judge against this, never change it)
Expected results
- Step 3: the List shows the Imported work orders, including {Work-order-1}.
- Steps 4 and 6: the Tech View and Board View buttons are greyed out. Hovering each shows the tooltip "Not available while Imported is selected."
- Steps 5 and 7: neither button opens its display. The page stays on List and keeps showing {Work-order-1}.
- Step 9: with Imported no longer selected, Tech View opens.
- Steps 11 and 12: in Tech View the "Imported" option in Status is greyed out with the tooltip "Imported work orders open in List." It cannot be ticked.
- Steps 15 and 16: in Board View the "Imported" option in Status is greyed out with the same tooltip, "Imported work orders open in List." It cannot be ticked.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 48 (12 Oct 2026, Chris Ward), S1-R1, S1-R13a and S1-R13b (added in version 48) with their context note (engineering proposal 17 Sep 2026, agreed by Sasha Grosman 24 Sep 2026, confirmed by Chris Ward 12 Oct 2026), read 14 Oct 2026. Secondary: Work Orders Board View & Tech View Display Options Technical Implementation Plan (revised 24 Sep 2026, uploaded 8 Oct 2026), section 1.4 (follow-up A3) and section 3.26. Source-verified 14 October 2026.
Exact quotes from the source (for reproducibility)
- S1-R13a: “Imported work orders open in List only. While "Imported" is selected in the Status filter in List, the Board View and Tech View options are greyed out with the tooltip "Not available while Imported is selected."”
- S1-R1: “The Work Orders toolbar offers List, Tech View, and Board View display options.”
- S1-R13b: “In Board View and Tech View, "Imported" is greyed out in the Status filter with the tooltip "Imported work orders open in List."”
- Tech plan 3.26 Imported: “Imported is excluded from the board displays (follow-up A3). While the Imported status chip is selected, Tech View and Board View are disabled in the switcher with a tooltip; while in Tech View or Board View, the Imported option in the Status filter is disabled.”
