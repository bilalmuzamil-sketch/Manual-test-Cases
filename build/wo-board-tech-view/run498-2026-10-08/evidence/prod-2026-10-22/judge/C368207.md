# C368207 — A view-only user sees no Create Work Order button in the List
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3792528

## Preconditions
Preconditions
- Needs: 2 users · 2 browsers · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011), desktop browser, window at least 1024 px wide.
- Role: Owner/Admin. On the sign-in page click the Admin quick-login button (you appear as Admin ShopView). The Admin role has Work orders > View and Create & Edit (check: your initials (top right) > Settings > Roles & Permissions > Admin > edit). (for the setup).
- Location: Staging Heavy Duty - 9919 for the whole case (shown next to the bell; change it with your initials > Change Location).
- View: on Work Orders the List is shown (click List in the display switcher at the right of the toolbar; its tooltip reads "List").
- A second user [User-V] whose role has Work orders > View on and Create & Edit off (custom role "ZZAUTOTEST WO View Only"), at this location. Sign in as [User-V] in a private window for the steps.
Setup
- Settings > Roles & Permissions > Create Custom Role > in "Choose a template" pick Service Advisor > Apply > Role Name* "ZZAUTOTEST WO View Only" > under Work orders turn Create & Edit off (View stays on) > Create (message "Role created successfully."). Then Settings > Staff > New Staff Member: First Name, Last Name, an Email you can open > Role = ZZAUTOTEST WO View Only (listed under CUSTOM) > Departments = Service > Location = Staging Heavy Duty - 9919 > Save & Close. The new user accepts the invitation from that email and sets a password. Record the user as [User-V] (the case calls this user "that user").
- Check the setup worked: Settings > Staff lists [User-V] with role ZZAUTOTEST WO View Only.

## Steps
- As [User-V] open Work Orders, click List in the display switcher and click the All tab.
- Look for the Create Work Order button.
