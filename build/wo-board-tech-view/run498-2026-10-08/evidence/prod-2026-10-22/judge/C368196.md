# C368196 — Clicking a sortable List header orders the rows
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3792517

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011), desktop browser, window at least 1024 px wide.
- Role: Owner/Admin. On the sign-in page click the Admin quick-login button (you appear as Admin ShopView). The Admin role has Work orders > View and Create & Edit (check: your initials (top right) > Settings > Roles & Permissions > Admin > edit).
- Location: Staging Heavy Duty - 9919 for the whole case (shown next to the bell; change it with your initials > Change Location).
- View: on Work Orders the List is shown (click List in the display switcher at the right of the toolbar; its tooltip reads "List").
- Customer "ZZAUTOTEST List Sort" (used by this case only) with one contact, one asset and three work orders [WO-1], [WO-2], [WO-3] created in that order.
- Names and numbers are examples.
Setup
- Customers > New Customer > Name "ZZAUTOTEST List Sort" > Save (the customer page opens). Contacts tab > New Contact > First Name "ZZAUTOTEST", Last Name "Contact" > Save. Assets tab > New Asset > Contact = ZZAUTOTEST Contact > Year 2022 > Make: type "Freight" and pick Freightliner > Model: type "M2" and pick it > Unit "TRK-118" > Save (Contact and Make are required).
- Work Orders > Create Work Order > New Work Order: Customer = "ZZAUTOTEST List Sort" > Asset = its asset > Save. If a Confirmation says the customer is over their credit limit, click Create. The work order opens on its Lines tab with the New Line form open. Record the number shown at the top left as [WO-1] (the expected results call it "S1-781").
- In New Line > What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service" (it has no parts) > turn Line Approved on > Save & Close.
- Create a second and a third work order the same way (Create Work Order > the same customer and asset > Save; a ready-made line). Record them as [WO-2] ("S1-782") and [WO-3] ("S1-783").
- Check the setup worked: All tab > Search "ZZAUTOTEST List Sort" lists exactly [WO-1], [WO-2], [WO-3].

## Steps
- Open Work Orders, click the All tab, click Search and type "ZZAUTOTEST List Sort".
- Click the Number column header.
- Read the order of the rows.
- Click the same header again.
- Read the order of the rows.
- Repeat steps 2 to 5 for every other header that can be clicked to sort (a header with a small arrow: On Site, Status, Customer, Asset, Unit, VIN/Serial #, Service Advisor, Lead Technician, Clocked In, Lines, Total Price, Created On; Progress cannot be clicked).

## Expected (source quote — judge against this, never change it)
Expected results
- Step 3: S1-781, S1-782, S1-783. Step 5: S1-783, S1-782, S1-781.
- Step 6: every sortable header orders the 3 rows by that column, one way then the other. Write down any header that does not.
Source — where this behaviour comes from
Regression for epic SV-10043 (PR #3548); developer's regression list, received 8 Oct 2026; QA handoff test plan (generated 2026-10-08), §2; PRD Confluence 845185030 (edited 7 Oct 2026) where quoted (§1 Business Case). Source-verified 8 October 2026.
Exact quotes from the source (for reproducibility)
- QA handoff §2: “Every sortable header orders the rows.”
- PRD §1 Business Case: “List remains the default and stays exactly as it is in production today; the only addition to the Work Orders page is the switcher that offers the two new displays.”

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.19-1493c63, on 17 October 2026.
- Result: Passed on staging, following the test's steps. Search "ZZAUTOTEST List Sort 83521": S2-36910, S2-36911, S2-36912, made to differ in every column (asset, unit, advisor, lead, clocked in, lines, price, on site).
- Number: first click S2-36910, S2-36911, S2-36912; second click S2-36912, S2-36911, S2-36910.
- On Site, Status, Customer, Asset, Unit, VIN/Serial #, Service Advisor, Lead Technician, Clocked In, Lines, Total Price and Created On each ordered the 3 rows one way, then the other, with the header marked as sorted (for example Total Price: $52.20, $313.18, $435.27, then the reverse; Created On: all three read "Today").
- Clocked In: first click nobody, Dana Ortiz, Ralph Edwards; second click Dana Ortiz, Ralph Edwards, then nobody (the two with one person clocked in keep their order).
- Progress cannot be clicked to sort: it has no sort mark and the order did not change. No header failed to order the rows.
