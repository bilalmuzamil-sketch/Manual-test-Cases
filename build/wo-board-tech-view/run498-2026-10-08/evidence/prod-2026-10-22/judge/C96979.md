# C96979 — A new user's Tech View opens on the design's 13 columns
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481923

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919). You are {User-A}.
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- Brand-new staff user {User-B} (for example Nora New) has the Admin role at {Location-A}, has never changed any Work Orders columns, and is signed in in a second browser.
- Custom role {Role-A} (for example "ZZAUTOTEST F2 No Financial") has Work Orders view on and See Financial Data off.
- Brand-new staff user {User-C} (for example Nate Nofinance) has role {Role-A} at {Location-A}, has never changed any Work Orders columns, and is signed in in a third browser (or a private window).
- Approved work order {Work-order-1} (for example S10043-17602) for customer {Customer-A} (for example "ZZAUTOTEST F2 Tech Default Columns") has one approved line, {Line-1} (for example "Service - Full grease service"), and no lead technician.
- Your own List columns may be anything at the start; the steps set them.

## Steps
- In {User-B}'s browser, open Work Orders and click the All tab.
- Click List in the display switcher.
- Write down every column shown in List, left to right.
- Click Tech View in the display switcher.
- Write down every column shown in Tech View, left to right.
- Click the Column Selection button and read which columns are on and which are off.
- Close the menu.
- In {User-C}'s browser, open Work Orders, click the All tab and click Tech View in the display switcher.
- Write down every column shown in Tech View, left to right.
- In your own browser, open Work Orders, click the All tab and click List in the display switcher.
- Click the Column Selection button.
- Turn Service Advisor off.
- Turn Created on on.
- Close the menu and reload the page.
- Click Tech View in the display switcher.
- Click the Column Selection button, turn one column off (for example Unit) and close the menu.
- Click List in the display switcher.
- Reload the page and read List's columns.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 3: {User-B}'s List shows List's own default columns, unchanged by this feature (the same columns a new user's List shows on production), and it has no Assigned Techs column.
- Step 5: {User-B}'s Tech View shows exactly 13 columns, in this order: Status, Waiting On Parts, Number, Customer, Unit, Asset, Progress, Service Advisor, Clocked In, Lines, Assigned Techs, Created on, Total price. On Site, VIN/Serial # and Lead Technician are not shown.
- Step 6: in Tech View's menu Assigned Techs is on, and On Site, VIN/Serial # and Lead Technician are offered but off.
- Step 9: {User-C}'s Tech View shows the same columns in the same order without Total price: 12 columns, ending with Lines, Assigned Techs, Created on.
- Steps 14 and 18: your List keeps Service Advisor off and Created on on after the reload, after switching to Tech View and back, and after the second reload. List choices saved before this release cannot be recreated by hand: write "pre-release List choice not checked" in the result comment unless you have such a user.
Source — where this behaviour comes from
Epic SV-10043; stories SV-10048 (Story 5, Fields to display (Board View) and columns (Tech View)) and SV-10050 (Story 7, Show line technicians on cards and rows); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 54 (15 Oct 2026, Chris Ward), S5-R4 and S7-R7 (rewritten in version 51 on 14 Oct 2026 (Chris Ward ruling after Sasha Grosman's staging review: Tech View's default columns are the design's 13, and Assigned Techs is on by default); before, Tech View started with the production List default columns), S5-R12, S5-E2 and S7-R1, read 15 Oct 2026. Technical Implementation Plan (revised 24 Sep 2026, uploaded 8 Oct 2026), section 3.9, item 9 (production default List columns), read 14 Oct 2026. Product owner answers: Chris Ward, WO Board and Tech View question sheet (https://docs.google.com/spreadsheets/d/1gBGmNB4B1bRrD2ZJvBn1tuvbfxFPjcsKddz_I5H3CvU), answer 14, read 15 Oct 2026. In version 54 S5-R4 gained one sentence (column headings use List's labels, for example Unit, and Assigned Techs); the default columns and their order are unchanged, so the expected results are unchanged. Source-verified 15 October 2026. Last checked against build v26.40.19-1493c63 (staging) on 10/16/2026.
Exact quotes from the source (for reproducibility)
- S5-R4: “Until the user changes Tech View’s columns, Tech View shows these columns, in this order, as in the design: Status, Waiting On Parts, Number, Customer, Unit, Asset, Progress, Service Advisor, Clocked In, Lines, Assigned Techs, Created on, Total price (Total price subject to financial permission). On Site, VIN/Serial # and Lead Technician are off by default; each can be added with the column chooser (S2-R4). Column headings use the List’s labels for List columns (for example Unit, not Unit #) and Assigned Techs for the new column. List’s columns are unchanged.”
- S7-R7: “In Tech View the Assigned Techs column sits immediately after Lines, matching the design. It is on by default (S5-R4) and can be removed through the column chooser (S2-R4).”
- S5-E2: “Without see financial data permission, hide all dollar-amount fields from displays, filters, and field/column pickers.”
- S7-R1: “Board View cards (when the line technicians field is on) and a new optional Assigned Techs column in Tech View show a compact avatar group: the lead technician plus the distinct technicians assigned to work order lines. List does not get this column.”
- Tech plan 3.9 (default List columns): “Default List columns = every non-required column except `invoicedDate`, `daysOpen`, `partRequestsCount`, `partReturnRequestsCount`, `unreceivedPartRequestsCount`.”
- S5-R12: “Existing saved List column selections stay exactly as they are.”

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.19-1493c63, on 16 October 2026.
- Result: Passed on staging, following the test's steps.
- A brand-new user who never saved a choice ("Nora New"): her List shows List's own columns (On Site, Status, Number, Customer, Asset, Unit, VIN/Serial #, Progress, Service Advisor, Lead Technician, Clocked In, Lines, Total Price, Created On), with no Assigned Techs.
- Her Tech View shows exactly 13 columns in this order: Status, Waiting On Parts, Number, Customer, Unit, Asset, Progress, Service Advisor, Clocked In, Lines, Assigned Techs, Created On, Total Price. On Site, VIN/Serial # and Lead Technician are off but offered.
- Without financial data (Nate Nofinance, same run) Tech View shows the same columns in the same order without Total Price: 12, ending Lines, Assigned Techs, Created On.
- My own List with Service Advisor off and Created On on kept that after a reload, after switching to Tech View and back, and after a second reload.
- Pre-release List choice not checked.
