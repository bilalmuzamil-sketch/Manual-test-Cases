# C368199 — Switching List tabs quickly shows only the last tab's work orders
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3792520

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 5 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011), desktop browser, window at least 1024 px wide.
- Role: Owner/Admin. On the sign-in page click the Admin quick-login button (you appear as Admin ShopView). The Admin role has Work orders > View and Create & Edit (check: your initials (top right) > Settings > Roles & Permissions > Admin > edit).
- Location: Staging Heavy Duty - 9919 for the whole case (shown next to the bell; change it with your initials > Change Location).
- View: on Work Orders the List is shown (click List in the display switcher at the right of the toolbar; its tooltip reads "List").
- Needs no test data of its own (the site has work orders on every tab).
Setup
- Check the setup worked: Work Orders > List shows the tabs All, Estimates, Work Orders, Completed.

## Steps
- Open Work Orders and click the All tab.
- Click Estimates, Completed, Work Orders and Completed again as fast as you can.
- Wait for the List to finish loading.
- Read the rows and look for any error message.

## Expected (source quote — judge against this, never change it)
Expected results
- Only the Completed tab's work orders show (every row reads Complete or a later status, as the Completed tab shows today).
- No error message appears.
- Requests the page stops on the way are a developer check. This part cannot be checked by hand; write 'not checked by hand' in the result comment and pass or fail on what you can see.
