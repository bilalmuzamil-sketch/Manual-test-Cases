# C368150 — Enter opens the focused card or row, and no key drags it
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3761671

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in as an Admin user (the "Admin" role, which has Work orders > View and Create & Edit) at {Location-A}.
For example: {Location-A} is Staging Heavy Duty - 9919.
- Two technicians are active at {Location-A} with the "Technician" role and Time Clock on: {Technician-A} and {Technician-B}.
For example: {Technician-A} is ZZAUTOTEST C368150 Ana and {Technician-B} is ZZAUTOTEST C368150 Ben.
- Customer {Customer-A} has four Approved work orders: {Work-order-1} and {Work-order-2} led by {Technician-A}, {Work-order-3} led by {Technician-B}, and {Work-order-4} with no lead technician.
For example: {Customer-A} is ZZAUTOTEST C368150 Enter, and {Work-order-1} to {Work-order-4} are S10043-17701 to S10043-17704.
- {Technician-A} and {Technician-B} are pinned in your Board View, and no other technician is pinned.
- Starting screen: "Work Orders" > "All" tab, "Board View" shown, the name of {Customer-A} in "Search", no filter chosen, "Assigned to me" off, in a browser window at least 1024 px wide.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Click once in the "Search" box.
- Press Tab until a card shows a focus ring.
- Use the arrow keys to move the focus ring to the card for {Work-order-1}.
- Press Space, then Shift with each arrow key.
- Press Enter.
- Press the browser Back button.
- Click "Tech View" in the display switcher.
- Click once in the "Search" box.
- Press Tab until a row shows a focus ring.
- Use the arrow keys to move the focus ring to the row for {Work-order-1}.
- Press Enter.
- Press the browser Back button.
- With the mouse, click the row for {Work-order-1} without moving the mouse while the button is down.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: the cursor is in the "Search" box.
- Step 2: a card shows the focus ring: the card you focused last or, if no card has been focused yet, the first card in "Unassigned" ({Work-order-4}).
- Step 3: the card for {Work-order-1} shows the focus ring.
- Step 4: no card moves: {Work-order-1} stays in its place in {Technician-A}'s column and no message about a lead change appears.
- Step 5: the work order page for {Work-order-1} opens, the same as a click.
- Step 6: Board View shows again.
- Step 7: Tech View shows the same work orders.
- Step 8: the cursor is in the "Search" box.
- Step 9: a work order row shows the focus ring.
- Step 10: the row for {Work-order-1} shows the focus ring.
- Step 11: the work order page for {Work-order-1} opens.
- Step 12: Tech View shows again.
- Step 13: the click opens the work order page for {Work-order-1}, as it does today.
Source — where this behaviour comes from
Epic SV-10043; story SV-10054 (Story 11, Keyboard access and focus); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 68 (19 Oct 2026, Chris Ward), S11-R1, S11-R3, S11-R4, S11-R10, S11-R9 and Out of Scope, read 19 Oct 2026. Product owner answers: Chris Ward, WO Board and Tech View question sheet (https://docs.google.com/spreadsheets/d/1gBGmNB4B1bRrD2ZJvBn1tuvbfxFPjcsKddz_I5H3CvU), answer 28, read 15 Oct 2026. Source-verified 19 October 2026. Not yet checked against a build in this wording.
Until 15 Oct 2026 Story 11 only listed keyboard behaviour the design still had to define, so this case asked the tester to try keys and write down what each did. Chris Ward answered on 15 Oct 2026 (answer 28): Tab reaches every control, Enter opens, Escape closes, focus returns to the control that opened a menu or dialog, reassigning by keyboard goes through the ⋯ menu, and there is no keyboard drag. PRD version 54 rewrites Story 11 into these requirements, and this case now checks them.
Chris Ward's answer 28 (15 Oct 2026) and PRD version 54 said Tab reaches every row, card and header in on-screen order. PRD versions 55, 60 and 61 (15 and 16 Oct 2026, Chris Ward rulings on Slavcho Mitrov's questions and the QA triage of SV-11395, SV-11397, SV-11422 and SV-11421) changed this: each view is one Tab stop that lands on a work order, and the arrow keys move between cards, rows, headers and columns. Version 62 (16 Oct 2026, Chris Ward ruling on Bilal's QA questions 32 and 33) added where the first Tab lands when nothing has been focused yet, and version 67 (19 Oct 2026) reworded S11-R9 for the Assign or Reassign lead technician dialog. This case follows version 68, the latest.
Exact quotes from the source (for reproducibility)
- S11-R1: “Each view is a single Tab stop. Tab lands on one work order row (Tech View) or card (Board View), the one last focused, or, when none has been, the first work order shown in on-screen order: the first row or card in Unassigned, or the first technician’s first row or card when Unassigned is collapsed or empty (never a group or column header while a work order is shown; when every group is collapsed, Tab lands on the first group header; after the user arrows onto a header and tabs out and back in, Tab returns to a work order row while any row is shown; on Board View, if the last-focused card has scrolled out of view in its column, Tab lands on the first card in view); the focused row or card shows a visible focus ring.”
- S11-R3: “Inside a view the arrow keys move focus: Up and Down move between rows and group headers in Tech View, and between cards and the column header within a Board View column; Left and Right move between Board View columns. Tab from a focused row, card or header reaches its own controls (more actions, pin, collapse) in order, then leaves the view. Tab never stops on every row.”
- S11-R4: “Enter on a focused row or card opens the work order, the same as a click.”
- S11-R10: “Opening a work order by keyboard is Enter (S11-R4); dragging is by mouse or touch only, so the two never conflict. A mouse click without a drag opens the work order as today (S2-R8).”
- S11-R9: “Assigning, reassigning and unassigning by keyboard go through the more-actions menu: Assign lead technician or Reassign lead technician (S3-R14) opens the lead technician dialog, and Unassign is a menu item. There is no keyboard drag in this release, so reordering work orders and technicians is by mouse or touch only.”
- Out of Scope: “Reordering work orders or technicians by keyboard. Reordering is by mouse or touch drag in this release (S11-R9).”
