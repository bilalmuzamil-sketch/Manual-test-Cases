# C97024 — Fields on and off are recorded once per display per session
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481962

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- You can open Google Analytics for the property the QA build reports to, at Admin > DebugView, and your device shows there within a few seconds of opening any ShopView page. If you cannot open DebugView, the event checks cannot be done by hand: write "not checked by hand" in the result comment and pass or fail on what you can see on the Work Orders page.
- The event names to look for in DebugView are work_orders_display_view, work_orders_field_load, work_orders_density_load, work_orders_field_toggle and work_orders_density_change.
- Your role has See financial data.
- In Board View's Fields to display, VIN/Serial is on as a saved choice and every other optional field is at its default.
- You start in a fresh browser session: every browser window was closed, a new private window opened and you signed in.

## Steps
- Open Work Orders and click Board View in the display switcher.
- In DebugView, count the work_orders_field_load events and read each one's field name, on or off value and source.
- Click Tech View in the display switcher.
- In DebugView, count the new work_orders_field_load events.
- Click Board View in the display switcher.
- Click List in the display switcher.
- Click Board View in the display switcher.
- In DebugView, count the new work_orders_field_load and work_orders_density_load events since step 4.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 2: 13 events, one per optional Board View field (lead technician name, customer, asset, VIN/serial, progress, service advisor, clocked in, line count, line technicians, estimated hours, total price, on-site indicator, created date). Fields you never changed show source default, and VIN/Serial shows on with source saved. There is also one work_orders_density_load event for Board View.
- Step 4: 17 events for Tech View's optional columns (the same columns as List, plus Assigned Techs), plus one work_orders_density_load event.
- Step 8: no new field events and no new density events. Reopening a display in the same session records nothing again. The session's field-load events total 13 + 17 = 30.
QA lead decision, 19 Oct 2026: Tech View's count is 17, not 15. PRD version 64, S2-R4: “Tech View offers the same columns as List, plus the Assigned Techs column (Story 7), through its own column chooser (Story 5).” List offers 16 columns, plus Assigned Techs makes 17. The earlier 15 came from a developer's comment of 6 Oct 2026.
Source — where this behaviour comes from
Epic SV-10043; story SV-10593 (Story 12, Google Analytics for display and field usage); SV-10048 (Story 5, Fields to display and columns); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 54 (15 Oct 2026, Chris Ward), S12-R2 and S5-R11, read 15 Oct 2026. Event names and timing: SV-10593 comments by Slavcho Mitrov and Milos Vasic, 6 Oct 2026 (the agreed GA4 event table). Field counts (Board View 13, Tech View 15) from Slavcho Mitrov's SV-10593 comment, 6 Oct 2026. In version 54 the clocked-in wording of S5-R11's field list changed (full name, answer 31); the list of fields is unchanged, so the expected results are unchanged. Product owner answers: Chris Ward, WO Board and Tech View question sheet (https://docs.google.com/spreadsheets/d/1gBGmNB4B1bRrD2ZJvBn1tuvbfxFPjcsKddz_I5H3CvU), answer 31, read 15 Oct 2026. Source-verified 15 October 2026. Last checked against build v26.40.8-7a95011 on 10/8/2026.
Exact quotes from the source (for reproducibility)
- S12-R2: “Measure selected and unselected fields available to each user, including untouched defaults and restored preferences. Record this snapshot once per display per session, the first time the user opens that display in the session, not on every open. Field changes are still recorded each time they are saved (S12-R3).”
- S5-R11 optional fields: “*Optional fields:* lead technician name, customer, asset (year/make/model), VIN/serial, progress, service advisor, clocked in (the names of the technicians currently clocked in to the work order, shown the way List’s Clocked In column shows them today: the first technician’s full name, then +N, with every name on hover), line count, line technicians, estimated hours, total price, on-site indicator, and created date.”
