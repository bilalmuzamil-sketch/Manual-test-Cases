## Steps
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- Click Search and type ZZAUTOTEST F2 Column Scroll so only this test's work orders show.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Scroll down inside the Unassigned column.
- Watch the neighbouring columns and the headers.
- Try to scroll the whole page down with the mouse over the empty area below a short column.
- Scroll down inside Esther Howard's column.
- Scroll the board sideways to the far right and back.
- Count the technician columns you passed and compare with [Tech-count].

## Expected (source quote — judge against this, never change it)
Expected results
- Scrolling inside Unassigned moves only its cards: the next columns and every header stay where they are.
- The page itself does not scroll down: only the content inside a column scrolls.
- Esther Howard's column scrolls on its own the same way.
- Sideways scrolling reaches every technician: the number of technician columns equals the number of eligible technicians (e.g. 8). None is hidden automatically.
Source — where this behaviour comes from
Epic SV-10043; story SV-10046 (Story 3, Board View — board by lead technician); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S3-E1, read 8 Oct 2026; S3-E2 re-read at version 65 on 19 Oct 2026. Review Decisions 853901313 UX-11 / DR-40. PRD inline comment Branko Cicovic 28 Sep 2026 (only content inside the columns scrolls).
Exact quotes from the source (for reproducibility)
- S3-E1: “Every Board View column, including Unassigned, scrolls vertically on its own when its cards exceed the available viewport, while adjacent columns and pinned headers remain visible. The page itself does not scroll vertically; only the content inside each column does.”
- S3-E2 (version 65): “Allow horizontal scrolling when technician columns exceed the available viewport; never hide technicians automatically. The board’s sideways scrollbar is 16px thick, and its grab handle is never shorter than 150px at any screen width or number of technician columns. When more of the board fits on screen, the handle is longer, as the browser draws it. The scrollbars inside each column are unchanged. Firefox shows its own standard scrollbar.” (The scroll bar size is checked in its own case: Board View’s sideways scroll bar is thick and its handle is never tiny.)
