# C96986 — Without See Financial Data no dollar amounts show in Tech or Board View
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481930

## Preconditions
Preconditions
- Needs: 2 users · 2 browsers · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- [User-B] = "Nate Nofinance" (the expected results name him, so keep this name): a second user whose role is a custom role with Work Orders view and, for now, See Financial Data, signed in in a second browser.
- One technician at this location: [Tech-A] (e.g. "Esther Howard"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 No Dollar Amounts" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- One Approved work order for that customer, [WO-1], led by [Tech-A], with a price.
- As Nate Nofinance, Total price is on in Tech View's Column Selection menu and in Board View's Fields to display.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff > New Staff Member, enter First Name and Last Name (e.g. "Esther Howard") and an email. Pick a Role that is not Office User or Time Clock User (e.g. "Technician"), pick at least one Department (required), set Location to this location and turn Time Clock on, then click Save & Close. Record as [Tech-A].
- Settings > Roles & Permissions > Create Custom Role (e.g. "ZZAUTOTEST F2 Finance Toggle") > turn on Work Orders view and See Financial Data > Save.
- Settings (your initials at the top right > Settings) > Staff > New Staff Member for "Nate Nofinance" with an email you can open, Role = the new custom role, at least one Department (required), with this location picked in Location, Time Clock off > Save & Close, then accept the invitation and set a password. Keep him signed in in a second browser.
- Create a customer used only by this case so a search shows only its work orders: top menu Customers > New Customer, Name "ZZAUTOTEST F2 No Dollar Amounts" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact)

## Steps
- As the admin, edit Nate Nofinance's role and turn See Financial Data off, then save.
- As Nate Nofinance sign in again, open Work Orders, pick Tech View and search for ZZAUTOTEST F2 No Dollar Amounts.
- Read the columns and open Column Selection.
- Open every filter in the toolbar and read its options.
- Pick Board View, read the card and open Fields to display.

## Expected (source quote — judge against this, never change it)
Expected results
- Tech View has no Total price column and its column chooser does not offer it; Board View cards show no dollar amount and Fields to display does not offer total price.
- No filter offers a dollar-amount option, and Nate's earlier saved choice (Total price on) does not bring any dollar value back. List is not part of this change and stays as in production.

- S5-E6: “Saved filters and field selections must not reveal financial values when see financial data is off.”
