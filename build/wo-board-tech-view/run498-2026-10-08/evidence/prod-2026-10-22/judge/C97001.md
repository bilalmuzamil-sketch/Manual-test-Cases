# C97001 — Work orders can be dragged within a technician and to another technician
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481945

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 25 minutes
- Build: the Work Orders QA build (sv10043). Desktop browser window at least 1024 px wide (narrower windows show only the List, without the display switcher).
- Role: Owner/Admin. On a QA branch sign in with the Admin quick-login button on the sign-in page; you appear as "Admin ShopView". The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders). This user is the dispatcher.
- Location: one location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location. Every technician and work order below belongs to this location.
- Technicians (examples, the expected results call them by first name or full name): "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo", "ZZAUTOTEST Cal Charlie". A staff member counts as a technician when, in Settings > Staff > the staff member's edit icon > Edit Staff Member, they are Active, Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customers (used by this case only, each with one contact and one asset): "ZZAUTOTEST F3 Drag Order Alpha Co", "ZZAUTOTEST F3 Drag Order Bravo Co", "ZZAUTOTEST F3 Drag Order Charlie Co", "ZZAUTOTEST F3 Drag Order Delta Co", "ZZAUTOTEST F3 Drag Order Echo Co". The steps and expected results call them by the end of the name ("Alpha Co", "Bravo Co", "Charlie Co", "Delta Co", "Echo Co").
- Work orders (all Approved): lead Ana — Alpha Co, Bravo Co, Charlie Co; lead Ben — Delta Co; lead Cal — Echo Co. Ana's group starts in the order Alpha Co, Bravo Co, Charlie Co (with the example data).
- None of these technicians has a shift on the Schedule for these work orders (check the Schedule page). If a window titled "Clear … scheduled shifts?" still appears during a move, click "Keep shifts".
Setup
- Settings (your initials at the top right > Settings) > Staff: confirm "ZZAUTOTEST Ana Alpha", "ZZAUTOTEST Ben Bravo", "ZZAUTOTEST Cal Charlie" exist and count as technicians at this location (edit icon > Edit Staff Member). To add one: New Staff Member with those settings (at least one Department is required) (e.g. first name "ZZAUTOTEST Ana", last name "Alpha") > Save & Close.
- Create this case's customers: "ZZAUTOTEST F3 Drag Order Alpha Co", "ZZAUTOTEST F3 Drag Order Bravo Co", "ZZAUTOTEST F3 Drag Order Charlie Co", "ZZAUTOTEST F3 Drag Order Delta Co", "ZZAUTOTEST F3 Drag Order Echo Co". For each: top menu Customers > New Customer, Name > Save; on the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact); then the Assets tab > New Asset > pick the Contact, then Year, Make, Model (e.g. 2022, Freightliner, M2) > Save. Make is required; Unit can be left empty.
- Create each work order listed in the Precond

## Steps
- Open Work Orders from the top menu and click the All tab.
- Type "ZZAUTOTEST F3 Drag Order" in Search so only this case's work orders show.
- Click Tech View in the display switcher at the right of the toolbar (tooltip "Tech View").
- In Ana's group, write down the order of the three rows (with the example data: Alpha Co, Bravo Co, Charlie Co).
- Press on the Charlie Co row and drag it above the Alpha Co row, then release.
- Drag the Bravo Co row from Ana's group into Ben's group, below the Delta Co row, and release.
- Click Board View in the display switcher (tooltip "Board View").
- In Ben's column, drag the Bravo Co card above the Delta Co card and release.
- Drag the Echo Co card from Cal's column into Ana's column, below the last card, and release.

## Expected (source quote — judge against this, never change it)
Expected results
- After step 5, Ana's group lists Charlie Co, Alpha Co, Bravo Co: the row moved inside the group to where you dropped it.
- After step 6, Bravo Co is listed in Ben's group below Delta Co and is gone from Ana's group.
- After step 8, Ben's column shows Bravo Co above Delta Co.
- After step 9, Echo Co is the last card in Ana's column and Cal's column is empty.
- Every drag in both Tech View and Board View was allowed and the row or card stayed where you released it.
Source — where this behaviour comes from
Epic SV-10043; story SV-10052 (Story 9, Drag to reorder work and technician groups/columns); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S9-R1, read 8 Oct 2026.
Exact quotes from the source (for reproducibility)
- S9-R1: “Allow dragging work orders within or between technician groups/columns in Tech View and Board View.”
