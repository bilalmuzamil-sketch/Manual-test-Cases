# C590111 — Design: View button tips read List, Tech View and Board View and show above
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3995720

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as {User-A} (for example Admin ShopView), an Owner or Admin user whose role has Work orders > View, Work orders > Create & Edit and See financial data, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is 1440 px wide, with the browser zoom at 100%.
- For the steps that name 1536 px, your screen lets you widen the window to 1536 px.
- The design picture DC-02-tech-view-header-row-1440.png is open beside the app at 100% zoom (actual size); it is attached to this case.
- The design picture shows the column header row that must stay readable; the design has no tooltip of its own on the switcher, so where the tooltip opens comes from the PRD.
- Technician {Technician-A} (for example ZZAUTOTEST DC02 Ben Tooltip) is an active technician at {Location-A}.
- Customer {Customer-A} (for example "ZZAUTOTEST DC02 Switcher Tooltip") is used by this case only.
- Approved work order {Work-order-1} (for example S10043-17805) for {Customer-A} is led by {Technician-A}.
- On the Work Orders page nothing is chosen in any filter (if the Asset on Site chip shows Yes or No, click the x on the chip), Assigned to me is off, Search is empty and density is Regular (the default).

## Steps
- Open Work Orders, click the All tab and click Tech View in the display switcher.
- Hover the List button of the display switcher and wait until its tooltip shows.
- Hover the Tech View button and wait until its tooltip shows.
- Hover the Board View button and wait until its tooltip shows.
- Click Board View in the display switcher.
- Hover each of the three switcher buttons in turn, waiting for each tooltip.
- Widen the window to 1536 px.
- Click Tech View in the display switcher.
- Hover each of the three switcher buttons in turn, waiting for each tooltip.

## Expected (source quote — judge against this, never change it)
Expected results
- Steps 2 to 4: each tooltip opens above the switcher, between the switcher and the tabs above it, never below it. While it shows, the table's column header row (Status, Waiting On Parts, Number …) stays fully readable, as in the design picture: no part of the tooltip lies over it. The tooltips read List (step 2), Tech View (step 3) and Board View (step 4).
- Step 6: in Board View each tooltip also opens above the switcher, reads List, Tech View or Board View, and covers none of the column headers (technician names and counts).
- Step 9: at 1536 px each tooltip still opens above the switcher and leaves the column header row fully readable.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 54 (15 Oct 2026, Chris Ward), S1-R9b and S1-R1, read 15 Oct 2026; Claude Design project "Work Orders" (Branko Cicovic), export of 14 Oct 2026, board "Work Orders.dc.html", state core__work-orders__tech-regular__light__1440 (design pictures DC-02-tech-view-header-row-1440.png, rendered from that export at the width in the name), read 14 Oct 2026. Covers the design defects SV-11322 (reported 14 Oct 2026 by Chris Ward). Where the PRD says nothing about the look, the design is the source. Product owner answers: Chris Ward, WO Board and Tech View question sheet (https://docs.google.com/spreadsheets/d/1gBGmNB4B1bRrD2ZJvBn1tuvbfxFPjcsKddz_I5H3CvU), answer 24, read 15 Oct 2026. Source-verified 15 October 2026. Last checked against build v26.40.19-72f4f3b (staging) on 10/16/2026.
The design shows only the browser's own hover text on the switcher (Table, By Lead Tech, Board). Chris Ward answered on 15 Oct 2026 (answer 24) that the tooltips read List, Tech View and Board View; PRD version 54 says so, and this case now checks the words as well as the position.
Exact quotes from the source (for reproducibility)
- S1-R9b: “The switcher’s hover tooltip opens above the switcher, so it never covers the table’s column header row. The tooltips read List, Tech View and Board View.”
- S1-R1: “The Work Orders toolbar offers List, Tech View, and Board View display options.”
- Design — _ds_bundle.js (design library), view switch label: “label: 'By Lead Tech',”

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.19-1493c63, on 17 October 2026.
- Result: Passed on staging, following the test's steps.
- Tech View at 1440 px: the tooltips read List, Tech View and Board View, and each opens above the switcher (about 8 px above), covering no part of the column header row.
- Board View: the same three tooltips open above the switcher and cover none of the column headers.
- Tech View at 1536 px: the same.
- The earlier failure (tooltips below the switcher) is gone; it was reported in SV-11322, now in Testing Stage.
