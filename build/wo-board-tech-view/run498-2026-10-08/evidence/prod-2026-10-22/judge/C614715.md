# C614715 — With no work orders at all, Tech View and Board View show No work orders yet
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/4006367

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role and can switch to location {Location-B}, which has no work orders at all: no work orders, estimates or completed work.
For example: {Location-B} is ZZAUTOTEST Empty Location.
- Starting screen: any page, in a browser window at least 1024 px wide.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Go to your initials (top right) > "Change Location" > {Location-B}.
- Go to "Work Orders" > "All" > "Tech View".
- Click "Board View" in the display switcher.
- Click the "Create Work Order" button in the empty state.
- Close the window that opened without saving.
- Click "List" in the display switcher.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: the top bar shows {Location-B}.
- Step 2: instead of groups the page shows a clipboard-list icon in a grey circle, "No work orders yet", then "Create a work order and assign a technician to see it here." and a "Create Work Order" button.
- Step 3: Board View shows the same first-run state instead of columns.
- Step 4: the same "New Work Order" window opens as from the page's own "Create Work Order" button.
- Step 5: the window closes and the first-run state shows again.
- Step 6: List shows its usual empty page, as it does today, without "No work orders yet".
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 61 (16 Oct 2026, Chris Ward), S1-N1c, read 16 Oct 2026. S1-N1c was added in version 55 on 15 Oct 2026 (Chris Ward ruling on Slavcho Mitrov's v54 follow-up questions). Source-verified 16 October 2026.
Exact quotes from the source (for reproducibility)
- S1-N1c: “When no filter and no search are active and the filter view has no work orders at all, Tech View and Board View show the design’s first-run state: the clipboard-list icon in a grey circle, “No work orders yet”, then “Create a work order and assign a technician to see it here.”, with a Create Work Order button that does the same as the page’s Create Work Order button. List keeps its production empty state.”

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.19-1493c63, on 17 October 2026.
- Result: Passed on staging, following the test's steps (round 3 re-run, 17 Oct).
- Step 1: your initials > Change Location > "ZZAUTOTEST C614715 Empty Location", a location with no work orders at all; the top bar shows it.
- Step 2: Tech View shows, instead of groups, the clipboard icon in a grey circle, "No work orders yet", "Create a work order and assign a technician to see it here." and a Create Work Order button.
- Step 3: Board View shows the same first-run state instead of columns.
- Step 4: the empty state's Create Work Order opens the same New Work Order window (Customer, Asset, Save) as the page's own Create Work Order button.
- Step 5: closing it asks "Are you sure you want to close this dialog?"; after Close the window is gone and the first-run state shows again.
- Step 6: List shows its usual empty page ("No work orders found.") without "No work orders yet".
