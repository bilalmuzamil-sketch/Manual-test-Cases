## Steps
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Header Counts" in Search.
- Read the count in [Tech-A]'s, [Tech-B]'s and Unassigned's column headers.
- Drag one of [Tech-A]'s cards (e.g. [WO-1]) into [Tech-B]'s column.
- If a "Clear …'s scheduled shifts?" prompt opens, click Keep shifts.
- Read the three header counts again without reloading the page.
- Open [Tech-B]'s card [WO-4] More actions > Reassign lead technician, pick Unassigned and confirm.
- If a "Clear …'s scheduled shifts?" prompt opens, click Keep shifts.
- Read the three header counts again without reloading.
- Pick Tech View in the display switcher and read the three group header counts.
