# C368218 — Purchase Orders keeps a chosen filter after a reload
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3792539

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 5 minutes. No test data of its own: it uses the rows the page already lists.
- Sign in as an Admin (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). Desktop browser window at least 1024 px wide; narrower windows show only the List.
- Work in one location throughout, shown next to the bell in the top bar (e.g. "Staging Heavy Duty - 9919"); to change it click your initials (top right) > Change Location. Create everything in that location.
- Parts in the top menu opens the parts area; its left menu lists Part Sales, Inventory, Catalog, Returns, Purchase Orders, Vendor Invoices, Vendors.
- This page has no Vendor filter button; its filter is the Search box at the right of the page header (not the search in the top bar, which searches the whole app).

## Steps
- Click Parts in the top menu, then Purchase Orders in the left menu. Write down how many rows show.
- Click the Search box at the right of the page header (on the same line as the page title "Purchase Orders"; not the search in the top bar).
- Type a purchase order number from the list (e.g. the first row's number, such as "S10043-18432") and wait for the list to update. Write down the rows shown.
- Reload the page.
- Read the Search box and the rows.
- Clear the Search box to put the page back as it was.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 3: the list narrows to the rows that match what you typed.
- After the reload the Search box still shows what you typed and the same rows show as before the reload.
- No error message appears.
Source — where this behaviour comes from
- Regression for epic SV-10043 (PR #3548); developer's regression list, received 8 Oct 2026, Medium 6; QA handoff test plan (generated 2026-10-08), hotspot 5; PRD Confluence 845185030 (edited 7 Oct 2026) where quoted. Source-verified 8 October 2026.
- QA lead decision, 9 Oct 2026: this page has no filter button; its filter is the Search box at the right of the page header.
Exact quotes from the source (for reproducibility)
- Dev reply 6: “Pages that remember filters and settings: Orders, Vendors, Return Requests, Return Credits, Part Sales, Deliveries, Parts Catalogue, Inventory, and the report pages.”
- Dev reply 6: “Set a filter, reload, and check that it's kept.”
