# C96941 — The Unassigned column is first and stays put when scrolling sideways
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481885

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 30 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- At least 8 technicians at this location, so the board is wider than the window (e.g. [Tech-A] "Esther Howard" … [Tech-H]). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Sticky Unassigned" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Work orders for that customer: a few (e.g. 2) with no lead and one led by each technician.
- Names are examples; what must hold is that the board scrolls sideways.
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: confirm each technician below is active at this location with Time Clock on, or add it: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] to [Tech-H] (e.g. Esther Howard, Ralph Edwards, Jenny Wilson, Kristin Watson, Theresa Webb, Dana Ortiz, Brenda Martinez, Cameron Williamson).
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Sticky Unassigned" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left empty.
- Work Orders > Create Work Order > in the New Work Order window pick Customer "ZZAUTOTEST F2 Sticky Unassigned" and its asset > Save. The work order opens on its Lines tab with the New Line form open: in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; the build offers only ready-made lines), turn Line Approved on > Save & Close; the work order becomes Approved. Repeat for one work order per technician p

## Steps
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- Click Search and type ZZAUTOTEST F2 Sticky Unassigned so only this test's work orders show.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Note the first column.
- Scroll the board all the way to the right (scroll bar, trackpad, or the column overview at the bottom right if shown).
- Look at the left edge of the board.
- Scroll back to the left.

## Expected (source quote — judge against this, never change it)
Expected results
- Unassigned is the first column.
- While scrolling right, Unassigned stays fixed at the left edge and the technician columns slide past behind it, so Unassigned is always visible.
Source — where this behaviour comes from
Epic SV-10043; story SV-10046 (Story 3, Board View — board by lead technician); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S3-R2, read 8 Oct 2026. Design: Claude Design export of 8 Oct 2026 (Work Orders.dc.html), Board, sticky Unassigned column and "Drag to scroll" overview; on-screen labels only.
Exact quotes from the source (for reproducibility)
- S3-R2: “The Unassigned column is the first column and is fixed: it stays in place while the user scrolls the technician columns horizontally.”
