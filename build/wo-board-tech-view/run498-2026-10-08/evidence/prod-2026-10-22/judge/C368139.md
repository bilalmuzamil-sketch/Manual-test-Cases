# C368139 — Two drops into one technician at once show a board-busy alert
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3761660

## Preconditions
Preconditions
- Needs: 2 users · 2 browsers · about 20 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- [User-B]: a second user with Work Orders view and create and edit (e.g. "Sam Second", Admin role) in a second browser, both screens side by side.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Two eligible technicians at this location: [Tech-A] (e.g. "Esther Howard") and [Tech-B] (e.g. "Ralph Edwards"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Board Busy" (used by this case only) with two Approved work orders led by [Tech-A]: [WO-1] and [WO-2].
- Names and numbers are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard), [Tech-B] (e.g. Ralph Edwards).
- A second user with Work Orders view and create and edit (e.g. "Sam Second", Admin role): Settings > Staff > New Staff Member with an email you can open, Role Admin, at least one Department (required), this location in Location > Save & Close; accept the invitation and set a password. Record this user as [User-B] and sign in as [User-B] in a second browser. Put both screens side by side.
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Board Busy" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Uni

## Steps
- In both browsers open Work Orders, click the All tab, pick Board View and search for "ZZAUTOTEST F1 Board Busy".
- In browser 1 start dragging [WO-1] over [Tech-B]'s column; in browser 2 start dragging [WO-2] over [Tech-B]'s column.
- Count 3-2-1 and release both at the same moment (keep shifts if asked).
- Read any alert in either browser and where each card ends up.
- Repeat steps 2 to 4 up to five times, then reload both browsers.

## Expected (source quote — judge against this, never change it)
Expected results
- If the second drop cannot be saved in time, that browser shows an alert reading exactly: The board is busy with another move. Please try again. and its card goes back to where it was.
- Two people dropping at exactly the same moment cannot be guaranteed by hand. If every drop saved, write 'busy alert not reproduced by hand' in the result comment and pass or fail on what you can see: no card may be lost or shown twice, and after the reload each card is in exactly one column.
