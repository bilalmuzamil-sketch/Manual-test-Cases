# C96971 — When two people reassign the same work order, the later one wins
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481915

## Preconditions
Preconditions
- Needs: 2 users · 2 browsers · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- [User-B]: a second user with Work Orders view and create and edit (e.g. "Sam Second", Admin role), signed in in a second browser at the same location.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Three eligible technicians at this location: [Tech-A] (e.g. "Esther Howard"), [Tech-B] (e.g. "Ralph Edwards"), [Tech-C] "Dana Ortiz". A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Later Reassign Wins" (used by this case only) with one Approved work order [WO-1] led by [Tech-A].
- Dana Ortiz is named in the expected results and stays as written; the other names and the number are examples.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard), [Tech-B] (e.g. Ralph Edwards), [Tech-C] = "Dana Ortiz" (use exactly this name: the expected results name it).
- A second user with Work Orders view and create and edit (e.g. "Sam Second", created under Settings > Staff with an Admin role): New Staff Member with an email you can open, Role Admin, at least one Department (required), this location in Location > Save & Close; accept the invitation and set a password. Record this user as [User-B] and sign in as [User-B] in a second browser at the same location.
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Later Reassign Wins" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > S

## Steps
- In both browsers open Work Orders, click the All tab, pick Board View and search for "ZZAUTOTEST F1 Later Reassign Wins".
- In browser 1, move the card to [Tech-B] with More actions > Reassign lead technician (keep shifts if asked).
- In browser 2, without reloading, move the same card (still shown in [Tech-A]'s column) to [Tech-C] with More actions > Reassign lead technician (keep shifts if asked).
- Reload the page in both browsers.
- Open the work order in both browsers and read Lead Technician.

## Expected (source quote — judge against this, never change it)
Expected results
- Dana Ortiz, the later change, is the final lead.
- After the reload both browsers show the card in Dana Ortiz's column and the work order page reads Dana Ortiz in both.
