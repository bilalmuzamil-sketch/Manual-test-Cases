# C590127 — Design: The Technician filter sits right after Assigned to me in both views
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3995736

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role at {Location-A}.
For example: {Location-A} is Staging Heavy Duty - 9919.
- The browser window is 1440 px wide with the zoom at 100%, and the design picture "DC-18-tech-technician-chip-open-light-1440.png" attached to this case is open beside it at 100% (actual size). Names, numbers and rank numbers in the pictures are sample data. The picture's Department filter is left out of this release.
- Technician {Technician-A} is active at {Location-A} and leads the Approved work order {Work-order-1} of customer {Customer-A}.
For example: {Technician-A} is ZZAUTOTEST C590127 Yan, {Customer-A} is ZZAUTOTEST C590127 Technician Filter and {Work-order-1} is S10043-17850.
- Starting screen: "Work Orders" > "All" tab, "Tech View" shown, "Search" empty, no filter chosen, "Assigned to me" off, density "Regular".
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Look at the filter bar from left to right.
- Click the "Technician" filter.
- Look at the list that opens.
- Tick {Technician-A}.
- Press Escape.
- Click "Board View" in the display switcher.
- Click "List" in the display switcher.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: the "Technician" filter sits directly after "Assigned to me", with the design's thin outline wrench icon, the word "Technician" and a down arrow, as in the picture. There is no Department filter.
- Step 2: a list opens directly below the filter.
- Step 3: the list starts with "Unassigned", then the location's technicians by first name then last name, each with a tick box.
- Step 4: {Technician-A} is ticked.
- Step 5: the list closes.
- Step 6: Board View shows the same "Technician" filter in the same place, still with {Technician-A} chosen.
- Step 7: List's filter bar has no "Technician" filter.
Known problem (SV-11326, open: https://shopview.atlassian.net/browse/SV-11326): staging has no Technician filter yet. If you see no Technician filter, mark this test Blocked and raise nothing new.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 61 (16 Oct 2026, Chris Ward), S1-R15, S1-R15b, S1-R9a and Out of Scope, read 16 Oct 2026. Claude Design project "Work Orders" (Branko Cicovic), export of 14 Oct 2026, board "Work Orders.dc.html" (the design pictures named in the preconditions were rendered from it), read 14 Oct 2026. Related tickets: SV-11326. Product owner answers: Chris Ward, WO Board and Tech View question sheet (https://docs.google.com/spreadsheets/d/1gBGmNB4B1bRrD2ZJvBn1tuvbfxFPjcsKddz_I5H3CvU), answer 12, read 15 Oct 2026. Source-verified 16 October 2026.
The design's Technician list has no Unassigned entry and filters by any assigned technician; this case follows the PRD (S1-R15, added in version 52). The design gives the filter a wrench icon; Chris Ward answered on 15 Oct 2026 (answer 12) that the filter chips use the design file's icons in every display option, and PRD version 61 still says so, so step 1 checks the wrench icon.
Exact quotes from the source (for reproducibility)
- S1-R15: “In Tech View and Board View the filter bar also offers a Technician filter, after Assigned to me. It is a multi-select listing Unassigned first, then the location’s technicians (the same people who get a group or column, S9-R4), by first name then last name. Choosing one or more shows only those technicians’ groups or columns; every other group or column, pinned ones included, is hidden. It filters by lead technician only.”
- S1-R15b: “List does not offer the Technician filter and stays as in production. Switching to List while technicians are chosen shows List as if none were chosen; switching back to Tech View or Board View brings the choice back. The choice is remembered the same way as the other filters.”
- S1-R9a: “The switcher uses the design’s icons at 20px: List is Lucide `list`, Tech View is `user-round`, Board View is `square-kanban`. In Tech View and Board View these icons are the design’s: density (`row-height` in Tech View, `card-height` in Board View, custom icons in the design system’s icon set), collapse chevron (`chevron-down`), pin and unpin (`pin` / `pin-off`), Invoiced or Paid lock (`lock`), Unassigned avatar (`user-round`) and the empty state when there are no work orders at all (`clipboard-list`). The filtered no-results state is the List’s, magnifier included (S1-N1). The filter chips and Search use the design file’s icons in every display option, List included, each exactly as the design file draws it. The display switcher (new on every view, List included) shows the design’s slate icons in every view, so it keeps one color as the user moves between views. These are the only changes to List. Every other List icon is unchanged.”
- Out of Scope: “A Department filter. The design shows one, but a work order’s department is not shown or editable on any work order screen today, so users could not see why a work order matches. Revisit once the work order shows its department.”
- Design — _ds_bundle.js (design library), Technician filter icon: “ICON_WRENCH: lazyGlyph("wrench"),”
AUTOMATION: HOLD - not yet build-verified on the Work Orders QA build

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.20-0509710, on 20 October 2026.
- Result: Passed on staging by the test's steps.
- Step 1: the Technician filter sits directly after Assigned to me, with the wrench icon, the word Technician and a down arrow. No Department filter.
- Steps 2 and 3: the list opens directly below the filter, starting with Unassigned, then technicians by first name then last name, each with a tick box.
- Steps 4 and 5: the technician is ticked; Escape closes the list.
- Step 6: Board View shows the same filter in the same place, still with the technician chosen.
- Step 7: List has no Technician filter.
- Seen but not part of this test: on opening the list, the red message 'This change would exceed the 50-value limit across all filters' already shows although nothing is ticked.
