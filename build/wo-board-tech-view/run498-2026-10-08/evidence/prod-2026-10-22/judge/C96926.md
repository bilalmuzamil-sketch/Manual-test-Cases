Preconditions
- Needs: 2 users · 1 browser · about 25 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- The case is run as [User-B]: a user who has never reordered the technician groups (the order is saved per user). A newly created user is safest: Role Admin (holds Work orders > View), Time Clock off, at this location, with an email you can open.
- [User-A]: an Owner/Admin user who creates the data (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). - One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Five technicians at this location, created in this order: "Aaron Zed", "Aaron Baker", "Brenda Martinez", "Chris Lee" (first), then a second "Chris Lee" (second, different email). These five names are the ones the expected results use. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Name Order" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Five Approved work orders for that customer, one led by each of the five technicians: [WO-1] led by the first Chris Lee and [WO-2] led by the second Chris Lee, so you can tell the two apart.
- Nobody is pinned by [User-B].
Setup
- Sign in with the Admin quick-login button on the sign-in page (you appear as "Admin ShopView"). Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff > New Staff Member > First Name and Last Name, an email you can open, Role "Admin", at least one Department (required), Location = this location, Time Clock off > Save & Close. Accept the invitation from that email and set a password. Record this user as [User-B].
- Top menu Customers > New Customer > Name "ZZAUTOTEST F2 Name Order" > Save (if it already exists, open it instead). On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, TRK-118) > Save. Make is required; Unit can be left 

## Steps
- Sign in as [User-B].
- Click Work Orders in the top menu.
- Click the All tab on the left of the toolbar.
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Read the group headers from top to bottom.
- For the two Chris Lee groups, note which work order each contains ([WO-1] or [WO-2]).
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Read the column headers from left to right.

- Unassigned is first. Your five technicians then appear in this relative order: Aaron Baker, Aaron Zed, Brenda Martinez, Chris Lee, Chris Lee (first name A-Z, then last name A-Z). Other technicians at the location fit in alphabetically between them.
