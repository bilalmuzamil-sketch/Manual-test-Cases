# C368151 — Verify the main Board View and Tech View controls work with the keyboard
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3761672

## Preconditions
- Work Orders View and Create & Edit permissions; desktop browser at least 1024 px wide.
- An Approved work order led by an active technician at the location; technician unpinned at the start.
- In Tech View, expand that technician’s group and enable Assigned Techs. The work order must have a technician avatar.
- Open Work Orders → All and search for the test work order or its customer.
- Tab enters the view at the last-focused work order, or the first work order if none was focused; it does not land on a header while work orders are shown. Use arrow keys between cards, rows and headers, then Tab to the focused item’s controls. Use Tab/Shift+Tab for toolbar controls. Mouse use is allowed for setup and switching to Tech View in Step 5.
Execution dependency: The previous Tech View blocker was recorded using Tab-only navigation. Rerun using the arrow-key navigation above before deciding whether access is still blocked. Automation remains on hold pending execution.

## Steps
In Board View, focus the work order card using the keyboard.
- Tab to More actions. Press Enter, then Escape. Repeat using Space, then Escape.
- Reach the technician’s column header with the arrow keys. Tab to its pin button and press Enter.
- Keep focus on the pin button and press Space.
- Switch to Tech View. Use the keyboard to reach the technician’s group header, then Tab to its collapse arrow and press Enter.
- Keep focus on the collapse arrow and press Space.
- Use the arrow keys to reach the work order row, then Tab to a technician avatar in Assigned Techs.
- Focus Column Selection. Press Enter, Tab into its options, then Escape.
- Using the keyboard, open Status, select Approved, and close the options. Focus the Status chip’s x and press Enter.
- Focus the Board View switcher button and press Enter.

## Expected (source quote — judge against this, never change it)
Step 1: The card shows a focus ring and its More actions (…) button appears without hovering.
Step 2: Enter and Space each open the menu. Escape closes it without changes and returns focus to More actions.
Step 3: The technician is pinned.
Step 4: The technician is unpinned.
Step 5: The group collapses.
Step 6: The group expands again.
Step 7: The focused avatar shows the technician’s name.
Step 8: The options open and are reachable with Tab. Escape closes them and returns focus to Column Selection.
Step 9: The Status filter is applied, then cleared by Enter on its x.
Step 10: The display changes to Board View.
Source — where this behaviour comes from
PRD v60, S11-R1/R3, S11-R2, S11-R5/R6, S11-R7/R8 and S3-R13.

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.19-1493c63, on 17 October 2026.
- Result: Passed on staging, using the keyboard only (steps 1 to 8 and 10 seen in round 4 on 17 Oct; step 9 in round 5, with no focus placed by the script).
- Step 1: Tab from Search lands on S2-37098's card with a focus ring and More actions shows.
- Step 2: Enter and Space each open the menu (Reassign lead technician, Unassign); Escape closes it and focus is back on More actions.
- Steps 3 and 4: the up arrow reaches the technician's column header, Tab reaches the pin; Enter pins and Space unpins.
- Steps 5 and 6: in Tech View, Enter on the group's collapse arrow collapses the group and Space expands it.
- Step 7: the avatar in Assigned Techs, reached by keyboard, shows "ZZAUTOTEST Ana Alpha".
- Step 8: Column Selection opens with Enter, Tab moves into its options, Escape closes it and focus is back on Column Selection.
- Step 9: Tab reaches Status, Enter opens it, Tab reaches Estimate and then Approved, Enter ticks Approved (chip "Status: Approved"), Escape closes the options with focus back on the chip, Tab reaches its x and Enter clears the filter.
- Step 10: Enter on the Board View switcher changes the display to Board View.
