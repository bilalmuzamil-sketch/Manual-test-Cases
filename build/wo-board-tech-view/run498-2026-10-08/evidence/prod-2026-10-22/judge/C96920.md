# C96920 — A display change that cannot be saved keeps the old choice and allows a retry
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481865

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes.
- Build: staging (https://app.staging.shopview.com), v26.40.17-a5c4210.
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- [Tech-A]: one eligible technician at this location. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Unsaved Display" (used by this case only) with one Approved work order [WO-1] led by [Tech-A].
- You can turn your computer's network connection off and on (e.g. Wi-Fi off).
- Names are examples; what must hold: there are work orders to show, and the network can be switched off during the case.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location. Create everything below in this location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Unsaved Display" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Unsaved Display": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads A

## Steps
- Open Work Orders.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Refresh the page and check it opens in Board View.
- Click Tech View, then List, then Board View in the display switcher, and wait until each has shown its work orders (this loads every display while online, so that offline only the saving of your choice can fail).
- Turn your network connection off.
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Note whether the display switched.
- In the display switcher, click List (tooltip "List").
- Turn the network connection back on and refresh the page.
- Note the display.
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Refresh the page and note the display.

## Expected (source quote — judge against this, never change it)
Expected results
- With the network off, the switcher still changes the display when clicked (the work orders themselves may fail to load while offline, that is not part of this check).
- After reconnecting and refreshing, the page opens in Board View: the changes made while offline were not saved, so the earlier choice was kept.
- Switching again while online works and is saved: after the last refresh the page opens in Tech View.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S1-N3, S1-N4, read 8 Oct 2026. Review Decisions 853901313 DR-23.
Exact quotes from the source (for reproducibility)
- S1-N3: “A failed preference save retains the previously saved preference.”
- S1-N4: “A failed preference save does not prevent view switching or retrying the save.”

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.19-1493c63, on 17 October 2026.
- Result: Passed on staging, following the test's steps (fix-up re-run, 17 Oct).
- Board View was chosen and a refresh opened Board View.
- Tech View, List and Board View were each loaded while online.
- With the network off, clicking Tech View and then List still switched the display; the saving failed ("Network Error").
- After the network came back and the page was refreshed it opened in Board View: the offline changes were not saved.
- Tech View chosen again online, then a refresh: the page opens in Tech View.
