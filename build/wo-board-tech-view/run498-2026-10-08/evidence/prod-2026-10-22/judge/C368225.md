# C368225 — Inventory keeps a chosen filter after a reload
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3792546

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 5 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011), desktop browser, window at least 1024 px wide.
- Role: Owner/Admin. On the sign-in page click the Admin quick-login button (you appear as Admin ShopView). The Admin role has Work orders > View and Create & Edit (check: your initials (top right) > Settings > Roles & Permissions > Admin > edit).
- Location: Staging Heavy Duty - 9919 for the whole case (shown next to the bell; change it with your initials > Change Location).
- Parts in the top menu opens the parts area; its left menu lists Part Sales, Inventory, Catalog, Returns, Purchase Orders, Vendor Invoices, Vendors.
- Needs no test data of its own beyond what the page already lists; filters you change here are restored at the end.
Setup
- Click Parts in the top menu > Inventory. If Category shows a value already chosen, clear it (the ⊗ on the filter button) so it shows its "All …" value.
- Check the setup worked: the page lists rows and the filter button shows no chosen value.

## Steps
- Click Parts in the top menu, then Inventory in the left menu.
- Open the Category filter and tick one value (e.g. the first one listed, "Uncategorized"). Write down the value.
- Close the filter (Escape or click outside it) and write down the rows shown.
- Reload the page.

## Expected (source quote — judge against this, never change it)
Expected results
- After the reload the filter still shows the value you ticked and the same rows show as before the reload.
- No error message appears.
Source — where this behaviour comes from
Regression for epic SV-10043 (PR #3548); developer's regression list, received 8 Oct 2026, Medium 6; QA handoff test plan (generated 2026-10-08), hotspot 5; PRD Confluence 845185030 (edited 7 Oct 2026) where quoted. Source-verified 8 October 2026.
Exact quotes from the source (for reproducibility)
- Dev reply 6: “Pages that remember filters and settings: Orders, Vendors, Return Requests, Return Credits, Part Sales, Deliveries, Parts Catalogue, Inventory, and the report pages.”
- Dev reply 6: “Set a filter, reload, and check that it's kept.”
