# C96996 — The technician field is blank only with no lead and no line technician
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481940

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View and Work orders > Create & Edit, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- Technician {Technician-A} (for example Esther Howard) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.
- Technician {Technician-B} (for example Ralph Edwards) is an active staff member at {Location-A} with Time Clock on and a Role other than Office User or Time Clock User.
- Customer {Customer-A} (for example "ZZAUTOTEST F3 Blank Technician") has exactly three work orders, all Approved, each with one approved line.
- Work order {Work-order-1} (for example S10043-17608) has no lead technician and its line {Line-1} (for example "Service - Full grease service") has no technician.
- Work order {Work-order-2} (for example S10043-17609) has no lead technician and its line {Line-2} (for example "Service - Full grease service") is given to {Technician-B}.
- Work order {Work-order-3} (for example S10043-17610) is led by {Technician-A} and its line {Line-3} (for example "Service - Full grease service") has no technician.

## Steps
- Open Work Orders, click the All tab and click Board View in the display switcher (tooltip "Board View").
- Type the name of {Customer-A} in Search.
- Click Fields to display, turn line technicians on and close the menu.
- Read the line technicians field on each of the three cards.
- Click Tech View in the display switcher.
- Click the Column Selection button and make sure Assigned Techs is on (it is on by default; turn it on if it was turned off), then close the menu.
- Read the Assigned Techs cell for each of the three rows.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 4: the {Work-order-1} card's field is blank, {Work-order-2} shows {Technician-B} and {Work-order-3} shows {Technician-A}. Only 1 of the 3 is blank. A "-" in an empty field counts as blank.
- Step 7: in Tech View the Assigned Techs cell is blank for {Work-order-1}, shows {Technician-B} for {Work-order-2} and {Technician-A} for {Work-order-3}.
Source — where this behaviour comes from
Epic SV-10043; story SV-10050 (Story 7, Show line technicians on cards and rows); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 52 (14 Oct 2026, Chris Ward), S7-N1 and S7-R7 (S7-R7 rewritten in version 51 on 14 Oct 2026 (Chris Ward ruling after Sasha Grosman's staging review: Tech View's default columns are the design's 13, and Assigned Techs is on by default); the Tech View step now only makes sure Assigned Techs is on, the expected results are unchanged), read 14 Oct 2026. Design export of 8 Oct 2026 (Claude Design project 787fef1a, Work Orders.dc.html): an empty group renders "-"; write down whether blank shows as empty or as a dash. Source-verified 14 October 2026. Last checked against build v26.40.8-7a95011 on 10/8/2026.
Exact quotes from the source (for reproducibility)
- S7-N1: “The field/column is blank only when there is no lead technician and no assigned line technician.”
- S7-R7: “In Tech View the Assigned Techs column sits immediately after Lines, matching the design. It is on by default (S5-R4) and can be removed through the column chooser (S2-R4).”
