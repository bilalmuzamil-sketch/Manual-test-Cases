Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481872

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011). A desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- [User-A]: an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). - One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- Three technicians at this location: [Tech-A] (e.g. "Esther Howard"), [Tech-B] = "Ralph Edwards" (the expected results name this technician, so keep this name) and [Tech-C] (e.g. "Jenny Wilson"). A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F2 Collapse Memory" (used by this case only), with one contact and one asset, so this case's work orders are kept apart from every other work order at the location.
- Three Approved work orders for that customer: [WO-1] led by [Tech-A], [WO-2] led by [Tech-B], [WO-3] led by [Tech-C].
- All groups start expanded for [User-A] (expand any collapsed group before starting). Numbers are examples; names marked "keep this name" stay as they are.

## Steps
- Open Work Orders.
- Click the All tab on the left of the toolbar.
- Click Search and type ZZAUTOTEST F2 Collapse Memory so only this test's work orders show.
- In the display switcher at the right of the toolbar, click Tech View (tooltip "Tech View").
- Click the collapse arrow on [Tech-B]'s group header.
- Check [Tech-A]'s and [Tech-C]'s groups are expanded.
- Refresh the page.
- Open Work Orders in a new browser tab.
- Close all Work Orders tabs, then open Work Orders again.
- Sign out, sign in again and open Work Orders in Tech View.
- Click the expand arrow on [Tech-B]'s group.

## Expected (source quote — judge against this, never change it)
Expected results
- Clicking the arrow collapses Ralph Edwards' group to its header only (rows hidden, header and count still shown).
- After the refresh, in the new tab, after reopening and after signing in again, Ralph Edwards' group is still collapsed and the other groups are still expanded.
- Clicking the arrow again expands the group and shows its rows.
