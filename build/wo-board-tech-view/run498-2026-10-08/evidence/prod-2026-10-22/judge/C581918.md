# C581918 — List ignores the Technician choice and Tech View brings it back
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3982133

## Preconditions
- Owner/Admin with Work Orders View and Create & Edit permissions; browser at least 1024 px wide. Active, clockable technicians A and B are eligible at the location.
- One unique customer has exactly three Approved work orders: WO1 led by A, WO2 led by B, WO3 unassigned. WO1 has Asset on Site = No.
- Clear filters and search; Assigned to me off.
Source: PRD v60, S1-R15b and S1-R3.
Execution dependency: The Technician filter must be available. The latest execution is blocked by SV-11326 (Open, checked 16 Oct 2026). Rerun when available; automation remains on hold pending execution.

## Steps
Open Work Orders → All → Tech View. Search for the customer and select technician A.
- Switch to List.
- Switch back to Tech View.
- Set Asset on Site = No, then reload the page. Inspect both the Asset on Site and Technician selections.

## Expected (source quote — judge against this, never change it)
Step 1: Only WO1 appears.
Step 2: All three customer work orders appear and List has no Technician filter; the stored Technician choice does not restrict List.
Step 3: Technician A is selected again and only WO1 appears.
Step 4: The Technician choice is remembered in the same way as the other filters: if Asset on Site = No survives reload, A also remains selected; if the other filter resets, Technician also resets. Record which behavior occurred.
AUTOMATION: Not available on Build to test Yet - Last checked 10/16/2026
