# C154885 — Tech View and Board View are offered only at 1024 pixels wide or more
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481978

## Preconditions
Dev-layer test — fe-unit. Existing coverage: app/src/components/ts/work-orders/**/WorkOrdersToolbar.spec.ts:115,127; workOrdersPreference.spec.ts:586
Preconditions
- Needs: 1 user · 1 browser · about 10 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser with the window at least 1024 pixels wide (full screen on an ordinary laptop or monitor). Below that width the page shows only List.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- [Tech-A]: one eligible technician at this location. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Width" (used by this case only) with one Approved work order [WO-1] led by [Tech-A].
- You know your screen width (e.g. a 1280 x 800 laptop: a full-screen window is 1280 pixels wide, a window snapped to half the screen is 640). A tablet that can be held sideways is optional.
- Names are examples; what must hold: you can make the window clearly narrower than 1024 pixels and full screen again.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Check the location in the top bar next to the bell; to change it click your initials at the top right > Change Location. Create everything below in this location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Width" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Width": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New L

## Steps
- Open Work Orders full screen.
- In the display switcher at the right of the toolbar, click Board View (tooltip "Board View").
- Make the window clearly narrower than 1024 pixels (e.g. snap it to half the screen).
- Look at the work orders area and the toolbar.
- Make the window full screen again.
- Note the display.
- Optional: open Work Orders on a tablet held sideways (1024 pixels or wider) and look at the toolbar.

## Expected (source quote — judge against this, never change it)
Expected results
- In the narrow window the page shows List exactly as it does today (the phone card layout) and there is no display switcher.
- Back at full width the switcher is offered again and the page is in Board View: the narrow window did not change your saved choice.
- On a sideways tablet of 1024 pixels or wider, Tech View and Board View are offered, the same as on a desktop.
- The exact 1024-pixel edge cannot be measured by hand: check clearly below and clearly above it and write "edge not checked by hand" in the result comment.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD Confluence 845185030, edited 7 Oct 2026 (status line "PRD v33"), S1-R14, read 8 Oct 2026. Tech plan revised 24 Sep 2026 (uploaded 8 Oct 2026), section 3.18. Review Decisions 853901313 DR-34.
Exact quotes from the source (for reproducibility)
- S1-R14: “The display options follow the same screen-width switch the List uses in production today. On a screen narrower than 1024px, the Work Orders page shows List exactly as it does today (the phone card layout), with no display switcher. At 1024px and wider, Tech View and Board View are offered, whatever the device: a tablet held sideways at 1024px or wider gets them too. The switch is by screen width only; the app never detects the device type.”
- Tech plan 3.18: “below the desktop breakpoint the mobile List renders and the new displays are withheld, and nothing overwrites the user's desktop choice.”
