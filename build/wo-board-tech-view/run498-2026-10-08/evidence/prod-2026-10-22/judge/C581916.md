# C581916 — Choosing technicians hides every other group and column, pinned ones too
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3982131

## Preconditions
- Owner/Admin with Work Orders View and Create & Edit permissions; browser at least 1024 px wide. Active, clockable technicians A, B and C are eligible at this location.
- For one unique customer, create Approved work orders: WO1 led by A; WO2 by B; WO3 by C; WO4 unassigned; WO5 led by C with A assigned only to a line item.
- Pin C’s Board View column. Clear filters, turn Assigned to me off and use the All tab.
Source: PRD v60, S1-R15 and S1-R3.
Execution dependency: The Technician filter must be available. The latest execution is blocked by SV-11326 (Open, checked 16 Oct 2026). Rerun when available; automation remains on hold pending execution.

## Steps
Open Tech View and search for the test customer.
- Select Unassigned and A in the Technician filter; close the options.
- Switch to Board View.
- Clear only the Technician selection.

## Expected (source quote — judge against this, never change it)
Step 1: WO1–WO5 are available in their lead-technician groups before applying the Technician filter.
Step 2: Only Unassigned and A groups remain, showing WO4 and WO1. B and C are hidden. WO5 is excluded because its lead is C, even though A is a line-item technician.
Step 3: The same selection is retained. Only Unassigned/WO4 and A/WO1 appear; all other columns, including pinned C, are hidden. WO5 remains excluded.
Step 4: All technician groups/columns are restored for the customer’s results, including WO2, WO3 and WO5. C is still pinned.
AUTOMATION: Not available on Build to test Yet - Last checked 10/16/2026
