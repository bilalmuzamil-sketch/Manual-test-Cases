# C682439 — Design- In the Dark theme, Board View column scrollbars are thin and dark
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/4060517

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role at {Location-A}, in a browser window at least 1024 px wide.
For example: {Location-A} is Staging Heavy Duty - 9919.
- The app is in the dark theme.
- At least one technician column at {Location-A} holds more work orders than fit on screen, so it scrolls.
For example: Unassigned at Staging Heavy Duty - 9919.
- Starting screen: "Work Orders" > "All" tab, "Board View" shown, in a window 1440 px wide.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Look at the right edge of the Unassigned column and of each technician column.
- Scroll one column down.
- Reload the page and look again.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: no bright white scrollbar track shows; any scrollbar is thin, in a dark grey on a transparent track, blending into the board.
- Step 2: the column scrolls and its scrollbar stays thin and dark.
- Step 3: after the reload the scrollbars are still thin and dark.
Known problem (SV-11430, Done; seen on staging on 16 Oct 2026): every column showed a bright white scrollbar track in the dark theme. (1) If you see exactly that, mark this test Failed and raise nothing new. (2) If it fails in a different way, report it. (3) If the scrollbars are thin and dark, mark it Passed.
Exact quotes from the source (for reproducibility)
From: PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 66 (19 Oct 2026, Chris Ward), read 19 Oct 2026 · Epic SV-10043, story SV-10044 (Story 1, Switch between display options), story SV-10046 (Story 3, Board View); ticket SV-11430
- S1-R9c: “Tech View and Board View work in the application’s dark theme as well as its light theme, using the design file’s dark colors. Every rule in this PRD holds in both themes.”
Not yet checked against a build.
References from Design
Shopview design system library in the design export of 14 Oct 2026 (_ds_bundle.js): scrolling panels use a thin scrollbar in the border colour on a transparent track; the dark-theme screenshots of the export (screenshots/*-dark.jpg) show no white track.
- Design system library, scrolling panel: “scrollbarWidth: "thin",
      scrollbarColor: "var(--sv-border-strong) transparent"”
