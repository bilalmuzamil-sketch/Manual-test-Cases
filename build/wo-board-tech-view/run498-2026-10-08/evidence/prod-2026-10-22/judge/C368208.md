# C368208 — A view-only user cannot change a row's Asset on Site toggle
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3792529

## Preconditions
Preconditions
- Needs: 2 users · 2 browsers · about 15 minutes
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011), desktop browser, window at least 1024 px wide.
- Role: Owner/Admin. On the sign-in page click the Admin quick-login button (you appear as Admin ShopView). The Admin role has Work orders > View and Create & Edit (check: your initials (top right) > Settings > Roles & Permissions > Admin > edit). (for the setup).
- Location: Staging Heavy Duty - 9919 for the whole case (shown next to the bell; change it with your initials > Change Location).
- View: on Work Orders the List is shown (click List in the display switcher at the right of the toolbar; its tooltip reads "List").
- A second user [User-V] whose role has Work orders > View on and Create & Edit off (custom role "ZZAUTOTEST WO View Only"). Sign in as [User-V] in a private window for the steps.
- Customer "ZZAUTOTEST View Only Toggle" (used by this case only) with one contact, one asset and one Approved work order [WO-1], made by you as Admin ShopView.
Setup
- Settings > Roles & Permissions > Create Custom Role > in "Choose a template" pick Service Advisor > Apply > Role Name* "ZZAUTOTEST WO View Only" > under Work orders turn Create & Edit off (View stays on) > Create (message "Role created successfully."). Then Settings > Staff > New Staff Member: First Name, Last Name, an Email you can open > Role = ZZAUTOTEST WO View Only (listed under CUSTOM) > Departments = Service > Location = Staging Heavy Duty - 9919 > Save & Close. The new user accepts the invitation from that email and sets a password. Record the user as [User-V] (the case calls this user "that user").
- Customers > New Customer > Name "ZZAUTOTEST View Only Toggle" > Save (the customer page opens). Contacts tab > New Contact > First Name "ZZAUTOTEST", Last Name "Contact" > Save. Assets tab > New Asset > Contact = ZZAUTOTEST Contact > Year 2022 > Make: type "Freight" and pick Freightliner > Model: type "M2" and pick it > Unit "TRK-118" > Save (Contact and Make are required).
- Work Orders > Create Work Order > New Work Order: Customer = "ZZAUTOTEST View Only Toggle" > Asset = its asset > Save. If a Confirmation says the customer is over their credit limit, click Create. The work order opens on its Lines tab with the New Line form open. Record the number shown at the top left as [WO-1] (the expected results call it "S1-794").
- In New Line > What Are You Doing? type "grease" and pick the ready-made line "Service - Full grease service" (it has no parts) > turn Line Approved on > Save & Close.
- Check the setup worked: as Admin, All tab > Search "ZZAUTOTEST View Only Toggle" lists [WO-1] with a green location pin in On Site.

## Steps
- As [User-V] open Work Orders, click List, click the All tab, click Search and type "ZZAUTOTEST View Only Toggle".
- Click the [WO-1] row's Asset on Site toggle (the location pin in the On Site column).
- Reload and read the toggle.

## Expected (source quote — judge against this, never change it)
Expected results
- The toggle is shown disabled and does not change, before or after the reload.
Source — where this behaviour comes from
Regression for epic SV-10043 (PR #3548); developer's regression list, received 8 Oct 2026; QA handoff test plan (generated 2026-10-08), §2; PRD Confluence 845185030 (edited 7 Oct 2026) where quoted (§1 Business Case). Source-verified 8 October 2026.
Exact quotes from the source (for reproducibility)
- QA handoff §2: “View-only user: no Create Work Order button, and the toggle is disabled.”
- PRD §1 Business Case: “List remains the default and stays exactly as it is in production today; the only addition to the Work Orders page is the switcher that offers the two new displays.”
