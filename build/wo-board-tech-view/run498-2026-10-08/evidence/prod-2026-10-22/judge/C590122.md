# C590122 — Design: Empty groups, empty columns and no-results pages look as in the design
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3995731

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in as an Admin user (the "Admin" role, which has Work orders > View and Create & Edit) at {Location-A}.
For example: {Location-A} is Staging Heavy Duty - 9919.
- The browser window is 1440 px wide with the zoom at 100%, and the design pictures "DC-18-tech-technician-chosen-light-1440.png" and "DC-13-tech-search-empty-light-1440.png" attached to this case are open beside it at 100% (actual size). Names, numbers and rank numbers in the pictures are sample data. The pictures' words differ from the ones checked here; compare the look and the place only.
- Technician {Technician-A} is active at {Location-A} with the "Technician" role and leads no work orders.
For example: {Technician-A} is ZZAUTOTEST C590122 Sam.
- Starting screen: "Work Orders" > "All" tab, "Tech View" shown, "Search" empty, no filter chosen, "Assigned to me" off, density "Regular".
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- On the "Work Orders" page, look at the group under {Technician-A}'s group header.
- Click "Board View" in the display switcher.
- Look at {Technician-A}'s column.
- Click "Status" and tick "Paid".
- Type "zzzz" in "Search".
- Click "List" in the display switcher.
- Click "Tech View" in the display switcher.
- Click "Clear all filters".
- Leave "zzzz" in "Search" and look at the page.
- Click "List" in the display switcher.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: the group shows the words "No work orders" in grey, centred, with the clipboard outline icon before them, as in the empty group at the bottom of the first picture.
- Step 2: Board View shows.
- Step 3: the empty column shows a dashed rounded box holding a light-grey circle with the clipboard icon and the text "Drag a work order here to assign it".
- Step 4: the "Status" chip shows "Paid".
- Step 5: the board is replaced by an empty state centred on the page: List's magnifier in a grey circle, "No work orders match these filters", "Try removing a filter to widen your results." and a "Clear all filters" button.
- Step 6: List shows the same empty state, with the same icon, words and button.
- Step 7: Tech View shows the same empty state as List.
- Step 8: every filter is cleared and "zzzz" stays in "Search", as it does in List.
- Step 9: Tech View shows "No work orders match the search "zzzz"." with no button, centred as in the search-only picture.
- Step 10: List shows the same message as Tech View at step 9.
Source — where this behaviour comes from
Epic SV-10043; stories SV-10045 (Story 2, Tech View), SV-10046 (Story 3, Board View), SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 61 (16 Oct 2026, Chris Ward), S2-R15, S3-R20, S1-R9a, S1-N1, S1-N1a and S1-N1b, read 16 Oct 2026. Claude Design project "Work Orders" (Branko Cicovic), export of 14 Oct 2026, board "Work Orders.dc.html" (the design pictures named in the preconditions were rendered from it), read 14 Oct 2026. Related tickets: SV-11319. Product owner answers: Chris Ward, WO Board and Tech View question sheet (https://docs.google.com/spreadsheets/d/1gBGmNB4B1bRrD2ZJvBn1tuvbfxFPjcsKddz_I5H3CvU), answers 10 and 17, read 15 Oct 2026. Source-verified 16 October 2026. Last checked against build v26.40.19-e435950 (staging) on 10/19/2026.
QA lead decision, 19 Oct 2026: "Clear all filters" keeps the search, as List does (in production too), so step 8 checks that the search stays and step 9 no longer types it again.
The design's empty texts read "No work orders assigned" and "No results for …"; Chris Ward answered on 14 Oct 2026 (answer 10) that the PRD's words are right, and this case follows them. The PRD (version 52) gave empty states the clipboard icon while List and the design use a magnifier on the no-results page; Chris Ward answered on 15 Oct 2026 (answer 17) that the no-results page keeps List's magnifier and the clipboard is only for a view with no work orders at all. PRD version 61 still says so, and steps 5 to 7 check the magnifier.
PRD version 58 reworded S1-R9a (the display switcher's slate icons in every view); what this case checks is unchanged.
Exact quotes from the source (for reproducibility)
- S2-R15: “A technician group with no work orders under the current filters, and an empty Unassigned group, show the text “No work orders”.”
- S3-R20: “A technician column with no work orders under the current filters, and an empty Unassigned column, show “Drag a work order here to assign it” to a user who can reassign work orders (S4-N1), and “No work orders” to everyone else.”

The filter chips and Search use the design file’s icons in every display option, List included, each exactly as the design file draws it. - S1-N1: “When the active filters or a search return no work orders, Tech View and Board View show the same empty state as the List, with the same messages and action.”

- S1-N1b: “With only a search active, the empty state reads “No work orders match the search "{search}".” and shows no button.”

- Design — SKILL.md (design library), empty states: “Empty-state illustrations are a deliberate omission — Shopview empty states are text only.”

## Newest PASSED result in run 498 (staging judgement)
Tested on staging, build v26.40.19-e435950, on 19 October 2026.
- Result: Passed on staging. Step 8 now expects the search to stay after "Clear all filters", as it does in List on production and staging, and as the requirements say (the List's clear-filter behaviour in every view). QA lead's decision, 19 Oct 2026.
- Empty technician group, empty Board View column and the filtered no-results page looked as the test describes.
- With Status Paid and the search zzzz, Tech View, Board View and List showed "No work orders match these filters" with the Clear all filters button.
- Clicking Clear all filters cleared the Status filter and kept zzzz in Search; Tech View then showed "No work orders match the search "zzzz"." with no button, and List showed the same.
