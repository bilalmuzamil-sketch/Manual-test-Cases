# C581890 — A search alone that matches nothing shows the search message with no button
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3973196

## Preconditions
Setup (manual QA tester and Claude session)
Preconditions
- You are signed in as an Owner or Admin user whose role has Work orders > View, at {Location-A} (for example Staging Heavy Duty - 9919).
- Your browser window is at least 1024 px wide, so the display switcher (List, Tech View, Board View) shows at the right of the Work Orders toolbar.
- No work order at {Location-A} matches the search text {Search-A} (for example ZZAUTOTEST-NOMATCH-A02).
- On the Work Orders page nothing is ticked in Status, Asset on Site shows no choice (if its chip shows Yes or No, click the x on the chip), Assigned to me is off and Search is empty.

## Steps
- Open Work Orders and click the All tab.
- Click Board View in the display switcher.
- Type {Search-A} in Search.
- Read the board.
- Click Tech View in the display switcher.
- Read the page.
- Click List in the display switcher.
- Read the page.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 4: the board shows "No work orders match the search "{Search-A}"." with the text you typed (for example: No work orders match the search "ZZAUTOTEST-NOMATCH-A02".), and no button.
- Step 6: Tech View shows the same message with the text you typed, and no button.
- Step 8: the List shows the same message, and no button.
Source — where this behaviour comes from
Epic SV-10043; story SV-10044 (Story 1, Switch between display options); PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 48 (12 Oct 2026, Chris Ward), S1-N1 (reworded) and S1-N1b (added) in version 43 (8 Oct 2026, Chris Ward), read 14 Oct 2026. Design export of 14 Oct shows "No results for …" with other text; the PRD wins (design follow-up). Source-verified 14 October 2026.
Exact quotes from the source (for reproducibility)
- S1-N1b: “With only a search active, the empty state reads “No work orders match the search "{search}".” and shows no button.”
- S1-N1: “When the active filters or a search return no work orders, Tech View and Board View show the same empty state as the List, with the same messages and action.”
