# C368137 — A reorder that cannot be saved shows its alert and the card goes back
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3761658

## Preconditions
Preconditions
- Needs: 1 user · 1 browser · about 15 minutes.
- Build: the Work Orders QA build (sv10043, v26.40.8-7a95011).
- [User-A] = you: an Owner/Admin user (on a QA branch the Admin quick-login user, shown as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit.
- Desktop browser window at least 1024 px wide. Narrower windows show only the List, without the display switcher.
- One location for the whole case, shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); everything below is created in this location.
- [Tech-A]: one eligible technician at this location. A person only counts as a technician here when the staff member is active (not deactivated), Time Clock is on, the Role is neither Office User nor Time Clock User, and this location is picked in their Location field.
- Customer "ZZAUTOTEST F1 Reorder Offline" (used by this case only) with three Approved work orders led by [Tech-A]: [WO-1], [WO-2], [WO-3].
- You can turn this computer's network connection off and on (e.g. Wi-Fi off).
- Names and numbers are examples; what must hold: three cards in one technician's column.
Setup
- Sign in as an Owner/Admin user (on a QA branch: the Admin quick-login button on the sign-in page; you appear as "Admin ShopView"). The Admin role holds Work orders > View and Work orders > Create & Edit (to check: your initials at the top right > Settings > Roles & Permissions > Admin > Work orders).
- Use one location for the whole case: it is shown in the top bar next to the bell (e.g. "Staging Heavy Duty - 9919"); to change it click your initials at the top right > Change Location.
- Settings (your initials at the top right > Settings) > Staff: reuse a technician only after checking it is active, has Time Clock on, a Role other than Office User or Time Clock User and this location in Location; otherwise add one: New Staff Member > First Name and Last Name, an Email, Role "Technician", at least one Department (required), Location = this location, Time Clock on > Save & Close. Record them as [Tech-A] (e.g. Esther Howard).
- Create the customer used only by this case: top menu Customers > New Customer > Name "ZZAUTOTEST F1 Reorder Offline" > Save. On the customer page click the Contacts tab > New Contact > First Name and Last Name > Save (a new asset needs a contact). Then click the Assets tab > New Asset > pick the Contact, then Year, Make, Model and Unit (e.g. 2022, Freightliner, M2, unit "TRK-118") > Save. Make is required; Unit can be left empty.
- Create these work orders for "ZZAUTOTEST F1 Reorder Offline": Work Orders > Create Work Order > in the New Work Order window pick the Customer and its Asset > Save. The new work order opens with the New Line form (otherwise click New Line on the Lines tab): in "What Are You Doing?" pick a ready-made line (e.g. "Replace - Brake pot"; typed free text finds no results), turn on Line Approved so the work order status reads Approved, and click Save & Close. ## Steps
- Open Work Orders, click the All tab and pick Board View in the display switcher (right side of the toolbar; tooltip "Board View").
- Type "ZZAUTOTEST F1 Reorder Offline" in Search.
- Write down the order of the three cards in [Tech-A]'s column (e.g. [WO-1], [WO-2], [WO-3]).
- Turn off this computer's network connection (e.g. Wi-Fi off).
- Drag the last card to the top of [Tech-A]'s column.
- Read the alert and the order of the cards.
- Turn the network back on and reload.
- Repeat steps 3 to 7 in Tech View.

## Expected (source quote — judge against this, never change it)
Expected results
- An alert reads exactly: Couldn't save the new order. Please try again. (A straight or curly apostrophe is not a difference.)
- The card goes back to where it was, so the order is again as written down, and stays so after the reload. No lead change message appears.
