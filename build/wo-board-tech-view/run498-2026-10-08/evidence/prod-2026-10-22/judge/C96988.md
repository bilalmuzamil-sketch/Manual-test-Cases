# C96988 — Density changes spacing and size only, never what is shown
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3481932

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role at {Location-A}, in a browser window at least 1024 px wide.
For example: {Location-A} is Staging Heavy Duty - 9919.
- Technician {Technician-A} is active at {Location-A}, with Time Clock on and a Role other than "Office User" or "Time Clock User".
For example: {Technician-A} is Esther Howard.
- Customer {Customer-A} has one Approved work order, {Work-order-1}, led by {Technician-A}.
For example: {Customer-A} is ZZAUTOTEST F1 Density Content and {Work-order-1} is S1-702.
- In Tech View's "Column Selection", "Lead Technician" is turned on (it is off until you turn it on).
- Starting screen: "Work Orders" > "All" tab, "Tech View" shown, the name of {Customer-A} in "Search", no filter chosen, "Assigned to me" off, density "Regular".
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- Write down every column heading and every value in {Work-order-1}'s row.
- Click the density button and choose "Compact".
- Compare the column headings and the values in {Work-order-1}'s row with what you wrote down at step 1.
- Click the density button and choose "Comfortable".
- Compare the column headings and the values in {Work-order-1}'s row with what you wrote down at step 1.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: the row shows a value in its columns, including {Technician-A} under "Lead Technician", a progress bar under "Progress" and an amount under "Total price".
- Step 2: the rows are tighter (shorter) than at Regular. Nothing else about the row changes.
- Step 3: the same columns, in the same order, with the same values as at step 1. "Lead Technician", "Progress" and "Total price" are still shown.
- Step 4: the rows are roomier (taller) than at Regular.
- Step 5: the same columns, in the same order, with the same values as at step 1.
Exact quotes from the source (for reproducibility)
From: PRD "Work Orders — Board View & Tech View Display Options", Confluence 845185030, version 71 (20 Oct 2026, Chris Ward), read 20 Oct 2026 · Epic SV-10043, story SV-10049 (Story 6, Density in Tech View and Board View)
- S6-R2: “Density adjusts spacing and the size of rows, cards, and their elements.”
- S6-R6: “Changing density never changes which fields, columns, or values are displayed.”
- Key decision, Fields vs. density are separate controls: “Density changes spacing and element sizing only; it never hides fields.”
