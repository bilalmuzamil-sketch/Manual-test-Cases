# C368159 — Toggling On Site from a stale page does not undo another user's lead change
Test in run 498: https://shopview.testrail.io/index.php?/tests/view/3761680

## Preconditions
Setup file (for Claude sessions; a tester does not need it)
Preconditions
- You are signed in with the "Admin" role at {Location-A} in browser 1, in a window at least 1024 px wide.
For example: {Location-A} is Staging Heavy Duty - 9919.
- User {User-B} is signed in at {Location-A} in browser 2, with a role that has Work Orders View and Create & Edit.
For example: ZZAUTOTEST Dispatcher Two.
- Technicians {Technician-A} and {Technician-B} are active at {Location-A}, and both are offered in the Lead Technician list on the work order page.
For example: AA ZZAUTOTEST C368159 Ana and AA ZZAUTOTEST C368159 Ben (names starting "AA" sit near the top of the work order page's technician lists, which offer only about the first 100 people in A to Z order (SV-11429)).
- Customer {Customer-A} has one Approved work order, {Work-order-1}, led by {Technician-A}.
For example: {Customer-A} is ZZAUTOTEST F3 Stale On Site Site Co.
- If any record above is missing, mark this test Blocked: "setup not done".

## Steps
- In browser 1, open "Work Orders" > "All".
- In browser 1, type the name of {Customer-A} in "Search" and click "List".
- In browser 2, open {Work-order-1}.
- In browser 2, change "Lead Technician" on the work order page to {Technician-B}.
- In browser 1, without refreshing, click {Work-order-1}'s "On Site" toggle.
- In browser 1, refresh the page.
- In browser 1, open {Work-order-1}.

## Expected (source quote — judge against this, never change it)
Expected results
- Step 1: Work Orders opens on the "All" tab.
- Step 2: the List shows {Work-order-1}, led by {Technician-A}.
- Step 3: the work order page of {Work-order-1} opens.
- Step 4: "Lead Technician" reads {Technician-B}; it saves at once.
- Step 5: the "On Site" toggle changes.
- Step 6: {Work-order-1}'s "On Site" toggle keeps the change made in step 5.
- Step 7: "Lead Technician" reads {Technician-B}. Browser 1's older page did not put {Technician-A} back when it saved On Site.
