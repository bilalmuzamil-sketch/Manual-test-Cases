## Steps for a manual tester (once each test can be run)
1. Work Orders > All > Tech View. Point at the button at the left end of the column headings, click it, point again, refresh, click again.
2. Needs an imported work order. Board View > search it > card's More actions > point at Reassign lead technician. Repeat in Tech View.
3. Work Orders > All > Board View > Fields to display > turn every field off > close the menu > read any card.
4. As a brand-new user: Work Orders > All > Tech View > Column Selection > read the heading and count > untick "Created on" > click Show all > click Reset to default.
5. Tech View > Column Selection > type "ass", then "ASS", then "zzqx", then clear. Then Board View > Fields to display > type "zzqx", clear.
6. Someone with Google Analytics access: open the Story 12 density and field reports for 9 Oct 2026.
7. Day 1: user 1 turns VIN/Serial on, off, on in Board View > Fields to display. Day 2: user 2 turns VIN/Serial on; user 3 turns Total price off; user 4 only opens Board View. A week later read the Board View field selection report.
8. This week: user 1 opens Work Orders 5 times, Board View, density Compact; user 2 twice, Tech View, Comfortable; user 3 once, stays on List; user 4 once, Tech View, leaves Regular. Then read the weekly display use and density reports.
9. Invoice a work order (Finance > Create Invoice). On its page, try to change Lead Technician, Mileage and Engine Hours in the left card; reload.
