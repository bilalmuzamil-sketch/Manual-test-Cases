# Problem reports waiting for your yes, in the order we will ask (15 Oct 2026)

Nothing has been raised. We ask you about one report at a time and wait for your answer before the next.
Every one of these was seen on the staging site on 15 October.

**Before you answer, one thing to know:** for 11 of the 17 reports below (numbers 3 to 13), the same
problem was already reported on 14 October by the product owner or a developer, and those reports are
still open; number 15 may be covered by one of them too. For those, our suggestion is to attach our failed tests to the existing report
and raise nothing new. You decide each one.

1. **Work order order in a new group.** Before anyone reorders a technician's work orders, the new
   views list them in the order they were made instead of A to Z by customer. Not reported before (an
   earlier report of the same problem was closed as no longer needed after it worked on the test site).
2. **The technician list stops at about 100 people.** On a work order page, the lead technician list and
   the add-technician list stop at about the first 100 people, so later names cannot be picked. We cannot
   tell whether this is new: the live site has too few people to show it, and this release changed those
   lists. Not reported before.
3. **No Technician filter.** The new views have no Technician filter after Assigned to me, so users cannot
   show only chosen technicians. Already reported.
4. **Icons.** The view switcher and the density button use different drawings from the design, and the
   board view reuses the table view's density drawing. Already reported.
5. **Switcher hint covers the headings.** The hint on the view switcher opens below it and covers the
   table's column headings. Already reported.
6. **Table view has side margins.** The table should run to both edges of the page; it has a grey strip
   on each side. Already reported.
7. **Board view sits in a grey panel.** The board should run full width; it sits inside a grey rounded
   panel. Already reported.
8. **Wrong starting columns.** The table view opens on the wrong set and order of columns. Already reported.
9. **Column headings too heavy.** The column headings are bold and black instead of small and grey.
   Already reported.
10. **Table cells.** The work order number is not blue, there is no progress bar, and the advisor has no
    picture. Already reported (one small part, the heading picture not changing size with the row height,
    is not in that report).
11. **Status label height.** The status label does not get taller in the roomiest row height. Already
    reported.
12. **No drag handles.** The rows and group headings in the table view show no drag handle. Already reported.
13. **Grey initials.** People without a photo show as a solid blue circle instead of grey initials, on the
    board and in the change-lead window. Already reported.
14. **No shadow on hover.** Resting the pointer on a board card shows no soft shadow. Not reported before.
15. **Menu without icons.** The card's menu item has no small icon before it. Possibly covered by the
    existing report about icons; you decide.
16. **Name hint below the picture.** The name hint on a technician's picture opens below it instead of
    above. Not reported before.
17. **"Lead technician updated" message.** It shows as a solid green box with a Close button instead of the
    design's white box with an X. Not reported before.

**What we need from you:** for number 1, yes or no to raise it. Then we come back for the next one.
If we hear nothing, nothing is raised.
