## Time-zone fact found in this run
The test machine's time-zone database is **2026e**. Python, the system `date` and the browser all agree on it, and it puts **America/Edmonton at UTC−6 and America/Vancouver at UTC−7 all winter** (year-round daylight time). Toronto moved to UTC−5 on 1 Nov. The requests in this run used those offsets (for example, Lethbridge Last 12 Months ends 2026-11-05T05:59:59Z), and every tile matched its report. Whether the **server's** time-zone database agrees has not been checked. If it is older, Lethbridge and QB Location day boundaries would differ by one hour between browser and server. **Open item: check the server's zone offset for Edmonton.**
