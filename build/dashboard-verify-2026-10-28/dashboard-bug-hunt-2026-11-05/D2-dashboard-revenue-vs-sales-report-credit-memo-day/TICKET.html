What is wrong

On the Dashboard, the Revenue tile and the Sales report it links to can show different amounts for the same day at an Edmonton (Alberta) location. It happens to sales and credit memos made between midnight and 1:00 AM, location time.

Why (in plain words): the Dashboard works out where a day starts and ends on the server, using the newest time-zone rules. The Sales report works it out in the user's web browser, using whatever time-zone rules that browser has built in. The newest rules (time-zone data version 2026e) keep Edmonton at UTC−6 after 1 Nov 2026. A browser with older rules, including the Chromium 153 browser we tested with, still moves Edmonton back to UTC−7. So that browser starts the report's day one hour later than the Dashboard does.

Example (location Staging Heavy Duty - 9919)

  • Credit memo CM11839-4189 for $5.00 was made between 12:00 AM and 1:00 AM on Nov 3 under the newest rules. Under the browser's older rule, that is 11 PM to midnight on Nov 2.
  • Nov 3: the Revenue tile shows $1,625.23. The Sales report opened from the tile shows $1,630.23. The four invoices that day add up to $1,630.23. The tile takes the $5.00 credit memo off ($1,630.23 − $5.00 = $1,625.23); the report leaves it out.
  • Nov 2: the Revenue tile shows $0.00. The Sales report shows −$5.00. Its only row is CM11839-4189, and that row is dated "Nov 03 2026".
  • When we ask the server for the Sales report with the day starting at midnight under the newest rules (UTC−6), the credit memo falls on Nov 3, the same day as the tile. So the tile's day is the right one, and the report's day comes from the browser's older rule.

Steps to reproduce

  1. Use a browser whose time-zone rules still put Edmonton on UTC−7 after 1 Nov 2026, with the computer set to Edmonton time. (We used Chromium 153.)
  2. Log in as an Admin and pick the location Staging Heavy Duty - 9919 in the top bar.
  3. Open Dashboard.
  4. On the Revenue tile, click the date button, click 3 (November) twice, and click Apply. Note the amount.
  5. Click the small report icon next to the word "Revenue". The Sales report opens in a new tab on the same day. Note the Totals amount in the Subtotal column.
  6. Repeat steps 4 and 5 with Nov 2.

Actual: Nov 3: tile $1,625.23, report $1,630.23. Nov 2: tile $0.00, report −$5.00, with one row dated "Nov 03 2026".

Expected: the tile and the report show the same amount for the same day, whatever time-zone rules the user's browser has built in. Dashboard PRD (Confluence page "Dashboard", version 53):

  • S3-R1: "Every figure the dashboard shows for a measure equals the figure the measure's matching report shows for the same workplace, date range, and filters. This holds at every moment, not merely in principle."
  • S3-N1: "If a measure's report shows a value, the matching tile shows the same value; the two never disagree."
