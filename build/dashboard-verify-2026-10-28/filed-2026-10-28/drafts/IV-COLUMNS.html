Description

When Inventory Value is opened for the first time in a browser, the Margin and Total Sell columns are already shown. The written rule is that both start hidden, and the user turns them on from the column selector if wanted.

Impact: every new user (and every user on a new browser or device) sees two extra money columns by default, so the default view is wider than intended and shows sell-side figures the default view is meant to leave out.

What is NOT affected: the column selector works: turning Margin or Total Sell off hides it, and turning it on brings it back in the right place. The figures in the columns are correct. This was first reported as SV-8927 (closed on 9 Aug 2026); it still happens on the current build.

Steps to Reproduce

  1. Open a browser window that has never opened Inventory Value before (a private / incognito window works).
  2. Sign in to staging as an Admin. In the top bar, choose the location DVI Test.
  3. Open Reports. In the left menu, under Parts, click Inventory Value.
  4. Read the column headings across the top of the table. They are: Part #, Description, Category, Vendor, Location, Qty, Unit Cost, Unit Sell, Margin, Margin %, Total Sell, Total Cost.

Actual Result

  • On the first visit, Margin and Total Sell are shown.

Expected Result

  • On the first visit, Margin and Total Sell are hidden. The visible columns are Part #, Description, Category, Vendor, Qty on Hand, Unit Cost, Unit Sell, Margin % and Total Cost (plus Location for a user with more than one location).

Source: Confluence Inventory Value report specification, last changed 13 Aug 2026, read 28 Oct 2026. S3-R12: "On first visit, the visible columns are: Part #, Description, Category, Vendor, Qty on Hand, Unit Cost, Unit Sell, Margin %, and Total Cost." S3-R13: "The Margin and Total Sell columns are hidden by default and can be turned on from the column-selection control (Story 8)." S8-R3: "Every other column is available in the control; Margin and Total Sell are off by default, the rest on by default (S3-R12)."

Technical details for developers

  • The browser stores the view under report_table:inventory-value; with nothing stored, the default visible set is every selectable column (IV_DEFAULT_VISIBLE_COLUMNS in app/src/components/ts/reporting/inventory-value/Model.ts).
  • Related story: SV-8670 (Inv Value Story 3, Columns and Calculations).
