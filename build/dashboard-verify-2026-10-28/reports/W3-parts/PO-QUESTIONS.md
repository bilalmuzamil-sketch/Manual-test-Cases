| PQ-1 | Report Suite · Parts Velocity | Should **Last 90 days** cover exactly 90 days (today and the 89 days before it)? *Yes / No* | Today it covers **91** days: on 28 Oct it runs 30 Jul – 28 Oct. SV-11514 only says "The default range is Last 90 Days." | |
| PQ-2 | Report Suite · Parts Velocity | Should Revenue, Margin, Avg Cost, Avg Sell, Sold (WO), Sold (Parts Sale) and every Special Order figure be dated by the **invoice date**? *Yes / No* | The spec (Story 5, "Work-order date") dates them by the work order's **end date**, but work orders do not get an end date (it is empty on the paid work order S2-17193 we opened, and the build's own notes say it is never filled), so the report uses the invoice date. A "Yes" means the spec should be updated; a "No" means we need a different date. | |
| PQ-3 | Report Suite · Parts Velocity | Should a return **to the vendor** made from **Parts → Returns** count in **Units Returned**? *Yes / No* | It does today (we returned 1 unit of ZZAUTOTEST-PV1-10282011 to the vendor and Units Returned went from 0 to 1; cancelling it put it back to 0). The spec names only "a work-order part return or a parts-sale credit". | |
| PQ-4 | Report Suite · Parts Velocity | When a user who has several locations picks **one** location, should the **Location** column be **hidden**? *Yes / No* | It is hidden today. The spec says both: S2-R12 "when a single location is in scope the column is hidden", and S3-R10 / Key Decisions "shown by default … regardless of how many locations are currently selected". (This is the same open point as the contested SV-8938.) Inventory Value shows the column with one location selected. | |
| PQ-5 | Report Suite · Parts Velocity | Is the date list on screen the intended one — **This week, Last week, This month, Last month, This quarter, Last quarter, This year, Last year, Last 90 days, Last 12 months, Custom** (no Today, no Yesterday)? *Yes / No* | That is what the screen offers, in line with your 5 Aug answer and SV-11514. The spec text (S2-R2) still lists Today and Yesterday and does not list Last 12 months, so a "Yes" means S2-R2 should be updated. Every option's dates were checked and are right. | |
| PQ-6 | Report Suite · Parts Velocity | Should a part's past sales **stay** in Parts Velocity after the part record is **deleted**? *Yes / No* | Today they disappear. S3-N1 says "A part with billed Revenue > 0 is always kept". We could not delete a sold part from the screen, so we have not raised a ticket. | |
| PQ-7 | Report Suite · Parts Velocity | Should **Last Sale** for a stocked part include a sale that was billed but recorded **no stock movement**? *Yes / No* | Example: N000000001069 at Staging Heavy Duty - 9919 was billed on S2-16621 (30 Jul 2026) but Last Sale reads 160 days (its previous stock-moving sale). | PQ-8 | Report Suite · Inventory Value | When a part's cost is **above the highest price band** of its category's pricing matrix, should Unit Sell use that highest band's markup? *Yes / No* | That is what it does today, and it matches the parts list (example: 2599273C92 at Staging Lethbridge - 4310, cost $526.70, category HD-Filters whose bands stop at $500 → Unit Sell $752.44 = +42.86%).
