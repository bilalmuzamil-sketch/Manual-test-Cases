## Create a new report - Technician Efficiency (invoiced)

**Report is to be location specific, please start populating data once complete**

This report is a report to show efficiency numbers after work orders are closed and invoiced. 

‌

**Which staff should populate in the report?** 

* Any user that has time punched into a WORK ORDER, and that work order has been _invoiced within the time period selected,_ would show up in this report. 
* If the user was not on any work orders, and was only clocked into departments, then they would not show up on this report. 
* If a user clocked into work orders, but none of those work orders got invoiced, they should not populate on it, because there would be no information to populate for them (since nothing was invoiced)

‌

_**When**_ **does information push to the report?** 

* When the invoice button is clicked, and the invoice is created. The report should pull information from all invoices _(Paid or unpaid)_
* If the invoice is reversed, it would become a work order again, and it would not longer be pushing information to the report.   

 

**Title, Filters, Header/Totals and Scrolling:**

* Date filter - Should be the same date filter components as the others on the other reports. Need to confirm that all auto date range selections work properly (Today, this week, last week, etc..etc..), and also the custom date range works properly. (We have had issues with this in the past)
* Default the date filter to ‘This month’
* Lock table headers at the top
* Create totals as noted in the spreadsheet - lock to bottom of page and **bold**

    * Add tool tips with the noted Descriptions to the totals
    
* Scroll within the header and totals
