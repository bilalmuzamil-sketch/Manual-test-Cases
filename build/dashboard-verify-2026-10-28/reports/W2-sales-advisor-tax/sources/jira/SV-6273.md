Technician Efficiency Report – Completed Date Filter Includes Data from Incorrect Dates

For example, selecting **March 17th** also returns data from **March 16th**, indicating that the date filter is not being applied correctly.

Precondition: Log in to the staging environment:  
Username: [ayesha.khan+1@shopview.com](mailto:ayesha.khan+1@shopview.com)  
Password: [REDACTED]

---

###   
**Steps to Reproduce (STRs):**

1. Navigate to **Reports → Technician Efficiency Report**.
2. Ensure the report is set to use the **Completed Date** column.
3. Apply the date filter for **March 17th**.
4. Review the data in the report.

---

### **Actual Result:**

* The report includes entries from **March 16th**, even though only **March 17th** was selected.

---

### **Expected Result:**

* The report should display **only the data for the selected date (March 17th)**.
* No data from other dates should be included.
