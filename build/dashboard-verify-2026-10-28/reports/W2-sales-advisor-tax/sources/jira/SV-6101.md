# SV-6101 — Sales Report: Incorrect profit and totals when credited parts have sell price lower than cost
Status: Done · created 2026-03-12 · updated 2026-05-05 · parent SV-3602

System allows the **sell price of parts to be lower than their cost**, we need a better formula for calculating **credits**.

For example:

* If a part **costs 20** and the **sell price is 30**, the profit is **10**.  
  If that transaction is **credited**, the profit should be displayed as **-10**, which is correct.
* If a part **costs 20** and the **sell price is 10**, the profit is **-10**, which is also correct.  
  If this case is **credited**, the report still shows the profit as **-10**, while it should actually be **+10** (because the credit reverses the original loss)  

As a result, **profit per row is not calculated correctly when the sell price is zero or lower than the cost**.

Because of this, the **Totals row is also incorrect**, since it sums row values that are already calculated incorrectly.

Note:  
Something similar exists in almost every report in the app. Edge cases, such as discounts, warranties, and other adjustments, use the same mechanism, and they will break the reports unless we fix the math.
