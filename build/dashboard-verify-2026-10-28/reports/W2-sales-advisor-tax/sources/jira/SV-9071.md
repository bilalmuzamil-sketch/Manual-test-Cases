# SV-9071 — SBC | "Inv. Hrs" column is misnamed
Status: Done · created 2026-08-10 · updated 2026-08-27 · parent SV-8610

The column headed **Inv. Hrs** does not contain invoiced hours. It contains invoiced hours minus clocked hours. Those are two different quantities with two different ranges:

| Quantity | Range | Why |
| --- | --- | --- |
| **Invoiced hours** | Always ≥ 0 | ShopView invoices the estimate time set on the line or work order. It is billed regardless of how much the tech actually clocked, so it can never go below zero |
| **Delta hours** (invoiced − clocked) | Negative, zero, or positive | A difference between two independent values |

  
**Expected**

The heading names what the column holds. Recommended label: **Labor Delta** — the term the spec already defines in Terminology, so no new vocabulary is introduced.
