# SV-6147 — Sales Report margin displays N/A when Parts Invoiced is $0.00
Status: Open · created 2026-03-16 · updated 2026-06-26 · parent None

In the Sales Report, rows with parts cost but **no** **parts** **invoiced** (e.g., `P1-6`, `C1-554`) display:

* **Parts** **Invoiced** = $0.00
* **Parts** **Margin** = N/A

  The `N/A` appears because margin is calculated as `(profit / invoiced) * 100`, and dividing by zero is not possible.

‌

**Questions:**

1. Should margin show **N/A** when invoiced is $0? (current behavior)
2. Or should it show **0%**, **-100%**, or something else?
