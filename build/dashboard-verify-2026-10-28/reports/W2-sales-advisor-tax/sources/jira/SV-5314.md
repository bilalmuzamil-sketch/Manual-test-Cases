# SV-5314 — BE Credit on Sales report
Status: Done · created 2025-12-24 · updated 2026-03-30 · parent SV-3602

**As a** user viewing the Sales Report  
**I want** credits to appear as separate entries with all financial values shown as negative  
**So that** reporting accurately reflects reversals and does not imply an active Work Order link.

---

## Description

When a credit exists, it must be included on the Sales Report. For credit entries, the report must display key financial metrics as **negative values**. The Work Order (WO) link must not be shown for credits. Instead, the **Credit ID** should be displayed **as plain text (no link)**.

---

## Acceptance Criteria

1. **Credit Included on Sales Report**

    * Each created credit appears on the Sales Report as its own row/record (or as per existing report grouping rules).
    
2. **Negative Values for Credit Entries**

    * For credit rows, the following fields are displayed as **negative** values:
    
        * Parts invoiced
        * Parts cost
        * Parts margin
        * Profit
        * Margin
        * Subtotal
        
    
3. **WO Link Removed**

    * For credit rows, the Work Order (WO) link is **not displayed** (removed or blank, per layout).
    
4. **Credit ID Display (No Link)**

    * The Credit ID is displayed on the report as **non-clickable text** (no hyperlink).
    
5. **Non-credit Rows Unchanged**

    * Normal (non-credit) sales rows continue to display current values and links unchanged.
