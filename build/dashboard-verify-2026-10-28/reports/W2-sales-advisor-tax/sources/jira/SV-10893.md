# SV-10893 — Advisor Analysis report: add "Last 12 months" to the date filter
Status: Done · created 2026-10-05 · updated 2026-10-22 · parent SV-9582

**Affected Role or Area:** Reports → Advisor Analysis report, Date filter. Affects users with the Reports permission.

**Description:** The Dashboard's Billing Efficiency card offers a "Last 12 Months" date option, but the Advisor Analysis report it links to doesn't. When you open the report from the Billing Efficiency card set to Last 12 Months, the dates carry over but show as "Custom", and users can't pick Last 12 months on the report themselves. Chris Ward confirmed the Advisor Analysis report should offer this option.

**Steps:**

1. Log in to [sv490.qa](http://sv490.qa) as a user with the Reports permission.
2. Go to Reports → Advisor Analysis.
3. Click the Date filter and look through the options.
4. Go to the Dashboard, set the Billing Efficiency card to Last 12 Months, and click the report icon next to "Billing Efficiency".

**Actual Result:** The Advisor Analysis report's date filter has no "Last 12 months" option. Opening it from the Billing Efficiency card shows "Date: Custom".

**Expected Result:** The Advisor Analysis report's date filter includes "Last 12 months", covering the same dates as the Dashboard's Last 12 Months.

**Impact:** Users can't view the last 12 months on the Advisor Analysis report without entering custom dates, and the report doesn't line up with the Dashboard card it comes from.
