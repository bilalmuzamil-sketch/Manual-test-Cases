# SV-5450 — BE 'Completed' Technician Efficiency Report
Status: Done · created 2026-01-14 · updated 2026-03-25 · parent SV-5871

## Summary

Create a new technician efficiency report that calculates efficiency based on **Completed labor lines**, independent of invoice status. This report should mirror the existing Technician Efficiency report but use completion state and completion date as the source of truth.

---

## Problem Statement

The current Technician Efficiency report relies on **invoiced tech time labor**, which delays or distorts technician efficiency metrics due to invoicing timing. We need the ability to also evaluate technicians on work they have **completed**, not when administrative invoicing occurs.

---

## Goal

Provide a technician efficiency report that:

* Includes labor lines once they are marked `Completed`
* Excludes labor lines that are not completed
* Is not affected by whether an invoice exists
* Accurately reflects technician performance in near real-time

---

## Scope

### New Report

* Report name: **Technician Efficiency (Completed)**
* Split into two tabs, one for ‘invoiced’ (current report) and one for ‘completed’

## Report Logic

### Inclusion Rules

A labor line should appear in the report **only if**:

* Labor line status = `Completed`

A labor line should **not** appear in the report if:

* Status is anything other then complete.
* Status is reverted from Complete to any other state

Invoice status must **not** affect inclusion.

---

### Completion State Behavior

* When a labor line is marked `Complete`, it appears in the report
* If a completed line is later uncompleted:

    * It must be removed from the report
    
* If that same line is re-completed:

    * It must reappear in the report
    * The report must use the **most recent completed timestamp**
    
* Completion is determined **only** by line status = Complete, not by clock-out state or invoice state.
* Always use the location timezone for the timestamp. Not the user time zone.

## Calculations

### Completed Tech Time Hours

* Sum of ‘tech time’ hours from labor lines where:

    * Status = Completed
    * Tech has clocked time on that line. 
    * Completion date falls within the report date range
    

Efficiency calculation logic should remain identical to the existing report, only changing the source hours.

* If multiple technicians have clocked time on the same labor line:

    * Once the labor line is marked `Completed`, each technician’s contribution is calculated using their individual clocked hours on that line
    * `Completed Tech Time Hours` are allocated proportionally based on each technician’s share of total clocked hours
    * Each technician receives a proportional share of the Completed Tech Time Hours for that labor line
    

    _This calculation must follow the **existing behavior** used in the **Technician Efficiency (Invoiced)** report. No changes to the calculation logic are included in this scope._
