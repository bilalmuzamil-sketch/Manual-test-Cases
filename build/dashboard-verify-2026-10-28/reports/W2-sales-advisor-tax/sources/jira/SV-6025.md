# SV-6025 — FR – Add “Filter by Customer” Option to Sales Report
Status: Board Backlog · created 2026-03-05 · updated 2026-04-24 · parent None

**Customer Name:** Advantage Fleet LLC  
**Requested By:** Tyler Brooker

‌

### **Detailed Description of Feature Requested:**

Add the ability to **filter the Sales Report by Customer** within a selected date range.

Currently, the Sales Report does not provide an easy way to isolate sales data for a specific customer. Users must manually review or export data to determine total sales for one account.

The requested enhancement is to:

* Add a **“Customer” filter** to the Sales Report
* Allow users to select one or multiple customers
* Combine this with a selectable date range
* View total sales, labor, parts, and other breakdowns for that customer

---

### **Why It Matters / Impact:**

Shops often need to review revenue generated from specific fleet accounts or key customers.

This would:

* Improve reporting visibility
* Save time on manual calculations
* Help analyze customer value
* Support account reviews and sales strategy

---

### **Use Case / Example Scenario:**

A manager selects a 90-day date range and filters the Sales Report by a specific fleet customer to see total revenue generated during that period.
