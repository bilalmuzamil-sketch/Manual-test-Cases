# SV-2463 — Labor efficiency wrong on Sales report
Status: Done · created 2024-03-01 · updated 2024-03-20 · parent None

The labor efficiency is not calculating correctly on the Sales report. 

I suspect is is not removing declined lines from the calculation, like it is on the statistics tab. 

‌

It needs to match the statistics tab, which currently, it does not. 

‌

In Foothills production, work order S-848 on the sales report shows a labor efficiency of 18.11%

It appears that the root cause of the problem may be that the time sheets are not being moved to the new work order when the line gets moved to another work order. 

‌

**\*\*When a line gets moved to a new work order, the time sheet entries need to get moved along with it to the new work order.**
