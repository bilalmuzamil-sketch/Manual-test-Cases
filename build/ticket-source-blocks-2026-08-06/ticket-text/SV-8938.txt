# SV-8938 — Parts Velocity Location column sits sixth, after Vendor, instead of first before Type
# parent: SV-8643

1. What happens now
On the Parts Velocity report the Location column appears in the middle of the table, in sixth place, after Vendor. The written description asks for it to be the first column of all, before Type.
2. What should happen instead
Parts Velocity specification, version 5, requirement S7-R8: "When shown (S2-R12 / S3-R10), the per-row Location column renders as the leftmost column, before Type, using the suite's standard column treatment so its placement matches the same column on the other reports in the suite."
3. How to see it
Sign in as a user who can see more than one location and open Reports > Parts Velocity.

Leave the Location filter on All locations, so more than one location is in view.

Read the column headings from left to right.

Open the three-dot menu and choose Download (CSV), then read the heading row of the downloaded file.

Exact test data this was seen with: locations Staging Heavy Duty - 9919 and Staging Lethbridge - 4310, date range This Year, type Both, no search. The organisation is Staging Foothills Group Inc.
4. What was actually shown
On screen, left to right:
{noquote}
Type | Part # | Description | Category | Vendor | Location | Units Sold | Unit Cost | Sell Price | Revenue | Margin | Margin % | Demand | Last Sale | On Hand
{noquote}
The downloaded spreadsheet puts it in the same sixth place:
{noquote}
Type,"Part #",Description,Category,Vendor,Location,"Units Sold","Unit Cost","Sell Price",Revenue,Margin,"Margin %",Demand,"Last Sale","On Hand"
{noquote}
5. What was ruled out
It is not the column chooser. The Location column is not one of the twenty entries in the column chooser, so a user cannot have moved or re-enabled it - the report places it there itself.

The rest of the column behaviour is correct. The column only appears when more than one location is in view; each stocked row shows its own location's name; and a special-order row that covers several locations correctly shows the word Multiple.

It is not only the screen. Both downloads place it in the same wrong position, because they follow the screen.

6. How often
Every time, on every view looked at.
7. Where it was seen
Reports > Parts Velocity, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
