# SV-8949 — Technician Utilization downloads are not ordered by technician name A to Z
# parent: SV-8654

1. What happens now
The rows in a Technician Utilization download are in no recognisable order. The written description asks every download to be ordered by technician name from A to Z.
2. What should happen instead
Technician Utilization specification, version 6, requirement S7-R10a: "Rows in every download are ordered by Technician name A to Z (the default order). The on-screen column sort is applied client-side only and is not carried into the export."
3. How to see it
Open Reports > Technician Utilization and set the date range to This Year.
Open the three-dot menu and choose Summary (CSV), then Summary (PDF).
Read the technician names in order down each file.
Exact test data this was seen with: organisation Staging Foothills Group Inc; signed-in user Admin ShopView; active location Staging Heavy Duty - 9919; the other accessible location Staging Lethbridge - 4310; date range This Year (1 January 2026 to 6 August 2026), which returns 29 technicians.
4. What was actually shown
Both files begin: Alexander Cohen, Brittany Anderson, Colleen Guerrero, Wesley Mcclure, Jacob Chung, William Johns, Judy Garcia, Andrew Wade, Monica Miller, Frank Hendrix - and end with Admin ShopView, Taylor Kelley, Margaret Garcia, Veronica Miller, Christopher Cobb. That is neither alphabetical nor the order on screen.
The on-screen table at the moment of download was sorted correctly by Technician A to Z.
5. What was ruled out
It is not the on-screen sort leaking into the file. The screen was in its default A to Z order when the files were taken, and the files were still unordered; the request for the file carries no sort instruction at all.
It is not a spreadsheet-only problem - the PDF has exactly the same order.
It is not the order the server returns for the table. The table's own request returns the technicians alphabetically.
6. How often
Every time, in both file types.
7. Where it was seen
Reports > Technician Utilization, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
