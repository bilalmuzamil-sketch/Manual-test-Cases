# SV-8956 — Sales By Customer download file names leave out the date range
# parent: SV-8612

1. What happens now
A Sales By Customer download is always called the same thing whatever period it covers, so two files taken for different date ranges are indistinguishable once they are saved.
2. What should happen instead
Sales By Customer specification, version 15, requires the file name to carry the period: the Summary file is named sales-by-customer-summary-{range} and the Expanded file sales-by-customer-expanded-{range}, where {range} is the period that was chosen (this_week, last_week, this_month, last_month, this_year, last_year, this_quarter, last_quarter).
3. How to see it
Open Reports > Sales By Customer with the date range on This Month.
Open the three-dot menu, choose Download Summary (CSV), and note the file name.
Choose Download Expanded View (CSV) and note that one too.
Exact test data this was seen with: organisation Staging Foothills Group Inc; signed-in user Admin ShopView; active location Staging Heavy Duty - 9919; the other accessible location Staging Lethbridge - 4310; Product Type left at Parts & Service unless the step says otherwise.
4. What was actually shown
The two files were called sales-by-customer-summary.csv and sales-by-customer-expanded.csv - correct apart from the missing period. There is nothing in either name to say which range it covers.
The files themselves are right: each begins with a "Date Range: Aug 1, 2026 - Aug 6, 2026" line and a "Locations: All locations" line, so the information is in the file, just not in its name.
5. What was ruled out
It is not the browser shortening the name - the name comes from the download itself.
It is not a Summary-only or a spreadsheet-only problem; both spreadsheet options behave the same way.
It is not the range being ignored - the file contents cover exactly the chosen range.
6. How often
Every time.
7. Where it was seen
Reports > Sales By Customer, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
