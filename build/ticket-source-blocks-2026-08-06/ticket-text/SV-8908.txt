# SV-8908 — Work In Progress Asset filter leaves out a vehicle that shares a unit number
# parent: SV-8663

1. Description
On the Work In Progress report, the Asset filter does not offer every asset that is on the report. Where two different vehicles happen to share the same unit number, the filter lists only one of them — and it shows that one's vehicle identification number against the shared unit number. The other vehicle is simply not in the list, so typing its vehicle identification number brings up nothing at all.
The filter is meant to let you type either the unit number or the vehicle identification number. For these vehicles the second half of that promise does not work, and a service manager searching for a truck by the number on its windscreen concludes the truck has no open work, when in fact it has.
On today's test data six vehicles are affected across five shared unit numbers. The clearest one belongs to customer Euwood Paving, which has two different trucks both numbered 854.
Why it matters quietly rather than loudly: the filter looks like it is working. You type a unit number, you get a result, and nothing tells you that a second vehicle with that same number exists and has been left out.

4. Expected behaviour
Every asset that appears on the report should be offered in the Asset filter, and typing either identifier should find it. The Work In Progress specification, version 9, requires (S7-R4):
The toolbar has an Asset filter, a searchable type-ahead multi-select listing the assets present across all open jobs in the current scope. Each option shows the unit number and the vehicle identification number, and the user's typed text matches against EITHER the unit number OR the vehicle identification number.

Two vehicles that share a unit number are still two assets present on the report, so both should be listed and both identification numbers should match.
For non-vehicle assets, note that this field holds the unit's serial number rather than a true vehicle identification number — that is expected and is not what this ticket is about.
5. Current behaviour
The Asset filter offers one entry per unit number. Where two vehicles share a unit number only one is listed, the listed entry shows only that one's identification number, and the other vehicle's identification number matches nothing typed into the filter. Six vehicles are affected on the current test data.
