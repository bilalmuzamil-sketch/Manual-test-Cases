# SV-8936 — Parts Velocity download success message is a general one and does not name the report or the file type
# parent: SV-8646

1. What happens now
When a download from the Parts Velocity report finishes, the message that pops up reads "Success - Data exported successfully." That is a general message that could belong to any screen in the application; it does not name the report or say which of the two files was produced.
2. What should happen instead
The written description sets the exact wording, and it names both the report and the file type.
Parts Velocity specification, version 5, requirement S6-R9: "On a successful download, a success toast reads \"Velocity report exported (CSV)\" or \"Velocity report exported (PDF)\"."
3. How to see it
Sign in as a user who can see reports and open Reports > Parts Velocity.

In the report's own search box type BRAKECLEAN, so the view is small enough to download.

Open the three-dot menu at the top of the report and choose Download (CSV). Watch the message that appears.

Do it again and choose Download (PDF). Watch the message that appears.

Exact test data this was seen with: part number BRAKECLEAN, locations Staging Heavy Duty - 9919 and Staging Lethbridge - 4310, date range This Year, type Both.
4. What was actually shown
Both downloads showed the same message:
{noquote}
Success
Data exported successfully.
{noquote}
The expected messages were Velocity report exported (CSV) and Velocity report exported (PDF).
5. What was ruled out
It is not a missing message. A message does appear, and it appears for both file types - it is the wording that is wrong.

It is not the failure message. The failure message is correct: when a download is refused, the message the server sends is passed through and shown to the user word for word, which is what the written description asks for.

It is not one file type. The spreadsheet and the PDF both show the same general wording.

It is not a timing problem. The message was captured as it appeared, on four separate downloads.

6. How often
Every time. Four downloads out of four.
7. Where it was seen
Reports > Parts Velocity, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
