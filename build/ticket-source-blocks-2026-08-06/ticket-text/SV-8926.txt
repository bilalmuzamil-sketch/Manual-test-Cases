# SV-8926 — Inventory Value totals row is labelled Totals on screen where the written description asks for Total
# parent: SV-8671

1. What happens now
At the bottom of the Inventory Value report there is a summary row that adds up the whole shelf. Its first cell, in the Part # column, reads Totals.
2. What should happen instead
The written description asks for the singular word. Inventory Value requirement S4-R1: "A totals row is shown at the bottom of the report, with the literal label "Total" in the Part # column's cell."
The plural Totals is the label the downloaded files are meant to use - requirement S10 says the downloads "include a totals row matching the on-screen totals, labeled "Totals"". So the two are meant to differ, and the screen is currently using the download's word.
3. How to see it
Sign in and open Reports > Inventory Value.

Leave the date range on This Month and both locations selected.

Scroll to the bottom of the table and read the first cell of the last row.

Exact test data this was seen with: no seeding needed - the organisation's own stock. Locations Staging Heavy Duty - 9919 and Staging Lethbridge - 4310, date range This Month, 5,657 rows in scope.
4. What was actually seen
The last row reads:
{noquote}
Totals | | | | | 195,247.93 | | | $855,066.82 | 46.7% | $1,832,142.09 | $977,075.27
{noquote}
Everything else about the row is correct: the Description, Category and Vendor cells are blank, the Unit Cost and Unit Sell cells are blank, the Total Cost cell is bold and pinned to the right, and the row stays visible at the bottom while the rows scroll. Only the word is wrong.
5. What was ruled out
It is not a filter effect. The label reads Totals with no filters, with a category chosen, and with a part search applied.

It is not the sort. Sorting by any column leaves the row at the bottom, still reading Totals.

It is not the download. The download is separately required to say Totals and does. This is the on-screen row.

6. How often
Every time.
7. Where it was seen
Reports > Inventory Value, on the QA branch, build v3.5-16cf83f, on 6 August 2026.
