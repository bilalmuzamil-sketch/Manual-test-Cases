Story 16**When the completion wizard opensAs a user, I want the wizard to appear only when something is genuinely missing, so that finishing a tidy work order is not interrupted. | **Design**[Shopview App](https://claude.ai/design/p/0c2ed95b-ce68-4b7f-a86d-0e3de1af5a28?file=Shopview+App.dc.html)**Prerequisite** - The user has taken an action that completes one or more lines **Requirements** - The wizard opens from these entry points, and from nothing else     - Complete on a line, covering that line     - Complete lines in the bulk bar, covering the selection     - Complete all lines, covering every open line     - Create invoice, covering every open line     - Clock out and complete, covering the line being clocked out of - **Mark as reviewed never opens it**, because it only becomes available once every line is complete and the wizard exists to collect what is outstanding before a line closes - It opens only when something required is both outstanding and collectable. If nothing is, the action completes immediately and no wizard appears - What counts as collectable is a missing tech story, a missing mileage or engine hours reading, an unpicked inventory part, **an unresolved core**, or an unreceived part - The run records which lines it covers and whether it is on its way to an invoice. Both are fixed when the run opens and are never inferred later **Negative cases** - Nothing else opens the wizard. No timer, no background job and no side effect of another action - A step the user's role cannot perform is not shown. Where that step is the only outstanding work, the action fails with the reason instead of opening an empty wizard |
