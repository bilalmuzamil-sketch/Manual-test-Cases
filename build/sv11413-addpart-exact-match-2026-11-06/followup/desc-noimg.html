Found while testing SV-11413

Summary

In a work order's Add Part box, a word that matches a lot of parts (for example brake) shows only one page of results. Parts past that page can't be found with that word at all; you have to type more of the name, and nothing on the screen says that more parts match. This was already the case before SV-11413.

Steps to reproduce

  1. Open the QA branch to reproduce the issue: https://sv11413.qa.shopview.com. Sign in. The location at the top right is Staging Heavy Duty - 9919.

  2. Open work order S11413-17580.

  3. On the Lines tab, under line 1 ("Service - Electric brake trailer CVIP"), next to Parts, click + Add Part.

  4. Click the Part number box and type brake.

  5. Scroll the list that opens all the way to the end. DOT 3 BRAKE FLUID (part number PBFPS301C) is not in it (pictures 1 and 2).

  6. Clear the box and type brake fluid. DOT 3 BRAKE FLUID now appears (picture 3), so the part is there.

Fastest way to see it: open S11413-17580, click + Add Part under line 1, type brake and scroll to the end of the list.

The same happens on staging, which does not have the SV-11413 fix: work order S2-38096 at Staging Heavy Duty - 9919, same search, same part missing (picture 1).

What should happen

This needs a decision on how a broad search should behave (for example: every matching part can be reached, or the list says more parts match and asks you to narrow the search). Dusan proposed this ticket in his comment on SV-11413:

"The Add Part list shows one page of results. When a word matches more parts than fit, some are always left out."

"Each tag on a part takes up its own row in that page. So parts with several tags mean fewer distinct parts are shown, sometimes well under the page size."

"I suggest we handle both, the page limit on broad searches and the tag rows, together in a separate ticket."

Related: SV-12286 (making search behave the same across the app).
